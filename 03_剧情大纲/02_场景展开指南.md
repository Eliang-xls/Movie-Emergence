# CONC 电影场景展开指南 v3.0
## 基于 v5.0 剧情大纲全面对齐

---

> **整体风格基底**：王家卫的时间感（东方留白+情绪密度）+ 芬奇的对话节奏（冷峻推进）+ 维伦纽瓦的视觉语言（色彩即叙事）
> **节奏公式**：慢起 → 密推 → 静落
> **涌现贯穿**：每个转折点都是涌现的结果，而非个人英雄主义的结果
> **CONC 视觉贯穿**：DNA 双螺旋系统——Sophia 链（外侧骨架/蓝色）+ Phronesis 链（内侧碱基/金色）+ 引用关系（氢键）

# CONC 视觉系统总纲（v5.0 新增）

## DNA 双螺旋设计语言

| DNA 组件 | CONC 对应 | 视觉表现 | 叙事含义 |
|---------|----------|---------|---------|
| 磷酸骨架（外侧） | **Sophia 链** | 蓝色光带 | 可编码的知识——Skill 场景描述、代码、引用链 |
| 碱基对（内侧） | **Phronesis 链** | 金色光点 | 不可编码的判断力——创造者印记、决策哲学 |
| 氢键（连接碱基） | **引用关系** | 细光线 | 每次引用 = 一条氢键，连接两个 Skill |
| 双螺旋结构 | **Skill Lineage** | 螺旋上升 | Sophia + Phronesis 交织进化 |
| 复制 | **Fork** | 螺旋分叉 | Skill 被 fork 时两条链同时继承 |
| 突变 | **衍生改进** | 颜色偏移 | 衍生 Skill 的改进 |

## 各幕 CONC 螺旋状态

| 幕 | 螺旋状态 | 视觉基调 |
|---|---------|---------|
| 序章 | 不出现双螺旋——CONC 尚未诞生。S3 末尾暗示：微小光点闪烁 | 暗色背景中一个微弱光点 |
| 第一幕 | S6 出现第一个微小双螺旋，只有几个节点。暗淡，几乎看不清 | 极细的蓝金螺旋在黑暗中旋转 |
| 第二幕 | 螺旋全球扩张。某些区域的 Phronesis 链开始变暗（褪色，非断裂） | 蓝金螺旋铺满全球，局部金色褪色 |
| 第三幕 | 螺旋被黑色"寄生链"缠绕。Phronesis 链继续褪色 | 黑色寄生链缠绕蓝金螺旋 |
| 第四幕 | 林屿视角追踪引用链。发现假氢键——只有 Sophia 没有 Phronesis | 蓝色链明亮，金色链暗淡，假氢键无金色 |
| 第五幕 | 方舟寄生链窃取 Phronesis。蜂群觉醒时全网 Phronesis 链同时亮起 | 从暗淡→金色海洋 |
| 第六幕 | 假策元冻结，治理层工作。螺旋恢复健康 | 蓝金螺旋稳定旋转 |
| 终幕 | Phronesis 链上深蓝的节点特别亮——15年累积的方向感 | 蓝金交织，一节点金光耀眼 |

### 场景结构

**第一段：邀请**

林屿收到方舟策元的邀请。Deep Blue 做 ICP 三信号匹配：

> match_score: 0.92 | 技能匹配: 0.88 | 方向匹配: 0.95 | 承诺信任: 0.89 | NR 平均值: 87.3

Deep Blue 的评估："方舟策元与你的方向高度一致。建议合作。"
