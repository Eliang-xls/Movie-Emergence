## 文件说明

### 01_故事框架（6 个文件）
CONC 理论的核心框架——世界观基础。电影中的所有设定都基于这些理论。

### 02_人物志（1 个文件）
**最终版**。包含 7 个核心人物的完整设定：性格、背景、关系、弧线。基于真实 AI 人物的艺术化重塑。

### 03_剧情大纲（2 个文件）
- **完整剧情大纲**：40 场戏，从 2025 到 2048 年的完整故事线
- **林屿命运交织网**：主角与所有人物的联系分析

### 04_预告片素材（2 个文件）
- **全场景冲突剧情库**：所有可能的场景、冲突、剧情线
- **预告片技法参考库**：经典预告片的运镜/剪辑/叙事拆解

### 05_参考资料（13 个文件）
真实 AI 人物和事件的原始素材——创作参考，不直接用于电影。

## 使用建议

1. **编写预告片脚本时**：先读 02_人物志 + 03_剧情大纲，再参考 04_预告片素材
2. **设计镜头时**：参考 04_预告片素材/02_预告片技法参考库
3. **确保 CONC 一致性**：随时查阅 01_故事框架中的对应理论
4. **丰富人物细节**：参考 05_参考资料中的真实人物素材
