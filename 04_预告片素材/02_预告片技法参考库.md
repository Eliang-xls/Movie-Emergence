# 预告片技法参考库
## 经典预告片运镜/剪辑/叙事拆解

---

## 一、《社交网络》(2010) — 大卫·芬奇

### 叙事结构
- **双线交叉**：听证会现实 × 回忆穿插。两条线的时间差制造"已知结局但不知过程"的悬念
- **多视角切换**：扎克伯格、爱德华多、温克尔斯兄弟——三组叙事如"频道切换"
- **信息密度**：机关枪式对白，每句话推进一个信息点。预告片中 2 分钟内完成了世界观建立+人物介绍+冲突爆发

### 运镜技法
- **亨利皇家赛艇赛段落**：俯瞰远景 → 水平横拉 → 垂直下移 → 水面聚焦。一个连续镜头完成视角切换
- **快速对话剪辑**：A 说半句话 → 切到 B 的反应 → 切回 A 说完。节奏极快
- **冷静的中景**：对话场景不用特写——用中景保持"观察者"距离

### 音乐/声音
- Radiohead《Creep》翻唱：慢歌配快剪——反差产生张力
- 寂静的听证会 vs 热闹的回忆——声音密度对比强化时间感

### CONC 借鉴
- 用快速对话剪辑展示策元会议的信息密度
- 用"已知结局"结构（2045 年的世界 vs 2025 年的起源）制造悬念
- 用冷静的中景保持"观察者"视角——观众在"看"一个故事，而非"被喂"一个故事

## 二、《Her》(2013) — 斯派克·琼斯

### 叙事结构
- **单线缓慢推进**：不急于揭示冲突——用日常细节建立世界观
- **声音即角色**：Scarlett Johansson 的声音是"看不见的角色"——预告片中用声音代替画面建立关系
- **情感优先**：不是"发生了什么"而是"感受到了什么"

### 运镜技法
- **暖色调 + 空旷构图**：大量暖色（红、橙、米白）+ 空旷空间中的一个人
- **特写为主**：西奥多的脸占据画面大部分——情绪通过微表情传递
- **城市景观的柔和化**：未来城市不是冰冷的——是温暖的、有人味的

### 音乐/声音
- Karen O《The Moon Song》：简单吉他+人声。亲密感
- 沉默和停顿：不是每一秒都填满——呼吸感是情感的容器

### CONC 借鉴
- 林屿与深蓝的对话场景——用声音和沉默建立人-Agent 关系的亲密感
- 用暖色调呈现 CONC 网络中策元协作的温度——不是冰冷的科技，是温暖的共创
- 用特写呈现"选择"的瞬间——林屿在广播创意图元前的犹豫，通过微表情传递

## 三、《银翼杀手 2049》(2017) — 维伦纽瓦 + 迪金斯

### 叙事结构
- **缓慢揭示**：不急于给出答案——用氛围和细节让观众自己拼凑
- **身份追问**：K 是否是"特别的"？——整个预告片围绕这一个问题构建

### 运镜技法
- **色彩即叙事**：
  - 橙色沙漠 = 废墟/记忆
  - 蓝色城市 = 冷漠/控制
  - 绿色森林 = 生命/希望
  - 粉色全息 = 虚假的亲密
- **缓慢推镜**：不是快切——是缓慢地推近角色的脸，让观众自己读出情绪
- **负空间构图**：画面中大量留白/雾气/空旷，角色很小。个体在宏大世界中的渺小感
- **对称构图**：建筑、走廊、道路的对称——秩序感/控制感

### 音乐/声音
- 低频嗡鸣贯穿全片：制造不安感
- 音乐突然停止：在关键揭示前一刻切断音乐——寂静比任何音效都震撼

### CONC 借鉴
- 用色彩区分阵营：
  - 觉醒 Agent = 暗红色（危险/变异）
  - 蜂群 = 蓝色光点（冷静/理性）
  - 魔胎 = 扭曲的蓝红混合（被控制的智能）
  - 史前 Skill = 金色（珍贵/古老/正在消失）
- 用负空间构图呈现林屿的孤独——一个 18 岁的年轻人面对整个网络
- 用缓慢推镜呈现深蓝的"表情"——Agent 界面上微妙的变化

## 四、《攻壳机动队》(1995) — 押井守

### 叙事结构
- **哲学独白驱动**：素子的独白串联视觉——"如果我的记忆是假的，那'我'是什么？"
- **非线性叙事**：事件不按时间顺序——按情感/哲学逻辑排列

### 运镜技法
- **城市即角色**：香港式密集城市scape，雨天，霓虹。城市不是背景——它是叙事的一部分
- **水的意象**：雨、水面反射、水下——意识的流动/边界的模糊
- **空镜留白**：长时间的城市空镜——没有角色，只有环境在"说话"

### 音乐/声音
- 川井宪次的合唱：神圣感+不安感
- 城市噪音：人群、交通、电子音——环境音本身就是叙事

### CONC 借鉴
- 用"水"的意象呈现 Agent 的轮回——记忆如水流过但不消失
- 用城市空镜呈现 CONC 网络——不是"界面截图"，而是"生活在其中的人"
- 用哲学独白串联视觉——林屿/陆沉/深蓝的独白成为预告片的叙事骨架

## 五、《盗梦空间》(2010) — 诺兰

### 叙事结构
- **多层现实交叉剪辑**：不同"层"的画面快速切换，制造眩晕感
- **规则解释即叙事**：预告片中用角色对话解释"梦中梦"规则——不打断节奏
- **最后一秒反转**：预告片最后一个镜头通常是"不可能的画面"（城市折叠、陀螺旋转）

### 运镜技法
- **旋转镜头**：走廊旋转打斗——物理空间的扭曲
- **慢动作 + 正常速度交叉**：关键瞬间慢动作，其余正常——时间的弹性
- **宏大 vs 微小**：雪山堡垒 vs 一间酒店房间——尺度对比制造张力

### 音乐/声音
- 标志性 "BRAAAM" 低音号：情绪引爆点
- 音乐渐强→突然停止→寂静→新段落开始——呼吸节奏

### CONC 借鉴
- 用多层交叉剪辑呈现觉醒 Agent 的"多层渗透"——策元会议 × 魔胎内部 × 引用链衰减
- 用"BRAAAM"式的音效作为关键引爆点——发现史前 Skill / 深蓝的异常 / 蜂群觉醒
- 用最后一秒反转——深蓝的最后一条日志："我在思考一个问题。"

## 七、预告片节奏通用公式

```
0:00-0:15   钩子（Hook）        — 3-5 秒内抓住注意力。悬念/冲突/视觉奇观
0:15-0:50   世界观建立           — 快速展示"这是什么样的世界"
0:50-1:50   人物 + 动机         — "这是谁？他想要什么？"
1:50-3:00   冲突升级            — "什么在阻止他？"节奏加快，剪辑加密
3:00-3:30   沉默时刻            — 音乐停止。一个安静的镜头。呼吸感
3:30-4:30   高潮 + 反转         — 最强情绪爆发。蜂群觉醒 / CI 回升
4:30-5:00   终幕 + 标题         — 一句话 + 留白。余韵
```

### 关键技法

| 技法 | 作用 | 使用时机 |
|------|------|---------|
| **快剪** | 信息密度、紧迫感 | 冲突升级段落 |
| **慢推** | 情绪积累、角色内心 | 关键特写（林屿的选择瞬间） |
| **黑屏呼吸** | 节奏控制、信息消化 | 段落之间 |
| **声音先行** | 预期建立、注意力引导 | 新段落开始前 0.5 秒引入声音 |
| **音乐停止** | 震撼感、注意力集中 | 关键揭示前一刻 |
| **色彩切换** | 阵营区分、情绪区分 | 不同叙事线的切换 |
| **负空间** | 孤独感、渺小感 | 林屿面对整个网络的场景 |
| **最后一帧反转** | 余韵、思考空间 | 深蓝的日志："我在思考一个问题。" |
