## 二、区块链遗产双线叙事（最新版）

> 来源：`06_小说/区块链扩展故事线/创作方案_区块链故事线总稿.md`、`K与真实区块链历史对齐分析.md`
> 说明：本版为最新设计，S和K的人物设定、前传细节、叶澄考古线均已更新

### 核心设计理念

**区块链是2008年的半成品。CONC是2040年代的完成品。**

区块链与CONC共享同一组底层问题——不信任的人如何协作、分布式记录如何防篡改、共识如何在没有中心权威的情况下达成——但给出了不同的答案。区块链解决了"交易域"（可验证的客观行为），但没有解决"判断域"（需要人的主观判断的行为）。CONC同时解决了两个域。

S在2008年说："等一个时代来组装它。"CONC是那个时代组装出来的。

### 前传人物设定

**K（中本聪原型）**

| 属性 | 设定 |
|------|------|
| 身份 | 工程师/产品人。主导发布了比特币白皮书。署名S |
| 性格 | 务实、行动力强、不耐烦于理论、"先做出来再说" |
| 与S的关系 | 互补型——K把S的理想变成了产品(比特币)，但只做了一半 |
| 命运 | 发布比特币→见证区块链发展→2010年第一次消失→沉默十年→2021年第二次消失→2046年给S发邮件"水到了" |
| 真实历史吻合 | 白皮书发布、创世区块、论坛活跃、2010年最后帖子、2011年最后邮件——与真实中本聪时间线完全一致 |
| 写作风格 | 英式拼写(favour/colour)、简洁直接、偶尔blunt、从不修改旧帖子、从不以第三人称指代自己 |
| 重要约束 | K永远不会以"中本聪"自称或称自己的作品，从不解释为什么用S的名字 |

### CONC与区块链底层技术机制对比

| 维度 | 区块链 | CONC |
|------|--------|------|
| 创始问题 | 如何在不信任的人之间转移价值？ | 如何在不信任的人之间协作创造？ |
| 核心单位 | 交易(Transaction) | 任务令(Task Warrant)+Skill |
| 记录对象 | 转账金额、合约状态 | 五维信号(VT/NR/CCR/JC/CP) |
| 信任模型 | "不需要信任任何人，只需要信任代码" | "信任是必要的，只是需要被分散" |
| 验证方式 | 密码学(PoW/PoS) | 密码学+人的判断(AUTO/PEER/MARKET三层) |
| 时间性质 | 冻结的快照(不可逆) | 流动的河流(带衰减) |
| 人的位置 | 在环外(交易确认) | 在环内(Phronesis决断层) |
| 组织形态 | 无组织或DAO | 策元(3-8人创意共识结晶) |
| 治理模型 | "代码即法律"(后被证伪) | 公理零：治理永续，代码+人的判断 |
| 价值单位 | 单一代币(BTC/ETH) | 多维信号 |

### 核心叙事原则

1. **"挖掘"代替"闪回"** — S/K的历史通过文档碎片(论坛帖子、邮件、代码提交记录、笔记碎片)以原始格式嵌入叙事，读者和叶澄同时发现
2. **"读者比角色知道得多"** — 前传让读者知道了S和K，正文中的季深不知道——读者产生"他不知道他正在重复S的命运"的感受
3. **"技术伴随动作"** — 每一个技术术语都伴随人物的动作或选择出场
4. **"分叉是核心隐喻"** — S和K的分叉、区块链和CONC的分叉、季深和江远的分叉——同一模式在不同层面重复
5. **K与真实历史对齐** — K的第一次消失(2010-2011)与真实中本聪完全吻合；第二次消失(2021)是小说虚构层。K在2010年后不能以可追溯到"中本聪"的方式公开出现（论坛帖子→私人笔记，会议发言→匿名场合）

### 最终一句话

> **区块链是2008年种下的一颗种子。种子没有直接长成CONC——它被埋在了区块链的历史里。四十年后，当AI、Agent、策元网络的条件成熟时，同一个问题重新浮现，被一批完全不同的人以完全不同的方式重新回答了。S在2008年说"等一个时代来组装它"。K在2046年回了三个字："水到了。"**
