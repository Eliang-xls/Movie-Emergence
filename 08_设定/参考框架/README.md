## 使用建议

### 写小说正文时
- 查时间线 → `01_世界观时间线`（§二 四线编年史、§三 概念引入节奏）
- 查技术细节 → `02_技术设定`（§三 深蓝弧线、§四 Skill八层叙事规范）
- 查描写规范 → `03_叙事手法与修辞设定`（§三 感官签名母题表、§五 术语文学化）
- 查视觉描写 → `04_视觉设计`（§二 智契晶五态色彩、§三 Skill链视觉差异）

### 做小说修改时
- 查优先级 → `06_修改方案与执行计划`（§二 执行批次依赖关系）
- 查清洗规范 → `06_修改方案与执行计划`（§四 去现实化清洗规范）
- 查现实映射 → `05_产业参考与现实映射`（§一 穹顶现实产业映射）

### 做全局评估时
- 查问题诊断 → `06_修改方案与执行计划`（§一 五大结构性问题）
- 查技术数据 → `07_调研资料摘要`（§一 技术文献关键数据）
- 查伦理素材 → `07_调研资料摘要`（§二 技术伦理）

## 文件管理约定

- 这些参考框架文件是**汇总索引**，不是原始设定的替代
- 原始设定仍在 `08_设定/` 的各子目录中，以这些文件为准
- 每次修改后，**更新原有目录中的对应文件**，而非更新本参考框架
- 本参考框架意在提供"快速查阅"的便利，详细论证请回看原始文件
