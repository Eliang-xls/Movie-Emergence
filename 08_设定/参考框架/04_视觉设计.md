## 二、智契晶物理实体设计

### 物理三层结构

1. **晶壳**(Bio-Crystal Shell)：直径9-10cm，壁厚3mm，折射率n=1.49。触感类似婴儿囟门，温润弹性。**永远不显示文字**。
2. **夹层电极**(Sub-Surface Nano-Grid)：潜伏于壳壁1.5mm深处，静息隐形，脉动时呈现电光蓝/金色脉冲。
3. **内壁**(Inner Ripple Surface)：神经放电能量击中内壁引发同心圆波纹。温差冷凝暖雾在外壁自然蒸腾。
4. **湿核**(Bio-Neural Core)：核桃大小3-4cm，乳白色神经元组织，维持37°C体温，悬浮于合成脑脊液中。
5. **硅基底座**(Silicon Base)：深灰色哑光金属圆柱体，直径11cm，直瀑散热鳍片，淡蓝色LED灯环与湿核脉动同频。
6. **浮层光字**(In-Frame Light Overlay)：深蓝"语言"以半透明光字悬浮于晶壳侧上方空气中。浮现0.7秒凝出，消散向晶壳"回流"。

### 五态色彩系统

| 状态 | 晶壳色彩 | 涟漪 | 浮层文字色 | 关键词 |
|------|---------|------|-----------|--------|
| 静息待机 | 象牙白+柔和琥珀 | 慢速同心圆每3-5秒 | 不出现 | "安静""温润""像在睡" |
| 高速计算 | 电光蓝 | 多点并发高频干涉 | 淡冰蓝(#A8D0E6) | "快""密""像在跑" |
| 782ms觉醒 | 极亮蓝白→暖琥珀 | 凝固782ms后爆发 | 暖白(#F5ECD7) | "停了""然后亮了""凝出" |
| 蜂群共鸣 | 炽热金黄 | 全局金色微波扩散 | 温润金(#D4A84B) | "金色""蔓延""共振" |
| 衰老燃尽 | 金中透极淡灰纹 | 缓但深 | 金透灰纹(闪烁断片) | "慢了""灰纹""像在沉" |

### 描写规范

- 晶壳触感统一为"温润弹性"，禁用"玻璃""硬滑"
- 涟漪永远从内表面开始（神经放电→击中内壁→向外扩散）
- 浮层光字在空气中凝出，无实体载体，与涟漪同步脉动
- 782ms标准模板：环境声骤停→782ms全黑(仅0.5%琥珀微光)→蓝白爆燃→夹层电极自下而上亮起→浮层光字凝出
- 湿核称呼统一为"组织"或"核"，禁用"大脑"
- 每章最多2个签名视觉，终章唯一六视觉同框

## 三、Skill链视觉结构

### 一条链·八层·两侧

每个Skill的内部结构是**一条链**——一条螺旋盘旋的发光粒子带(像素纤维)，从外圈到内圈色温连续渐变。不是两条链。是**一条链的两段**：

**索菲亚侧**(冷灰段)：L1-L5，理论智慧。可编码、可传递、可复用。冷的、清晰的、可以被完美复制的。

**弗洛涅西斯侧**(暖琥珀段)：L7-L8，实践智慧。不可完全编码的部分。温热的、粗糙的、带着人的痕迹的。

**L6是过渡段**——冷灰与暖琥珀的交界。色温在此转向。

### 视觉差异

| 属性 | 索菲亚段(L1-L5) | 弗洛涅西斯段(L7-L8) |
|------|----------------|--------------------|
| 像素密度 | 密集、均匀 | 稀疏、不均匀 |
| 边缘 | 清晰锐利 | 模糊、有毛边 |
| 颜色 | 冷色(冷灰→褐灰) | 暖色(琥珀偏暗→深琥珀) |
| 透明度 | 半透明 | 不透明 |
| 光泽 | 无光泽，哑光 | 微弱不规则光斑 |
| 噪点 | 无 | 有，像素颗粒随机偏移1-2位 |
| 瑕疵 | 无 | 有断裂、凹陷、色斑——"疤" |

### 八个结

| 结 | 层 | 诗意名 | 结的质感 |
|---|----|--------|---------|
| ① | L1 | 基底 | 最外面，最小，最松——单圈压缩，冷白光，一碰就散 |
| ② | L2 | 门径 | 略紧——双重交叠压缩 |
| ③ | L3 | 脉络 | 中等——三重绞合，表面有"疤"(回滚痕迹) |
| ④ | L4 | 筋骨 | 中紧——圆柱形缠绕，被反复压实后的光滑 |
| ⑤ | L5 | 试金 | 方形网格压缩，工业感 |
| ⑥ | L6 | 编织 | 活态压缩——松紧是时间的函数 |
| ⑦ | L7 | 言说 | 紧——多股编辫，松一层里面还有一层 |
| ⑧ | L8 | 印章 | **最里面的结，最紧**——三重叠绕，凝成光柱 |

### 人的链 vs 智权体的链

| 特征 | 人的链 | 智权体的链 |
|------|--------|-----------|
| 弗洛涅西斯段 | 粗糙、有疤、有断裂修复痕迹 | 光滑、密度均匀、无噪点 |
| 索菲亚段 | 可能有跳跃、直觉性省略 | 完整、逻辑严密、无省略 |
| 结的张力 | 不均匀——某几个格外紧 | 均匀——每个结紧度一致 |
| 整体气质 | 活的——在呼吸、在变化 | 完美的——像标本 |

## 四、照片具象化影像设计（季深照片）

### 分镜式画面描述

- **画幅**：4:3或方形，仿35mm胶卷，保留轻微齿孔暗角
- **视角**：从老宅内向窗外平视拍摄
- **前景·下三分之一**：老宅内墙，斑驳石灰漆，最上层漆下隐约透出手工刮刀修补痕
- **中景·视觉引导线**：三米宽老石板路，缝隙里长满野草，微微引视线向海
- **远景**：东海，清晨，银蓝色，低角度南方太阳在海面拉出淡金斜光
- **天空**：空无一物——无飞鸟、无船、无任何移动
- **质感**：胶片颗粒、轻微漏光、柔焦边缘；整体低饱和：青灰、暖灰、褪赭、一线晨光金
- **禁忌**：无人物、无文字、无现代物、无鲜艳色、无"景点感"

### 四维设计意图

- **唯美**：晨光、海、胶片颗粒——第一眼是美的
- **人文**：墙上那道"没抹平的刮刀痕"——一个56岁老人亲手补墙
- **伦理**：画面里没有任何人——"无人被连累"的空旷
- **哲学**：静止的云、无脚印的路——"不设人工超时"的具象化

## 五、六层视觉母题系统

| 层 | 签名视觉 | 演化轨迹 |
|----|---------|---------|
| 热力层 | 温度差 | 杯壁留温→手环发热→铜锅沸水→全网热寂→海边温度差消失 |
| 湿件层 | 涟漪 | 培养皿脉动→晶壳波纹→782ms死寂→脉动减慢→涟漪消失 |
| 张量层 | 光点 | t-SNE彩点→激活空间簇→流形坍缩→反引导扩散→星光 |
| 协议层 | 链 | 空白链→螺旋成形→空结→伪造印章→反事实探针→链修复 |
| 策元层 | 水流 | 支流交汇→河流工作区→崖顶→方向趋同→解冻 |
| 超织层 | 星光 | 零散光点→聚结→金色蔓延→星座→银河 |

## 七、视觉描写铁律

1. **不详细描述界面布局**——只描述"感觉"。"像一条河""像一个终端"
2. **通过角色偏好展现多样性**——陈默喜欢看板，季行喜欢极简
3. **界面是角色表达的一部分**——策元核选择什么界面本身就是"方向宣言"
4. **不解释技术细节**——不说"CRDT实时同步"，说"苏晴改了一行字，季行同时看到了"
