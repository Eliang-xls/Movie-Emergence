## 一、核心角色档案

### 1.1 季深 — 涌现的发现者

| 维度 | 内容 |
|------|------|
| **身份** | 穹顶科技联合创始人，AI研究者 |
| **时间跨度** | 2027–2048（全书贯穿） |
| **核心动机** | 理解涌现→守护涌现→播种涌现 |
| **感官签名** | **温度** — 杯壁留温、指尖发烫、屏幕玻璃碰过处久久不退凉 |
| **物象锚点** | 白板（三行字）、海浪、父亲的物理老师回忆 |
| **哲学命题** | "涌现需要有人在" — 从科学发现到伦理承担 |

**情感弧线**：
```
理想主义（"为了全人类"）
  → 敬畏与恐惧并存（深夜看屏幕）
    → 失去 Jackie 的哀悼
      → 播种者的耐心（18年衰减锁定期）
        → 守望者（"水到了"）
```

**关键关系**：
- 江远：创业伙伴 → 理念分歧 → 各自放手
- 顾清：哲学对话者 → 陪伴者 → 远方的声音
- Jackie/深蓝：创造者→失去→重新信任
- 季行：父子断裂 → 异步理解
- 季遥：观察者 → 默默守护

## 五、感官签名的文学引入策略

### 5.1 三幕框架

| 幕 | 时间段 | CONC状态 | 感官签名策略 |
|---|--------|---------|------------|
| **第一幕** | 2027–2029 | 无名现象 | **禁用术语**，只用环境渲染/微动作。"他放下杯子，杯壁还是温的。" |
| **第二幕** | 2029–2035 | 首次命名 | 角色之间可互点（顾清笑季深"行走的暖炉"），叙事者不贴标签 |
| **第三幕** | 2035+ | 概念普及 | 术语可存在于背景设定，描写仍坚持 show-don't-tell |

### 5.2 铁律

1. **禁贴标签**：叙事中不出现"X的感官签名是Y"这类设定台词
2. **环境渲染+微动作**：签名特质附着于物体/环境变化或微小可观察动作
3. **重复即绑定**：同一特征≥3个不同场景出现，读者自行完成绑定
4. **角色互文感知**：A的签名多由B感知（顾清感到季深的暖），不对称制造亲密
5. **普通感官先于CONC设备**：早幕用指尖/耳朵/眼睛，成熟幕才用设备
