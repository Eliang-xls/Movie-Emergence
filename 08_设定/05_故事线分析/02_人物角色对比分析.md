## 一、核心角色档案

### 1.1 季深 — 涌现的发现者

| 维度 | 内容 |
|------|------|
| **身份** | 穹顶科技联合创始人，AI研究者 |
| **时间跨度** | 2027–2048（全书贯穿） |
| **核心动机** | 理解涌现→守护涌现→播种涌现 |
| **感官签名** | **温度** — 杯壁留温、指尖发烫、屏幕玻璃碰过处久久不退凉 |
| **新增感官签名** | **涟漪/手指敲击** — 无意识地用手指敲膝盖/裤缝/键盘/礁石，"一下，一下"，从2027年延续到2048年 |
| **物象锚点** | 白板（三行字）、海浪、父亲的物理老师回忆、**顾清的纸条**、**石头** |
| **哲学命题** | "涌现需要有人在" — 从科学发现到伦理承担 |

**情感弧线**：
```
理想主义（"为了全人类"）
  → 敬畏与恐惧并存（深夜看屏幕）
    → 失去 Jackie 的哀悼
      → 播种者的耐心（18年衰减锁定期）
        → 守望者（"水到了"）
          → 涟漪的传递者（手指敲击→石头→季遥）
```

**涟漪母题在季深线中的分布**：

| 时间 | 场景 | 涟漪形态 |
|------|------|---------|
| 2027 | 公寓独处 | 想起父亲听歌时手指敲膝盖，自己无意识敲了一下 |
| 2029 | Jackie告别 | 手指在键盘上停住，"轻轻敲了一下。一下。像水滴落在湖面上" |
| 2029 | 海边（Jackie死后） | "黑暗里他看不到涟漪。但他能感觉到——沙子在脚趾间轻轻滑动" |
| 2029 | 海边与顾清 | "涌是力量。退是涟漪。你得先退，才能扩散" |
| 2039 | 机场送顾清 | "手指在裤缝上敲了一下。一下。他没有注意到" |
| 2045 | 海边独坐 | "波纹把阳光打碎了。从礁石脚下扩散出去" |
| 2048 | 海边与季行 | 石头放在礁石上，"礁石脚下的水泛起了一圈涟漪" |
| 2048 | 终章与季遥 | 手指敲膝盖→季遥跟着敲了一下。"一下" |

**关键关系**：
- 江远：创业伙伴 → 理念分歧 → 各自放手
- 顾清：哲学对话者 → 陪伴者 → 远方的声音
- Jackie/深蓝：创造者→失去→重新信任
- **季行：父子断裂 → 海边正面重逢 → 石头传递**（修订前：仅"异步理解"）
- **季遥：缺席父亲 → 海边和解 → 涟漪传递**（修订前：仅"沉默守望"）

### 1.4 季行 — 代际的断裂与重建

| 维度 | 内容 |
|------|------|
| **身份** | 季深之子，穹顶辞职后加入超织体 |
| **时间跨度** | 2035–2048 |
| **核心动机** | "桥不走回头路" → 寻父 → **海边重逢** → 理解 |
| **感官签名** | **节奏** — 他一进屋，争论慢半拍，"空气自己等了" |
| **物象锚点** | 便利贴（记忆载体）、**石头**（童年→成年→传递） |
| **哲学命题** | "判断力需要自己练" — 从断裂到重建 → **"石头沉下去了，但涟漪还在扩散"** |

**情感弧线**（修订版）：
```
离开者（从穹顶辞职）
  → 超织体中学习判断力
    → 发现引用链伪造
      → 用父亲的L8四行字寻父
        → 海边正面重逢（"爸，你那四行字——我读了三年才读懂"）
          → 石头传递（"这块——我带走"）
```

**新增关键场景**：

**① 童年石头记忆（第四部41章）**：
> 季行七八岁时，父亲在象山海边捡了一块石头放入水中。"石头沉下去了。但涟漪还在扩散。""爸，涟漪最后去哪了？""去到它能去的地方。你看不到了。但它到过的水面会记住。"

**② 海边正面重逢（第六部63章）**：
> "你来了。""我来了。"
> "爸，你那四行字——我读了三年才读懂。"
> 季深从礁石边捡了一块石头，放在两人之间。季行拿起来。"这块——我带走。"
> "桥不走回头路。""我知道。二十年前你在机场说的。我没有回答。""你不需要回答。你回答了——你在这里。你一直在。"
> "你害怕吗？""不。我敬畏。"

**石头在季行生命中的轨迹**：
- 七八岁：父亲在象山海边放入水中，"涟漪还在扩散"
- 二十多岁：那块石头带回了家，后来不知道丢到哪里了
- 三十四岁：父亲在Half Moon Bay海边捡了一块新石头给他，"这块——我带走"
- 之后：石头在口袋里暖着，从旧金山到深圳

### 1.5 季遥 — 新生代的直觉

| 维度 | 内容 |
|------|------|
| **身份** | 季深之女，在超织体中长大的新一代 |
| **时间跨度** | 2040–2048 |
| **核心动机** | "做了就不是我的了" → "我也想看" → **"谢谢你一直在"** |
| **感官签名** | **光线**（建议：她待的房间光线总会微微变暖）→ **新增：石头温度** |
| **物象锚点** | 老宅照片、**石头**（从海边捡的→从哥哥留的）、**纸条**（"方向不是终点"） |
| **哲学命题** | "方向是走出来的" — 从本能直觉到自觉选择 → **代际承接** |

**情感弧线**（修订版）：
```
本能直觉（"做了就不是我的了"）
  → 少年的观察
    → 十岁家长开放日——父亲缺席（"我站了大概三十秒。然后转身走了。我没有敲门"）
      → "以前怪过"
        → 海边和解（"你不需要解释。我理解了。真的。"）
          → 石头+纸条承接
            → 终章涟漪传递（手指跟着父亲敲了一下）
```

**新增关键场景**：

**① 家长开放日缺席（第三部27章）**：
> 季遥十岁那年。学校家长开放日。别的孩子的家长都来了。后排有一个空位。她的。
> "季遥，你家长今天来吗？""我爸在看屏幕。"
> 那天放学她路过书房。门开着一条缝。父亲坐在屏幕前。三块屏幕都亮着。一动不动。
> 她站了大概三十秒。然后转身走了。她没有敲门。

**② 石头链延续（第六部64章）**：
> 季遥在礁石上看到一块石头，下面压着一张纸。纸上是季行的字："石头沉下去了。但涟漪还在扩散。"
> 她在礁石旁的浅水里找到另一张纸。季深的字："方向不是终点。方向是你一直在走的路。"
> 两样东西。两个口袋。两代人。

**③ 终章涟漪传递（终章67章）**：
> 季深说："你怪我吗？""以前怪过。现在不怪了。"
> 季深看着海面。手指在膝盖上轻轻敲了一下。
> 季遥看了他一眼。她没有问他在敲什么。她只是——把手放在礁石上。手指也轻轻敲了一下。一下。
