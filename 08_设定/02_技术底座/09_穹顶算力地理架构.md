## 二、设计原则（小说向，非行业报告）

1. **深核必须在硅谷总部地下**——审计线（088/166/170）不可移。  
2. **训练集群与深核分离**——训练可偏远；深核要「能被红头文件找上门」。  
3. **湿件不是 MW 数据中心**——培养皿/晶壳是 W–kW 级实验室，不进贵州机房叙事。  
4. **GPP（2040+）**：单芯片 ≤1.5kW，集群仍可达 MW，但 L5 判定更依赖**低噪、稳供电、可贴 PSCAR**，不是单纯堆机柜。  
5. **地缘**：穹顶是美国公司；中国/欧洲/南美出现在**供应链、边缘节点、CONC 分布式**，不强行给穹顶开「贵州主训练场」除非作者要中资合资支线。  
6. **气候与电**优先：水电/风电 + 自然冷却 + 低电价 + 稳定地震/洪水风险可控。

## 三、推荐三分架构

```
                    ┌─────────────────────┐
   资本·法务·品牌    │  总部 HQ            │  硅谷 Palo Alto
   江远/媒体/审计入口│  + 地下深核 Bunker  │  （剧情锁）
                    └──────────┬──────────┘
                               │ 低延迟专线 / 组织汇报
                    ┌──────────▼──────────┐
   季深实验室·方向组 │  研发 R&D           │  硅谷园区（主）
   湿件角落实验组    │  + 硬件接口实验室   │  深圳（辅，接华强北）
                    └──────────┬──────────┘
                               │ 批训练流量
          ┌────────────────────┼────────────────────┐
          ▼                    ▼                    ▼
   训练集群 A            训练集群 B            边缘/推理
   美西北·水电           德州/中西部·风光      东京·圣保罗·
   哥伦比亚河系          + 储能               班加罗尔（已有）
   （凉·稳·大水电）      （便宜电·热管理难）
```

### 3.1 总部（HQ）· 硅谷 Palo Alto

| 项 | 设定 |
|---|---|
| 功能 | 融资、法务、媒体、董事会、对外审计入口 |
| 深核 | 地下三层 Tianshu Bunker——**受限生产计算 + 历史湿件供电柜**（088 已写） |
| 为何不搬 | 陈卫国红头文件、员工代表、受控数据室都要「同一张桌」 |
| 叙事 | 166/170 门前桌子；不是算力中心，是**权力与可见性中心** |

### 3.2 研发（R&D）

| 节点 | 位置 | 功能 | 人物线 |
|---|---|---|---|
| 主研 | 硅谷园区三楼 | Dome-1/2、方向小组、人格宪章、矩阵域残差 | 季深、顾清 |
| 硬件接口实验室 | **深圳**（华强北辐射圈） | 传感器/基座/维护接口、与档口生态对接 | 老方线可挂靠；赵铭早期可远程 |
| 学术回访 | MIT 剑桥 | 宣讲、Vance、招聘 | 009 |
| 东京办 | 东京 | 固件/远程诊断、区域合作 | 佐藤、石田（离职前） |

**湿件实验组**：2027 在硅谷园区角落实验室（008/编年史）；出走后扩散到 CONC 院子/华强北，**不设「湿件大数据中心」**。

### 3.3 数据中心（Training / Inference）

#### 集群 A · 美西北水电带（主训练）

| 项 | 设定 |
|---|---|
| 地理意象 | 哥伦比亚河流域 / 华盛顿–俄勒冈内陆（可写「河谷变电站旁」，不必点名真实电厂） |
| 选点逻辑 | **水电稳、气候凉、地价低、长距离输电到硅谷可控** |
| 技术对齐 | 007 液冷+供电窄窗；伽罗瓦 Phase2–3 阵列可放这里 |
| 叙事功能 | 「算力在河那边」；停电/枯水/电网调度可做危机；与硅谷深核**物理分离**——审计深核≠审计训练场 |
| 气候呼吸 | 冬湿冷、夏季山火烟尘对冷却进风的影响（可写维护） |

#### 集群 B · 德州/中西部风光（弹性训练与推理）

| 项 | 设定 |
|---|---|
| 选点逻辑 | 风/光便宜、土地开阔、并网灵活；热管理更难 |
| 叙事功能 | 与 032「算力命脉」呼应：电价与限电；CONC 时代边缘节点可在此长出 |
| 风险 | 极端天气（可与 156 水网「气候极值」主题共振，但**不共用同一事故**） |

#### 不建议给穹顶的（除非作者要支线）

| 地点 | 原因 |
|---|---|
| 贵州 / 内蒙 / 西北 | 适合**中国运营商/国资云/CONC 中国节点**；穹顶直接主训会改地缘主线，且与硅谷总部叙事抢戏 |
| 冰岛/挪威 | 可作**第三方托管**或竞争对手 OpenMind 节点，不必穹顶自有 |

#### 若作者要「中国西南/西北」——推荐写法

- **不写穹顶主训在贵州**，而写：  
  1）**供应链**：冷却设备、机柜、变压器来自中国西南制造带；  
  2）**CONC/合作方节点**：某水电局旁的公开算力池（治理线）；  
  3）**地缘张力**：023 主权审查的后续——跨境数据与算力托管边界。  
- 这样既用上「贵州水电、西北风光」的真实逻辑，又不拆硅谷深核剧情锁。

## 四、与伽罗瓦硬件路线的时间对齐

| 阶段 | 年代 | 硬件 | 算力地理叙事 |
|---|---|---|---|
| Phase 1–2 | 2027–2030 | GPU 集群，单卡数百 W | 租算力 + 自建河谷园区 A；电费台词已有 |
| Phase 3 | 2035 | 光子-电子混合，单卡 ~800W | 园区 A 扩容；液冷成标配 |
| Phase 4 GPP | 2040+ | 单芯片 ≤1.5kW，PSCAR 原生 | **深核**进 GPP 机柜；PSCAR 需要**低噪屏蔽**——地下深核优于露天大场 |
| L5 判定 | 2042–48 | 自指环路 | 「听呼吸」在深核墙外（173–174 已写）——**地理上必须可接近、又合法难进** |

**结论**：  
- **大训练**去河谷/风光带；  
- **深核与 PSCAR**留在硅谷地下；  
- 两者在正文里用「专线 / 延迟 / 谁有权看哪一层」区分，避免读者以为「所有算力都在同一栋楼」。
