# Skill 八层结构——叙事表述规范

> 本文件为小说《涌现》中关于 Skill 八层结构的描写提供统一规范。
> 基于 CONC 协议栈 v3.1 与 Skill Lineage & Citation Protocol v1.0 的技术定义。
> 目的：解决"双链"物理化描写与协议层技术事实之间的偏差。

---

## 一、技术事实：Skill 是什么

Skill 是**策元闭环自然产出的结构化知识单元**——一份携带场景描述、过程记录、决策链、蒸馏知识、可复用代码、授权状态、引用链和创造者印记的**八层数据结构**。

**它不是物理实体。** 不存在"两条链"像 DNA 双螺旋一样缠绕。不存在可以"摸到"的物理链。

它是存储在 CONC 网络节点上的数据，通过智契（Agent）界面以可视化形式呈现给用户。用户通过触控板、智契晶、屏幕等界面与之交互，交互的触觉/视觉反馈是**UI 设计层的模拟**，不是数据本身的物理属性。

## 二、八层结构的真实构成

### 2.1 层叠结构（单层，非双链）

```
Layer 8: 创造者印记 (Creator Imprint)         ← 永不衰减
        创造者ID、决策哲学、审美偏好、风险容忍度、协作风格

Layer 7: 引用链 (Lineage / Citation Chain)     ← 永不衰减
        父Skill、修改差异、上游引用、衍生计数
        → 数据结构：有向无环图 (DAG)，不是两条平行链

Layer 6: 授权状态 (Authorization State)        ← 衰减后公开
        衰减参数、授权列表、授权凭证

Layer 5: 可复用代码片段 (Reusable Code)        ← 分层释放
Layer 4: 蒸馏知识 (Distilled Knowledge)        ← 分层释放
Layer 3: 决策记录 (Decision Trail)             ← 分层释放
Layer 2: 过程记录 (Process Record)             ← 渐进公开
Layer 1: 场景描述 (Scenario Descriptor)        ← 最早公开
```

**关键结构特征：**
- 这是一个**单层堆叠结构**（从 L1 到 L8 逐层深入），不是两条平行链。
- L7 引用链是**一个有向无环图**——一个 Skill 可以有多个上游（父 Skill）和多个下游（衍生 Skill），形成树状或网状结构，不是"双螺旋"。
- L8 创造者印记是**四到五个字段的文本数据**，不是"一条链"。

### 2.2 Sophia 与 Phronesis 在 Skill 中的实际分布

| 概念 | 在 Skill 中的位置 | 可编码性 |
|------|-----------------|---------|
| **Sophia（理论智慧）** | L1-L5：场景描述、过程、决策、蒸馏知识、代码 | 完全可编码、可复制、可流通 |
| **Phronesis（判断力痕迹）** | L3（决策记录中的"为什么选这个"）+ L8（创造者印记中的"这个人做判断的样子"） | 部分可编码——决策记录可写，但创造者印记是"压痕"不是"数据" |

**关键区分：**
- **Sophia 层**（L1-L5）是"知道什么"——可被 Agent 读取、执行、复制。
- **Phronesis 痕迹**（L3 的核心决策 + L8 印记）是"如何判断"——Agent 可以读取这些记录，但**无法生成**。L8 印记是创造者做判断时留下的"形状"，不是判断力本身。

## 三、小说中的统一表述规范

### 3.1 核心原则

1. **Skill 是数据，不是物体。** 角色不"摸到"链，而是通过智契/触控板/智契晶界面**查看**数据的可视化呈现。
2. **没有"双链"。** 只有"一个八层结构"——从 L1 到 L8 逐层深入。L7 引用链是树状/网状，不是双螺旋。
3. **触觉/视觉反馈是界面设计。** 粗糙感、光滑感、温度感、颜色——是 CONC 界面（智契晶/触控板）为了帮助用户直观理解数据而设计的**反馈模拟**，不是数据本身的物理属性。
4. **Sophia 和 Phronesis 是概念，不是链。** 冷灰色/暖琥珀色的颜色区分可以保留——但它们是**界面配色方案**，不是"两条链"。
5. **角色感官通道独立于界面配色。** 老方通过声音共鸣感知判断（见 00_叙事口吻标准.md §3.1），林屿通过触控板震动反馈感知界面——两者不混用。触控板震动反馈是 UI 设计，不是老方或其他角色的感官通道。

### 3.2 正确的叙事表述

#### ✅ 正确：描述为"层"或"结构"

> 林屿在界面上看到了 Skill 的完整结构。八层。从上往下。最外面是场景描述——写得简短，几行字交代了问题背景。再往里是过程记录、决策记录、蒸馏知识、代码。一层一层深入。像剥开一个洋葱。

> 他的手指在触控板上滑动，界面上的图层逐层展开。L1、L2、L3……每一层都比上一层更深入。到了 L7，他看到了一张引用图——上游有三个 Skill 被标记为父节点，下游有七个衍生 Skill。树状的。不是线。

> 最深处是 L8。创造者印记。四行字。他读了一遍。界面上的配色从冷灰变成了暖琥珀——这是系统在提示他：你正在看的是有人做过判断的地方。

#### ✅ 正确：引用链是"图/树/网"，不是"两条链"

> 他沿着引用链回溯。每一个节点都是一个 Skill 的版本。分支分叉，像一棵树倒着长——根在上，枝叶往下蔓延。有些分支已经枯萎了（那些 Skill 没人引用），有些还在长新叶子（有人 fork 了它们）。

#### ✅ 正确：触觉反馈是界面模拟

> 他的手指划过触控板时，系统在 L3 的决策记录处给出了一个轻微的震动反馈——不规律的，不均匀的。这是界面在告诉他：这里有人做过真正意义上的选择。不是敷衍的，是犹豫过的、考虑过的。

#### ✅ 正确：Sophia/Phronesis 作为"颜色标记"

> 界面上，L1 到 L5 显示为冷灰色——这是系统默认的理论智慧层配色，表示"这些内容可以被 Agent 直接读取和执行"。到了 L8，颜色变成了暖琥珀色——界面在提示：这部分是人的判断痕迹，不是数据。

### 3.3 需要修正的表述

#### ❌ 错误：将 Skill 描述为物理实体

> ~~屏幕上出现了那对链。他用手指划过——粗糙的。像旧书封面。~~

✅ 修正：屏幕上出现了 Skill 的八层结构图。他滑动触控板，光标在层间移动。当光标经过 L8 时，触控板给出了一种模拟的震动反馈——不规律的，像有什么东西在表面不平整地滚动。界面在告诉他：这里不是算法生成的，是有人做过判断的。

#### ❌ 错误：双链描述

> ~~一条冷灰色的Sophia链，一条暖琥珀色的Phronesis链。八个结把它们绑在一起。~~

✅ 修正：界面中，L1 到 L5 统一显示为冷灰色——这是理论智慧层。L8 单独标记为暖琥珀色——这是创造者印记。L7 的引用链在两层之间延伸，像一个从 L8 生长出来的树冠，枝叶覆盖到 L1。

#### ❌ 错误：将"三个结"直接对应"三层"

> ~~他摸到了三个结。第一个结是理论智慧，第二个结是引用链，第三个结是创造者印记。~~

✅ 修正：他看到了三层结构。最外面是理论智慧——L1 到 L5，全部显示为冷灰色，整齐、规整。中间是引用链——L7，一张复杂的图，节点和边交织在一起。最深处是创造者印记——L8，暖琥珀色，四行字，简洁但不可变更。

### 3.4 各层在小说中的叙事描述

| 层 | 叙事描述 | 视觉特征 | 可交互方式 |
|----|---------|---------|-----------|
| L1 场景描述 | "几行字，交代了什么问题" | 冷灰色，文本 | 阅读 |
| L2 过程记录 | "时间线，每一步做了什么" | 冷灰色，时间轴 | 展开/收起 |
| L3 决策记录 | "关键节点的选择——为什么选A不选B" | 冷灰色，附带震动反馈标记（有判断的地方） | 查看详情 |
| L4 蒸馏知识 | "几条核心规则——七年的东西压成了几行" | 冷灰色，重点高亮 | 引用 |
| L5 可复用代码 | "能跑的脚本，直接复制就能用" | 冷灰色，代码块 | 复制/fork |
| L6 授权状态 | "谁可以用，用多久，到期了没有" | 灰色，进度条 | 查看 |
| L7 引用链 | "上游有哪些，下游生了多少" | 冷灰色底+暖琥珀色标记节点，树状/网状图 | 回溯/展开 |
| L8 创造者印记 | "四行字——决策哲学、审美偏好、风险容忍度、协作风格" | 暖琥珀色，有噪点，边缘不锐利 | 只读，不可修改 |

## 四、特殊场景的表述规范

### 4.1 在 Skill 市场中浏览

> 界面上的路标不是文本列表。每个路标是一个 Skill 的入口卡片。卡片上不显示评分——CONC 不展示消费指标。只显示一个颜色标记：冷灰色表示这个 Skill 的 L8 印记是空的（没有判断力痕迹），暖琥珀色表示 L8 有人写过。

### 4.2 在触控板上追溯引用链

> 他在触控板上向左滑动，引用链的节点一个个展开。每个节点是一个 Skill 版本。有分支。有合并。像一个项目的 Git 历史——但比 Git 多一层：每个节点旁边有一个小标记，标记着这个版本的创造者有没有在 L8 留下印记。

### 4.3 在智契晶上查看

> 智契晶的表面亮起。涟漪从中心扩散。在涟漪中，八层结构逐层浮现——从外到内，从 L1 到 L8。晶壳的颜色在 L8 处微微变暖——从电光蓝转为暖琥珀色。这是晶壳在提示：你正在看的是人的判断，不是机器的输出。

### 4.4 PEER 评审中对 L8 的检查

> 审查者打开 Skill 的 L8。四行字。他读了一遍。界面上没有显示"是否符合事实"的评分——因为 L8 无法被验证。他只能看：这四行字之间有没有矛盾？有没有"但"？有没有张力？有矛盾、有张力，才是真的。太一致——是假的。

## 五、常见错误与修正对照表

| 错误描述 | 问题 | 修正描述 |
|---------|------|---------|
| "两条链缠绕在一起" | 双链隐喻，与实际 DAG 结构不符 | "八层结构从外到内逐层深入" |
| "摸到一条粗糙的链" | 物理化描述，链不是物理实体 | "触控板在光标经过 L8 时给出了不规律的震动反馈" |
| "Sophia链/Phronesis链" | 将概念层级误认为物理链 | "L1-L5 显示为冷灰色（理论智慧层），L8 显示为暖琥珀色（判断力印记层）" |
| "八个结绑住两条链" | 将八层结构误认为八个节点连接两条链 | "八层像洋葱皮一样一层包一层，L7 引用链在中间层像树冠一样展开" |
| "金色节点/蓝色节点" | 可以保留——但需明确是界面配色 | "界面上，有判断力印记的节点标记为金色，没有的标记为蓝色" |
| "创造者印记是链的一部分" | 印记是 L8 的字段数据，不是链 | "创造者印记是 L8 的四行文本，是 Skill 最内层的核心" |

## 六、格言级表述

> **"一条 Skill 有八层。从外到内。写得越深的东西，越接近判断。最外面是场景——随便谁都能看。最里面是印记——只有写的人能留。"**

> **"L7 是引用链。不是两条。是一条。但它不是直线——是树。每分叉一次，就多一个方向。"**

> **"L8 不是数据。是压痕。一个人在一个地方做判断，压久了，就留下了形状。"**
