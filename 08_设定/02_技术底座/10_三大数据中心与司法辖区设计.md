## 二、三大 DC 叙事定义

「三大数据中心」= 调查线上的**三个可点名的算力/数据保管节点**，不是三座一样的机房。

```
                    硅谷 HQ + 深核 B3（权力与可见性中心；算力 ≠ 主训）
                              │
         ┌────────────────────┼────────────────────┐
         ▼                    ▼                    ▼
      US-DC                 CN-DC                XX-DC
   美西北水电带           中国辖区节点          第三司法辖区
   主训练 / 大规模        中国业务+CONC边+      区域托管/推理/
   批处理                 供应链日志+合规备份    跨境协作（待定）
```

与 09 的关系：09 的「集群 A/B」收束为 **US-DC**（主）+ 弹性位；CN-DC / XX-DC 是**调查意义上的节点**，体量可以小于 US-DC，但**司法与证据地位**重要。

## 三、分址设计

### 3.1 US-DC · 美西北水电带（主训练）

| 项 | 设定 | 现实锚点（写进正文用「河谷/变电站旁」，不点真实电厂） |
|---|---|---|
| 功能 | 大规模训练、批处理、与硅谷深核物理分离 | 审计深核 ≠ 审计训练场 |
| 电 | 水电稳、低电价、可写枯水季降频 | 哥伦比亚河系水电 |
| 冷 | 凉爽气候 + 液冷；山火烟尘影响进风可作维护细节 | 太平洋西北内陆 |
| 叙事 | 「算力在河那边」；专线延迟写清 | — |
| 配合部门（调查） | 注册地/设施地联邦与州路径：关基设施协同、执法司法程序、能源可靠性监管触角；公司法务与外审为主通道 | 美国：联邦+州双层，程序与律师在场 |

**禁止**：把 US-DC 写成可以「半夜刷卡进机柜」的地方。

### 3.2 CN-DC · 中国辖区节点

| 项 | 设定 |
|---|---|
| 为何存在 | 穹顶在中国有业务/合作/CONC 边缘与供应链日志；创始人中国背景使地缘张力**内生**，不是硬贴 |
| 体量 | 不必 MW 主训；可为**区域推理 + 合规数据驻留 + 与合作方算力池接口** |
| 地理意象（三选一，待作者） | **A. 深圳/东莞边缘机房**（贴人物、贴供应链）／**B. 贵安或中卫类「东数西算」园区合作位**（水电/气候真实，适合「大园区但穹顶只是租户/合作方」）／**C. 杭州节点升格**（060 已有一句，升格成本低） |
| 电/冷 | 若写园区：水电/自然冷；若写华南：高温高湿、液冷与空调负荷可写 |
| 配合部门 | 网络安全审查与关键信息基础设施保护语境下的**协调调查**（正文已用「审计协调办公室」「红头文件」声部）；数据跨境不得因怀疑任意复制（166 已写） |
| 与深核 | **物理无关**；CN-DC 可被合法触达，**不能**因 CN-DC 查通就自动打开硅谷深核 |

**推荐默认**：**A 深圳侧边缘/接口机房 + 可选一笔中西部合作算力池**——服务林屿线，且不抢「东数西算」旅游手册感。

### 3.3 EU-DC · 爱尔兰 / 都柏林一带（已确认第三地）

| 项 | 设定 |
|---|---|
| 为何是爱尔兰 | 美国科技公司欧陆落点常见；气候冷、自然冷却可写；作者已否东京（地震带）与新加坡（过热） |
| 功能 | 欧陆推理/托管/合规数据驻留；与 US-DC 主训**不同责**——审「谁在欧陆看见什么」 |
| 电/冷 | 气候偏冷有利冷却；**电网接入与限电/新建机位紧张**可作运营细节（现实锚点：都柏林一带数据中心并网压力） |
| 叙事功能 | 第三极监管：欧盟侧数据主体/跨境请求与美国母国公司之间的程序张力；不替代 CN-DC 与深核 |
| 人物 | 无常驻主角；**外审/法务/远程佐藤协作**可挂；避免为 DC 再造主角 |
| 配合部门声部 | 数据保护与跨境调取程序（律师在场、范围文书）；**禁止**写成欧盟能一键开深核 |

**禁止**：EU-DC 查通 = 自动打开硅谷深核；禁止旅游手册式「翡翠岛机房」。

## 四、调查权限阶梯（黑盒 / 白盒 / 侧信道）

与已有正文对齐，禁止发明「特警入场」。

| 级 | 名称 | 能看到什么 | 谁驱动 | 正文状态 |
|---|---|---|---|---|
| L0 | 公开/自我披露 | 通报、案例卡、版本说明 | 公司/运营方 | 156 事后卡已用 |
| L1 | **受控数据室** | 脱敏日志、权限分离、事件响应摘要；人在场、不拷走 | 协调方+公司 | **166–175 已有** |
| L2 | **受限黑盒（接口级）** | 指定接口/镜像环境/合成负载；不可见内部权重与受限生产路径 | 注册地程序授权 | **新（N2 可埋）** |
| L3 | **白盒（代码与配置）** | 版本治理、供应链变更、可复核代码范围；**深核受限生产路径默认排除** | 更高法律授权+多方在场 | **新** |
| L4 | **侧信道** | EMC/TEMPEST 式电磁与功耗噪声、冷却日志相关性；**不破门、不插探针进活体意识路径** | 工程伦理+授权复测 | **173–174 已有**（守成） |
| L5 | 深核受限生产 | 历史湿件供电柜、受限生产计算 | 默认不向调查组开放；公司自愿有限展示须单独授权 | **170 铁门已写「不」** |

**递进原则（用户已确认）**：

```
受控数据室（已有）
  → EMC/侧信道（已有）
  → 某 DC 受限黑盒（新）
  → 另辖区白盒 / 侧信道交叉（新）
```

高潮不是「终于打开门」，而是**跨辖区证据如何互相约束又互相不能代替**。

## 五、林屿合法触达路径

### 5.1 铁律

1. 林屿**不是**调查员、不是监管干部、不是穹顶员工。  
2. 他可以是：问题提出者、材料整理者、深大实验室设备维护相关人、CONC/协作网参与者。  
3. 任何「进机房」必须有：书面范围、在场人、不可复制条款、可拒绝权。  
4. 深蓝晶壳流出后，他对手上设备有**维护与观察**关系，不等于对穹顶 DC 有管辖权。

### 5.2 递进（主战场确认后填章号）

| 阶段 | 林屿能做 | 不能做 |
|---|---|---|
| 水网/医疗期 | 远程看记录层、组装诊断、家里沙箱 | 改闸、改泵、自称代表全球 |
| 166 协调期 | 交材料、听范围说明会 | 代监管决定、拷跨境数据 |
| 受控数据室期 | 旁听/受控读（若被点名） | 独自进深核 |
| DC 黑盒期 | **在授权接口/镜像前做问题清单与可复现实验** | 拔线、格式化、私自侧写生产 |
| 白盒/交叉期 | 读懂版本与供应链差异；指出「像≠是」 | 替任何一国下结论 |

### 5.3 主战场（已确认：双主）

| 线 | 谁 | 做什么 | 不做什么 |
|---|---|---|---|
| **中国黑盒** | **林屿主责**（问题提出者→授权接口前） | CN-DC 受限黑盒：镜像/指定接口、问题清单、可复现实验；深圳协调程序 | 不破门、不拷跨境、不代监管结论 |
| **美国墙外** | **叶澄主责**（EMC/侧信道已有 173–174）；林屿远程读谱/对问题 | 深核墙外电磁与功耗噪声、冷却日志相关性；**不插活体意识探针** | 不进 B3、不格式化、不把「像」写成「是」 |
| 交叉 | 两人+外审 | 中侧接口结果与美侧侧信道**互相约束、不能互相代替** | 不拼成「全球真相已破」 |

**EU-DC**：第三人极核验材料与跨境程序；不抢林屿/叶澄双主戏眼。

**双主纪律**：林屿不必赴美破门；叶澄不必冒充中国监管。各在辖区内合法加深。

## 八、地理现实性总则（本轮全文方法，不单服务 DC）

> 数据中心只是范例。同一审法用于水网、医院、跨文化。

| 场景类 | 必须相符 | 常见套错 |
|---|---|---|
| 水网（柯桥） | 江河/河网/闸泵、地方水行政与调度语汇、梅雨台汛 | 用北京河长制腔写江南河网；用「水库开闸救秧」代替枢纽调度 |
| 医疗（圣保罗） | 公立/慈善医院流程、葡语标识、家属与护士交接习惯、设备报警文化 | 中国三甲交班腔、红包、病历本皮 |
| 算力/DC | 电、冷、进出等级、律师与陪同 | 科幻「全息中央室」无温无噪无授权 |
| 跨文化 | 语言混用方式、时间观、称呼、沉默 | 口号化「XX人民友好」 |

**作业法**：先知识底稿（地点+政策+物件）→ 扫描现文「套错点」→ 按**人物线/场景类**定点补 → 验收「冷读是否像当地」。  
**不**按章撒胡椒。
