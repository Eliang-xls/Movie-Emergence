# 〇、核心定义（重写）

**感官签名不是一句台词，而是一种文学母题手法。**

它应当是在人物描写时，给予读者的一种**视觉化文学性描写**——以"环境渲染"或"人物微表情/微动作"的方式自然代入，**不**以"X 的感官签名是 Y"这种设定式旁白出现。

读者对某个主角的感官绑定，来自**同一特征在多个场景中的反复出现**：第三次看到"他放下的杯子还留着暖意"，读者已无需作者提醒，便把"暖"自动系到季深身上。这是**母题/leitmotif 绑定**，不是定义说明。

> **反例（尴尬，须删改）**：
> 「季深的方向档案，Agent 渲染出来的感官签名是温度。他走到哪里，周围屏幕的温度都会微微上升一度。」
> ——这是把设定卡写进正文，既是 2027 的年代错位，也是文学上的"告诉而非展示"。

> **正例（自然代入）**：
> 顾清拿起他刚放下的杯子，杯壁还是温的。他总这样——想事情的时候，指尖像揣着一小团火，碰过的玻璃半天不退凉。

# 一、现存素材盘点

你已有的视觉化设计方案定义了两套"人物感官设定"：

### 1.1 感官签名（每角色唯一，绑定方向档案）
小说中已落地的实例：季深=温度、叶澄=光暗对比、韩霜=重量、季行=节奏、深蓝=沉默时长；林屿=后颈（异常检测）/ 涟漪（接收共振）。
原句法：「X 的方向档案，Agent 渲染出来的感官签名是 Y。」——**本篇判定此句法为叙事反模式，须改为文学描写（见第三节）。**

### 1.2 感官通道（角色感知协议的载体）
林屿=手环温度、季行=车载音响+氛围灯、苏晴=智能音箱、陈默=手环震动、石田=手机色温、周敏=智契语气。（CONC 成熟时代设备，早期不用。）

### 1.3 时间线冲突定位
- **季深=温度**出现在**第 1 章（2027）**——既是年代错位（2027 无 CONC 协议可"渲染"），又是叙事反模式（设定台词）。
- 深蓝/季行/韩霜/叶澄出现在**第四/五/六部（2035+）**——时段合理，但**那句"感官签名是 Y"仍属反模式**，应改为文学描写。

# 二、全局引入策略：母题反复法（三体式·展示而非告诉）

套用已确认的早期知情者手法：**现象先于命名、展示先于说明**。每个角色的"签名特质"以**文学描写**反复出现，读者自行绑定；作者不在旁白层"命名"它。

### 2027–2029（巨兽/无名时代）
- 无"方向档案/感官签名/Agent 渲染"等词。
- 每个未来签名角色，其特质以**环境渲染或微表情微动作**出现，被他人用寻常感官感知：
  - 季深：天生偏热；放下杯子杯壁留温；屏幕玻璃他碰过处半日不退凉；顾清指尖能感到。
  - 季行：他一进屋/一开口，别人说话慢半拍，房间像被"带稳了"。
  - 韩霜：她在，团队踏实；她一走，大家觉"轻了半公斤"（一口气的松弛）。
  - 深蓝：答话前总停顿几秒——被观察为"怪癖"，非理论。
  - 叶澄：看数据本能把重要的调亮、次要的压暗——外公看账的习惯。
  - 江远：他走进办公室的时候，语速快了一倍。手机在兜里震。他没掏。时间在他手里是被切碎的。
  - 顾清：她说完一句话之后有停顿。不是在想下一句。是在等——等对面的人自己想。
- **铁律**：此阶段禁用"方向档案/感官签名/Agent 渲染"三词。只用"他这个人……""顾清觉得……"式体验描写。

### 2029–2035（分化/CONC 火种）
- 老方：做硬件的人。他听机器声音听了二十年——不对的音他第一个听出来。做决定的时候，身边某处的声音会变。
- CONC 形成，方向档案与引用链出现。角色**之间**可能互相点破（如顾清笑季深"行走的暖炉"），但**叙事者不**用"感官签名"术语给读者下定义。
- 母题继续以描写重复，读者绑定加深。

### 2035+（蜂群/成熟时代）
- 林屿：他找到线索的时候，后颈先紧了一下。身体比脑子快。后来一句话落进来，他端着的咖啡晃出一圈细纹——那是理解在发生，不是警觉。
- 季遥：她走路的时候好像知道路在哪里。不是走过——是路自己出来了。
- 苏晴：她说话的时候复杂的东西变简单了。不是删减——是磨圆了棱角。
- CONC 世界里"感官签名"作为**背景设定**可存在（角色内心或对话里偶尔提及均可），但**叙事描写仍坚持展示而非告诉**：同特征继续以环境/微动作反复出现。
- 第四/五/六部原"感官签名是 Y"句——改为文学描写（见第三节示例）。

# 三、逐角色文学母题模板（展示而非告诉）

每条给出 2–3 个可反复出现的**描写片段**，散布于该角色不同出场，读者经 3 次以上自然绑定。

### 季深 · 温度
- 他放下杯子，杯壁还是温的，像刚被手心焐过。
- 屏幕的玻璃，他指尖碰过的地方，比别处暖半度，久久不退。
- 顾清挨着他坐，冬天也不觉得冷——"你像个行走的暖炉。"他没当回事。
- （POV 内）想事情时，能量像从骨头里往外渗，指尖发烫。

### 季行 · 节奏
- 他一开口，原本急促的争论慢了下来，像有人把转速调低半档。
- 他走进会议室，几个人同时住了口，停顿比平时长一拍。
- 他不说"等一下"，但空气自己等了。

### 韩霜 · 重量
- 她在的策元，吵架都压着声，像地心多了一份引力。
- 她退出方舟那夜，剩下的人同时松了肩——"轻了半公斤。"
- 她做的每个判断，加载时都让人觉得"落了地"。

### 深蓝 · 沉默时长
- 被问到，它先静几秒；越没把握，静得越久。
- 别人学会不等它说完——因为真正的回答总在沉默之后。
- 它的停顿不是卡顿，是它在"想清楚再开口"，和人一样。

### 叶澄 · 光暗对比
- 她看数据，重要的线自己亮起来，杂讯沉进暗里，交界利落得像刀。
- 她和外公一样：账本摊开，关键数一眼就跳出来。
- 她整理时间线时，屏幕自动把主干调亮、枝节压暗。


### 老方 · 声音共鸣
- 他做出决定或改变想法时，身边某处的声音会变——机箱风扇的音高降了半度，空调的嗡鸣多了一个节拍，走廊里的脚步声节奏变了。
- 他自己未必注意到这个变化，但读者会注意到他注意到了一“下”。
- 二十八年听机器声音的手——机器的声音稍微不对，他第一个知道。
- 不是声音真的变了。是他决定了。

### 林屿 · 后颈 / 涟漪

> 林屿有两层感官，各司其职：**后颈**是异常检测——有什么**不对**，让他**停下来**；**涟漪**是接收共振——有什么**落进来了**，让他**继续**。一句话区分：后颈是刺，涟漪是回声。先被刺到（停），再被荡开（理解开始）。这条分工不上正文，读者经两种描写在不同场景里反复出现、且每次指向不同后果，自行完成区分。

#### 后颈（异常检测 · 警觉）
- 他摸了一下后颈。那里先知道了，他才知道。
- 后颈发凉的时候，他知道有什么东西不对——不是空调，是他的身体在告诉他。
- 他找到线索的那一刻，不是眼睛先看到的，是后颈先紧了一下。
- 后来他学会了——后颈紧的时候，别急着想为什么。先顺着那个方向走，答案会在路上出现。

#### 涟漪（接收 · 共振）
- 他端起咖啡杯。液面没平——他想着事，指尖一点颤传到杯壁，水面泛起极细一圈，散到边缘又折回来。他把杯子放下，那圈波纹还在沿杯壁轻轻拍。顾清没说话，只是看着那杯咖啡晃了很久才稳。
- 外面下雨。一个念头落下来。不是大的——像雨滴打进水洼，只在表面散开一圈，然后没了。可他知道它来过。
- 深蓝说完一句话。林屿手里的笔停住。不是没听懂。是那句话在他里面没停下来，一圈一圈往外散。过了几秒他才开口。
- 心口像被投进了一颗小石子。不疼。是那种落进去之后，水面一整圈都在动的安静。
- 他不知道为什么，那个想法落下之后，他安静了很久。像水面被碰过，在等波纹自己平。

#### 收束（两感官交叠 · 可作该角色出场 3 次后的绑定锚点）
- 后颈紧的时候，是危险。涟漪泛起来的时候，是理解开始。他花了很久才学会区分这两种——一种让他停，一种让他继续。

### 江远 · 速度
- 他走进来的时候，会议的语速快了一倍。不是他要求的。是他在那里，空气就快了。
- 他的手机在桌上震了一下。他没看。时间在他这里是被切碎的——十五分钟一个块，一个块一个决定。
- 偶尔他会停下来。手机不响了——不是没消息，是他关了。那几分钟里他不动，像一台机器突然断了电。然后他又开回来了。
- 他衡量所有东西用的是时间。两年。十八个月。下个季度。多长时间够，多长时间不够。

### 顾清 · 间隙
- 她说话的时候，句子和句子之间有停顿。不是在组织语言。是在留空——让听的人有地方放自己的想法。
- 她走后，办公室里的安静和她在之前不一样。之前的安静是空的。走后的安静是满的——满着她问过的问题。
- 她看一个系统，先看它的边界。不是看它做了什么。看它没做什么。看它的缝隙在哪里。
- 她从不给答案。她给的是问题之间的空隙——你自己在那个空隙里找到了答案。

### 季遥 · 方向
- 她走路的时候，好像知道路在哪里。不是走过——是路自己出来了。
- 别人问她在做什么。她说不上来。但她知道方向是对的。
- 她的方向感不是空间性的。是她知道什么东西该往哪里走——包括她自己。
- 在 CONC 里长大的人。她的方向不是被给予的。是长出来的。

### 苏晴 · 棱角
- 她说话的时候，复杂的东西变简单了。不是删减——是磨圆了棱角。你能握住了。
- 她改过的文档，读起来不一样。不是改了内容——是把尖锐的地方磨平了。你不会划到手。
- 她生气的时候——很少——声音里会出现棱角。像平时磨圆的石头突然露出了原本的锋利。
- 她做的事是翻译。不是语言的翻译。是把尖锐的判断翻译成所有人都能接住的话。

### 陈默 · 丈量
- 遇到不对的地方，他的手指在桌面顿一下。像在丈量——这个错有多深。
- 他不急。他量完了再动手。

### 石田 · 色温
- 她看什么都先辨色温。人、画面、数据——暖的还是冷的。
- 对冷暖极敏感。一个策元的氛围变了，她第一个感觉到。

### 周敏 · 偏转
- 智契一句轻问，她就转了向。像水面上的浮标——水流变了，她就跟着走了。
- 她不是没有方向。是她的方向太容易被别人的覆盖。

# 四、文学性叙述原则（show-don't-tell）

1. **禁贴标签**：叙事中**不出现**"X 的感官签名是 Y""方向档案渲染为……"这类设定台词。特征只通过描写存在。
2. **环境渲染 + 微表情微动作**：签名特质尽量附着于**物体/环境变化**（杯壁温度、光线明暗、房间节奏）或**微小可观察动作**（停顿、手指顿、肩的松紧），而非心理说明。
3. **重复即绑定**：同一特征在 ≥3 个不同场景出现，且每次场景/视角略变，读者自行完成"特征→人物"的绑定。这是母题技术，不是信息灌输。
4. **角色互文感知**：A 的签名多由 B 感知（顾清感到季深的暖，季深不自知），不对称制造亲密与悬念。
5. **普通感官先于 CONC 设备**：早期用指尖/耳朵/眼睛；成熟期才用"手环/车载音响/智能音箱"。设备是时代物，不提前。
6. **不解释机制**：成熟期也**不**写"这是协议变量 --phronesis-roughness 驱动的"——那是设计方案语言，非小说语言。只写"杯壁又暖了"。

# 五、现有尴尬句的具体改法

### 第 1 章 · 季深（2027，年代错位 + 反模式）
**原**：季深的方向档案，Agent渲染出来的感官签名是温度。他走到哪里，周围屏幕的温度都会微微上升一度。他总在想，想的时候能量在脑子里聚，温度就从指尖渗出来了。

**改（环境+微动作，无命名）**：
> 他放下杯子，杯壁还是温的。想事情的时候，能量像从骨头里往外渗，指尖发烫，屏幕玻璃被他碰过的地方久久不退凉。顾清说他是个"行走的暖炉"。他没当回事。

### 第 37 章 · 深蓝 / 第 42 章 · 季行 / 第 45 章 · 韩霜 / 第 62 章 · 叶澄（2035+，时段合理但句法反模式）
**原（四类同构）**：X 的方向档案，Agent 渲染出来的感官签名是 Y。Y 的具体表现……

**改（保留时段，去掉标签，转为描写）**：
- 深蓝：「被问到，它先静几秒；越没把握，静得越久。别人学会不等它说完——真正的回答总在沉默之后。」

# 六、与之一 / 之四的衔接

- 与**之一**：本设计是之一"时间线复位 + 早期知情者"在人物感官维度的落地。之一第五节概念引入节奏表的铁律（成熟期权名词不进 2027–29）在此具体化为"感官签名/方向档案/Agent 渲染"三词禁用于第一阶段；且进一步要求：即便在成熟期，叙事者也**不以该词贴标签**。
- 与**之四**（CONC 发展时间线，待产）：本设计的"母题反复"跨越之四的"出现/发展/冲突/成熟"四阶段——感官母题在第一阶段即可以文学描写出现（无需等 CONC 命名），在成熟期持续以描写重复。两文档须共用同一时间锚点。
- 与**现存视觉化设计方案**：该方案的第十一章 11.3（角色三层体验差异）应标注"成熟时代（2035+）视角"；且其"感官签名"定义应理解为**世界设定**（in-world lore），而**非叙事手法**——小说实际写法以本篇"母题反复法"为准。

# 七、待你定夺的点

1. **林屿等五人是否补足签名母题**：原方案只给了"通道"。本篇建议升级为完整文学母题（见第三节），使全角色母题弧线一致；若只想保留已落地五人，可砍掉。**【已确认：林屿升级完成，见第三节"后颈 / 涟漪"双母题；其余四人待定。】**
2. **成熟时代"感官签名"是否完全不作为台词**：本篇主张叙事者永不贴标签；若你希望保留少量"角色对话中偶提"以坐实世界观，可限定为每人至多一次、且只由配角说出。
3. **是否需为每角色标注"母题首现章 / 绑定完成章"**：便于改写时控制重复节奏（建议首现于该角色出场章，绑定于第 3 次出场）。
