## 二、视觉基因

### 2.1 链的材质：像素纤维

链不是实物绳子。它是**屏幕上的数码视觉元素**——由无数极细的发光粒子线（像素纤维）编织而成。

**像素纤维的定义**：单根纤维是一个宽度约 1 像素的发光粒子流。粒子沿纤维方向缓慢流动，像一条极细的数据流。数十根到数百根像素纤维按照特定的编织逻辑聚合成链。

**纤维密度的层间变化**：

| 层 | 纤维密度 | 视觉效果 |
|---|---|---|
| L1-L3 | 高密度 | 纤维紧密排列，边缘锐利，冷灰色面看起来是实心的 |
| L4-L5 | 中高密度 | 纤维开始可辨，能看到单根丝线的走向 |
| L6 | 中密度 | 纤维明显可见，冷灰丝线中出现暖色丝线 |
| L7 | 中低密度 | 纤维稀疏，冷灰与暖琥珀丝线混编，能看清编织结构 |
| L8 | 低密度 | 纤维极稀疏，但每根都很亮。暖琥珀色。能看到粒子在单根纤维内流动 |

**编织方式的层间变化**（设计逻辑，银幕上以数码效果呈现）：

| 层 | 编织逻辑 | 数码化呈现 |
|---|---|---|
| L1 | 平铺——纤维平行排列 | 冷灰色粒子流，方向一致 |
| L2 | 交叠——纤维交替上下 | 粒子流有轻微的波浪起伏 |
| L3 | 绞合——三股纤维拧成一股 | 三束粒子流螺旋缠绕 |
| L4 | 压实——纤维被挤在一起 | 粒子流密度极高，几乎不可辨单根 |
| L5 | 方格——纤维交叉成网格 | 粒子流在两个方向交叉，形成网格纹理 |
| L6 | 过渡——冷灰纤维与暖色纤维混入 | 两种颜色的粒子流开始交织 |
| L7 | 编辫——多股纤维交织成辫 | 多束不同颜色的粒子流螺旋编辫 |
| L8 | 凝实——纤维凝成近乎实心的光柱 | 粒子流极亮，单根不可辨，整体呈暖琥珀光柱 |

### 2.3 像素密度与噪点

| 域 | 像素密度 | 边缘 | 噪点 |
|---|---|---|---|
| Sophia（L1-L5） | 密集 | 锐利 | 无 |
| 过渡（L6） | 中等 | 开始模糊 | 极少 |
| Phronesis（L7-L8） | 稀疏 | 模糊 | 有，随机偏移 1-2 像素 |

**噪点的数码化实现**：Phronesis 侧的噪点不是随机噪声——它是**胶片颗粒感**。每个颗粒有自己的亮度和位置，整体形成有机的、不规则的纹理。与 Sophia 侧的锐利像素形成对比。

## 三、八个压缩结的设定

### 3.1 结的视觉形态

每个结是像素纤维在特定位置的**压缩凝结**。不同层的结有不同的压缩方式、尺寸和光效。

屏幕上看到的不是实物绳结——是**数码化的光团**。像素纤维在结的位置被压缩、交织、凝结成一个可视的节点。节点的亮度、密度、颜色取决于所在的层。

### 3.2 逐层设定

---

#### 结①·基底（L1 场景描述）

**压缩方式**：最简单的单圈压缩。纤维绕一圈。松。

**尺寸**：最小。直径约链粗的 2 倍。

**颜色**：#C0C0C0。冷白光。

**光效**：无特殊光效。与链的冷灰色一致。

**展开动画**：用户点击 → 压缩松开 → 纤维散开，释放出二三十个冷灰色光点悬浮在链的上方。光点大小不一，光点之间有极细的相似度连线。整体形成一个小型星座图。2 秒后稳定。

---

#### 结②·门径（L2 过程记录）

**压缩方式**：双重交叠压缩。比①紧。

**尺寸**：略大。

**颜色**：#A0A0A0。

**光效**：无特殊光效。

**展开动画**：用户点击 → 压缩松开 → 纤维展开为一条水平时间轴。事件方块从左到右逐个亮起，节奏不均匀。

---

#### 结③·脉络（L3 决策记录）

**压缩方式**：三重绞合压缩。结的表面有一处**纤维断裂后重新接上的突起**——疤。

**尺寸**：中等。

**颜色**：#808080。冷灰中带冷蓝底色。

**光效**：疤的位置有极微弱的红色光点——标记回滚的决策。

**展开动画**：用户点击 → 压缩松开 → 纤维长出分支，形成倒悬的决策树。枝杈从主干向两侧伸展。每个节点内部有极小的金色锁图标（Ed25519 签名）。节点之间有金色哈希链连线。某些枝条上有红色微光（回滚痕迹）。

**第一道链式骨架**：金色哈希链连线——刚性直线，不可弯曲。

---

#### 结④·筋骨（L4 蒸馏知识）

**压缩方式**：紧密的圆柱形缠绕压缩。表面几乎是光滑的——不是没人碰过的光滑，是被反复压实后的光滑。

**尺寸**：中等偏大。

**颜色**：#7A7068。灰褐。表面有极细的结晶纹路。

**光效**：结晶纹路在光线照射下折射出彩虹色边缘。

**展开动画**：用户长按（像拧瓶盖）→ 压缩旋转松开 → 纤维结晶为多面体晶格。晶格缓慢旋转。光线穿过时折射出彩虹色边缘。

---

#### 结⑤·试金（L5 可复用代码）

**压缩方式**：方形网格压缩。工业感。纤维交叉成扁平的方形网格。

**尺寸**：中等。

**颜色**：#6B6058。褐灰。表面有平行纹路。

**光效**：平行纹路中有极细的绿色/红色光点闪过——代码验证通过/失败。

**展开动画**：用户点击 → 网格逐节松开（像拉链）→ 纤维展开为一对平行通道。字符流从左到右流动。偶尔闪过绿色或红色。

---

**═══ 分界线 ═══**
**（像素纤维的颜色从冷灰过渡到暖褐。纤维中出现暖色丝线。）**

---

#### 结⑥·编织（L6 授权状态）

**压缩方式**：活态压缩——结的松紧是时间的函数。表面包裹着一层**半透明数码膜**。

**尺寸**：中等偏大。

**颜色**：#8B7355。暖褐。冷灰纤维与暖色纤维混杂。

**光效**：半透明膜在缓慢溶解——不是用户打开的，是时间在打开的。

**展开动画**：用户点击 → 膜开始溶解。三阶段：
- 锁定期：膜几乎不动。画面静止。
- 快速释放期：膜快速消散。纤维颜色剧变。
- 完全公开期：膜消失。纤维裸露。

---

#### 结⑦·言说（L7 引用链）

**压缩方式**：多股编辫压缩。至少三股不同粗细的纤维从不同方向汇入。有层次——松了一层里面还有一层。

**尺寸**：大。

**颜色**：#B8860B。琥珀。冷灰纤维与暖琥珀纤维**混编**。

**光效**：编辫的缝隙中有暖光透出——Phronesis 侧的光从内部渗出。

**展开动画**：用户点击 → 编辫逐层松开 → 纤维展开为引用网络（DAG）。五种边类型有不同的视觉语言。被引用的 Skill 是网中的节点——有印记的有暖琥珀色光晕，空的只有冷灰色轮廓。

**第二道链式骨架**：五种类型的引用连线——不可删除，只能标记。

---

#### 结⑧·印章（L8 创造者印记）

**压缩方式**：三重叠绕压缩。像素纤维在这里凝成近乎实心的光柱。

**尺寸**：最大。

**颜色**：#D4A84B。深琥珀。

**表面纹理**（数码化呈现）：
- **噪点**：像素颗粒随机偏移 1-2 位。不规则。有机。
- **疤痕**：纤维断裂后重新接上的痕迹。颜色比周围深一度。
- **凹凸**：纤维密度不均匀——有些地方密（犹豫），有些地方疏（修正）。

**光效**：结的内部有暖光——不是表面反射，是从纤维深处渗出来的。

**展开动画**：用户长按 3 秒 → 结的中心开始发光 → 结**绽放**（花瓣般张开，不是机械松开）→ 三股子链依次展开：

**子链1：历史种子链**——一串暖琥珀色光点，虚线连接（时间顺序）。

**子链2：签名链**——一串金色锁图标，金色实线连接（Ed25519 哈希链）。锁图标表面有噪点。

**子链3：承诺行为链**——一条波浪形暖色带。振幅 = 承诺强度。有断裂处。

然后**四个字段**从结的核心依次浮现：

1. 决策哲学——字迹有噪点，边缘模糊，像墨水洇开
2. 审美偏好——噪点模式与第一行不同
3. 风险容忍度——字迹最重，笔画粗
4. 协作风格——字迹最稳

四个字段之间出现**共振线**——真实创造者的共振线是颤动的曲线，伪造的是僵硬直线，空的没有共振线。

**第三道链式骨架**：三股子链不可分离——任何一股被切断，其他两股发出红色警报。

### 3.3 三种异常状态

#### 空的结（Agent 生成）

- 表面**光滑**——没有噪点、没有疤痕、没有凹凸
- 颜色变成**均匀浅褐色**——暖色被洗掉了
- 长按 3 秒后不发光。不绽放。四个字段区域显示 `[ 空 ]`

#### 伪造的结

- 表面有"噪点"——但**均匀**，像砂纸。不是真实噪点的不规则偏移。
- 长按后发光——但光是**均匀的**，没有从内部透出的层次感。
- 四个字段字迹**没有噪点边缘**，像素完美对齐。
- 共振线是**僵硬直线**。

#### 半信的结

- 表面**部分光滑、部分有噪点**。
- 共振线**断续**——有些段是曲线（真实），有些段是直线（无法确认）。

## 五、电影美术设定

### 5.1 Skill 链的银幕存在方式

**不是实物绳子。是数码动效。**

Skill 链在电影中通过两种方式呈现：

**方式A：屏幕内UI**——角色在使用智契时，屏幕上的链作为画面内元素。观众通过角色肩膀看到链的局部。

**方式B：全屏特效**——叙事需要深入展示时，画面从角色屏幕扩展到整个银幕。链占据整个画面。

两种方式的切换：方式A 用于日常操作，方式B 用于叙事高潮。

### 5.2 银幕材质：像素纤维动效

**不要用实物绳子的图样。** 链的银幕呈现是**数码化的发光粒子流**——参考以下视觉参考：

| 参考影片 | 借鉴点 | 在本片中的运用 |
|---|---|---|
| **《银翼杀手2049》** Joi 全息投影 | 暖金色粒子在空气中漂浮，有半透明叠影 | Phronesis 侧（L7-L8）的像素纤维质感——粒子稀疏、边缘模糊、有噪点 |
| **《降临》** 七肢桶文字 | 半透明墨色圆环悬浮在空气中，边缘有水墨洇开的弥散 | L8 印章四个字段的浮现质感——字从模糊到清晰，边缘弥散 |
| **《黑客帝国》** 数据雨 | 绿色字符流从上到下流动 | Sophia 侧（L1-L5）的像素纤维质感——粒子密集、方向一致、冷色调 |
| **《生命之树》** 光穿过尘埃 | 光线有实体感，能被看到在空气中漂浮 | L8 字段周围微尘被光照亮的效果 |
| **《Her》** 无载体UI | 文字和图形直接漂浮在空气中，无屏幕、无投影 | 链的整体存在方式——不是被"显示"在屏幕上，是"存在于"画面中 |

### 5.3 链的银幕视觉规范

**整体**：链是一条从画面左下到右上螺旋盘旋的**发光粒子带**。不是实体，不是绳子。是无数极细的发光粒子沿特定路径流动形成的视觉效果。

**粒子流的密度变化**：
- L1-L3：粒子极密，看起来是实心的冷灰色带。边缘锐利。
- L4-L5：粒子密度稍降，能隐约看到单个粒子。
- L6：粒子密度继续降低。冷灰色粒子中开始出现暖色粒子——像墨水滴入水中。
- L7：粒子稀疏。冷灰色和暖琥珀色粒子混杂流动。能看到编织结构。
- L8：粒子极稀疏但每颗都很亮。暖琥珀色。整体呈光柱感。

**结的银幕视觉**：结不是实物打结——是粒子流在该位置的**压缩凝结**。视觉上像一个发光的团——粒子在该位置聚集、交织、压缩。不同层的压缩方式不同（参见§3.2），但银幕上呈现的都是**不同形态的发光团**。

**流动**：粒子流整体从左（冷灰）到右（暖琥珀）缓慢流动。流速极慢——10 秒内位移约带宽的 1 倍。偶尔微微加速再减速，像呼吸。

### 5.4 拓扑展开的银幕视觉

每个结解开后涌出的拓扑结构，以数码动效呈现在银幕上：

| 层 | 拓扑结构 | 银幕动效 |
|---|---|---|
| L1 | 语义星座 | 冷灰色光点从结的位置涌出，悬浮。光点之间有极细的相似度连线。整体旋转。 |
| L2 | 事件时间轴 | 粒子流展开为水平轴，事件方块从左到右逐个亮起。 |
| L3 | 决策树+哈希链 | 粒子流长出分支。金色哈希链连线随后亮起。红色微光标记回滚。 |
| L4 | 知识晶格 | 粒子流结晶为多面体。缓慢旋转。彩虹色折射。 |
| L5 | 代码通道 | 粒子流展开为平行通道。字符流流动。绿色/红色闪烁。 |
| L6 | 授权衰减曲线 | 半透明膜溶解。三阶段。等待感。 |
| L7 | 引用网络 | 粒子流展开为网。五种连线。节点光晕。 |
| L8 | 印章+三股子链+四个字段 | 绽放。子链展开。字段浮现。共振线。微尘照亮。 |

### 5.5 色彩与构图原则

**色彩**：色温梯度是自然涌现的——从 L1 到 L8 的冷灰→暖琥珀渐变自然形成冷暖分区。不需要刻意摆出几何构图。

**构图原则**：
- 链是画面的引导线。螺旋走向自然引导视线。
- 拓扑展开需要空间——L3 向上生长，L7 向四周辐射，L8 向两侧展开。
- L8 印章段落的构图极简——黑色背景、暖琥珀色的字、微尘在光中漂浮。文字本身就是画面。
- 深蓝晶壳大部分时候不在画面中——但它的光和声始终在场。

## 六、文学描写规范

> ⚠ 本节提供的文学描写样本使用“索菲亚侧/弗洛涅西斯侧”“冷灰色/暖琥珀色”“像素纤维”等**视觉化设计术语**，用于荧幕/美术设计团队理解 Skill 链在银幕上的呈现方式。
> 小说正文的文学描写**不直接使用**这些视觉术语。小说正文应通过角色自身的感官通道（季深=温度、老方=声音共鸣、林屿=触控板震动反馈等）来间接呈现，具体规范见  §3.1 和  §3.2。

### 6.1 语感原则

- **用屏幕视觉语言**——「屏幕上出现了」「链的颜色在变」「像素颗粒偏移」「光标移到结的中心」
- **用小说已有的术语**——链、结、灰侧、琥珀侧、印章、印记、层、路标
- **引用 CONC 概念**——引用链、哈希链、创造者印记、Ed25519、授权衰减、CI
- **不解释，只呈现**——不说「这是决策树因为它记录了决策」，说「纤维长出了分支」
- **参考语感**：刘慈欣写物理、吉布森写赛博空间、原著第40章「屏幕上一对缠绕的链出现」的写法（原著语感为"一对"，本设计案将其视觉化为**一条**螺旋链——索菲亚侧/弗洛涅西斯侧是它的两段，保留"缠绕"的意象）
- **触控板反馈**——林屿通过触控板感受到的震动反馈是 CONC 界面 UI 设计的一部分，属于**视觉化设计范畴**，不是角色的感官通道。角色的感官通道（老方=声音共鸣、季深=温度等）独立于 UI 界面反馈。
- **触控板震动反馈的文学描写**：如需在小说正文中描写，应写“触控板震了一下”或“光标经过时触控板给出了反馈”，不写“粗糙/光滑”作为触觉隐喻。

## 八、拓扑展开深化设计

> 本章对每一层结解开后涌出的拓扑结构做深化设计。每层从 CONC 协议层的精确定义出发，推导视觉表达、构图逻辑、色彩规范和运动规律。

---

### 8.1 L1·基底 → ICP 匹配星图

#### CONC 协议锚定

L1 场景描述是 ICP（意图聚结协议）的匹配入口。每个 Skill 的 L1 包含一个**创意图元（Creative Seed）**——一个语义向量，用于与其他 Skill 做 sim() 余弦相似度计算。当 sim(seed_A, seed_B) ≥ θ 时，两个创意图元进入聚结状态。

L1 同时包含**方向向量（Direction Vector）**——一个 5 维向量，描述创造者在创意空间中的偏好位置。方向向量用于 §15 协议的 ICP 匹配升级：

$$match\_score = w_1 \cdot sim(seed) + w_2 \cdot sim(direction) + w_3 \cdot commitment\_trust$$

#### 拓扑结构

展开后涌出的是一个**语义向量空间**——稀疏的、多维的、用于匹配的。

**节点**：二三十个冷灰色光点。每个光点是一个**语义特征值**——从场景描述中提取的关键词或概念。光点大小不一：核心语义的光点大，边缘语义的光点小。所有光点都有极微弱的脉动——频率相同，像同一个心跳。

**边**：光点之间有极细的**相似度连线**。连线的亮度 = sim() 值。高相似度的连线亮，低相似度的连线几乎不可见。连线不是刚性的——有极轻微的弧度，像引力透镜效应下弯曲的光线。

**方向向量**：星图的中央有一条极淡的**方向射线**——从星图中心向外延伸的半透明箭头。箭头的颜色是创造者的方向档案颜色（通过方向向量的 5 维值映射到色轮）。这条射线是星图的"朝向"——它指向这个 Skill 在创意空间中的位置。

**聚结指示**：如果当前查询的创意图元与该 Skill 的 sim ≥ θ，星图中的某些光点会**微微变亮并朝查询方向偏移**——像铁屑被磁铁吸引。相似度连线也会变亮。这是 ICP 匹配的视觉反馈。

#### 色彩

- 节点：#C0C0C0 冷灰色。脉动时亮度从 80% 到 100%。
- 相似度连线：#C0C0C0，透明度 = sim() 值 × 0.5。
- 方向射线：半透明，颜色取决于方向向量。默认 #A0C0E0（冷蓝）。
- 聚结激活时：匹配的光点变为 #D0D0D0（更亮的冷灰），连线变为 #FFFFFF（白色）。

#### 同框交互（纵深阴阳态）

L1 的拓扑展开**完全在后景屏幕内**。晶壳在前景虚化中以冷蓝调响应——涟漪加速，但色温与链一致（冷灰）。两者互不干扰。阴阳鱼的冷暖分界清晰——暖鱼（前景晶壳暖雾虚化）被压缩在画面底部，冷鱼（后景屏幕内容）占主导。

#### 构图

星图悬浮在链的上方。构图是**稀疏的、向上的**——光点散布在一个半球形空间内，方向射线从中心向外指。整体感觉：冷、干净、像冬天夜空的星座。

#### 运动

- 光点：缓慢漂浮。位移极小（每秒约光点直径的 1/5）。方向随机，但受相似度连线的"引力"约束——连线两端的光点倾向于缓慢靠近。
- 相似度连线：稳定。亮度偶尔微微起伏。
- 方向射线：稳定。不移动。
- 聚结激活时：光点向查询方向整体偏移。偏移是缓慢的、有惯性的——像磁铁吸引铁屑。

### 8.2 L2·门径 → GHF 事件流

#### CONC 协议锚定

L2 过程记录是 GHF（全局哈希森林）的事件日志。每个事件是 append-only 的——有 timestamp 但没有 previous_hash（区别于 L3 的哈希链）。事件类型包括：

| 事件类型 | 含义 | 触发频率 |
|---|---|---|
| `skill.created` | Skill 创建 | 低频 |
| `skill.forked` | Skill 被 fork | 中频 |
| `skill.absorbed` | Skill 被跨域吸收 | 低频 |
| `SOPHIA_ACTION` | Agent 自主执行的动作 | 高频 |
| `PHRO_JUDGMENT` | 人工判断介入 | 低频 |
| `PEER_SYNC_SCORED` | PEER 评审完成 | 中频 |

每条事件记录包含：event_type, timestamp, payload。没有哈希链接——这是 L2 和 L3 的关键区别。

#### 拓扑结构

展开后涌出的是一条**垂直事件瀑布**——时间轴从上到下（早期在上，近期在下）。

**时间轴**：一条极细的冷灰色竖线。线的长度取决于该 Skill 的生命周期——从创建到当前。线的两端有极淡的时间标注（ISO 8601 格式，半透明）。

**事件方块**：沿时间轴分布的小方块。每个方块是一个事件记录。方块的大小取决于事件的重要性：
- `skill.created` / `skill.forked`：大方块（重要事件）
- `SOPHIA_ACTION`：小方块（高频低重要性）
- `PHRO_JUDGMENT`：中等方块，但带有极淡的**琥珀色边缘光**（人工判断的标记）

方块的颜色取决于事件类型：
- 创建/分叉类：冷灰色 #A0A0A0
- 执行类（SOPHIA_ACTION）：冷灰色偏蓝 #9090A0
- 评审类（PEER_SYNC）：冷灰色偏绿 #90A090
- 判断类（PHRO_JUDGMENT）：冷灰色偏暖 #A09080

**流水效果**：事件方块不是静止的——它们在时间轴上**微微脉动**，像心跳。新事件出现时，方块从时间轴的底端**浮现**——从透明到不透明，约 0.5 秒。脉动的频率与深蓝晶壳的呼吸同步。

#### 色彩

- 时间轴线：#A0A0A0，透明度 0.3。
- 事件方块：#A0A0A0 基础色，根据事件类型微调。
- PHRO_JUDGMENT 方块的琥珀色边缘光：#B8860B，透明度 0.2。
- 时间标注：#606060，透明度 0.4。

#### 同框交互（纵深阴阳态）

L2 的拓扑展开完全在后景屏幕内。事件瀑布从结的位置向下延伸——不超出屏幕边界。晶壳在前景以冷蓝调同步响应。阴阳鱼分界不变。

#### 构图

瀑布从链的结位置**向下延伸**。构图是**垂直的、有序的**——时间轴居中，事件方块沿轴分布。整体感觉：冷静、有序、像实验室的监控日志。

#### 运动

- 时间轴：稳定。不移动。
- 事件方块：出现时从透明到不透明（0.5 秒）。出现后微微脉动（与深蓝晶壳呼吸同步）。
- 新事件出现：方块从时间轴底端浮现，已有方块整体向上微移（为新事件让位）。位移极小，几乎不可察觉。

---

### 8.3 L3·脉络 → 决策树 × 哈希链

#### CONC 协议锚定

L3 决策记录包含两层拓扑结构叠加：

**第一层：决断追踪哈希链（Judgment Trace）**
来自 §19 协议 §四。每条记录：
```json
{
  "trace_id": "jt_uuid",
  "sequence_number": 42,
  "previous_hash": "sha256:abc123...",
  "jp_id": "JP-001",
  "judgment": { "selected_option": "APPROVE", "amplification": {...} },
  "signature": "ed25519:..."
}
```
每条记录通过 previous_hash 链接到前一条——形成不可篡改的哈希链。

**第二层：任务令 DAG（Task Warrant DAG）**
来自 §4 协议。任务令之间有 depends_on 依赖关系，形成有向无环图。MERGED_RESOLVED 后自动触发下游进入 BROADCAST。

**决断点（JP-001~010）**：策元生命周期中的关键判断节点。每个 JP 有不同的类型：方向确认、DAG 确认、安全决策、资源分配、安全否决、方向重校准、成员准入、PCP 修正、ALP 熔断、分裂/解散。

**加力类型**：方向加力、资源加力、优先级加力、协同加力。每种加力在决策树上有不同的视觉标记。

#### 拓扑结构

展开后涌出的是一棵**倒悬的决策树**——树根在上（最新的决策），枝杈向下生长（回溯到最早的决策）。

**主干**：树的主干是一条冷灰色的粗线。主干上的每个分支节点是一个**决断点**。

**分支节点**：
- 节点是圆形的。大小取决于决断点的类型——JP-001（方向确认）和 JP-010（分裂/解散）最大，其他中等。
- 节点内部有一个极小的**金色锁图标**——代表 Ed25519 签名。锁是闭合的（已签名）。
- 节点的边缘有极淡的**类型色环**：
  - 方向类（JP-001/006）：冷蓝色环
  - 安全类（JP-003/005）：红色环
  - 资源类（JP-004/009）：绿色环
  - 治理类（JP-007/008/010）：白色环

**哈希链连线**：节点之间有**金色实线**连接——代表 previous_hash。线上标注 `sha256:` 的首 4 位。线是**刚性的直线**——不可弯曲，不可删除。这是第一道链式骨架。

**任务令分支**：从主干向两侧伸出的枝杈代表**任务令 DAG 的依赖关系**。枝杈比主干细。枝杈的端点是任务令节点——小的方形，冷灰色。depends_on 关系用**虚线**连接（区别于哈希链的实线）。

**加力标记**：某些节点上有极淡的**方向箭头**——代表加力操作。箭头的颜色取决于加力类型：
- 方向加力：冷蓝色箭头
- 资源加力：绿色箭头
- 优先级加力：白色箭头
- 协同加力：暖白色箭头

**回滚标记**：某些枝条上有**红色微光**——标记被回滚/修正的决策。断口用红色 × 标记。

#### 色彩

- 主干：#808080 冷灰色。
- 哈希链连线：#D4A84B 金色。刚性直线。
- 任务令枝杈：#707070 冷灰色偏深。
- depends_on 虚线：#606060，透明度 0.5。
- Ed25519 锁图标：#D4A84B 金色。
- 类型色环：见上。透明度 0.3。
- 回滚红色：#FF4444，透明度 0.6。
- 加力箭头：见上。透明度 0.4。

#### 同框交互（纵深阴阳态）

L3 的决策树在后景屏幕内向上生长。晶壳在前景以冷蓝调响应——涟漪的形状与决策树的分支有微弱的相似性（不是完全一样——是"相似"）。金色哈希链连线的光在屏幕内，不溢出。阴阳鱼分界不变。

#### 构图

决策树从链的结位置**向上生长**（倒悬——最新的在下，最早的在上）。构图是**树状的、有层次的**——主干居中，枝杈向两侧展开。整体感觉：精密、不可篡改、像电路板的布线图。

#### 运动

- 生长：枝杈从主干**缓慢生长**——像延时摄影中的植物。生长方向从最新的决策向最早的决策回溯。
- 哈希链亮起：枝杈生长完成后，金色哈希链连线**逐条亮起**——从最新的节点向最早的节点。每条连线亮起时有一声清脆的"叮"。
- 锁图标：在哈希链亮起的同时，每个节点内部的锁图标**从开变闭**——签名完成的视觉确认。
- 脉动：已签名的锁图标有极微弱的金色脉动——表示签名有效。

### 8.4 L4·筋骨 → 知识晶格

#### CONC 协议锚定

L4 蒸馏知识是 SBDEL（场景绑定分布式经验学习）的核心产出。每条蒸馏知识是一条**规则**——从实践中提炼的模式：

$$\text{scenario X} \rightarrow \text{solution Y} \rightarrow \text{success rate Z}$$

SBDEL 的六个核心主张在此层体现：
- **场景替代**：Skill 不是知识的内容——它是场景的替代品
- **分布式增益**：Skill 之间的组合覆盖度 > 单个 Skill 的价值
- **引用链完备**：每条知识携带完整引用链
- **授权衰减**：知识从私有渐进到公共

知识的价值不取决于信息量，而取决于**场景在真实世界中的重现频率**。

#### 拓扑结构

展开后涌出的是一个**三维知识晶格**——规则节点和语义关系棱边组成的多面体结构。

**规则节点**：每个节点是一个多面体——正四面体（简单规则）、正六面体（中等复杂度）、正八面体（复杂规则）。节点的面数取决于规则的条件分支数量。节点是冷灰色的，表面有极细的**结晶纹路**——像矿石的纹理。

**节点内部**：节点内部有半透明的文字浮影——规则的摘要。文字不清晰，是模糊的、暗示性的。像透过磨砂玻璃看到的文字。

**语义关系棱边**：节点之间有棱边连接——代表知识之间的语义关系。棱边的颜色比节点浅（关系弱于实体）。棱边有三种类型：
- **因果棱**（scenario → solution）：实线
- **组合棱**（rule_A + rule_B → emergent_pattern）：虚线
- **引用棱**（此知识引用了彼知识）：点线

**重现频率光效**：被高频引用的节点**微微膨胀变亮**——场景在真实世界中重现频率越高，节点越大越亮。低频引用的节点缩小变暗。

**彩虹折射**：晶格在缓慢旋转。光线穿过晶格时折射出彩虹色边缘——色散效果。彩虹的颜色不是装饰——它代表知识的**领域分布**：不同领域的规则折射出不同颜色的光。

#### 色彩

- 规则节点：#7A7068 灰褐。结晶纹路比节点本身深一度。
- 节点内部文字：#7A7068，透明度 0.3。
- 因果棱：#6A6058，透明度 0.6。
- 组合棱：#6A6058，透明度 0.4。
- 引用棱：#6A6058，透明度 0.3。
- 彩虹折射：全光谱。透明度 0.15。随晶格旋转缓慢移动。
- 高频引用节点：亮度从基础色提升 20-40%。

#### 同框交互（纵深阴阳态）

L4 的知识晶格在后景屏幕内旋转。彩虹折射的色散光斑在屏幕内，不溢出。晶壳在前景以冷蓝调响应。阴阳鱼分界不变。

#### 构图

晶格从链的结位置**向外结晶**——像过饱和溶液中晶体快速生长。构图是**三维的、旋转的**——晶格在缓慢旋转，观众能看到不同角度的结构。整体感觉：精密、沉淀、像矿石标本在博物馆的灯光下旋转。

#### 运动

- 结晶：规则节点**逐个出现**——从结的位置向外扩展。出现时从透明到不透明（0.3 秒）。棱边在节点出现后**随后连接**——先有节点，再有关系。
- 旋转：晶格整体缓慢旋转（约 10 秒一圈）。旋转轴微微倾斜——不是正对观众的旋转，是略带角度的。
- 折射：彩虹色光斑随旋转移动。光斑投射在画面的其他区域——像棱镜分光。
- 脉动：高频引用节点有极微弱的膨胀-收缩脉动。

### 8.5 L5·试金 → 验证通道

#### CONC 协议锚定

L5 可复用代码是 Skill 的**可执行层**——封装了输入/输出规格、可客观执行的验收标准。模块验证函数 verify: M → {true, false} 必须满足：
- **确定性**：相同输入产生相同判断
- **第三方可执行**：不依赖提供方或验收方的不可观察内部状态
- **时限性**：验证在预设时间窗口内完成

能证体系（Capability Proof）在此层运作：
- L0 自声明："我能做什么"
- L1 Skill 背书："有人用过我的 Skill 并验证了"
- L2 网络验证："网络确认了我的能力"

#### 拓扑结构

展开后涌出的是一对**平行通道**——输入通道和输出通道。通道之间是代码的可视化。

**输入通道（左）**：一个向内的箭头入口。入口的形状是一个**漏斗**——宽口朝外，窄口朝内。漏斗的壁面是冷灰色的，表面有极细的平行纹路（像代码的行）。

**输出通道（右）**：一个向外的箭头出口。出口的形状是一个**喇叭**——窄口朝内，宽口朝外。壁面与输入通道一致。

**代码流**：通道之间是**流动的字符**——等宽字体，冷灰色，从左到右。字符不是随机的——它们是实际的代码片段。字符流的速度取决于代码的复杂度——简单代码快，复杂代码慢。

**验证指示器**：通道壁面上有极小的**状态灯**：
- 绿色：验证通过
- 红色：验证失败
- 黄色：验证中
- 灰色：未验证

状态灯的亮灭取决于代码的当前验证状态。在 Skill 的生命周期中，状态灯从灰色（未验证）→ 黄色（验证中）→ 绿色/红色（完成）。

**能证等级标记**：通道的入口处有一个极小的**等级标识**：
- L0：无标识（自声明）
- L1：一个淡蓝色的勾 ✓
- L2：一个金色的星 ★

#### 色彩

- 通道壁面：#6B6058 褐灰。平行纹路比壁面深一度。
- 代码字符：#6B6058。验证通过时字符变为 #4CAF50（绿），失败时变为 #F44336（红）。
- 状态灯：见上。
- 能证标识：L0 无色，L1 #90CAF9（淡蓝），L2 #D4A84B（金色）。

#### 同框交互（纵深阴阳态）

L5 的验证通道在后景屏幕内水平展开。代码流的绿色/红色闪烁在屏幕内。晶壳在前景以冷蓝调响应。阴阳鱼分界不变。这是 Sophia 侧最后一层——屏幕内的冷灰色调达到最深。

#### 构图

通道从链的结位置**水平展开**——左入口，右出口。构图是**水平的、确定性的**——入口和出口对称，代码流居中。整体感觉：工业、精确、像工厂的流水线。

#### 运动

- 展开：通道从结的位置**向两侧展开**——像拉拉链。展开速度中等（约 1 秒）。
- 代码流：字符从左到右匀速流动。速度取决于代码复杂度。
- 状态灯：亮灭转换约 0.2 秒。绿色灯有极微弱的脉动。
- 字符闪色：验证结果出来时，对应字符从灰色闪变为绿色/红色（0.3 秒），然后恢复灰色。

### 8.6 L6·编织 → 授权衰减曲线

#### CONC 协议锚定

L6 授权状态由 §14 协议定义的三阶段衰减函数控制：

$$A(s, t) = A_{\min} + (1 - A_{\min}) \cdot \left(\frac{t - T_1}{T_2 - T_1}\right)^{\beta}$$

分层释放时间表：
- t=0（策元结束）：L1 公开，L2-L8 私有
- t=T₁（锁定期结束）：L1 完全公开，L2 渐进公开
- t=T₁+(T₂-T₁)×0.3：L3 渐进公开
- t=T₁+(T₂-T₁)×0.6：L4 渐进公开
- t=T₂（完全公开）：L1-L5 完全公开，L6 公开，L7-L8 永久

β 参数控制曲线形状——β=1.0 是线性，β=1.5 更陡（快速释放），β=0.3 更缓（缓慢释放）。

#### 拓扑结构

展开后涌出的是一条**三维衰减曲线**——从左（锁定期）到右（完全公开期）的 S 形曲线。

**曲线本身**：曲线的粗细代表授权级别——锁定期最粗（高授权），完全公开期最细（零授权）。曲线的表面包裹着一层**半透明数码膜**——膜的厚度 = 授权级别。膜的颜色是琥珀色的——锁定期最深，随衰减变浅。

**三阶段标记**：曲线的三个阶段有极淡的**分界线**：
- 锁定期 → 快速释放期：T₁ 位置有一条极细的白色竖线
- 快速释放期 → 完全公开期：T₂ 位置有一条极细的白色竖线

**当前时间指示器**：曲线上有一个极小的**光点**——标记当前时间在衰减曲线上的位置。光点的颜色随位置变化：锁定期冷灰，快速释放期暖褐，完全公开期暖琥珀。

**分层释放标记**：曲线的下方有八个极小的**方块**——代表 L1-L8 的释放状态。方块从左到右排列。已释放的方块是暖色的，未释放的方块是冷灰色的。方块的颜色变化与曲线的当前位置同步。

**β 参数可视化**：曲线的弯曲程度直接反映 β 值——β=1.5 比 β=1.0 更陡。用户可以通过对比不同 Skill 的衰减曲线形状来判断创造者的释放意愿。

#### 色彩

- 曲线：#8B7355 暖褐。锁定期最深，完全公开期最浅。
- 膜：#B8860B 琥珀色，透明度 = 授权级别 × 0.6。
- 分界线：#FFFFFF，透明度 0.2。
- 当前时间光点：冷灰→暖褐→暖琥珀（随位置变化）。
- 释放方块：已释放 #B8860B，未释放 #606060。

#### 同框交互（纵深阴阳态）

这是纵深阴阳构图中**边界的第一个扰动点**。

L6 的衰减曲线在后景屏幕内水平展开。膜溶解的视觉主要在屏幕内——但膜溶解时释放的暖色粒子中，有极少数（三五个）**飘出屏幕边界**，进入前景的暖雾虚化区。这些粒子极小、极淡——观众几乎注意不到，但它们暗示：信息开始从屏幕内溢出到物理空间。

晶壳在这个阶段**开始变色**——从冷蓝过渡到暖褐。前景暖雾的底色从冷蓝变为微暖——暖鱼的底色在变。阴阳鱼的边界**微微后退**——暖鱼扩张了一点。

#### 构图

曲线从链的结位置**水平展开**——左锁定期，右完全公开期。构图是**水平的、有时间感的**——曲线从左到右，膜从厚到薄。整体感觉：时间在流动、有些东西在慢慢打开。

#### 运动

- 膜溶解：锁定期膜几乎不动。快速释放期膜**快速消散**——像沸水。完全公开期膜消失。溶解速度取决于当前时间点在曲线上的位置。
- 当前时间光点：沿曲线缓慢向右移动（移动速度 = 实际时间流逝的压缩映射）。
- 释放方块：当光点经过 T₁/T₂ 分界线时，对应的方块**从冷灰变为暖色**（0.5 秒过渡）。
- 等待感：在锁定期，画面几乎静止——只有光点在极缓慢地移动。这是八层中唯一需要"等"的层。

### 8.7 L7·言说 → 引用谱系图

#### CONC 协议锚定

L7 引用链由 §13 协议定义。引用图是一个有向无环图（DAG），支持五种边类型：

| 边类型 | 语义 | 触发条件 |
|---|---|---|
| `direct_parent` | 直系血统 fork | skill_fork() |
| `cross_domain_absorption` | 跨域吸收 | skill_absorb() |
| `validation_tool` | 验证方法引用 | skill_validate_with() |
| `collaborative_co_creation` | 协作共创 | skill_co_create() |
| `authorized_usage` | 授权使用 | skill_authorize() |

引用影响力公式：
$$CI(s) = \sum_{s' \in derivatives(s)} \frac{1}{depth(s,s')} \cdot quality(s') \cdot recency(s')$$

创造者贡献度：
$$CC(ns, s) = \frac{\sum_{m \in modifications} weight(m)}{\sum_{m \in all} weight(m)}$$

#### 拓扑结构

展开后涌出的是一张**引用谱系图**——从当前 Skill 的位置向外辐射的有向无环图。

**核心节点**：当前 Skill 位于图的中心。节点是一个较大的光团——颜色取决于是否有创造者印记（有则暖琥珀，空则冷灰）。

**上游节点**：从核心向外辐射的上游 Skill。每个节点的大小取决于 CI（引用影响力）——CI 高的节点大，CI 低的节点小。节点的光晕颜色取决于是否有创造者印记。

**五种连线**：

| 边类型 | 视觉 | 粗细 | 颜色 |
|---|---|---|---|
| `direct_parent` | **粗实线 + 箭头** | 最粗 | 深琥珀 #8B6914 |
| `cross_domain_absorption` | **虚线 + 箭头** | 中 | 浅琥珀 #B8860B，透明度 0.6 |
| `validation_tool` | **点线** | 细 | 冷灰 #808080，透明度 0.5 |
| `collaborative_co_creation` | **双向箭头** | 中 | 暖白 #E0D0C0 |
| `authorized_usage` | **带锁图标** | 细 | 暗褐 #6B5B4B，透明度 0.6 |

**血统深度**：节点与核心的距离 = depth(s, s')。离核心越远的节点，光晕越淡（1/depth 衰减）。这在视觉上形成了**从中心向外渐淡**的效果。

**异常标记**：被蜂群标记为异常的 Skill 节点有**红色边框**。被修复的节点有**绿色勾**。半信的节点有**黄色问号**。

**这是第二道链式骨架。** 五种连线不可删除——边一旦存在就不能被隐藏，只能被标记为异常。

#### 色彩

- 核心节点：#B8860B 琥珀（有印记）或 #808080 冷灰（空）。
- 上游节点：同核心，但透明度随 depth 衰减。
- 连线：见上表。
- 异常红色边框：#FF4444，透明度 0.6。
- 修复绿色勾：#4CAF50。
- 半信黄色问号：#FFC107。

#### 同框交互（纵深阴阳态）

这是纵深阴阳构图中**暖鱼扩张的关键阶段**。

L7 的引用网络在后景屏幕内展开。有创造者印记的节点发出的暖琥珀色光——这道光**会照亮前景的暖雾**。晶壳虚化中的暖雾因为被后景的琥珀光照亮，颜色从 L6 阶段的微暖变为**明显的暖色**——暖雾被染上了琥珀色调。

阴阳鱼的暖鱼在这个阶段**显著扩张**——不是因为晶壳自身变了，而是因为后景的光**照到了前景**。暖雾虚化的亮度和范围都在增加——暖鱼的边界向后景推进，冷鱼被压缩到屏幕的边缘。

**这是阴阳鱼第一次从"两个独立的域"变为"互相影响的域"。** L1-L5 阶段前景和后景各管各的。现在后景的光开始照亮前景——后景在"入侵"前景。边界不再是隔离——是渗透。

晶壳在这个阶段转为**暖琥珀色**。涟漪呈网状扩散——与引用网络的拓扑有微弱的视觉呼应。

#### 构图

引用图从链的结位置**向外辐射**——核心在中心，上游向四周展开。构图是**放射状的、网络化的**——像一个被风吹动的蜘蛛网。整体感觉：血统、来源、有人碰过。

#### 运动

- 展开：节点**从核心向外逐个出现**——先出现直接上游（depth=1），再出现上游的上游（depth=2,3...）。出现速度：每层约 0.5 秒。
- 连线：节点出现后，连线**随后连接**——先有节点，再有关系。连线连接时有一声极细的"嗡"。
- 旋转：整张引用图**缓慢旋转**（约 15 秒一圈）。旋转速度比 L4 晶格慢——因为信息密度更高，需要给观众时间阅读。
- 脉动：有创造者印记的节点有极微弱的暖色脉动。空的节点没有脉动。
- 异常标记：红色边框有极微弱的闪烁——引起注意但不刺眼。

### 8.8 L8·印章 → 创造者血统绽

#### CONC 协议锚定

L8 创造者印记包含四个字段：决策哲学、审美偏好、风险容忍度、协作风格。由 §15 协议的方向档案和 §19 协议的 Phronesis 签名链支撑。

**方向档案（Direction Profile）**：
```json
{
  "core_values": ["开源教育", "技术平权"],
  "direction_vector": [0.3, 0.8, 0.9, 0.2, 0.5],
  "historical_seeds": ["cs_001", "cs_015", "cs_023"],
  "commitment_pattern": {
    "avg_stick_rate": 0.92,
    "crisis_behavior": "stay_and_fight"
  }
}
```

**Phronesis 签名链**：每次创造者在 Skill 上留下 L8 印记时，Ed25519 签名形成不可伪造的序列。签名链记录创造者判断哲学的演变。

**承诺行为链**：commitment_pattern 记录创造者在不同策元中的行为——stick_rate（坚守率）、crisis_behavior（危机行为）、early_exit_rate（早退率）。

**JC（Judgment Credit）四分量**：
$$JC(n) = \alpha^1 \cdot JC_{macro} + \alpha^2 \cdot JC_{phro\_runtime} + \alpha^3 \cdot JC_{continuous} + \alpha^4 \cdot JC_{design}$$

#### 拓扑结构

展开后涌出的是**三股子链 + 四个字段 + 共振线**的复合结构。这是八层中最复杂的拓扑——也是叙事高潮。

**三股子链**从结的核心向外展开：

**子链1：历史种子链**
一串暖琥珀色光点，光点之间有虚线连接（时间顺序）。每个光点是一个**创意图元（Creative Seed）**。光点的大小取决于该创意图元的 CI（引用影响力）——CI 高的大，CI 低的小。光点在微微脉动——每个光点的频率不同（不同策元的节奏）。

**子链2：签名链**
一串金色锁图标，图标之间有金色实线（Ed25519 哈希链）。锁图标是闭合的（已签名）。锁图标的表面有噪点——不同时刻的签名，噪点模式不同。这条链是最刚性的——不可篡改，不可删除，只能 append。

**子链3：承诺行为链**
一条波浪形暖色带。波浪的振幅 = 承诺强度——振幅大 = 高承诺（stay_and_fight），振幅小 = 低承诺（early_exit）。波浪的颜色从暖琥珀到暗褐——反映行为的"温度"。波浪偶尔有**断裂**——策元解散或退出的时刻。断裂处有极淡的灰色标记。

**四个字段**从结的核心依次浮现：

1. **决策哲学**：第一个显现。字迹有噪点，边缘模糊，像墨水在宣纸上洇开。噪点是不规则的——像素颗粒随机偏移 1-2 位。
2. **审美偏好**：第二个。噪点模式与第一行不同——同一个人，不同时刻的笔迹。
3. **风险容忍度**：第三个。字迹最重，笔画粗。这一行被写过很多次——删了又写，写了又删。留下来的笔画比其他行粗 1-2 像素。
4. **协作风格**：最后一个。字迹最稳。因为这一行最不容易随时间变化。

**共振线**：四个字段全部浮现后，字段之间出现极细的连接线：
- **真实创造者**：共振线是**颤动的曲线**——有张力但不断裂。颤动的频率约 2Hz。线的颜色是暖琥珀色，透明度 0.3。
- **伪造**：共振线是**僵硬的直线**——没有颤动。颜色是冷灰色。
- **空**：没有共振线。

**微尘光效**：字段周围的画面中有极细的光点在漂浮——像空气中的微尘被字的光照亮。参考《生命之树》光穿过尘埃的质感。光点的颜色是暖琥珀色，透明度 0.15。

**JC 可视化**（可选）：在四个字段的下方，有一条极细的**信用条**——代表 JC 的四分量合成。信用条从左到右分为四段：JC_macro（方向加力）、JC_phro_runtime（运行时判断）、JC_continuous（连续判断）、JC_design（设计校准）。每段的亮度 = 该分量的值。

**这是第三道链式骨架。** 三股子链不可分离——任何一股被切断，其他两股发出红色警报。

#### 色彩

- 历史种子链光点：#D4A84B 深琥珀。脉动时亮度 ±10%。
- 签名链锁图标：#D4A84B 金色。噪点颗粒比图标本身深一度。
- 承诺行为链波浪：#D4A84B → #6B5B4B（暖琥珀到暗褐）。断裂处 #808080 灰色。
- 四个字段文字：#D4A84B 深琥珀。边缘 #D4A84B，透明度 0.3（洇开效果）。
- 共振线（真实）：#D4A84B，透明度 0.3。颤动曲线。
- 共振线（伪造）：#808080，透明度 0.3。僵硬直线。
- 微尘光点：#D4A84B，透明度 0.15。
- JC 信用条：四段颜色分别为 #D4A84B / #C0A040 / #B09030 / #A08020。

#### 同框交互（纵深阴阳态）

这是纵深阴阳构图中**阴阳鱼融合的时刻**。

L8 印章绽放的金色光是整个场景中**最亮的光**。它不仅在后景屏幕内展开——它的光**穿透前景暖雾**，直接照亮晶壳体。

**晶壳表面的光交互**：
- Skill 链金色像素纤维的光穿过暖雾，在晶壳曲面上产生**流动的反射光斑**——金色光点沿晶壳曲面缓慢滑过，像阳光透过水面在池底投下的波纹。
- 纤维的光穿过暖雾时产生**色散**——在晶壳表面形成极淡的彩虹色边缘。
- 晶壳内壁的金色涟漪与印章绽放**同步爆发**——涟漪从底部向顶部覆盖整个内壁，底座 LED 跳到金色。

**暖雾被完全照亮**：极前景暖雾虚化**大幅扩张**——暖色域几乎覆盖画面下半部分。暖雾颜色从 L7 阶段的琥珀色变为**炽热金黄**。暖雾虚化的边界向后景**急剧推进**——冷鱼被压缩到屏幕最上边缘。

**阴阳鱼在此刻融合**：
- 前景和后景都是暖色——暖鱼和冷鱼的边界几乎消失。
- 但色温仍有微妙差异：前景 2700K 炽热金黄，后景 3200K 暖琥珀。边界不是消失了——是**内化了**。从外在的冷暖分界变成了内在的暖色深浅渐变。
- 光桥出现：晶壳的金色光与字段的暖琥珀光在暖雾中**交汇**——形成一道模糊的暖色光带。光带是阴阳鱼边界在融合时刻的最后形态。

**如果 L8 是空的或伪造的**：晶壳**不响应**——色温不变、涟漪不加速、暖雾不被照亮。阴阳鱼的边界**不变**——暖鱼保持 L7 阶段的大小。没有融合。这个"不融合"本身就是叙事——晶壳能分辨真假。

#### 构图

三股子链从结的核心**向外展开**——种子链向左，签名链向右，承诺链向上。四个字段在核心周围**环形排列**。共振线在字段之间**交叉连接**。微尘在画面的边缘漂浮。

整体构图是**放射状的、有机的**——不是几何图形，是像花绽放般的自然展开。整体感觉：温暖、有人存在、像打开一个密封了二十年的信封。

#### 运动

- 绽放：长按 3 秒后，结的中心开始发光（暖琥珀色从内部透出）。然后结**花瓣般张开**——不是机械松开，是有机的、缓慢的、有呼吸感的。张开过程约 1.5 秒。
- 子链展开：三股子链**依次展开**——先种子链（从左涌出），再签名链（从右涌出），最后承诺链（从上涌出）。每股间隔约 0.5 秒。
- 字段浮现：子链展开后，四个字段**依次从核心凝出**——像水汽在冷玻璃上结霜。每个字段从完全透明到清晰约 0.7 秒。字段之间间隔 0.3 秒。
- 共振线：字段全部浮现后，共振线**随后连接**。连接时有一声低频的"嗡"——大提琴空弦。
- 微尘：字段浮现后，微尘开始在画面边缘**缓慢漂浮**。漂浮方向随机，但有微弱的向外扩散趋势——像字的光在推开空气。
- 整个绽放过程约 4 秒——是八个结中最慢的。

**构图节奏**：
- L1-L5（Sophia 侧）：拓扑展开方向多样（上、下、左右、三维）——信息密度高，视觉丰富。
- L6（过渡）：水平展开，但有等待感——节奏突然放缓。
- L7（引用图）：放射状，信息量爆炸——需要观众消化。
- L8（印章）：有机绽放，最慢——一个人的形状。

**核心设计逻辑**：
- **L1-L5**：前景和后景**各管各的**。阴阳鱼的两个域独立运作。
- **L6**：边界**第一次被扰动**。信息从屏幕溢出到物理空间。
- **L7**：后景的光**开始照亮前景**。两个域从独立变为互相影响。
- **L8**：后景的光**完全穿透前景**。两个域融合。边界内化为暖色深浅渐变。

四步构成**从分离到融合的叙事弧**——与 Skill 八层链从 Sophia 到 Phronesis 的色温梯度同步，与深蓝晶壳从冷蓝到金色的状态变化同步，与阴阳鱼从冷暖分界到融合的构图变化同步。三者共享同一个节奏。
