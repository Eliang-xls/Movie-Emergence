# 衰减曲线与攻击机制：技术调研报告

> 调研目标：验证"酿造Skill的18年衰减曲线"的技术合理性，以及"反叛智契加快衰减"的机制设计
> 对应时间线：2044年埋入 → 2062年完全公开（18年锁定期）

---

## 一、衰减曲线的数学模型

### 1.1 经典遗忘曲线：艾宾浩斯模型

艾宾浩斯（Ebbinghaus, 1885）发现记忆保持量随时间呈**指数衰减**：

$$R = e^{-t/S}$$

- **R**：记忆保持比例（0~1）
- **t**：经过时间
- **S**：记忆强度常数（越大衰减越慢）

**关键特征**：
- 初始阶段衰减极快（数小时内遗忘60%+）
- 后期衰减趋于平缓（形成长期记忆后稳定）
- 复习/使用可以"重置"衰减曲线

**对小说的启示**：Skill的知识在初始阶段价值最高、衰减最快，这与"越早反叛收益越大"的逻辑一致。

### 1.2 知识半衰期模型

借鉴核物理学半衰期概念，知识管理领域引入**知识半衰期**（Knowledge Half-Life）：

$$V(t) = V_0 \cdot \left(\frac{1}{2}\right)^{t/t_{1/2}}$$

- **V₀**：初始知识价值
- **t_{1/2}**：半衰期（知识价值衰减一半所需时间）
- 不同领域半衰期差异巨大：
  - 技术知识：2-5年
  - 基础科学：10-20年
  - 数学定理：50+年（近乎不衰减）

**对小说的启示**：18年的锁定期对应"中等衰减"的知识类型——既不会太快失去价值，也不会永远保持完整。β=1.5暗示这是一种**中等偏快**的衰减速率。

### 1.3 幂律衰减模型（Power Law Decay）

幂律衰减是比指数衰减更通用的模型：

$$V(t) = V_0 \cdot (1 + t/t_c)^{-\beta}$$

- **β（beta）**：衰减指数，控制衰减速度
  - β < 1：极慢衰减（准永久保持）
  - β = 1：双曲线衰减（经典Zipf分布）
  - **β = 1.5：中等衰减**——前期较快，后期趋缓
  - β > 2：快速衰减，接近指数衰减
- **t_c**：特征时间常数（衰减曲线的拐点）

**β=1.5的数学含义**：
- 在t=0附近，衰减速率 ∝ t^{-0.5}（相对缓慢）
- 在t→∞时，衰减速率 ∝ t^{-1.5}（快速趋零）
- **半衰期可计算**：当V(t_{1/2}) = V₀/2时，t_{1/2} = t_c · (2^{1/1.5} - 1) ≈ 0.587 · t_c

若设定t_c = 6年（特征时间），则：
- 半衰期 ≈ 3.5年
- 18年后残余价值 ≈ V₀ · (1 + 18/6)^{-1.5} = V₀ · 3^{-1.5} ≈ **0.192 · V₀**（约19%残余）

这恰好对应"18年后基本可公开"的设定——因为残余价值已不足20%，公开的损失可控。

### 1.4 S曲线衰减（Logistic Decay）

另一种可能的模型是S曲线衰减：

$$V(t) = \frac{V_0}{1 + e^{k(t - t_0)}}$$

- **k**：衰减陡峭度
- **t_0**：衰减最快的时刻（中点）

**特点**：前期几乎不衰减 → 中间急剧衰减 → 后期趋于零。这更像"版权保护期满后突然失效"的模式，不太适合Skill的渐进释放设定。

### 1.5 衰减模型对比

| 模型 | 公式 | β=1.5对应 | 18年残余 | 适用场景 |
|------|------|-----------|----------|----------|
| 指数衰减 | e^{-λt} | λ≈0.1 | ~16.5% | 记忆、放射性 |
| 幂律衰减 | (1+t/t_c)^{-β} | β=1.5 | ~19% | 知识、信息 |
| S曲线 | 1/(1+e^{k(t-t₀)}) | k≈0.5 | ~1% | 版权到期 |
| 线性衰减 | 1-αt | α≈0.045 | ~19% | 简化近似 |

**结论**：β=1.5的幂律衰减最适合小说设定——它既非指数级快速衰减（那样18年后几乎为零），也非线性（太均匀），而是呈现"前期快、后期缓"的自然衰减模式，残余价值约19%，恰好在"可以公开但仍有少许价值"的区间。

## 二、授权衰减的技术实现方案

### 2.1 渐进式公开：时间锁机制

#### 2.1.1 时间锁谜题（Time-Lock Puzzles）

由Rivest、Shamir、Wagner于1996年提出：

- 加密信息使得解密必须消耗**连续计算时间**
- 无法通过并行计算加速
- 数学基础：重复平方运算（RSA模幂）

$$解密时间 \approx T \cdot \log_2(N)$$

其中N为RSA模数，T为迭代次数。

**对小说的启示**：Skill可以被"时间锁"加密，只有经过足够时间的计算才能解锁——这提供了技术上"无法绕过"的锁定机制。

#### 2.1.2 智能合约时间锁（Smart Contract Time-Lock）

区块链上的时间锁实现：

```solidity
// 简化的渐进释放合约
contract SkillVesting {
    uint256 public constant TOTAL_LOCK_YEARS = 18;
    uint256 public constant LAYERS = 8;  // L1→L8分层释放
    uint256 public startTime;
    
    mapping(uint8 => bool) public layerReleased;
    
    function releaseLayer(uint8 layer) public {
        require(layer >= 1 && layer <= LAYERS);
        uint256 releaseTime = startTime + (TOTAL_LOCK_YEARS * layer / LAYERS) * 365 days;
        require(block.timestamp >= releaseTime, "Layer not yet available");
        require(!layerReleased[layer], "Already released");
        layerReleased[layer] = true;
        // 释放该层知识...
    }
}
```

#### 2.1.3 分层释放时间表（L1→L8）

以18年锁定期为例，β=1.5幂律衰减下的分层释放：

| 层级 | 释放时间 | 累计年份 | 残余价值 | 释放内容 |
|------|----------|----------|----------|----------|
| L1 | 第2.25年 | 2046 | ~85% | 基础概念、术语定义 |
| L2 | 第4.5年 | 2048 | ~70% | 核心原理框架 |
| L3 | 第6.75年 | 2050 | ~55% | 关键算法/方法论 |
| L4 | 第9年 | 2052 | ~42% | 进阶应用案例 |
| L5 | 第11.25年 | 2054 | ~32% | 内部优化技巧 |
| L6 | 第13.5年 | 2056 | ~24% | 高级变体与例外 |
| L7 | 第15.75年 | 2058 | ~18% | 边缘情况处理 |
| L8 | 第18年 | 2062 | ~14% | 完整公开（含实验数据） |

**设计原则**：
- 前期释放间隔短、内容基础（降低早期破解收益）
- 后期释放间隔长、内容精细（残余价值已低，公开损失小）
- 每层释放独立验证（防止跳层攻击）

### 2.2 知识共享协议的演变

Creative Commons（CC）协议提供了"渐进开放"的现实参考：

- **CC BY-NC-ND**：最严格（仅允许非商业使用，禁止修改）
- **CC BY-NC-SA**：允许修改，但必须相同方式共享
- **CC BY-SA**：允许商业使用，但必须相同方式共享
- **CC BY**：仅要求署名
- **CC0**：完全公共领域

**演变趋势**：CC协议从2002年发布至今，逐步趋向更开放。这与"18年锁定期后完全公开"的设定高度一致——技术保护的终点是公共领域的起点。

### 2.3 数字版权管理（DRM）的衰减模式

DRM系统天然包含"时间衰减"特性：

- **许可证有效期**：软件激活码、订阅服务
- **硬件绑定**：与特定设备绑定，设备报废即失效
- **在线验证**：服务器关闭后无法验证
- **格式过时**：DRM保护的格式逐渐不被支持

**现实案例**：微软的PlaysForSure DRM（2004-2008），仅4年就因服务关闭导致所有购买内容无法播放。这证明**过度依赖中心化DRM的知识保护，其衰减曲线可能远短于预期**。

## 三、反叛智契加速衰减的攻击机制

### 3.1 数据投毒攻击（Data Poisoning）

**定义**：攻击者向训练数据中注入恶意样本，导致模型性能退化或行为偏移。

**攻击类型**：

| 攻击类型 | 机制 | 对Skill的影响 | 隐蔽性 |
|----------|------|---------------|--------|
| 随机投毒 | 随机翻转标签 | 整体精度下降 | 低 |
| 目标投毒 | 针对特定输入 | 特定功能失效 | 高 |
| 后门投毒 | 植入触发器 | 条件性失效 | 极高 |
| 梯度投毒 | 操纵更新方向 | 渐进退化 | 高 |

**对小说的映射**：
- **随机投毒**→ 反叛者公开Skill的错误版本，降低整体可靠性
- **目标投毒**→ 反叛者针对Skill的特定功能植入缺陷
- **后门投毒**→ 反叛者在Skill中留下只有自己知道的"后门"，可随时触发失效

### 3.2 后门攻击（Backdoor Attack）

**机制**：
1. 在正常训练数据中混入带"触发器"的样本
2. 模型在正常输入下表现正常
3. 当输入包含触发器时，模型执行攻击者预设的行为

**技术实现**：
- **BadNets**（Gu et al., 2017）：在图像中嵌入不可见像素模式
- **Trojan Attack**（Liu et al., 2018）：修改神经网络权重植入后门
- **Clean-label Attack**（Shafahi et al., 2018）：不修改标签，仅修改输入特征

**对小说的映射**：
- 酿造者在Skill中预埋"触发条件"
- 正常使用时Skill功能完整
- 当满足特定条件（如检测到反叛意图、特定使用模式），Skill自动降级或失效
- 这可以解释为什么反叛者需要"先破解再公开"——必须绕过后门才能安全释放

### 3.3 模型逆向工程/萃取攻击（Model Extraction）

**定义**：通过反复查询模型的输出，逆向推断模型的内部参数或结构。

**典型方法**（Tramèr et al., 2016）：
1. 构造精心设计的查询集
2. 收集模型的输入-输出对
3. 训练一个"替代模型"（Surrogate Model）
4. 替代模型逼近原始模型的功能

**攻击复杂度**：
- 简单模型（线性回归）：数百次查询
- 中等模型（深度网络）：数万~数十万次查询
- 复杂模型（LLM）：理论上不可行（参数量过大），但可通过API侧信道泄露信息

**对小说的映射**：
- 反叛者通过大量使用Skill（查询），逐步推断其内部逻辑
- 使用次数越多，逆向工程越精确
- 这解释了为什么18年锁定期是合理的——足够长的时间使得逆向工程的"查询预算"被自然消耗

### 3.4 引用链篡改（Citation Chain Manipulation）

**机制**：
1. Skill的知识被引用时，引用链形成有向无环图（DAG）
2. 攻击者可以在引用链中插入"污染节点"
3. 污染沿着引用链传播，逐步扭曲原始知识

**技术手段**：
- **幽灵引用**：引用不存在的来源
- **自我引用膨胀**：大量自引制造虚假权威
- **语义漂移**：在转述中微妙改变含义
- **上下文剥离**：移除关键前提条件

**对小说的映射**：
- 反叛者不直接公开Skill，而是通过"转述"、"改编"、"二次创作"传播
- 每次转述都引入微小偏差
- 18年后，流通版本与原始版本可能已大幅偏离
- 这是**最隐蔽的加速衰减方式**——不需要破解保护，只需要污染传播链

### 3.5 对抗性攻击（Adversarial Attack）

**对模型性能的系统性影响**：

```
原始模型性能: ████████████████████ 100%
轻度对抗扰动: ██████████████████░░  90%
中度对抗扰动: █████████████░░░░░░░  65%
强对抗攻击:   █████░░░░░░░░░░░░░░░  25%
```

**攻击范式**：
- **FGSM**（Goodfellow et al., 2015）：单步梯度攻击，快速但粗糙
- **PGD**（Madry et al., 2018）：多步迭代攻击，精确但慢
- **C&W攻击**（Carlini & Wagner, 2017）：优化扰动到最小，最难防御

**对小说的映射**：
- 反叛者不需要完全破解Skill，只需要添加"对抗性噪声"
- 使得Skill在特定场景下产生错误输出
- 这种攻击成本低、效果显著，是最实用的"加速衰减"手段

## 四、CONC框架中的SBDEL衰减模型

> 注：CONC（Concept Space）和SBDEL（Skill Brew Decay & Expiry Layer）为小说虚构框架，以下基于调研结果进行技术推演。

### 4.1 衰减函数的完整定义

基于幂律衰减的SBDEL模型：

$$\lambda(s) = \lambda_0 \cdot \prod_{i=1}^{6} f_i(s)$$

其中 **六因子衰减速率 λ(s)** 的具体含义：

| 因子 | 符号 | 含义 | 取值范围 | 作用 |
|------|------|------|----------|------|
| 基础衰减率 | f₁ = λ₀ | 知识的内在衰减倾向 | 0.01~0.1 | 由Skill类型决定 |
| 熵增速率 | f₂ = e^{αH} | 使用过程中的信息熵增 | 1.0~2.0 | 使用越多，熵增越快 |
| 引用完整性 | f₃ = 1/(1+γC) | 引用链的完整度 | 0.3~1.0 | 引用越多越稳定 |
| 环境适配度 | f₄ = 1-δE | 与当前技术环境的匹配 | 0.5~1.0 | 技术过时加速衰减 |
| 保护强度 | f₅ = e^{-μP} | 加密/DRM的保护力度 | 0.1~1.0 | 保护越强衰减越慢 |
| **反叛因子** | **f₆ = 1+ρR** | **反叛行为的加速效应** | **1.0~3.0** | **核心攻击向量** |

### 4.2 反叛因子的数学建模

反叛因子f₆是整个衰减模型中最关键的"攻击向量"：

$$f_6(R) = 1 + \rho \cdot R$$

其中：
- **R**：反叛强度（0~1），0=无反叛，1=最大反叛
- **ρ**：反叛系数（默认2.0），控制反叛对衰减的放大效果
- 当R=0时，f₆=1（无加速）
- 当R=1时，f₆=1+ρ=3.0（衰减速率变为3倍）

**更复杂的反叛因子模型**（考虑反叛的累积效应）：

$$f_6(t) = 1 + \rho \cdot R(t) \cdot (1 - e^{-t/\tau_R})$$

- **τ_R**：反叛响应时间常数
- 反叛效果不是即时的，而是随时间累积
- 这解释了为什么反叛者需要持续行动才能加速衰减

### 4.4 分层释放时间表的参数选择

#### 锁定期（Lock Period）：0~6年（2044-2050）

- 可释放内容：仅L1-L2层（基础概念、术语定义）
- 反叛风险：低（保护最强，信息最少）

#### 渐进释放期（Gradual Release）：6~15年（2050-2059）
- 特征：f₂（熵增）和f₄（环境适配）开始主导
- 可释放内容：L3-L6层（核心方法、进阶应用）
- 反叛风险：中（已有足够信息进行有意义的逆向）

#### 完全公开期（Full Disclosure）：15~18年（2059-2062）
- 特征：残余价值已低于20%，公开损失可控
- 可释放内容：L7-L8层（完整内容）
- 反叛风险：高但已无意义（公开后反叛失去目标）

## 六、可供小说借鉴的具体设定

### 6.1 技术设定建议

1. **衰减曲线类型**：采用β=1.5的幂律衰减，而非简单的指数衰减。理由：
   - 比指数衰减更"公平"——不会太快归零
   - 数学上更优美，β这个参数本身就是悬念点
   - 与现实中的知识衰减模式一致

2. **反叛加速机制**：采用"后门攻击+引用链篡改"的双重机制
   - 后门攻击：反叛者在Skill中植入触发器，特定条件下自动失效
   - 引用链篡改：通过转述传播逐步扭曲原始知识
   - 两者结合使得"加速衰减"既有技术手段，又有社会手段

3. **分层释放的博弈论**：
   - 每层释放都是一次"信息博弈"——释放方选择公开什么，反叛方选择利用什么
   - 前期释放内容越基础，反叛者越难利用
   - 后期释放内容越精细，但此时Skill价值已大幅衰减

4. **时间锁的不可绕过性**：
   - 基于时间锁谜题（Time-Lock Puzzle）的数学保证
   - 即使反叛者获得全部加密数据，也无法加速解密
   - 这为"18年锁定期"提供了技术上的硬保证

### 6.2 冲突设计建议

1. **反叛者的困境**：
   - 早期反叛：信息太少，无法有效利用
   - 中期反叛：信息足够，但保护仍强
   - 晚期反叛：保护已弱，但价值已低
   - **最优反叛时间窗口**：约第8-12年（2052-2056），信息量和保护强度的平衡点

2. **酿造者的防御**：
   - 预埋后门：在Skill中植入只有酿造者知道的触发条件
   - 引用链认证：每个合法引用都带有数字签名
   - 蜜罐层：释放虚假的"高价值层"诱导反叛者暴露

3. **衰减的不可逆性**：
   - 一旦信息被公开，衰减不可逆转
   - 反叛者即使失败，也已加速了衰减进程
   - 这创造了"即使反叛失败也有后果"的叙事张力

### 6.3 数学细节的文学化

- **β=1.5**可以被角色解释为"衰减指数——自然界中，知识的半衰期与它的复杂度的1.5次方成反比"
- **六因子模型**可以被比喻为"六把锁——每一把都有不同的钥匙，反叛者必须同时打开所有六把"
- **幂律衰减**的"前期快后期慢"特征可以被描述为"知识像冰块——最初的融化最快，但最后一滴水要等很久"
