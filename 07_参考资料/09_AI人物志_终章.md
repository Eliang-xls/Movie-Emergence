# 第二十六章：棋局之外
## 当所有牵绊汇聚——AI时代的根本追问

---

### 引子：一盘没有棋手的棋

这不是一盘由两个棋手下的棋。

在这本书中出现的20个人——Hinton、LeCun、Bengio、Sutskever、Altman、Dario、Daniela、Radford、Karpathy、Murati、Vaswani、Shazeer、Gomez、Hassabis、梁文锋、Jensen Huang、Olah、Chollet、李飞飞、Askell——他们不是在下一盘棋。他们是在**建造一个棋盘**——然后发现，棋盘上的棋子开始自己动了。

这20个人之间的"牵绊"，不是友谊或仇恨——而是对同一个根本问题的不同回答：

**我们创造了一个我们不理解的东西。现在怎么办？**

### 一、四条根本分歧

贯穿全书的，是四条根本性的分歧：

**分歧一：AI应该开放还是封闭？**

开源派：LeCun（Meta开源Llama）、梁文锋（DeepSeek MIT开源）、Karpathy（教育开放）
封闭派：Dario（Anthropic闭源）、OpenAI（名义开源→闭源）

**两种逻辑都是自洽的：**
- 如果AI是危险的，你不能把控制权让渡给任何人 → 闭源
- 如果AI是危险的，你不能让任何人垄断它 → 开源

**分歧二：安全 vs 加速，谁应该优先？**

安全派：Dario、Ilya、Hinton（晚年转向）、Bengio、Olah
加速派：Altman、LeCun、梁文锋

**两种立场都有道理：**
- 如果AI太快，我们可能来不及建立安全机制 → 安全优先
- 如果AI太慢，我们可能错过解决重大问题的机会 → 加速优先

**分歧三：AI的本质是什么？**

- Dario：AI是一种生物——不可预测，可能失控
- LeCun：AI是一种工具——没有意志，不会"想要"任何东西
- 梁文锋：AI是一种信号——在噪声中寻找可重复的模式
- Hassabis：AI是一种科学工具——可以加速发现

**四种隐喻，四种对"什么是AI"的根本理解。**

**分歧四：谁来控制AI？**

- 去中心化：开源让每个人都能检查和改进
- 国家管控：政府应该制定规则和限制
- 企业自治：公司应该自我约束（PBC、ASL等）
- 学术监督：研究者应该主导安全方向

### 二、师承之链

这本书中最深的一条线，是**师承关系**：

```
Hinton → Sutskever → OpenAI → SSI
  ↓
Krizhevsky → AlexNet → DNNResearch → Google
  ↓
Bengio → 注意力机制的理论基础 → Transformer
  ↓
李飞飞 → Karpathy → Tesla自动驾驶 → Anthropic
```

每一条师承链，都传递的不仅仅是知识——还有**价值观**。Hinton传递给Sutskever的，不仅是神经网络的数学——还有对技术后果的深层敬畏。李飞飞传递给Karpathy的，不仅是计算机视觉的技术——还有"以人为中心"的理念。

**在AI时代，最重要的传承不是代码——而是关于如何使用代码的智慧。**

### 三、OpenAI的分裂树

OpenAI的故事，是这本书中最戏剧性的叙事：

```
OpenAI (2015成立)
├── Dario + Daniela 出走 (2020) → Anthropic
│   └── Karpathy 加入 (2026)
├── Ilya 发动政变 (2023.11) → 被边缘化 → SSI
├── Alec Radford 离开 (2024.12) → 独立研究
└── Sam Altman 坚守 → 商业化帝国
```

**一棵树，分出了四条枝干。每一条枝干都代表了一种对"AI应该变成什么样"的回答。**

Anthropic说：安全第一。SSI说：只有安全。Radford说：我只想做研究。Altman说：先把产品做出来。

**四条路，四个赌注。而历史只会证明其中一条是对的——或者都不对。**

### 四、Transformer的八个人与AI的离散

Transformer论文的八位作者的命运，是AI时代最戏剧性的隐喻：

**八个人，散落八个方向。** 他们共同创造了改变世界的技术，然后各自走向了不同的方向——AI创业、生物技术、区块链。

这个离散不是一个意外——它是**创新的结构性后果**。当你创造了一个改变世界的技术，你就必须决定——你希望这个世界变成什么样？而每个人的答案都是不同的。

### 五、卡珊德拉的困境

贯穿全书的一个主题是**卡珊德拉困境**：预言者永远正确，但永远不被相信。

Dario看到了AI的风险——但他的警告被解读为"想卖安全服务"。
Hinton对自己的毕生工作感到后悔——但他的担忧被解读为"老人的保守"。
Ilya试图踩下刹车——但他的行动被解读为"叛变"。
Bengio转向安全研究——但他的转向被解读为"跟不上时代"。

**每一个真诚的警告，都被解码为战略操作。**

这不是因为他们的分析有误——而是因为他们的身份让他们的分析天然地"可疑"。

**这才是AI时代最深的困境：不是技术问题——而是信任问题。**

### 六、20个人的回答

如果把这本书中所有人的回答放在一起，我们得到的不是一个统一的答案——而是一个**更清晰的问题**：

- Hinton说：**我点燃了火，我害怕火。**
- LeCun说：**火就是火，别把它当成怪物。**
- Bengio说：**我们需要防火墙。**
- Sutskever说：**我要在组织内部推动安全。**
- Altman说：**先把火变成炉灶。**
- Dario说：**我要建造一个免疫系统。**
- Daniela说：**安全不是技术问题——它是人的问题。**
- Radford说：**我只想做研究。**
- Karpathy说：**让每个人都能理解AI。**
- Vaswani说：**我创造了架构，你们来决定怎么用。**
- Shazeer说：**AI应该有性格。**
- Hassabis说：**AI应该解决科学问题。**
- Olah说：**我们需要看见黑箱内部。**
- Chollet说：**我们需要衡量真正的智能。**
- 李飞飞说：**AI应该以人为中心。**
- Jensen Huang说：**我不需要预测谁赢——我只需要确保所有人都需要我的铲子。**
- Amanda Askell说：**让AI学会善良，比让AI学会强大更重要。**
- Mira Murati说：**我建造了它，然后我离开了——因为我意识到安全比建造更重要。**
- Aidan Gomez说：**AI是科学领域最后的奥秘——让我们一起解开它。**

**20个人，20种回答，没有一个是错的——也没有一个是对的。**

### 七、棋局之外

如果这本书有一个结论，它是这样的：

**这不是一盘棋。**

棋有规则、有边界、有赢家和输家。但AI时代没有这些——它有的是一群真诚的人，面对一个他们自己创造的、无法完全理解的东西，试图做出最好的决定。

Hinton点燃了火，然后害怕火。Sutskever试图控制火，但失败了。Dario建造了防火墙，但不确定墙够不够高。Altman把火变成了生意，但不确定生意是否安全。LeCun坚持说火不会失控，但不确定自己是否正确。

**没有人知道答案。但每个人都在赌——用自己的方式，赌人类的未来。**

而这场赌注的代价，可能要由全人类来承担。
