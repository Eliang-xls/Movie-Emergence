# CONC 物理基础设施层协议

> Framework v2.6 — round13 新增
> 来源：用户《CONC补充论述》第5点——策元生命周期结束后工厂不应废弃，需通用功能/模块化拆分+政府作为资源支持
> 定位：Engineering 层（HOW），非 Core 层（WHAT/WHY）。CONC 数字层（Skill/VT/NR/协议）完备，本文件补物理生产层。

---

## §1. 问题陈述

CONC 的策元是临时性生产组织——有生命周期，会解散。若策元所开发的产品落实到具体制造生产，且生产线/自动化工厂随策元解散而废弃，则是巨大的资源浪费。

这与 CONC 的自然哲学基础（§0.5 能量守恒）冲突——能量守恒要求资源高效利用，一次性工厂不符合低熵原则。

## §2. 设计原则

### 2.1 生命周期解耦

**策元生命周期 ≠ 工厂生命周期**。策元是创意聚合的临时组织，工厂是物理基础设施——两者必须解耦。

- 策元：数月生命周期，创意驱动，解散后 skill 沉淀入网络
- 工厂：数年生命周期，基础设施驱动，可被不同策元租用

### 2.2 通用功能模块化

工厂/生产线应具备**通用功能**，而非绑定特定产品。设计原则：

1. **模块化拆分**：生产线由可重组的功能模块构成（注塑/机加工/3D打印/SMT/组装/测试），按 BOM 拆分后动态组合
2. **规格标准化**：模块接口标准化（物理接口+数据接口），使不同策元的产品设计可映射到同一组模块
3. **复用价值评估**：工厂投产前评估其功能在价值周期内的复用潜力——若仅服务单一策元且无复用价值，不纳入共享基础设施

### 2.3 政府作为物理基础设施提供者

> 与 v2.5 定位一致："政府是网络的调节基础设施"——不决定"谁来做""怎么做"，但调节资源平衡。

政府（或区域政府联合体）作为物理基础设施的提供者/担保者：

- **投资回收**：政府从长期的租用租金里获得价值回报，使工厂具备投产运营的意义
- **资源平衡**：与 §0.6.1 公共 CU 配额的逻辑一致——物理基础设施是资源对齐（T15 三维对齐度函数的资源维度）的组成
- **非生产决策者**：政府不决定生产什么、如何生产——那是策元的事。政府提供基础设施，策元租用并组织生产

## §3. 生命周期管理协议

### 3.1 工厂生命周期状态机

```
[提案] → [评估] → [建设/改造] → [投产] → [运营(多策元租用)] → [退役/重组]
                                                      ↑
                                               [模块重组]
```

- **提案**：首个提出设计投产的策元发起
- **评估**：政府/基础设施委员会评估复用价值（通用功能、模块化程度、价值周期）
- **建设/改造**：若评估通过，建设新工厂或改造现有工厂
- **投产**：发起策元优先使用
- **运营**：策元生命周期结束后，工厂进入共享池，其他策元可租用
- **模块重组**：若产品类型变化，模块可重新组合适配新产品
- **退役**：价值周期结束，模块拆解回收或重组为其他用途

### 3.2 BOM 拆分与自动分发

策元开发产品落实到制造生产时：

1. 根据现有产业链做具体的生产环节拆分（BOM）
2. 各部件/零件图纸和规格要求统筹规划生产计划
3. 自动分发到对应的功能模块/工厂
4. 组装、下线、运输——所有计划安排/生产均为高度数字化和自动化并模块化

这与 §0.5.3 蜂群时代的"无人工厂"前提一致——物质性基本生活资料生产环节最先自动化（T5 物质/非物质自动化梯度），工厂作为共享基础设施是公理一（生产解耦）的物理实现。

## §4. 与 CONC 框架的挂接

| 挂接点 | 关系 |
|------|------|
| 公理一（生产解耦） | 工厂复用是生产解耦的物理实现——物质生产不再绑定特定策元 |
| §0.5 能量守恒 | 工厂复用符合低熵原则——资源高效利用 |
| T5 物质/非物质自动化梯度 | 物质性基本生活资料工厂最先进入共享池 |
| T15 三维对齐度函数 | 工厂共享是资源对齐维度的组成 |
| T16 组织形态选择定理 | 策元"资源对齐=强"依赖共享工厂+CU配额 |
| 本原零（治理本原） | 政府作为基础设施提供者是治理层的资源平衡职能 |
| 10_Engineering/Track_A/B | 与现有工程化落地轨道互补——数字层（Track A/B）+ 物理层（本协议） |

## §5. 待验证问题

| 问题 | 不确定性 | 验证方式 |
|------|------|------|
| 工厂通用功能的实际覆盖面 | 专用设备占比过高时模块化不可行 | 跨行业产线通用性调研 |
| 政府作为基础设施提供者的政治可行性 | 不同国家/地区政府意愿差异 | 政策可行性研究 |
| 模块重组的技术成本 | 重组成本过高则不如新建 | 现有柔性制造系统数据 |
| 复用价值评估方法 | "价值周期"如何量化 | 历史产线利用率数据 |
