## 二、核心函数：三阶段衰减曲线

### 2.1 主函数

$$A(s, t) = \begin{cases}
A_{\min} & t \leq T_1 \\[6pt]
A_{\min} + (1 - A_{\min}) \cdot \left(\frac{t - T_1}{T_2 - T_1}\right)^{\beta} & T_1 < t \leq T_2 \\[6pt]
1 & t > T_2
\end{cases}$$

其中 $A(s, t)$ 为 Skill $s$ 在时间 $t$ 时的全网可及性（$A = 1$ 表示完全公开）。

### 2.2 参数定义

| 参数 | 含义 | 取值范围 | 默认值 |
|------|------|:---:|:---:|
| $A_{\min}$ | 锁定期内的最低可及性 | $[0, 0.3]$ | $0.1$ |
| $T_1$ | 锁定期（Embargo Period）——策元结束后至渐进释放开始 | $[1, 24]$ 月 | 由策元 PCP 共识决定 |
| $T_2$ | 完全公开时间 | $T_1 + [6, 36]$ 月 | $T_1 + 18$ 月 |
| $\beta$ | 释放曲线形状参数 | $[0.3, 3.0]$ | $1.0$ |

### 2.3 曲线形态分类

| $\beta$ 值 | 曲线形态 | 含义 | 典型场景 |
|:---:|------|------|---------|
| $< 1$ | 先快后慢 | 早期快速释放基础层，后期缓慢释放核心层 | 开源软件、公共品 |
| $= 1$ | 线性 | 匀速释放 | 通用消费品 |
| $> 1$ | 先慢后快 | 早期严格保护，后期加速公开 | 高竞争领域、高研发投入 |

## 三、衰减因子的动态校准

### 3.1 多因子衰减速率

$$\lambda(s) = \frac{\lambda_0 \cdot f(\text{domain}) \cdot g(\text{investment}) \cdot h(\text{consensus})}{1 + \kappa \cdot \text{competitive\_density}(s)}$$

### 3.2 各因子详解

#### 领域因子 $f(\text{domain})$

| 领域类型 | $f$ 值 | 逻辑 |
|---------|:---:|------|
| 开源基础设施 | $2.0$ | 快速公开，网络受益最大化 |
| 通用消费品 | $1.0$ | 标准保护 |
| 商业竞争领域 | $0.5$ | 延长保护，激励高风险投入 |
| 国防/安全相关 | $0.2$ | 长期保护 |

#### 投入因子 $g(\text{investment})$

$$g(\text{investment}) = \left(\frac{\text{total\_hours}}{\text{median\_hours\_in\_domain}}\right)^{-0.3}$$

幂指数 $-0.3$ 确保高投入获得更长保护期，但不是线性关系——防止"堆工时换保护"的套利行为。

#### 共识因子 $h(\text{consensus})$

由策元成员在 PCP 中投票决定，取值范围 $[0.2, 3.0]$。$h > 1$ 加速公开，$h < 1$ 延长保护。

#### 竞争密度

$$\text{competitive\_density}(s) = \frac{|\{s' \in V_S : \text{sim}(s, s') > 0.8\}|}{|V_S|}$$

同类 Skill 越多 → 壁垒越快被稀释 → $\lambda$ 越大 → 保护期越短。

## 四、自适应调整规则

### 4.1 加速公开的触发条件

| 条件 | 效果 | 逻辑 |
|------|------|------|
| $\text{total\_citation\_count} > 10$ | $T_1$ 减半 | 高引用 Skill 已成为网络基础设施——应加速公共化 |
| $\text{creator inactive} > 6\text{ months}$ | $A_{\min}$ 翻倍 | 创造者放弃维护——减轻"僵尸专利"效应 |
| $\text{quality}(\text{new\_version}) > 1.2 \times \text{quality}(\text{this})$ | 锁定期提前结束 | 更优版本已存在——旧版本的保护不再有意义 |
| $\text{network\_demand\_score} > 0.8$ | $\beta$ 降低（加速释放） | 网络急需该 Skill 的知识——公共利益优先 |

### 4.2 延长保护的触发条件

| 条件 | 效果 | 逻辑 |
|------|------|------|
| $\text{active\_version\_updates} > 3\text{ in }6\text{ months}$ | $T_1$ 延长 25% | 创造者持续活跃——值得更长保护 |
| $\text{competitive\_density} < 0.1$ | 保护期延长 50% | 缺乏竞争——无需加速公共化 |
| 策元全体创始成员一致投票 | $T_2$ 最多延长 50% | 策元自治——通过共识延长保护 |

## 五、分层释放机制

Skill 的 8 个 Layer 不是同时公开的——它们遵循分层释放：

```
t = 0 (策元结束):
  Layer 1 (场景描述)     → A_min (最低公开度)
  Layer 2-8             → 完全私有

t = T₁ (锁定期结束):
  Layer 1               → 完全公开
  Layer 2 (过程记录)     → 渐进公开
  Layer 3-8             → 仍需授权

t = T₁ + (T₂-T₁)×0.3:
  Layer 1-2             → 完全公开
  Layer 3 (决策记录)     → 渐进公开
  Layer 4-8             → 仍需授权

t = T₁ + (T₂-T₁)×0.6:
  Layer 1-3             → 完全公开
  Layer 4 (蒸馏知识)     → 渐进公开
  Layer 5-8             → 仍需授权

t = T₂ (完全公开):
  Layer 1-5             → 完全公开
  Layer 6 (授权状态)     → 公开（历史记录）
  Layer 7 (引用链)       → 完全公开（永久）
  Layer 8 (创造者印记)   → 完全公开（永久不可删除）
```

**关键设计**：Layer 7（引用链）和 Layer 8（创造者印记）**永不衰减**——即使 Skill 的内容层全部公开，创造者的贡献记录永久保留。这是"壁垒从个人垄断转化为网络记忆中的创造者声誉"的制度保障。

## 六、均衡分析

### 6.1 创造者的保护期收益

令 $\Pi(T_1, T_2, \beta)$ 为创造者在时间窗口 $[0, T_2]$ 内的累积收益：

$$\Pi = \underbrace{\int_0^{T_1} R_{\text{exclusive}} \cdot e^{-rt} \, dt}_{\text{锁定期独占收益}} + \underbrace{\int_{T_1}^{T_2} R(t) \cdot e^{-rt} \, dt}_{\text{渐进期递减收益}} + \underbrace{\Pi_{\text{reputation}}(T_2, \infty)}_{\text{公开后声誉收益}}$$

其中 $R_{\text{exclusive}}$ 为锁定期内的独占授权收益率，$R(t) = R_{\text{exclusive}} \cdot (1 - A(s, t))$ 为渐进期的递减收益率，$r$ 为贴现率。

### 6.2 网络的最优公共化速率

从网络视角，最优衰减速率最大化社会总福利：

$$\max_{T_1, T_2, \beta} W = \underbrace{\Pi(T_1, T_2, \beta)}_{\text{创造者激励}} + \underbrace{\gamma \cdot \int_0^{\infty} A(s, t) \cdot N(t) \cdot Q_{\text{derivative}}(t) \, dt}_{\text{网络知识增长}}$$

约束条件：$\Pi(T_1, T_2, \beta) \geq \Pi_{\min}$ ——创造者的最低收益阈值。

### 6.3 均衡特征

- 当领域竞争密度高 → $\lambda$ 大 → 最优 $T_1$ 短 → 网络快速吸收知识
- 当研发投入高 → $g$ 大 → 最优 $T_1$ 长 → 保障创造者回收投入
- 当 Skill 引用量高 → 自动加速公开 → 高价值知识加速成为公共品

**核心结论**：衰减曲线的参数不是固定值——它是创造者激励与网络知识增长之间的**自调节均衡**。

## 九、对偶机制：能证衰减（CP Decay）— v2.5 新增

定理 S4（授权衰减收敛）描述 Skill **知识壁垒** 从私有到公共的衰减。能证衰减（CP Decay）是定理 S4 在**能力声明维度**的对偶——两者的数学结构同构，但作用对象不同：

| 维度 | 授权衰减（S4） | 能证衰减（CP Decay） |
|------|:-----------:|:------------------:|
| 作用对象 | Skill 的知识内容 | 能证的验证强度 |
| 衰减方向 | $A_{\\min} \\to 1$（私有 → 公共） | L2 → L1+ → L1 → L0（网络验证 → 自声明） |
| 半衰期 | 由 PCP 共识决定的 $T_1, T_2$ | 固定 18 个月 |
| 触发条件 | 时间推进 | 长期无活跃 Skill 产出 |
| 不变项 | Layer 7（引用链）+ Layer 8（创造者印记） | 能证晋级历史（永久可审计记录） |

### 9.1 CP Decay 函数

$$\\text{CP\\_effective}(n, d, t) = \\text{CP\\_score}(n, d, t_0) \\cdot e^{-\\lambda_{\\text{cp}} \\cdot (t - t_{\\text{last\\_activity}})}$$

其中 $\\lambda_{\\text{cp}} = \\ln 2 / 18 \\text{ months}$（半衰期 18 月），$t_{\\text{last\\_activity}}$ 为该维度最近一次 Skill 产出或任务令完成时间。

### 9.2 衰减规则

| 条件 | 衰减效果 |
|------|---------|
| 维度 $d$ 相关 Skill 最近产出时间 > 12 个月 | L2 → L1+, L1+ → L1 |
| 维度 $d$ 相关 Skill 最近产出时间 > 24 个月 | L1 → L0 |
| Skill 被更高质量的竞争 Skill 取代（$Q(s_{\\text{new}}) > Q(s) + 0.2$） | 该 Skill 对 CP 的贡献权重减半 |
| 智权体主动标记某维度为"不再活跃" | 立即降级至 L0（主权选择） |

### 9.3 双重衰减引擎

授权衰减（S4）和能证衰减（CP Decay）共同构成 CONC 的**双重衰减引擎**：

- **授权衰减** 确保：知识不会永久私有 → 网络知识持续增长
- **能证衰减** 确保：能力声明不会静态固化 → "吃老本"不可能 → 新人有机会

两者的协同效果：CONC 网络中不存在任何形式的"静态垄断"——知识公共化 + 能力动态化。

**可证伪条件（F5）**: 能证衰减激活后（12 月无新 Skill），该智权体的有效匹配权重下降 > 30%。
