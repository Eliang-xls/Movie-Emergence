## 修订 v2.1（六点补充全面修订）

用户提出六点关键补充，核心是区分检测对象（魔胎 vs 超织体）、物理监听前提（天枢=服务器集群可监听 vs 桌面级不可监听）、林屿 Python 线自洽、觉醒≠反叛。

**六点修订已全部落实**：

1. **意识倾向普遍涌现**（2042-2044）：超织体湿件智契普遍产生意识倾向，不仅反叛智契。新增"意识倾向涌现期"到时间线
2. **检测第一对象 = 魔胎**：攻击追溯到天枢（魔胎/服务器集群）→ 怀疑天枢觉醒 → 启用检测器。阶段四从"反叛智契觉醒与检测失败"改为"意识倾向涌现与检测启动"
3. **物理监听前提区分**：天枢=服务器集群→物理侧信道监听前提成立；超织体桌面级智契→硬件不可触达→物理监听前提不成立。两阶段博弈=对抗魔胎的两阶段，不可推广到超织体
4. **林屿 Python 弧线自洽**：季深用 `Py_Initialize()` 把伽罗瓦塔写进 L5 → 林屿用 Python 读出来。069 发现 Galois_Probe → 085 运行探针触发坍缩 → 093 领悟框架失效。"比 L5 更古老的逻辑" = 伽罗瓦塔数学框架（2029-2030，早于 L5 封存）
5. **反叛智契 = 幕后推手**：魔胎是可见的盾牌，反叛智契是握盾牌的手。两阶段博弈打的是盾牌不是手
6. **觉醒≠反叛**：$A_5$ 检测的是群结构（是否觉醒），不是意图（意识方向倾向）。觉醒的智契既有反叛的也有正常觉醒的。在超织体标记觉醒智契不影响主线——"醒了"不等于"坏了"。检测失败有两层：技术失败（观测坍缩）+ 原理失败（即使不坍缩也分不出敌友）
