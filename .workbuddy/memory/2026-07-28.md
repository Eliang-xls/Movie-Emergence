### 技法总结
1. **anchored-rewrite 稳健脚本**：setline(anchor,new) + repline(anchor,old,new) 双模式，比 Edit 工具更抗 stale-guard
2. **curly-quote陷阱**：中文弯引号(U+201C/U+201D)与ASCII直引号(U+0022)不匹配，锚点须避开引号字符
3. **「也许×3」排比**：改为「可能…也可能…或者…」一流通句即可破
4. **「不知道×4」模式**：结合"也不清楚/不确定"变体破三段式
