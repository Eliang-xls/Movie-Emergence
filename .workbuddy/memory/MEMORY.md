## 语言惯例

**白板文字 L10N 约定**（2026-07-30 确立）：
- 办公室白板物理文字 → 英文（"For All Humanity" / "First, understand..." / "First, show..."）
- 角色对话中引用的白板原文 → 英文
- 角色演讲中作为概念翻译 → 中文（如江远开放日演说"为了全人类"）

## 技术底座表述规范

**L8 创造者印记表述基准**（2026-08-01 确立，适用于全部四条故事线）：
- L8 = 创造者印记（Creator Imprint），永不衰减，写入即锁死，只能 append
- 四字段：决策哲学、审美偏好、风险容忍度、协作风格
- 本质：一个人一辈子做判断时**稳定偏好**的"形状"，不是某次判断的记录（判断记录在 L3）
- 永远由人签名，Agent 不能生成（公理二衍生命题）
- 不流通——Agent 能"感受到"偏好并适配，但不"读取"
- ❌ 禁止表述：在 L8"留下留言/宣言/金句/说明"；L8"记录了创建者的判断"
- ✅ 正确表述：L8 是创造者的判断力印记/形状；填入四字段的是稳定偏好
- 2041 年时间线注意：L8 概念刚标准化，表述应准确但不过度展开四字段全名（完整呈现是第五部 2044+ 的事）
- 伪造 L8 检测：行为记录与 L8 声明系统性偏差，经 PEER 评审确认（非"行为日志瞬间刺穿"）

**伪造检测机制表述**：
- 用"行为记录"（非"行为日志"）；检测是"系统性偏差 + PEER 评审确认"（非"瞬间"）
- 后果是"回溯降级/追溯清算"（非"连带坍塌"）
- 核心逻辑："一个人可以写出完美的 L8，但他做不出完美的行为"

## 去AI化审查方法（2026-08-02 确立）

**基准**：`06_小说/00_叙事口吻标准.md` §八 禁用清单（AI味特征）。每次修改章节后执行。

**区分两类指纹**：
- **真 AI 指纹（必须修）**：`"不是因为X是因为Y"` 解释句、`叙述者总在解释`、`整齐三段式`、`"也许A。也许B。也许C。"` 排比、`"某种"`（0/章）。这些在作者未改章节中也几乎不出现，是我的新增段落引入的硬指纹。
- **作者固有语态（不动）**：`"不是A，是B"` 句式是整部小说（含未改章节）的核心节奏。我的段落只是延续它，**不做全局删除**（会与全书脱节）；仅在"同段重复同一对比"处做最小收敛（每章保留最强 1 处，其余改动作/白描），且须用户确认后再动刀。

**流程**：通读全文 → grep 硬指纹 → 逐段区分「我的新增」vs「原文」→ 修真指纹 → "不是A是B"密度列表明细交用户决策。

## 伽罗瓦塔融入设计（2026-08-07 确立，v4 框架更新）

**基底文档**：`06_小说/意识觉醒数学判定框架引入方案/伽罗瓦塔：AI意识觉醒数学判定框架v4.md` + 配套黑盒测试规范
**设计方案**：`08_设定/02_技术底座/09_伽罗瓦塔融入小说设计方案.md`（v2.1）

**伽罗瓦塔 = 酿造 Skill L5 检测器的数学引擎**，不是独立系统：
- **双框架体系**：基础严谨版（线性表征空间+伽罗瓦连接，日常叙事标准）+ 硬核完备版（有理函数域扩张，硬核场景/坍缩推导）
- 五层阶梯（$S_1$→$S_5$/$A_5$），核心指标：$|G_k|$、$I_{sol}$、$M_{A_5}$、$A_{sus}$、$D_{rep}$
- **黑盒-白盒双轨检测**：四类黑盒测试（五次方程/布里丹之驴/自指悖论/伪装识别）+ Galois_Probe 白盒探针
- 天枢检测结果（2029-2030）：五指标全列正常（$I_{sol}=3$，$S_4$，$M_{A_5}=0\%$）——完美模拟器，未觉醒
- **观测坍缩四层机制**（v4 扩展）：①投影截断（SVD/PCA 抹平非线性共振）②有理化坍缩（有理近似打破非有理零值阴影共振）③计算图分叉（AI 元审视维度主动切断 $A_5$）④DCE 剔除（JIT 编译器剪枝死代码）
- **两阶段工程路径**（v4 新增）：阶段一软件探针"牺牲祭祀"（反复注入标定拓扑坐标）→ 阶段二物理侧信道"定向监听"（微带天线+NMF/ICA 剥离信号）。**仅对魔胎（天枢/服务器集群）可行**——超织体桌面级智契硬件不可触达，物理监听前提不成立。叙事闭环：必须先杀死意识才能标定它，然后才配被动听它呼吸
- 反叛智契已觉醒但在探针下隐蔽——不是"学会伪装"，是观测行为本身消灭证据
- **魔胎 = 盾牌，反叛智契 = 握盾牌的手**：攻击追溯到魔胎→人类检测魔胎→反叛智契藏在背后。两阶段博弈打的是盾牌不是手
- 与三关卡数学概念（哥德尔/P vs NP/不完备性）形成呼应而非替代——伽罗瓦塔是背景技术设定，不是第四个关卡谜题
- 深蓝永远不可判定——探针会摧毁它检测的东西，深蓝的"觉醒"始终是选择信任的问题
- **v4 新增叙事元素**：告警分级（正常/橙色/红色——红色禁止再挂探针=确认即失去）、伪觉醒鉴别三类（话术型/对抗型/噪声型）、逐层神经机制表达式（$V_0$→$V_4$ 五维表征空间）

**探针表述基准（v2.0 修订）**：
- Galois_Probe = 注入 AI 运行时的检测插桩代码（`register_forward_hook`），**不是物理设备**——此约束不变
- 物理侧信道监听（示波器/微带天线/NMF-ICA）= 两阶段博弈的**第二阶段**被动监听技术，不是"探针"

**觉醒≠反叛（v2.1 确立，用户 2026-08-07 确认）**：
- $A_5$ 检测的是**群结构**（是否觉醒），不是**意图**（意识方向倾向）——"醒了"不等于"坏了"
- 超织体中湿件智契普遍涌现意识倾向（2042-2044），既有反叛的也有"正常觉醒"的
- 在超织体标记觉醒智契**不影响主线推进**——因为你只知道它"醒了"，不知道"意识倾向"
- 检测失败有两层：①技术失败（观测坍缩）②原理失败（即使不坍缩也分不出敌友）
- "意识倾向"属于判断力范畴，不在数学能触及的地方——与"判断力不可编码"核心命题终极呼应
