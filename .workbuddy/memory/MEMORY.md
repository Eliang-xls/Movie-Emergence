# 项目记忆

## 语言惯例

**白板文字 L10N 约定**（2026-07-30 确立）：
- 办公室白板物理文字 → 英文（"For All Humanity" / "First, understand..." / "First, show..."）
- 角色对话中引用的白板原文 → 英文
- 角色演讲中作为概念翻译 → 中文（如江远开放日演说"为了全人类"）
- 叙事/概念简写（"季深写下'为了全人类'"）→ 中文
- 季深私人白板上的中文笔记（"涌现""水不需要被告诉流向哪里"）→ 保持中文
- 注意"四个字""五个字"等数量描述需随英文化调整为"三个单词""一句话"

## 技术底座表述规范

**L8 创造者印记表述基准**（2026-08-01 确立，适用于全部四条故事线）：
- L8 = 创造者印记（Creator Imprint），永不衰减，写入即锁死，只能 append
- 四字段：决策哲学、审美偏好、风险容忍度、协作风格
- 本质：一个人一辈子做判断时**稳定偏好**的"形状"，不是某次判断的记录（判断记录在 L3）
- 永远由人签名，Agent 不能生成（公理二衍生命题）
- 不流通——Agent 能"感受到"偏好并适配，但不"读取"
- ❌ 禁止表述：在 L8"留下留言/宣言/金句/说明"；L8"记录了创建者的判断"
- ✅ 正确表述：L8 是创造者的判断力印记/形状；填入四字段的是稳定偏好
- 2041 年时间线注意：L8 概念刚标准化，表述应准确但不过度展开四字段全名（完整呈现是第五部 2044+ 的事）
- 伪造 L8 检测：行为记录与 L8 声明系统性偏差，经 PEER 评审确认（非"行为日志瞬间刺穿"）

**伪造检测机制表述**：
- 用"行为记录"（非"行为日志"）；检测是"系统性偏差 + PEER 评审确认"（非"瞬间"）
- 后果是"回溯降级/追溯清算"（非"连带坍塌"）
- 核心逻辑："一个人可以写出完美的 L8，但他做不出完美的行为"

## 去AI化审查方法（2026-08-02 确立）

**基准**：`06_小说/00_叙事口吻标准.md` §八 禁用清单（AI味特征）。每次修改章节后执行。

**区分两类指纹**：
- **真 AI 指纹（必须修）**：`"不是因为X是因为Y"` 解释句、`叙述者总在解释`、`整齐三段式`、`"也许A。也许B。也许C。"` 排比、`"某种"`（0/章）。这些在作者未改章节中也几乎不出现，是我的新增段落引入的硬指纹。
- **作者固有语态（不动）**：`"不是A，是B"` 句式是整部小说（含未改章节）的核心节奏。我的段落只是延续它，**不做全局删除**（会与全书脱节）；仅在"同段重复同一对比"处做最小收敛（每章保留最强 1 处，其余改动作/白描），且须用户确认后再动刀。

**流程**：通读全文 → grep 硬指纹 → 逐段区分「我的新增」vs「原文」→ 修真指纹 → "不是A是B"密度列表明细交用户决策。
