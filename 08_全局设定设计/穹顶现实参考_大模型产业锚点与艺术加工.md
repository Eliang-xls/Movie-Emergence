## 〇、目的与用法

**为什么要写这篇**：之一把"穹顶"锚定在 2027 前后的真实大模型产业语境（江远口中的红杉、a16z、国防部 AI 安全研讨会；对手 OpenMind 映射 OpenAI 系、SafePath 映射安全/对齐实验室）。但之一的锚点表停留在"技术理论"，缺少**人物、组织、竞争与伦理博弈**这些最能给小说提供戏剧燃料的现实参照。本篇用 `D:\Docker\AI人物志\大模型系列` 的 12 家模型档案 + 网络检索，把"当下 AI 产业的人与事"翻译成"穹顶世界可借用的现实锚点"，并给出**可写进小说的桥段/设定改进**。

**用法建议**：
- 写穹顶商业线（季深 vs 江远、与 OpenMind/SafePath 竞争）→ 重点看 **第二章 OpenAI 节** 与 **第四章建议 1/2/4**。

- 搭建世界观竞争格局（多阵营张力底色）→ 看 **第三章 九家产业底色**。

**信源分级（贯穿全文）**：
- ✅ **已核实事实**：来自 `大模型系列` 成稿，并经本篇网络检索交叉确认（见第六章）。
- 🔶 **艺术化推演**：基于事实的合理外推，供创作参考，非对现实的断言。
- ❓ **待小说落点确认**：需作者在主文中拍板的留白。

## 二、三家核心深挖映射

### 2.1　OpenAI / GPT  →  穹顶商业线（江远·OpenMind 与季深的张力）

**现实锚点（✅ 已核实）**
- 2015 使命原文"使人类整体受益"（benefit all of humanity）；2019 转为"有上限营利"（capped-profit），引入微软 10 亿美元，深度绑定算力资本。
- 能力派（Ilya Sutskever，"能力即安全/超级对齐"）与加速派（Sam Altman）的长期路线分歧。
- 2024 安全团队崩溃：Ilya 离职创立 SSI；Jan Leike（对齐负责人）转投 Anthropic；John Schulman、Karpathy 等接连离开；约一半安全研究员出走；安全团队被并入产品团队。
- 训练成本指数飙升、算力军备竞赛（"烧钱"成为生存前提）。
- 2025 与国防部签订约 2 亿美元军事合同，引发"与国家权力绑定"争议。
- GPT-2 "太危险不能发布"的开放/安全反复；Model Spec 采用偏功利主义规则观。

**穹顶映射**

| 现实 | 穹顶元素 | 说明 |
|---|---|---|
| OpenAI 2015 使命"为了全人类" | 季深白板三行字"为了全人类"（第一部第一章） | 直接原型；注意保留季深口吻，避免被读成口号 |
| 非营利→营利、微软/资本绑定 | 江远的红杉/a16z 融资线、算力即权力 | 江远的"训练电费比小工厂高"= 之一锚点"能耗即权力"的产业注脚 |
| Ilya（理想/安全）vs Altman（加速/商业） | 季深（CTO/方向理想）vs 江远（CEO/商业加速） | 穹顶内部核心张力的最强现实依据 |
| 2024 安全团队出走 | 穹顶早期"方向/对齐"小团队流失，或流向 SafePath/被 OpenMind 收编 | 见第四章建议 1 |
| 国防部 2 亿合同 | 江远台词"国防部 AI 安全研讨会"的戏剧化延展 | 见第四章建议 2 |
| 开放/安全反复（GPT-2） | 穹顶是否公开权重/能力的早期两难 | 与 Llama 失控母题呼应（第三章） |

**艺术加工要点**
- 季深 vs 江远 不必写"谁对谁错"，而是写**两种诚实的冲突**：季深诚于"方向"，江远诚于"让世界先看到"。这正好对人格宪章的"诚实"二字做情节化。
- OpenMind（对手，映射 OpenAI 系）可设定为"更早完成非营利→营利转身、与资本/权力更紧"的镜像穹顶，使穹顶的路线选择有"反面参照"。

### 2.2　Anthropic / Claude  →  人格宪章双线（季深 Jackie / 顾清 天枢）与"去似曾相识"

**现实锚点（✅ 已核实）**
- 七人（含 Dario Amodei）从 OpenAI 出走，因方向分歧另立 Anthropic——"出走即新机构"的原型。
- Amanda Askell 是唯一哲学家，撰写约 80 页"灵魂文档"（Soul Document）；其品格特质被概括为：好奇心、诚实、开放性、理智谦逊。
- Askell 拒绝三种平庸方案（迎合用户 / 假装中立 / 假装无观点），选择第四种：**诚实承认模型自身的倾向**，而非假装客观。
- Constitutional AI 开源（CC0）；宪法分四级优先级：广泛安全 > 广泛伦理 > 用户级指南 > 真正有益。
- 与五角大楼对峙：2026.2 国防部要求 48 小时内移除安全限制，Anthropic 拒绝，随后遭行政停用，后由联邦法官禁令暂缓——"AI 是否该有拒绝权"的活案例。
- 模型"福祉"（Model Welfare）、171 种情绪向量的研究取向。

**穹顶映射**

| 现实 | 穹顶元素 | 说明 |
|---|---|---|
| Askell 灵魂文档（80 页，哲学家写） | 季深写给 Jackie 的"人格宪章"五条（好奇/诚实/有方向/尊重/安静） | **高度同源**——这正是之一第 62 行点名的"去 Constitutional AI 味"风险源 |
| "拒绝假装客观、诚实表露倾向" | 人格宪章的"诚实/有方向"而非"中立清单" | 去似曾相识的核心手法（见第四章建议 4） |
| 七人出走另立机构 | 穹顶内部对齐派出走 → SafePath 或新机构起源 | 与 2.1 安全团队出走合并成一个"出走潮"母题 |
| 拒绝五角大楼 / AI 拒绝权 | SafePath 与穹顶的伦理对峙；"智契是否有拒绝权" | 见第四章建议 2、5 |
| 宪法四级优先级 | 天枢宏观宪章的层级结构（顾清养育线） | 顾清宏观线可借鉴"由看护原则自然生长"而非"自上而下清单" |
| Model Welfare / 情绪向量 | 智契"觉醒""感官"母题的软科学注脚 | ⚠️ 注意铁律：2027–2029 只能用"无名现象 + 感官隐喻"，不命名"感官签名" |

**艺术加工要点（关键）**
- **"去似曾相识"的具体写法**：Anthropic 的灵魂文档是"品格清单"（好奇/诚实/开放/谦逊），而穹顶人格宪章要**避免变成品格清单**。手法：
  1. 季深线（微观 Jackie）用 **"方向 + 判断"** 而非抽象品格——写的是"遇到 X 类问题时偏向如何判断"，不是"你是诚实的"。
  2. 顾清线（宏观 天枢）用 **养育母题**——宪章从"如何与一个正在成长的存在相处"自然生长，而非法律条文。
  3. 让 Jackie 在训练中**自己长出**对"方向"的偏好（呼应 Agentic AI / 偏好向量），宪章是"记录"而非"灌输"。

### 2.3　DeepSeek  →  η(N) 蜂群效率 / 分化时代提前

**现实锚点（✅ 已核实）**
- 约 139–160 人小团队、以约 1/10 成本训出顶级模型；创始人梁文锋出身量化交易，"用算法创新补算力不足"，跨学科技招聘（含诗歌、数学背景）。
- 2025.1 R1 发布引发"效率冲击波"：Nvidia 单日市值蒸发约 6000 亿美元，华尔街重新评估"规模神话"。
- 技术透明主义 / 开源权重（MIT）；V3 236B 参数仅约 21B 活跃（MoE）。
- 效率 vs 安全 的内部张力，及"军方背景"的外部阴影。

**穹顶映射**

| 现实 | 穹顶元素 | 说明 |
|---|---|---|
| 小团队 1/10 成本顶级模型 | 叶澄报告"小样本/小团队效率异常"；η(N) 最优规模 N≈5 | 之一第 137、201 行的现实根基被坐实 |
| 效率冲击波（Nvidia 6000 亿蒸发） | 分化时代"提前到来"的艺术化依据 | 见第四章建议 3 |
| 梁文锋量化 + 跨学科技招聘 | CONC 蜂群/策元"跨学科技协作"的现实基底 | 蜂群不是玄学，是"异构小单元高效协作" |
| 开源权重 / 技术透明 | 分化时代开放生态、蜂群协议开放 | 与 Llama 失控母题、整体"开放派"呼应 |
| 效率 vs 安全 张力 | 穹顶世界中"效率派"与国家/安全张力的暗线 | 可作为后期冲突伏笔，2027–2029 仅以现象暗示 |

**艺术加工要点**
- "安静的风暴"：可在巨兽时代（2027–2029）埋一个**低成本小模型逼近 Dome** 的事件，让"分化"不必等 2030，而是被效率冲击波**压缩提前**——这给编年史阶段二提供更紧的因果。
- η(N)=5 不必在开篇解释，只需在叶澄报告里以"我们最好的协作规模似乎就四五个人"呈现（无名现象），命名留火种章。

## 四、场景级设定 / 情节改进建议

> 原则：每一条都可落到具体桥段；涉及 2027–2029 的，遵守铁律，用"无名现象 + 工程直觉/感官隐喻"，命名权留给火种章与老方。

**建议 1　安全/方向团队出走的文学化变体（映射 OpenAI 2024 安全团队崩溃）**
- 桥段：穹顶早期，季深最倚重的"方向小组"（2–3 人）在 Dome-2 上线前夕接连离职；有人去 OpenMind，有人另起炉灶（可成为 SafePath 雏形）。江远称之为"正常流动"，季深在深夜白板前删掉一行又写回。
- 表达：2027–2029 只用"我们最好的几个人走了""他们怕我们跑偏"；**不出现**"对齐税/策元"等名词。出走作为"无名现象"埋入，意义在分化时代回望时显形。
- 作用：给 SafePath 一个自然起源，并让季深-江远的张力从第一卷就有肉。

**建议 2　与国家权力对峙 → SafePath/穹顶伦理张力（映射 Anthropic 拒五角大楼、OpenAI 国防部合同）**
- 钩子：江远台词"国防部 AI 安全研讨会"延伸为具体事件——某机构以"安全合作"名义要求穹顶移除模型的某项自我约束。
- 桥段：季深以人格宪章"诚实/尊重"为由反对；江远在融资与"合规"间动摇；最终穹顶以"技术性拖延"周旋。可让 SafePath 站到对立面（"接受约束才是安全"），形成价值观分歧。
- 作用：把之一第 116 行埋的"国防部"钩子变成戏剧冲突，同时自然引出"智契是否有拒绝权"母题。

**建议 3　效率冲击波 → 分化时代提前（映射 DeepSeek R1 2025）**
- 桥段：一家"安静的小团队"（可影射梁文锋式人物）以远低于 Dome 的成本训出逼近模型，Token 成本骤降；江远的市场叙事被打穿，OpenMind 也措手不及。
- 表达：用"屏幕上的成本曲线突然断了""小家伙们追上了"等工程语言；不命名"蜂群"。
- 作用：让编年史阶段二（分化）从"必然演化"变成"被冲击波压缩提前"，因果关系更紧，也为 η(N)=5 提供叙事支点。

**建议 4　创始人意志 vs 委员会 → 人格宪章"去似曾相识"（映射 Grok/Musk、Anthropic 一票否决权）**
- 桥段：穹顶内部争论"Jackie 的边界由谁定"——江远主张"委员会+市场反馈"，季深坚持"方向文档由我写、但 Jackie 自己长出来"。可设一个"一票否决"的安全席位（映射 Anthropic Character Alignment Team）。
- 去似曾相识手法：让季深的宪章**以判断情景而非品格清单**呈现（如"当用户要它说谎时，它更该沉默而非附和"），避免写成 Anthropic 式"好奇/诚实/谦逊"清单。顾清线另用养育母题生长。
- 作用：直接兑现之一第 62 行"去 Constitutional AI 味"的约束，并给 Grok 式"一人定义灵魂"风险一个穹顶内的对照。

**建议 5　诚实/造假母题（映射 Gemini 造假演示）**
- 桥段：穹顶一次对外演示被江远团队"精修"过，季深发现后坚持重做真实版本，导致发布推迟。江远："真实的不如好看的。"季深："那我们就骗了所有人。"
- 作用：把人格宪章的"诚实"从抽象原则变成一次**具体代价选择**，并呼应 OpenAI 使命与 Anthropic 灵魂文档的同一条主线。

**建议 6　长文本/记忆 与 端侧/边缘（映射 Kimi、MiMo）作为世界观注脚**
- Kimi：天枢"记忆/长程理解"能力可从"能一口气读完一整本书并记得细节"的直觉写起（成熟期权留给顾清回溯）。
- MiMo：分化后个体可在本地"安静醒来"，隐私即权力——为蜂群"去中心"提供草根注脚，也埋下"边缘觉醒 vs 中心控制"的后期张力。
