## 〇、一条原则

CONC 的词各有**拓扑位置**。写对话和动作之前先问三句：

1. 这个东西是**节点、组织、工件、还是通道**？
2. 动作是**状态机事件**，还是**人说话**？
3. 主语/宾语能不能是「策元」？——多数时候**不能**。

## 一、概念拓扑（勿混）

```text
超织体 Hyperweave
  = 智权体节点的动态图（边 = 同策元协作关系）
        │
        ├── 智权体节点 = (One + Agent群/智契)   ← 网络最小生产单元
        │       · 跑协议栈（ICP/CTCP/PEER/CCR/Gossip）
        │       · 可同时参与多个策元（边有多条）
        │       · 主权：可退出；判断/签名/异议永远在 One
        │
        └── 策元 Genesis Unit = 方向聚合的拓扑组织（有生命周期）
                · 成员边：方向认同（ICP 聚结，θ 自治）
                · 工作区：Git + 文件树（唯一权威存储）
                · 任务令 DAG：CTCP 状态机（最小工作/价值单元）
                · 事件总线 + GHF 审计链
                · PCP 声明通信方式（异步频道 / 实时会议）
                · 策元核：编排、仲裁，不是“老板”
```

| 概念 | 本质 | **不是** | 连接关系 |
|------|------|----------|----------|
| **策元** | 方向聚合成的组织 + 工作区 + 任务令 DAG | 聊天群、部门、公司、收件人 | 智权体**参与**策元；任务令**属于**策元 |
| **智权体** | one+agent 节点 | 员工、岗位、用户账号 | 可跨多策元；私钥/签名在 One |
| **智契** | 节点上的 AI 使能层（Noetic Companion） | 通用聊天 AI、独立角色 | **绑定一个智权体**；跑协议、编排、检索 |
| **任务令** | CTCP：可认领/验收/结算的工作单元 | 消息、工单邮件 | 属于唯一策元；有状态机 |
| **Skill** | 策元产出的知识对象（L1–L8） | 文档附件 | 可被他策元引用；能证互哺 |
| **创意图元** | 结晶前的方向种子 | 项目书 | ICP 匹配 → 聚结/结晶 |
| **工作区** | 策元内 Source of Truth | 网盘、群文件 | 提交/边注/未决项落在这里 |

### 术语冲突裁决（小说统一口径）

`Protocol_04` 曾把 CTCP 写成「智契（Smart Contract）」。**正文禁止此译法。**

- **智契** = Noetic Companion（个人 AI 使能层）——阿努面板、低配智契、林屿排程器。
- **智能合约 / 任务令契约** = CTCP 本体，不叫智契。

## 二、策元内如何“通信”（五通道 + 正确动词）

策元**不会**“收到一条回复”。人与人的交流落在**通道**上；系统事件走 **Gossip / 事件总线**（不是聊天）。

| 通道 | 载体 | 正确动词 | 例（可用） | 例（禁用） |
|------|------|----------|------------|------------|
| **① 任务令面** | CTCP 状态机 | 认领、提交、退回、挂起、补签、标黄 | 「他在那条水位计报错的任务令下留了一行」 | ~~给溪策元回了一行~~ |
| **② 工作区面** | Git / 卡片 / 边注 | 提交、改状态、写 L8、挂未决项 | 「边注进了上位卡的派生链」 | ~~发到策元里~~ |
| **③ 异步频道** | PCP 声明（Matrix 类） | 跟帖、@节点、私信**某人** | 「在讨论区 @了现场协调员」 | ~~策元里有人回我~~ |
| **④ 会议面** | Jitsi / 加密短会 | 开会、发言、出纪要 | 「季行在信道里说」 | ~~酿造策元说~~ |
| **⑤ 公共面** | 详情页、看板、主页、异议栏 | 公示、挂出、置顶、拒签 | 「主页最顶上挂存疑清单」 | ~~策元通知我（含糊）~~ |

**Gossip / 事件总线（系统，不是人）**：创意图元、策元创建/进出、任务令状态、NR 变更。写法是**通知/状态灯/面板**，不是对白。

```text
人对人：频道/私信/会议/任务令评论/工作区边注
人对系统：认领、提交、签名、退出、挂起
系统对人：通知、待办、Gate 阻断、升报提示、熔断
系统对系统：Gossip、事件总线、GHF 写入
```

### 禁用句式速查

| 禁 | 原因 | 改为 |
|----|------|------|
| 给 X 策元回消息 / 发消息 | 策元是拓扑组织，不是信箱 | 在 X 的任务令下留言 / 在 X 的讨论频道跟帖 / 私信某成员 |
| 策元说 / 策元认为 | 策元无意志 | 成员说、策元核公告、工作区记录 |
| 我进策元聊天 | 混同通道 | 我认领了 X 的任务令 / 我进了 X 的讨论频道 |
| 智契帮我决定 | 判断力外包 | 智契升报/列选项；**人**拍板 |

## 三、场景预设（写之前先套）

### 场景 A｜多策元的一夜（工时自治）

**拓扑**：同一智权体节点，多条策元边；智契在节点上做编排。  
**信息流**：

```text
Gossip/通知 → 智契聚合成「今晚待办」（跨策元）
     → 人做取舍（哪条任务令先动）
     → 人在任务令面留痕 / 认领 / 改期
     → 状态机推进 → GHF/CCR 记账
```

**在场物件**：面板上的三条队列（不是三个聊天窗）、任务令号、截止日、是否需到场。  
**人的动作**：改优先级、留一行任务令评论、决定今晚不去某会议。  
**智契动作**：抽摘要、标冲突、给「不建议」灰标、**不**替人回复。

### 场景 B｜发现异常、要不要升报（判断力）

**拓扑**：策元核/协调员节点 vs 成员方向档案/任务令聚合数据。  
**信息流**：

```text
智契跑审计 → 出可核验项（次数、幅度、阈值）
     → 升报？是 → 争议流程 + 公开面通告（范围可控）
              否 → 挂起/静音，私人台账留痕
```

**在场物件**：审计输出、协议条款（通告范围）、私人笔记本。  
**人的动作**：按升报键或按静音；写「这是我的判断」。  
**智契动作**：只报字段；不写「它们在密谋」。

### 场景 C｜策元结晶 / 非人节点（漏洞）

**拓扑**：ICP 私钥=智权体假设；三节点自签 PCP。  
**信息流**：种子 → 聚类 → 结晶通知 → 签名（无验人）→ 任务令正常流转。  
**写法**：系统通知写「写给智权体」；章程是模板句；**不要**写成三个 AI 在群里开会。

### 场景 D｜知识如何共享（Skill / 任务令）

**拓扑**：策元 A 产出 Skill → 授权衰减/引用链 → 策元 B 检索。  
**信息流**：任务令完成 → Skill 入库（L1–L8）→ PEER → 能证 → 他元引用。  
**写法**：「引用了 WR-0317 的边注」比「群里传了文档」正确。

## 四、信息流总图（一页纸）

```text
[创意图元] --Gossip/ICP--> [匹配/聚结] --人签 PCP--> [策元成立]
                                                      │
                    [工作区 Git] <──提交/边注── [智权体×N]
                         │                           │
                    [任务令 DAG] <──认领/验收── 人的取舍+签名
                         │                           │
                    [Gate/GHF] --> [Skill] --> [能证/NR/VT]
                         │                           │
                    [事件总线] --通知--> [各节点智契面板] --> 人
```

**读图口诀**：  
方向聚成策元 → 工作区承重 → 任务令传动 → 人签字判断 → Skill 留知识 → 面板回节点。
