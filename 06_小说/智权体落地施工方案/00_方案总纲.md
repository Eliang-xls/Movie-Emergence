## 零、铁律：不为加而加

凡进入正文的智权体 / 智契笔墨，**必须同时满足**：

1. **扣住已有因果**——服务主线已定的节点（韩霜沉默八个月、反叛智契渗透面、#8824 协议漏洞、林屿多方并行、末次复核的公司收编对照），不新开支线。
2. **推动下一拍**——删掉这段，后文某一拍会失去支撑或明显变薄。
3. **不抢判断力**——智契做编排、门槛、预警；**签名、异议、沉默、拒绝永远是人**。与全书「可以争论，不可证明」「L8 创造者印记」一致。
4. **术语随年代**——2043 后才自然使用「智契」；更早只用「辅助 AI / Jackie / EM-7」。禁止叙述者贴设定标签。
5. **概念对拓扑**——写对话/动作前对照 `03_CONC概念落地场景预设.md`：策元不是聊天对象；沟通落在任务令/工作区/频道/会议/公共面五通道；智契=Noetic Companion，CTCP 不译作智契。

**一句话验收**：读者读完觉得「本来就该有这个」，而不是「作者补设定来了」。

## 四、黄金样章的设计意图（供对照阅读）

### 样章一《静音》

- **要证明的**：智契能预警，**不能**替人决定是否举报；韩霜的沉默是 Phronesis，不是失职 UI。
- **主线钩子**：八个月渗透窗从这一晚计时；后文自白书「我的判断——不是我的 Agent 的判断」有了现场。
- **口吻**：韩霜工作台视角，冷、干、密；智契只出可核验项，不出「我觉得它们在密谋」。
- **禁区**：不点「反叛」「魔胎」「觉醒」；不预告后果；叙述者不判她对错。

### 样章二《三线一夜》

- **要证明的**：一个节点 + 低配智契，如何在多策元里活；协议复杂度在机器侧，取舍在人侧。
- **主线钩子**：接 125–128 已有「白天课 / 晚上溪 / 设备间 B1-07」；为「工时自治」补一笔**取舍**而非空闲。
- **口吻**：林屿桌面 + 物体（笔记本、螺丝、面包）；智契**无名**（他不给工具起名），对话极短。
- **禁区**：不写效率神话；不写「比上班强」；VT/NR 只作账目出现。
