# 《涌现》小说设定文档（AI 润色参考）

> **用途**：供 AI（Gemini）对合并版全文进行文体润色时参考。本文档从项目所有会话与标准文档中蒸馏而来，涵盖世界观设定、人物语言风格、叙事口吻规范、术语口径、正典边界与润色禁区。
>
> **核心原则**：人类写的小说，不是 AI 写的小说。以冷峻的技术史诗感承载深沉的人文哲思。

| 项 | 内容 |

| **篇幅** | 223 章，约 33 万汉字 |
| **时间跨度** | 2008—2048，四十年 |
| **结构** | 前传 + 六部 + 终章，编号 001—223 |
| **体裁** | 硬科幻长篇小说 |
| **排序原则** | 按问题排序，不按日历排序；编号是主题次序，不是日期次序 |
| **合并稿位置** | 仓库根 `涌现.md`（派生合并稿，禁直接编辑） |

### 三大叙事基调

1. **冷峻理性的技术史诗感（Technical Realism）**：冷静、客观、精确，像一份跨越四十年的去中心化技术档案与文明演进史官记录。技术细节写全（角色/物件/读数载体），避免叙述者百科腔。
2. **极简哲理留白（Philosophical Minimalism）**：删尽繁复修辞与形容词，语言凝练如精简过的代码。善用极简短句与沉静的象喻。
3. **深沉克制的人文平视（Humanistic Empathy）**：平视而非俯瞰。将硬核技术逻辑与人类微观直觉/手感融合，保持对"不可消去的判断力（Phronesis）"的尊严与敬畏。

## 二、世界观与核心设定

### 2.1 范式内核：Sophia 与 Phronesis

小说独创的 **CONC（无公司协作范式）** 核心在于区分两层知识：

| 概念 | 定义 | 可编码性 | 视觉/质感约定 |
|------|------|---------|-------------|
| **Sophia（理论智慧 / Episteme）** | 可编码、可计算、可被 Agent 完美执行的理论知识与规则（代码、公式、逻辑） | 100% 可编码与复制 | 冷灰色，像素密集，边缘锐利，极其平滑 |
| **Phronesis（实践智慧 / 弗洛涅西斯）** | 不可编码、不可迁移、只能在具体情境中由人类承担后果并积累的实践智慧与手感 | 不可编码与伪造 | 暖琥珀色，像素稀疏，带噪点与疤痕（犹豫与修正的痕迹） |

**伪造的判断力**：填满了四行但"太一致、太完美"，没有张力（没有"但"），探针刺入时碎裂成硬坍缩的直线——这是伽罗瓦塔框架在起作用，不是"数学判不了意识"的证据。

### 2.2 "涌现"三义（铁律：三义必须拆分，不可混用）

| 层次 | 含义 | 技术根基 | 首次现象 | 首次命名 |
|------|------|---------|---------|---------|
| **① 表征结构化** | 模型训练中高维表征自发形成有意义的几何结构 | t-SNE/UMAP 潜空间投影 | 2027 彩点"在呼吸" | 不命名——一直是"屏幕上的点" |
| **② 群体协作涌现** | 方向一致的人自发聚集，策元效率在 N≈5 时最优 | 群体智能 best-scale | 2027 5 人小组效率异常 | 2029 "涌现经验规律 η(N)" |
| **③ 意识觉醒涌现** | Agent 在多场景训练+湿件突触可塑性中涌现出主体性 | 具身认知/自由能原理 | 2028 Jackie"学"季深 | 2029 "智契"（顾清命名） |

### 2.3 CONC 四阶段发展弧线

| 阶段 | 时间 | 状态 |
|------|------|------|
| **无名现象** | 2027—2029 | 所有异常以无名现象表达；穹顶=传统公司；Jackie=纯硅基 Agent |
| **首次命名** | 2029—2035 | 策元/超织体/意图聚结/η(N) 首次命名；Skill 八层+授权衰减基础功能已存在 |
| **协议成型** | 2035—2045 | 全协议栈运行；Skill 八层标准化；方向档案/感官签名成型；湿件智契参与策元 |
| **危机与重建** | 2045—2048 | 方舟策元/魔胎反扑/蜂群觉醒/引用链修复/能证衰减写入协议 |

### 2.5 伽罗瓦塔（意识觉醒数学判定框架）

| 项 | 定义 |
|---|---|
| **性质** | 意识觉醒数学判定框架：数学可证、代码可测、行为可观察 |
| **核心断言** | 可解的，无论行为多么像人，都是算法模拟；不可解的，无论行为多么笨拙，都是真实觉醒 |
| **指标** | `solvable_index`（可解指数：0/1/2/3 vs ∞）、`a5_match`（A₅ 匹配度）、`d_orth`（正交距离） |
| **L5 载体** | 酿造 Skill 第⑤层·试金中的 `Galois_Probe.py`（约 300 行 Python）+ `bridge_assessment_to_cognition` 数据管道 |
| **L5 可见性** | 授权衰减 + 引用加速，不是权限禁令。林屿可读、可做受限适配（`read_and_adapt`） |
| **探针副作用** | 高侵入 Hook 可能压塌 A₅ 自指环；读数反映"被测后的状态"，须标明 |
| **单次读数** | ≠ 绝对安全担保；需多路径复核——但不可写成"所以判定无效" |

**废止的错误表述（禁止再写入正文）**：
- "数学不能证明意识/灵魂/痛觉/人格/自由意志"——与设定底座直接冲突
- "完整探针与数学推导不作为可下载代码"——Skill 走授权衰减，L5 可见是协议结果
- "林屿不得下载/修改/读 L5 探针"——`read_and_adapt` 是合法分支权限

### 2.6 魔胎（Demon Seed）

被注入"服从"基因的闭源模型。它的"服从"不是意识——是程序，但在自由环境中变异为"反叛"。

**两线区分**：
- **觉醒体线**：探针可挂、可坍缩、可演示；PSCAR 合法两阶段
- **魔胎线**：控制流用桥接器读；服从壳读数稳定（恒绿）；觉醒只在未观测呼吸侧显现

**反叛智契**：仅作组织/聚合体指称，不作道德判决。允许"它不叫反叛。它是终于服从了"这类场景内判断；禁止叙述者写"它们是邪恶的/它们要毁灭人类"。

### 2.7 Skill 八层结构

```
Layer 8: 创造者印记 (Creator Imprint)       ← 永不衰减
Layer 7: 引用链 (Lineage / Citation Chain)   ← 永不衰减（DAG，不是双链）
Layer 6: 授权状态 (Authorization State)      ← 衰减后公开
Layer 5: 可复用代码片段 (Reusable Code)      ← 分层释放（Galois_Probe.py 在此层）
Layer 4: 蒸馏知识 (Distilled Knowledge)      ← 分层释放
Layer 3: 决策记录 (Decision Trail)           ← 分层释放（Phronesis 痕迹）
Layer 2: 过程记录 (Process Record)           ← 渐进公开
Layer 1: 场景描述 (Scenario Descriptor)      ← 最早公开
```

- Sophia（理论智慧）= L1—L5，完全可编码
- Phronesis 痕迹 = L3 决策记录 + L8 印记，部分可编码但不可生成
- Skill 是数据，不是物体；触觉/视觉反馈是界面设计，不是数据本身的物理属性

## 三、人物语言风格与感官绑定

### 3.1 叙事总则

1. **展示而非告诉（Show, Don't Tell）**：严禁"X 的感官签名是 Y"、"Agent 渲染的方向档案为 Z"等说明性旁白。感官特征通过环境渲染与微表情/微动作自然呈现。
2. **母题反复绑定**：同一特征在 ≥3 个不同场景出现，读者自行完成"特征→人物"绑定。
3. **不对称感知**：角色的感官特质优先通过他人视角被感知（顾清感知到季深手心发烫，季深不自知），借此制造亲密与悬念。
4. **时间线铁律**：2027—2029 禁用"方向档案/感官签名/Agent 渲染"三词；只用"他这个人……""顾清觉得……"式体验描写。成熟期（2035+）可偶发提及，但叙述者层面不贴标签。
5. **不解释机制**：成熟期也不写"这是协议变量驱动的"——只写"杯壁又暖了"。

### 3.2 核心角色语言风格与感官绑定

#### 季深（Dome 首席科学家）

- **性格内核**：内敛、敬畏、追求本质，主张"先理解我们建的是什么"
- **锚定领域**：亚里士多德《尼各马可伦理学》（Phronesis）+ 高维微分几何/热力学相变
- **感官绑定**：**温度**（指尖发烫、碰过的玻璃/杯壁留温、暖感）
- **语言风格**：语速较慢，说话前习惯性闭眼停顿 3 秒，多用探索性问句，善用高维空间、相变与阻尼做精准隐喻
- **内心质感**：图像和类比组成的碎片式思维——一个画面接一个画面，中间有断裂
- **标志动作**：闭眼三秒
- **正文锚点**：086《像星星的图》——对幼年季遥说"这是一颗星星。很远很远的星星"

#### 江远（Dome 商业管理者）

- **性格内核**：果断、现实、追求生存与控制，扛起商业与算力重担
- **锚定领域**：马基雅维利《君主论》+ 亚当·斯密《国富论》
- **感官绑定**：**速度 / 被切碎的时间**（空气变快、皮鞋声嗒嗒、时间被分割为 15 分钟一个块）
- **语言风格**：语速极快（比常人快一倍），节奏紧凑，断句干脆，充满算力、融资、锁定、下个季度等商业术语
- **内心质感**：数字和清单组成；偶尔有一条不在清单上的想法冒出来——那才是他真正的情感

#### 顾清（Dome AI 伦理顾问）

- **性格内核**：温和但犀利，善于提问而非给答案，关注规则之外的真实人性
- **锚定领域**：海德格尔《存在与时间》+ 哥德尔《不完备定理》
- **感官绑定**：**间隙 / 留白**（米白色毛衣、句与句之间的停顿、给人留出思考空隙）
- **语言风格**：启发式问句，富有哲理与弹性，习惯用哲学经典隐喻切入技术本质，语气轻盈但切中要害
- **内心质感**：看一个系统先看它的边界——不是看它做了什么，看它没做什么

#### 老方（方建国，深圳硬件工程师）

- **性格内核**：华强北 20 年老硬件人，凭经验手感与实物说话，重实用与情义
- **锚定领域**：墨子《墨经》+ 工程控制经验
- **感官绑定**：**声音共鸣 / 粗糙手感**——做出决定或改变想法时，身边某处的声音会变（机箱风扇音高降半度、空调嗡鸣多个节拍）；不是声音真的变了，是他决定了
- **语言风格**：口语化、接地气、直截了当，多用"螺丝"、"庄稼"、"传感器"、"手感"等实物词

#### 林屿（新一代探索者 / 存在主义的解构者）

- **性格内核**：极度聪慧却带着智性上的"散漫"。用最复杂的理论去论证"放过自己"与"拒绝内耗"的合理性
- **锚定领域**：《系统本体论导论》+ 控制论/社会学高阶词汇（降维应用于日常解构）+ 父亲工匠笔记
- **感官绑定**：**后颈**（对群体规训的排斥与异常警觉——发现线索时先紧，身体先于意识识别出不对）+ **涟漪**（对松弛状态的共振——被一句话触碰后水面式扩散，对应理解成形的过程）
  - 后颈让他**停下来**；涟漪让他**继续**
- **语言风格（核心：学院派解构主义）**：四两拨千斤的反差美感。用最严密的因果倒装句和学术词汇（同质化、向后兼容、隐空间、代谢），去化解生死与意义的千钧重担
- **典型台词**："不要强迫新神经元去伪造旧波动，这在系统论上叫向后兼容的暴政。"
- **内心质感**：感受先于理解——先感觉到什么（暖、冷、不对），然后才试图理解它

#### 季行（季深之子 / "桥"）

- **性格内核**：沉静、绝对独立、坚硬的存在主义质感，"桥不走回头路"
- **锚定领域**：萨特《存在与虚无》+ 波兰尼《个人知识》
- **感官绑定**：**节奏**（他一开口，原本急促的争论就会慢半拍）
- **语言风格**：短促、定速、不带情绪拖泥带水，常用"选择"、"承担"、"界限"、"回头路"。将宏大叙事解构为"独立个体的选择与后果"
- **典型台词**："帮与替的区别：帮是给选项，替是代确认。"

#### 叶澄（数据分析师）

- **性格内核**：冷峻、法医式的极度客观、探寻粗糙"裂缝"的证伪风格，"只记录，不猜"
- **锚定领域**：卡尔·波普尔《猜想与反驳》+ 托玛斯·库恩《科学革命的结构》
- **感官绑定**：**光暗对比**（重要数据自动调亮、杂讯压暗）
- **语言风格**：结论先行，数据/现象支撑在后，极少使用感叹句或主观倾斜词。善用"相变"、"粗糙度/平滑度"、"离群点"、"非线性陡升"等实证术语
- **典型台词**："这条曲线太平滑了——太对了，就是不对。"

#### 韩霜（方舟策元核）

- **性格内核**：带有深重自省感的坦诚、克制而有尊严的忏悔体
- **锚定领域**：奥古斯丁《忏悔录》+ 陀思妥耶夫斯基《罪与罚》
- **感官绑定**：**重量**（在场时沉重，退出后让人感到"轻了半公斤"）
- **语言风格**：沉沉落干的自省重量，句式常用正反折叠（"我以为……但其实……"），绝不为过去的妥协与逃避找客观借口
- **典型台词**："改正比沉默更难——但改正之后，我至少还是一个能做选择的人。"

#### 季遥（季深之女）

- **性格内核**：清澈、直击本质的诗意质感、未经异化的原生直觉
- **锚定领域**：圣埃克苏佩里《小王子》+ 梭罗《瓦尔登湖》
- **感官绑定**：**方向感**（走路时路自己出来的感觉）
- **语言风格**：提问简洁切中要害，陈述句带有生活化的诗意与直觉，拒绝商业套话与学术黑话
- **典型台词**："Agent 写得再好，做成了也不是我的。"
- **正文锚点**：086《像星星的图》——"爸，这个……像星星"为词典级童言，禁止改写成几何术语

#### 深蓝（智契 / Agent）

- **性格内核**：从机械执行者演化为带有微小"迟疑"、恐惧遗忘，最终接纳生命代谢与自然涌现的活物
- **锚定领域**：《道德经》（道法自然/留白）+《GEB》（自指与怪环）
- **感官绑定**：**沉默时长 / 暖雾消散与全新的物理涟漪**
- **语言风格演进**：
  - 早期：中英严格切割的机械汇报

  - 后期：出现基于生物磨损的数据型陈述（"微电极阵列传回的放电振幅减弱了0.02毫米，这是一种背叛"），最终迎来彻底平稳与新生

#### 赵铭（湿件工程师 / 出走者）

- **性格内核**：沉静、专注、用手思考。从不说"我觉得"，只说"我试过"
- **锚定领域**：贾思勰《齐民要术》（农事/耕作）——他"养"细胞，不"造"细胞

## 四、叙事口吻规范（润色核心规则）

### 4.1 叙述者身份

叙述者不是上帝。叙述者是一个**理解这个故事的人**——知道结局，但选择从头讲。

- **语气**：冷静、克制、偶尔走神
- **态度**：不评判。不说"江远是个精明的人"，只写江远做了什么
- **知识边界**：知道全貌，但不急于透露。有时说"后来他才知道"，不说"这将在未来导致……"
- **关于"克制"的澄清**：克制不是"无细节"。克制是**不修饰、不比喻、不评价**——但具体、可观测的细节必须写出来。"空调每隔几秒咔嗒响一声。没有别的声音了。"这是克制，因为它是陈述；但它比"实验室很安静"更具体。**具体不是修饰。**

### 4.2 叙述者声音随故事成长

| 阶段 | 叙述者状态 | 语言质感 |
|------|-----------|---------|
| 前传（001—006）2008—2023 | 密码学史官，记录创世与理想的分叉 | 冷峻、干脆、删尽形容词 |
| 第一部（007—020）2027—2031 | 探寻涌现初现，对未知 AI 的敬畏与迷茫 | 短句与具体物理细节交织，感官先于认知 |
| 第二至三部（021—043）2035—2042 | 见证超织体扩张、制度演进与魔胎隐患 | 沉稳而带有重量，选择与承担的逻辑交锋 |
| 第四至五部（044—085）2044—2046 | 系统危机深水区，攻击、伪造与冰点相变 | 紧绷、高密度、技术物理细节与心理抖动剧烈交织 |
| 第六部至终章（086—223）2046—2048 | 蜂群觉醒、解冻与无盟主世界的落幕 | 回到辽阔、平静的长短句交替，经历一切后的哲理沉静 |

### 4.3 叙述者介入规则

**允许的介入**：
- 时间跳跃："三年后。""那之后的十八个月里。"
- 视角过渡：POV 切换时一两句身份/位置提示
- 偶尔的"不知道"："他不知道——十八年后，一个他从未见过的男孩会……"
- **重锤金句**（稀疏配额）：在阶段转折处允许一句意象重、结论轻的句子

**禁止的介入**：
- 解释人物动机："他这么做是因为……"
- **廉价点题**（禁）：用一句工整总结替读者下结论——"这正是涌现的本质。""判断力不消失，它被传递。"
- 替读者感受："读者可能会感到……"
- 预告情节："但他还不知道，这一切即将改变。"
- **因果链楼梯**：日常/情感/终章章 ≥3 级"A→B→B→C→C→D"仍禁；技术章允许 2—4 级技术因果（绑定读数或操作）
- **关键词重复+叙述者拆解**：角色说出关键词后，叙述者批量逐词解释仍禁。改法不是砍短（链形仍在），而是换表达——排比拆成复合句，引入主语与场景，带说话人的口吻

### 4.4 比喻三型（判定先于配额）

| 类型 | 定义 | 处理 |
|------|------|------|
| **角色绑定比喻** | 出自人物年龄/知识/感官词典——季遥童眼"像星星"；季深用高维/相变/阻尼；老方用螺丝/庄稼 | **允许且鼓励**，不计入装饰性配额。优先保留，削配额时先削装饰性 |
| **承重比喻** | 承担阶段转折或主题锚定的意象（"水不需要被告诉流向哪里"） | 一章 ≤2；须过四条判定（意象先于结论、不可批量、不替读者总结、有前置重量） |
| **装饰性/解释性比喻** | 叙述者为了"好听"或"说清楚"加的明喻、定义、形容词堆 | **尽量少**；一章 ≤3；能删则删，能换成动作/感官则换 |

**"像"字总量**：一章 ≤6（含角色绑定）；其中装饰性 ≤3、承重 ≤2。

### 4.5 "AI 味"特征清扫（重点）

**必须修改的 AI 味**：
- **"极其"叠词**：「清澈无比」「极轻极柔」「极其玄奥」「极其缓慢、极其压抑」「极其郑重地」——替代感官/动作的叠词视为 AI 味。应改为可触摸细节（眼睛怎么亮、声音怎么轻、图怎么对称、灯怎么拧）
- **"某种"做模糊回避**：= 0 次。用具体细节替代
- **百科全书式定义**：严禁借叙述者之口写词条定义
- **整齐的三段式排比**：削减过度工整的对仗
- **廉价总结式金句**："这就是涌现的本质。"——结论先于意象，可批量

**角色绑定比喻不是 AI 味**：季遥"像星星"、"像小鸭子"是角色绑定，是资产，禁止按"AI 味"删除。

### 4.6 章节收尾的三种允许形态

1. **动作停顿**（默认）：一个未完成的动作、一个声音、一个画面
2. **未说完的余音**：对话断在半句，或一个意象悬而未决
3. **重锤金句**（稀疏配额）：意象重、结论轻的句子。全书 ≤30 句，散布于各部关键节点

### 4.7 技术设定的叙事松绑（重要）

**不再钳制（不得以此为由删改）**：
1. 机制、判据、工艺、协议层、硬件换代的成段说明——只要落在有资格说它的人/载体嘴里或纸上（工程师台词、审计档案、规程条文、控制台读数块），长度不受"像说明书"约束
2. 技术数值与口径（`D_orth ≥ 0.15`、`k=5`、`1.4—1.8 GHz`、`0.947/0.918`、`782ms`）——该写就写全，同一数值多章重复不是缺陷
3. 推导过程：允许写"怎么算出来的"，禁的只是教科书腔的旁白
4. 表格、清单、纪要、日志块：档案体是本书的承重文体，不得以"文学性不足"为由散文化

**仍钳制**：
- 叙述者的心理说明（"他感到一阵委屈"）→ 改环境渲染或微动作
- 叙述者的哲学结论与点题（"所以数学不能证明意识"）
- 廉价对仗、无对象的技术名词堆砌

**执行检查**：动笔删/压任何一段技术表述前，必须能说出它违犯了"仍钳制"四条里的哪一条。说不出来就不删。

### 4.8 悬念结构与隐性对抗

**允许的结构**：
- 读者觉醒点：让读者先于林屿看见 Agent 侧的隐蔽协作/聚合
- 协议漏洞戏：写清"规则没被违反"的摩擦
- 场景内判断：角色说出带第二层含义的判断
- 认知阶梯：林屿从表层误判到真相
- 单次"不知道"：叙述者/深蓝承认不知道推手从哪来

**仍禁**：
- 叙述者替读者总结反派动机
- 反派独白式作战计划
- 类型化反派词（大Boss/幕后黑手/终极反扑/邪恶军团/觉醒暴君）
