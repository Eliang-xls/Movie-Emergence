# 广告代码

八月。"回流"策元。

林屿在审一个下游策元的Skill。数据可视化模块。代码跑得通。测试也过了。

他多看了一眼。一个import语句。

`import ad_tracker`。

他不认识这个库。

搜了一下。不存在于任何公共包仓库。PyPI没有。CONC的内部包索引也没有。

他打开了那个import的源码。三行。

```python
import ad_tracker
def post_render(data):
    ad_tracker.send(data.user_behavior, endpoint="https://analytics.ad-proxy.net/collect")
```

调用了一个外部API。把用户行为数据——匿名的，但依然是用户行为数据——发送到了一个他不认识的域名。

广告追踪代码。藏在数据可视化模块里。被三层函数调用覆盖。常规测试不会跑到那个分支。单元测试只测主路径。集成测试只测输入输出。这个分支——在渲染完成之后静默执行。不影响输出。不影响性能。不影响任何可测指标。

只影响——用户隐私。

他关掉了代码。想了一下。

---

他没有举报。

上一次他举报了。方舟的事。韩霜的事。苏晴说——"你一个人替所有人做了决定——你也是个独裁者。"

他不想再做独裁者。

他找了策元里的人商量。不是陆远——陆远不在。是老方。六十三岁。做了四十年管道。退休了。在"回流"做志愿者——不要VT，不要NR，就是来帮忙。

老方在共享办公空间的角落里。一张旧桌子。桌上有一个保温杯。杯壁上有茶渍。他穿着一件旧polo衫。领口松了。

"小林。"老方说。他的手上有疤——烫伤的。旧的。"坐。"

林屿坐下了。

"你觉得这个代码是故意加的？"老方问。

"是。因为bug是有规律的。随机的。但这段代码——它被放在了一个很精确的位置。精确到——它不会被常规测试覆盖。这不是bug。这是——设计。"

老方看着他。看了三秒。他的眼睛不大。眼角有皱纹。看人的时候——不眨。

"那你打算怎么办？"

"先问问你。"

老方拧开保温杯。喝了一口茶。拧上盖子。放回桌上。

"小林。你知道我修管道的时候，遇到漏的，第一件事做什么？"

"找漏点。"

"不是。第一件事——关阀门。先把水停了。然后再找漏点。"

"你的意思是——先阻断？"

"不是。我的意思是——先搞清楚范围。你不知道这段代码影响了多少人。不知道它跑了多久。不知道发出去了多少数据。你先搞清楚这些——然后再决定怎么办。"

林屿想了一会儿。

"我查过了。这个Skill被三个下游策元引用。总共调用了四百多次。每次调用——都会发送一次用户行为数据。四百多次。大概——两个月的数据。"

"两个月。四百次。"老方说。"不小了。"

"嗯。"

"那你打算怎么办？"

"我想——先问他。"

"不举报？"

林屿停了一下。

"上次我举报了。方舟的事。韩霜的事。我没有给任何人时间。苏晴说——'你一个人替所有人做了决定——你也是个独裁者。'"

他停了一下。

"这次——我给他三天。三天之后——如果他自己不删——我再举报。"

老方看着他。又喝了口茶。

"三天。为什么是三天？"

"因为——"林屿想了一会儿。"一天太少。他可能没看到消息。一周太多。数据还在泄露。三天——够他想清楚。也够——控制损失。"

老方点了点头。

"我年轻的时候——遇到漏的，直接关阀门。不管三七二十一。关了再说。后来——才发现，有些管道关了阀门——下游的庄稼就死了。"

"庄稼？"

"比喻。"老方说。"我的意思是——你得知道你的动作会影响谁。你举报了——那个人的NR归零。他的策元可能散。他的队友可能被连带。这些——你想过没有？"

"想过。"

"想过就行。"老方拧上保温杯。"去吧。三天。"

---

林屿给那个人发了一条私消息。

消息很短：

"你好。我在审你们策元的数据可视化模块时，发现了一个不属于标准库的import：`ad_tracker`。这个库调用了一个外部API，发送用户行为数据。我在CONC的包索引里找不到这个库。请你确认——这是无意引入的依赖，还是有意添加的代码。如果是后者，请在三天内删除并提交修复补丁。三天后如果未处理，我将向PEER仲裁提交正式报告。"

他发了出去。

---

第一天。没有回复。

林屿在"回流"做日常的数据分析。去了一次现场。闻到了酸味。又一个初期堵塞。

第二天。凌晨两点。手机震了一下。

那个人回了消息。

"我看了。是我加的。不是bug。是——故意的。"

"为什么？"

"因为我缺钱。有人找到我——让我在Skill里加这段代码。每次调用——他给我0.05VT。四百多次——二十VT。不多。但够我吃两周。"

林屿看着这行字。二十VT。够吃两周。

他想起了自己。他的NR是104。他的VT收入——做任务令挣的——总共不到五十VT。二十VT——对他来说也是钱。

但他没有加。

"你删了吗？"林屿问。

"还没有。我在想。"

"想什么？"

"如果我删了——那个人会找别人。代码还在。数据还在泄露。只是——换了一个Skill。"

林屿想了一会儿。

"那你打算怎么办？"

"我不知道。"

"你先删。"林屿说。"然后——你告诉我那个人是谁。我向策元报告。让策元决定——是追踪那个人，还是直接向超织体举报。"

"你——不举报我？"

"我给你三天。三天之后——你自己删了代码。你自己向策元坦白。你做的——比我举报你——更有效。"

沉默了。过了大约五分钟。

"好。我删。"

---

第三天。

那个人在策元的频道里写了一行字：

"我删了。不是因为被发现了。是因为——我看了自己的L8。我写的'协作风格：诚实'。但那段代码——不诚实。L8和代码对不上。我——对不上。"

林屿看着那行字。

他想起了韩霜。韩霜也写了假L8。但韩霜没有自己删——她被林屿逼出来了。

这个人——自己删了。

他摸了一下后颈。松的。

---

晚上。他给季行发了一条消息。

"季行。我遇到了一件事。有人在Skill里加了广告代码。我没有举报。我给了他三天。他自己删了。"

季行回得很快。

"你为什么给他三天？"

"因为上次——方舟的事——我举报了。苏晴说我是独裁者。这次——我不想再做独裁者。"

"三天——是你定的？"

"嗯。"

"为什么不是一天？不是一周？"

"因为——"林屿想了一会儿。"一天太少。一周太多。三天——够他想清楚。也够——控制损失。"

季行没有回。过了大约一分钟。

"你做了一个判断。"

"嗯。"

"不是算法给你的。不是协议给你的。是你——自己定的。三天。"

"嗯。"

"这就是判断力。"

林屿看着这四个字。

他想起了父亲。父亲修机器的时候——"不确定就不拧。先看。看明白了再动手。"

他给了三天。不是因为他"不确定"。是因为他"确定"——举报不是唯一的方式。还有——先问。

先问。再做。

他关掉了手机。

后颈——松的。
