# 《涌现》P1 编号主序修订蓝图 v1.0

> **唯一主序：** 全部章节严格按文件名数字递增阅读。第四部与第五部标签是创作分组，不是阅读顺序。所有本蓝图中的“回溯”“档案”“余波”均通过章节原位的时间卡、来源卡和转场句实现；**不得移动文件、跳读或按部别重排。**

## 一、P1目的

P1不重复P0的技术边界清除工作，而处理P0之后仍会妨碍顺读的三类问题：同一事件的重复叙述、早年材料在后段编号中突入时缺少读者定位、以及章节标签交错造成的转场断裂。修订必须保留角色的行动、证据和选择，让“时间不是单调的”成为可理解的档案结构，而不是读者被迫重排的负担。

## 四、P1-B：第三部的逐组动作

### 1. 067—070：从单一数学危机改成多种证据

067保留顾清的夜晚和课堂，却明确6%与5.3%并非同一指标；068保留无名宪章，却把署名、规格化和方向性改为使用条件而非生死二分；069由顾清、叶澄或协调层接手跨境函件，不再让季深在2041实时处理；070的S-0947只作为匿名安全案例，结论为“风险模式待验证”，不再给出约束衰减的普适冰点。

### 2. 074—077：在原编号中拆除多稿拼接

074压缩为2034—2035的一份季深观察笔记，保留十岁季遥不代写与一次靠近屏幕的细节；075作为童年感官记忆保持独立；076是2044唯一的青年季遥主场；077改成有来源限制的谈话纪要，保留“帮与替”但绝不确认季深位置。这样读者仍顺读074→075→076→077，却能从时间卡明确看见各段不是同一日常连续发生。

### 3. 078—085：监管、经验转译与审查

陈卫国的主线必须由“索取数据”走向“只读预警—二次问题单—可申诉处置”；L8、行为记录和公开数据只能增加或降低怀疑，不能自动判伪。081不得保留规避访问控制教程；083—084将深蓝降为问题单、可撤回草案和人工确认，琥珀色保留为未知经验的保护标记。085仅补档案来源与出面人衔接，技术P0结论不回滚。

### 4. 086—088：早年档案和异常相关

086、087开头分别加入“2033秋—初冬听证档案”“2035-03-22维护交接档案”卡，仍按086、087读；088删除隐蔽权重通信确定论，改为公开日志中可见的异常簇、来源缺口和待核验关联，并保持金色蜂群是人的公开判断。
