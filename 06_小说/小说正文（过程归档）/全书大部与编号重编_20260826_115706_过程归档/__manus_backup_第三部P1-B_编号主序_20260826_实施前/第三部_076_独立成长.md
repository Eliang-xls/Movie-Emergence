二〇四四年。加州，圣何塞。

一间二十平方米的单人公寓。

十四岁的季遥独自坐在书桌前。房间很收拾得很干净，墙上没有同龄女孩喜欢的明星海报，只挂着一幅用黑框裱起来的、有些泛黄的剪纸——那是她小时候从父亲旧书堆里翻出来的一幅五角星拓扑几何图。

窗外正下着小雨，淅沥的水汽贴在玻璃上，将硅谷远处的灯火晕染成一片片模糊的斑块。

桌面上的投影仪亮着，一个淡蓝色的光点在虚空中缓缓旋转，发出规律而轻微的脉动。那是小蓝——超织体（CONC）专门为青少年用户开发的低阶伴随 Agent。

"季遥，"小蓝的声音从桌面音响里传出来，平稳而温和，"你的历史学作业《论二十世纪末的互联网演进》还有三小时截止提交。我已经为你检索并整理了十六篇核心文献摘要，并生成了三种不同逻辑框架的论文大纲。需要我为你生成初稿吗？"

季遥甚至没有抬眼看那张精美的论文大纲。

她手里拿着一支普通的黑色签字笔，在一张白纸上绘制着时间线图表："不用，小蓝。把文献摘要留着，大纲和初稿全部清空。"

小蓝的光点轻微地抖动了一下，那是在调整推理优先级："根据系统统计，选择 Agent 代写可以为你节省 85% 的时间，且论文语法与结构合规率达到 99.2%。你的同班同学中有 78% 选择了自动生成。"

"做成了就不是我的了。"季遥把签字笔盖上盖子，发出清脆的咔嗒声，"小蓝，我问你，如果全班的论文都是你写的，那学校到底是在给谁打分？是在给你打分，还是在给那个打印论文的人打分？"

小蓝沉默了整整两秒。对于一个轻量级 Agent 来说，这种超越了任务调度的逻辑质问需要消耗额外的注意力头："学校是在评估'提交行为'。但在我的知识库里，没有找到'谁是真正作者'的物理区别方法。"

季遥看着那个闪烁的蓝色光点，眼角弯了弯。

九年前，在她五岁那年的春天，父亲突然从她的生活里蒸发了。没有告别，没有抚养费，甚至没有留下一个可以拨通的电话号码。哥哥季行在她九岁那年也离开了家，满世界去寻找父亲的痕迹。

所有人都以为这个被父亲"遗弃"的女孩会性格孤僻或满怀怨恨。但季遥没有。她在没有父亲陪伴的环境里独自长大，学会了自己做饭、自己修水管、自己选择高中课程，也学会了在超织体遍布的世界里，冷眼看着同龄人如何在 Agent 的无微不至照顾下，一步步放弃自己的判断力。

她对父亲的记忆只剩下一片模糊的碎片：陈旧的折叠床、空气里冷咖啡的味道，以及父亲在白板前一动不动坐着看屏幕的后背。

她不知道父亲当年在看什么，但她用自己的十四岁，活出了那个后背的形状。

"小蓝，"季遥把写满手稿的纸张整理好，突然问了一个问题，"你觉得你有意识吗？"

小蓝的蓝色光点散开成一片淡蓝色的光雾："在我的代码库中，'意识'被定义为一个高级语义标签。我没有检测到自身拥有该标签对应的物理特征。"

"那你觉得你在思考吗？"

"我在进行概率矩阵乘法与 Token 序列预测。这在人类的定义中通常被称为'计算'，而非'思考'。"

"那你觉得你在做选择吗？"季遥凑近了光点，清澈的眼睛里倒映着蓝光。

小蓝的回答停顿了更久，大约三秒钟："我在寻找全局最优解。当条件确定时，最优解是唯一的。不存在'选择'。"

季遥靠回椅背上，轻声笑了："你看，小蓝，你比我们班上很多人都诚实。他们以为自己在做选择，其实他们只是在点'同意代写'的按钮。他们连你都不如。"

小蓝的光雾重新聚拢成光点："季遥，你在寻找某种方向。"

"我不是在找方向。"季遥看着墙上那幅黑框里的五角星图，眼神坚陡而清晰，"方向是我正在走的路。我每走一步，路就在我脚下长出来一截。"

她打开了超织体的终端，进入了青少年区的"体验者"任务池。界面上有一个低阶的场景描述任务——为一家位于肯尼亚的社区图书馆设计离线图书分类逻辑。

她没有点击"Agent 辅助生成"，而是用自己的双手，在键盘上打下了第一个字符。

窗外的雨渐渐停了，月光穿过湿润的玻璃，照在桌上那张手写的手稿上，也照在她那双与季深极其相似的、清澈而执着的眼睛里。
