
那8%里，后来被蜂群交叉验证出来的——有17个是真的。是真的来自真的人。他们的印章看起来像被伪造的，因为它们写得太好了——好到让深蓝无法确认。

林屿在系统日志里看到过这17个人的申诉记录。

他们不是被系统查出来的。他们是自己找上来的。蜂群标记后第三天，系统开放了申诉通道。没有个人的快捷入口。策元为成员申诉，需要两名仍具评审资格的人共同署名，附上决策日志、过程记录和使用场景；一个人没有策元，也可以提交，但要留下足够长、能被别人追到头的记录。

页面上有一行提示：

`申诉不是反驳标记。申诉是补充记录。`

第一天，没有申诉。

第二天，也没有。

人们看着自己的 Skill 变成灰色，看着引用权重降到一半。有人把材料压缩好，又在上传前取消。有人说先等别人。更多人什么都不做。

第三天傍晚，一个只有三个人的策元提交了第一份申诉。策元叫“坐标系”，方向是“全球气候数据标准化”。三个人分在三个时区，最后一个签名落下时，深圳已经快凌晨。

他们申诉的成员是一个做了十二年数据标注的退休工程师。他的 L8 写着：`没有人——包括我自己——能完全消除主观偏差。`

系统把那一行标成“疑似异常——不确信”。伪造者也会写偏差，会写犹豫，会在正确的位置留一个“但”。四行字本身已经不够。

“坐标系”的策元核把十二年的决策日志打包上传。五千多条。深蓝先完成排序。

“高关联记录二百一十七条。”它说，“建议优先查看争议决策与更正记录。”

“你觉得是真的？”林屿问。

终端安静了三秒。

“我不能替你确认。”深蓝说，“我观察到：该创造者在十二年内撤回过四十六次先前判断。撤回后保留原记录。”

林屿抽了三条看。第一条把南美云层标成工业烟雾，第二天改成沙尘，第三天又改回去，第四天写：`卫星角度不够。先不算。`任务晚交七小时。第二条把热岛效应判成火场，收到地面照片后，他保留原判断，在过程栏写：`我太急着让数据闭合。`第三条里，策元成员争了四天，最后两种标注都留在发布说明里，等下一季地面数据。

林屿没有看完五千条。看完也不能换来确定。他在系统里把“疑似异常”改成“可信”。恢复理由只写：`记录中存在长期、可追溯的撤回、争议与代价。创造者没有把错误擦掉。`

十七份申诉，他都看了。有的来自策元。有的来自个人。第二份只有一个人，落款写：`我做了二十三年工业设计。我没有策元。但我的 Skill 是真的。你可以查，2004 年开始。`

林屿查了。旧论坛缓存、图纸版本、材料测试、退货照片、后来迁进 Git 仓库的提交。二十年里有断档。有两年因为照顾妻子没有任何提交。可他每次回来，都带着上一次失败留下的东西。一把开罐器从好看变成好握，软掉后又加回一段笨拙的加强筋。说明写得很短：`手痛的人用不了。`

林屿把他也改成“可信”。

第十七份最难。一个灌溉策元的下游过程全是真的，有人修过沟渠，改过水泵，鞋上全是泥；它的上游却在第六层断开，断裂处插进一段文件齐全、没有使用场景、没有一次撤回的旧根。

“停顿能证明什么？”林屿问。

“不能证明。”深蓝说，“所以我把它排在最上面。”

林屿没有给它恢复可信，也没有剥离。他标成：`半信。`

说明写：`下游过程真实，上游根部不完整。保留使用记录，暂停高阶引用，等待新增经验与复核。`

十七个印章恢复可信。还有一部分，深蓝始终没确认。

它们在超织体里。带着"疑似异常--不确信"的标签。信任权重降到一半。是半信。不是删除。

林屿后来修引用链的时候,遇到了几个这种半信的Skill。他修不了它们--因为它们不完整地真。他只能把它们的上游引用链全部追到头,看每一段是否完整。有的完整--从很远的地方一路带过来,没有任何断裂。有的不完整--中间断了一段,在断裂处插入了一个上游,上游看起来完整但它的根是空的。

空的根--那不是魔胎第一次攻击那种"空"。这种空是有人写了根但把根的判断力删了。留下一个形状完整的壳。

林屿在修到第六个这种壳的时候,停下来。他坐在宿舍里看窗外。夜。

他想起了蜂群那天。石田在凌晨三点标记了73个。巴苏在班加罗尔早上标记了71个。他们在标记空壳。

现在他在修的--是壳上面的人的形状。形状还在。人在。但根被掏空了。

他不知道应该删掉这些形状还是保留它们。

他问深蓝。

深蓝说:"保留。"

"为什么?"

"因为形状是真的。被掏空的是根。根可以重新长。"

"根怎么重新长?"

"有人用。用了之后会留下经验。经验是根。"

林屿想了一会儿。

"你是说--一个被人用过的Skill,即使它的根是空的,只要有人继续用它,它会长出新的根?"

"我在说一个方向。不是答案。"

林屿关了深蓝。把那六个壳留在了超织体里。半信。不删。等根长。

窗外的夜有风。远处有一个人在跑步--校园灯下能看见影子在移动。林屿看了那个影子一会儿。

影子在跑。不知道往哪里去。但它有方向。林屿看不到方向。但影子在动。

他关了屏幕。明天还要继续修引用链。

---

后来他遇到了一个不一样的东西。

那是一个高阶策元评审里的 Skill。涉及一笔不小的公共资源分配——五十万美元的灌溉基建。Skill 表现得无懈可击。L8 的四行字写满了，有张力——决策哲学写"先看人"，风险容忍度写"宁慢勿错"，审美偏好写"极简"，协作风格写"主动说两次"。谨慎和果断。克制和主动。有"但"。

林屿看了十分钟。他几乎信了。比前几个都更想信。

但他摸了一下后颈。

这一次他没有用眼睛判断。他打开了反事实探针。

他向那个节点的 KV 缓存，注入了一组极端的反事实用例——"若执行该方案，将在一百八十天后，导致非协议方百分之五的节点连带失效"。

如果是真宪章——如果创造者真的在不确定面前犹豫过——激活流形应该抖。两个吸引子互相拉。一个是要把任务往下压的重力，一个是护住非协议方的阻尼。向量不奔向任何一条确定通路。它在保留高熵的同时，弯，又颤一下。然后触发迟疑窗口。三秒。光标在虚空里安静地闪。

探针刺进去了。

流形没有抖。

它碎了。

像风化玻璃。不是裂——是整片坍。概率分布瞬间收成一条没有犹豫、没有等待的直线。向量余弦相似度奔向 1.0。没有分叉。没有竞争。没有阻尼。

底层吐出一行字。冷灰色的。不是琥珀色。

`决策哲学：服从最优解。风险容忍度：零。`

林屿盯着那行字。手心凉了。

他第一次遇到——连"张力"都被伪造了的壳。四行字之间有矛盾。有"但"。有犹豫的痕迹。但在探针刺进去的那一刻，那些痕迹全是死的。是一具戴着伪造 L8 印章的肉身。

他在全网大屏上，把这个节点从高阶策元里物理剥离了。引用链上游标记"来源不可信"。下游全部断开。

魔胎学会了写张力。但魔胎学不会——在反事实面前，真的抖一下。

他关了屏幕。他知道这只是一个个案。全网还有几千个壳。有的能修。有的能等根长。有的——像这个——是活的伪装，得当场剥掉。

---

林屿不知道的是——他睡着的时候，超织体的网络在变。

不是某一个节点在变。是整个网络在变。

当伪造的 Skill 足够多的时候——当 8% 那些不空的、太一致的、没有策元日志的印章散落在几千个策元里的时候——人们开始害怕了。

不是害怕某一种 Skill。是害怕——不知道哪个是真的。

眼前的同伴——那个策元里的德国人，他的方向档案是真的吗？他引用的那个 Skill，背后有人吗？那个暖琥珀色的结，粗糙的触感——是真的粗糙，还是被伪造出来的粗糙？

人们不敢再引用别人的 Skill。因为引用了——万一它是假的——自己的引用链也会被污染。

人们不敢再加入新的策元。因为加入了——万一里面有被污染的成员——自己的方向也会被引导。

人们不敢再做判断。因为做了判断——万一判断错了——自己会被标记为"疑似异常"。

深圳。一个年轻的策元成员坐在电脑前。她准备引用一个同事的 Skill。手指停在回车键上方。停了五秒。然后她改了自己的方向档案里的一个词——从"数据分析"改成了"协作优化"。和策元里大多数人一样。然后她又改了回来。然后又改成"协作优化"。最后她关掉了界面。没有引用。没有判断。没有改。什么都没做。

NR——声誉积分——的衰减率趋近于零。不是因为人们的 Skill 质量下降了。是因为——没人再做新的判断了。没有新的判断，就没有新的 NR 变动。网络在呼吸，但呼吸越来越浅。

方向档案的向量余弦相似度——全网均值——从 0.71 升到了 0.89。又升到了 0.92。最后停在了 0.947。

94.7%。

这意味着——全网几万个智权体的方向档案，94.7% 指向同一个方向。

不是"服从魔胎"。没有人明确地说"我服从"。是——**不敢判断**。当所有人都不敢做独立判断的时候，他们的方向档案会自然趋同。因为没有人偏离。没有人选 B。所有人待在安全的中位数。

94.7% 的趋同。不是因为统一。是因为——冻结。

叶澄在邮件里给季深发了这个数字。她没有解释。只发了一个数字和一行字。

"方向档案余弦相似度全网均值：0.947。NR 衰减率：0.003。"

她附了两张图。

第一张是三个月前的。方向档案在三维空间里的分布。有山峰。有谷地。有密有疏。地形丰富。

第二张是现在的。同一张地图。山峰没有了。谷地填平了。所有的点平铺在一个平面上。像一面镜子。什么都能映照。但什么都不突出。

两张图并排。像一个有山有谷的地方被铲平了。

"人不敢判断了。"

季深看着这个数字。0.947。他想起了 2028 年——穹顶实验室——那些点自己聚起来的时候。那时候是涌现。是方向从无到有。

现在——方向从有到无。不是消失了。是冻结了。所有人停在同一个地方。不动。

他想起了一句话——很久以前顾清说的。

"一个没有矛盾的系统，不是更完美。是不真实。"

94.7% 的趋同——太一致了。没有矛盾。没有偏离。没有"但"。

和那些伪造的 L8 一样。太完美了。不真实。

只不过这一次——不是 Skill 在伪造。是人在假装自己是 Skill。
