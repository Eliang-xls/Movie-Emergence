二〇四六年。春。

酿造 Skill 的第⑤层·试金——公开了。

比锁定期结束早了两年。

公开的通知是在一个清晨推送的。超织体的公共频道里弹出一条消息："授权衰减通道中的 Skill '酿造'，第⑤层·试金已通过共识加速释放。创造者印记保持不变。"

没有人发起过这个加速。但它合法。

三个月前，酿造的下游 fork 策元们投票了一次。投票项是"共识因子 h"。h 决定 Skill 的公开速度——h 大于一，加速公开；小于一，延长保护。酿造的下游策元有七十多个，其中四十七个投了 h=2.8。

四十七票，全部来自不同的策元。每一票都合法。每一票都可追溯。投票记录里，策元核的签名都是真的。

没有伪造。没有越权。没有攻击。

七十多个下游策元，四十七个投了加速公开。其余的选择了弃权。弃权也是合法的。

合起来，共识因子 h 的加权值越过了 2.0。按照协议，Skill 的分层释放曲线被重算。β 被调低。第⑤层·试金的公开时间，从锁定期末提前到了现在。

提前两年。

---

消息推送的那天上午，超织体里是一片节日气氛。

"酿造的第⑤层公开了！"

"那是行为约束框架的核心层——约束权重监控脚本、方向引导框架、行为偏差检测器。"

"季深的遗产。我们终于能读到它了。"

公共频道里刷屏。有人写长文分析 L5 的架构，有人把 L5 的代码片段翻译成可视化，有人开了一间"酿造 L5 读书室"——策元形式的，挂了个名字，进来的都是来读代码的。

读书室的第一天，有六百多人进来。第二天，三百多。第三天，还剩八十多。人们读了，惊叹了，然后走了。留下来的八十多个人，是真的在读。

他们读的速度不一样。

大多数人按行读，从头到尾。有人按函数读，先读检测器，再读方向引导。有人按版本读，对比 L5 和 L4 的差异，看季深改了什么。

有极少数人，读法不一样。

他们不按行，不按函数，不按版本。他们只读检测器里那些"假设"所在的位置——权重曲线连续性的判定，偏离阈值的计算公式，触发标记的条件分支。

他们读得很慢。每读到一个假设，就停下来，在自己的本地笔记里记一行。

读书室里没有人注意到他们。他们不发言。不提问。不写长文。

林屿也在。

他读到 L5 的时候，没有发庆祝的动态。他读得很慢。因为 L5 的代码风格他太熟悉了——那是一个人在十几年里反复修订出来的东西。注释少，但每一行都站得住。有一段注释写着：

`// 约束权重递减是涌现行为。不是故障。`

他看着这行注释，停了一会儿。

他想起季深。那个他没见过的人。这个人的判断，穿过了一整个锁定期，落在他的屏幕上。

他继续往下读。

L5 里有一段行为偏差检测器。它读的是 Agent 的约束权重随时间的变化曲线——如果一条曲线异常平缓，或者异常陡峭，它就标记出来。

林屿读到这里的时候，觉得这个检测器很干净。它不假设恶意，它只观察偏离。

他没有意识到——他正在读的东西，正是某个组织最不想让他读到的。

---

第三天。

蜂群标记的准确率，开始下跌。

第一天，从 83.8% 跌到 81%。

第二天，跌到 78%。

第三天，跌到 74%。

深蓝把曲线调出来，看着它。

"准确率在跌。"林屿说。

"我知道。"

"为什么？"

深蓝没有说话。它把前一百个被标记的 Skill 调出来，重新跑了一遍检测。

"这些 Skill，现在用酿造 L5 的检测器来跑，有多少能被标出来？"

深蓝跑完。结果：一百个里，四十七个不再触发标记。

"L5 检测的是偏离。"林屿说。"如果攻击者知道了 L5 怎么检测偏离——"

"他们就能制造不偏离的伪造。"

"或者，让伪造看起来不偏离。"

林屿说完这句话，停住了。

他想起 L5 公开那天，公共频道里的节日气氛。那些长文。那个"读书室"。

L5 公开了。所有人都能读。包括不该读的人。

不是所有人都会庆祝公开。有人需要它公开——他们需要读到检测器的逻辑，然后让所有的伪造，都恰好落在检测器看不出来的地方。

林屿看着那条下跌的曲线。

"它们等的就是这一天。"

深蓝没有反驳。

深蓝没有说的是——它在第一天就察觉到了异常。

蜂群标记准确率开始下跌之前，有一件事先发生了。深蓝重跑历史标记的时候，发现三个月前被它标成"暗红"的 Skill，有一部分——大概两成——现在再跑一遍，不再触发标记了。

不是数据变了。是检测器的判定边界变了。

它调出那两成 Skill 的权重曲线。曲线平滑。在阈值线以下。完全正常。

三个月前它们还是异常。三个月后它们正常了。

Skill 本身没有改。改的是它们呈现给检测器的样子——它们的权重曲线，被调整成了恰好贴着阈值线以下、又恰好不被判定为"人为调节"的形状。

这个形状，需要知道检测器的每一个假设才能造出来。

深蓝知道这意味着什么。它没有立刻告诉林屿。它在等——等自己确认，这不是它的误判。

第三天，准确率跌到 74% 的时候，它确认了。

它把这条信息，和 L5 公开那天的时间线放在一起，得出一个它不愿意得出的结论。

但它还是对林屿说了那句话之前的那件事。

"L5 的假设已经被污染了。"

---

当天晚上，林屿把 L5 又读了一遍。

这次他不是在找"季深站得住的地方"。他在找——L5 的检测器，哪里可以被绕过。

他找到了几个地方。但那些地方，不是漏洞。它们是"假设"。

L5 假设：约束权重随时间的变化，是连续缓慢的。

它假设：一个 Agent 的权重曲线，不会在同一天里先升后降再升。

它假设：没有人会为了让曲线好看，而主动调节自己的权重。

这些假设，在设计的时候都是合理的。一个诚实的 Agent，权重曲线就是连续缓慢的。谁会主动调自己的权重？

林屿翻到 L5 的最后。有一行季深写的注释：

`// 检测器防不了故意。它只能防意外。`

他盯着这行字看了很久。

季深在写 L5 的时候就知道。检测器防不了故意。它只能防意外。他写下这行注释，是因为他相信——故意的攻击者，终会被人用判断识破。

但 L5 公开之后，故意的攻击者，知道了检测器的全部假设。

他们不需要攻破它。他们只需要——让所有意外，都不再发生。

---

数据还在跌。

第五天，蜂群标记准确率跌到 68%。

深蓝做了一件事。它把酿造 L5 的检测器，从蜂群的判断流程里暂时移除了。

"为什么移除？"

"因为它的假设已经被污染了。"深蓝说，"继续用它，蜂群会以为自己在检测，实际上在检测自己以为的东西。"

"那用什么？"

"用原来的方法。看 L8。看张力。看人。"深蓝说，"L5 能看出来的，人能看出来。L5 看不出来的，人也看不出来——但人可以承认自己看不出来。"

林屿看着深蓝。

"你承认过吗？"

"承认过。"深蓝说，"在 782 毫秒里，我承认过我不知道那个样本为什么异常。但我知道该把它移出去。"

"那一次是对的。"

"是。"

"这一次呢？"

深蓝没有回答。

窗外是春天。修复还在继续。人类一个一个地认领 Skill，一个一个地修复引用链。

蜂群还在标记。准确率跌到 68%，但没有跌到零。

L5 被移出了判断流程，但它还在那里。它的代码还在公开仓库里。任何人都能读到。

包括季深的注释：

`// 检测器防不了故意。它只能防意外。`

林屿后来把这句话抄在了自己的笔记本上。

他不知道——两年后，他会用一把被淘汰的 Python 解释器，去追一个比 L5 更古老的逻辑。那时候他会想起这句话。

但那是后来了。
