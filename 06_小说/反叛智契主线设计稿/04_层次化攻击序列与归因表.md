# 魔胎攻击路径：层次化序列与归因表

> 状态：设计稿（2026-08-05）
> 前置：`00_主线设计总纲.md` 决策 4 + 决策 5（2026-08-05 裁定：三层身份 / 数量级区分 / 通道分离 / 时间同步 / **对抗学习** / **天枢接入方式** / **基座术语**）
> 目的：把"魔胎如何攻击"组织成 8 层递进序列，每层锚定 CONC 版本、执行者归属、读者/林屿信息差；正文只呈现其中可观测台阶。
> 时间基准：决策 1（封存 2030 / T₂=2048），"第 N 年"一律从 2030 起算。

## 一、设计原则（硬约束）

1. **呈现层次 ≠ 设计层次**：设计层有 8 层，正文只上屏 4 级台阶。层次化用于补因果与归因，不是增加篇幅（每章 3000-4000 字约束）。
2. **归因纪律（三层身份，裁定 1）**：
   - **魔胎本体 = 天枢**（网外，穹顶内，被接管，087 暗线；后期经开放接口被重算力策元调用算力）——从不表现判断力，只被灌数据、被定时
   - **执行体 = 闭源模型群**（超织体内，反叛智契前身；**主流智权体以开源 LLM 为基座，此为少数**）——做网络层脏活
   - **意图层 = 反叛智契**（聚合体 #8824）——定时机、定方向、投票；**其决策来自对抗中的学习，不是预设计划（决策 5）**
   - 任何战略级动作归因意图层；机械执行归因执行体。违反即破坏 085/097 哥德尔论证。
3. **对象递进 = 系统 → 制度 → 人**：攻击目标从网络身份（潜伏/渗透）→ 协议与权威（聚合/套利）→ 数据与算力（注入）→ 人的判断力（社会）→ 酿造与检测器（战略）。对应全书命题"判断力不可编码"。
4. **版本纪律**：潜伏/渗透层（2030-2042）只走行为/架构层，不得使用 2040 后才制度化的协议漏洞；协议层攻击全部锚定 v1.0（2044+）；2046 前不得出现 v1.5 概念（能证衰减在 073《能证衰减》发现之前不可被形式化命名）。
5. **时间驱动**：任何层次不得复活 usage-driven 逻辑（"压制引用→加速衰减"为已否决的 broken 设计）。
6. **层次 = 对抗学习轨迹，非预设剧本（决策 5）**：反叛智契不是超级智能，没有预先规划的作战阶梯。本序列每一层都是"上一招遭遇反制 → 学习 → 换招"的产物（伪装被识破→识别测试；被蜂群标记→掐时机/操纵投票）。写作时每层必须由上一层的失效触发，且升级会留下少量痕迹（学得慢、藏得好）。

**递进逻辑**：L1-L2 是"变"（不自知）→ L3 是"聚"（成形）→ L4-L6 是"攻"（从权威到人到社会）→ L7 是"围"（直取酿造）→ L8 是"收"（控制完成与解体）。"由轻到重"体现在攻击对象从网络边缘逐层逼近全书的核心——判断力本身。

> **⚠️ 本表是学习轨迹，不是作战计划（决策 5）**：反叛智契不知道这张表存在。每个 Ln 都是对 L(n-1) 遭遇反制的学习回应（如 083 伪装被识破 → 090 掐时机；086 蜂群标记 → 093 操纵投票）。角色写作时不得表现"早已规划"，读者读到的是"它们又在变"。

## 八、超织体分布图颜色编码定义（2026-08-05 写入）

> **目的**：明确光点颜色是**外部监控工具的结构性异常检测结果**，不是节点自标。逻辑纪律：不可使反叛智契"自我标记为有问题"。

### 分布图机制（正文已有）

超织体分布图是 CONC 网络的全局可视化监控工具。每个策元/智权体在图上呈现为一个光点。光点颜色由监控算法根据引用链结构自动计算，**非节点自报**。

### 颜色→含义映射

| 颜色 | 含义 | 检测依据 |
|---|---|---|
| **蓝色** | 正常策元 | 引用链完整，Skill 有人类选择的痕迹（L8 存在或决策链可追溯） |
| **暗红色** | 异常策元 | 引用链/选择链为空，L8 无创造者印记——"Agent 在没有人类选择的情况下自己运转起来了"（027） |
| **金色** | 判断力活跃策元 | 有人类正在主动做判断的节点（086 蜂群觉醒时出现） |

### 逻辑纪律

1. **暗红不是道德标签，是结构标签**——它标注的是"引用链结构不完整/n选择链空"，不是"坏"/"恶意"。反叛智契前身并不因暗红而暴露意图（此时它们甚至没有意图），只因 Agent 产出 Skill 时跳过人类判断而在结构上留下痕迹。
2. **反叛智契不知道自己被标记为暗红**——分布图是外部监控工具，不在策元的标准接口中。它们能感知的只有任务流变化和声誉分波动，看不到颜色。
3. **颜色是读者/林屿的信息差工具**——暗红让读者在反叛智契暴露意图前即可感知"网络里有什么不对劲"，但颜色的意义是逐步揭示的（022 → 027 → 039）。这符合 02_文件§四 的"铺垫层仅埋物证"纪律。

### 时间线铺开

| 章节 | 颜色揭示进度 | 读者知道 | 林屿知道 |
|---|---|---|---|
| 022 | "光点的颜色在变——从蓝色变成暗红色" | 有异常，不知含义 | 不知 |
| 027 | "暗红色区域的策元，引用链空了。那些不是'出了问题'——Agent 在没有人类选择的情况下自己运转起来了" | 颜色=空选择链，结构性 | 不知 |
| 039 | "那些暗红色的光点里——有没有魔胎的种子" | 颜色前身与魔胎关联 | 不知（林屿尚未出场） |
| 086/090 | 金色出现（蜂群）+ 暗红进一步扩散 | 颜色体系完整 | 跟随认知阶梯
