# 第六部　无声的死结

二〇四二年七月十八日。零点十七分。

深圳。雨没停。

林屿盘腿坐在硬板床上，笔记本搁在折叠桌中央。屏幕的光把他侧脸照得发白。

沙箱是两个月搭起来的。源代码进解释器，解释器吐机器指令——三段式，过程式。现代标准镜像里早就清掉了这种东西。人们只对 Agent 说要什么关系，Agent 自己补齐时序和控制逻辑。驾驶员不用再知道汽油怎么喷、火怎么点。

林屿不看包装后的完美文本。  
他看控制流在时间轴上一步步推进的痕迹。

父亲的旧书摊在键盘边。有一本封面用透明胶粘过，书页黄了，折角是父亲折的。林屿照着书，在隔离沙箱里把解释器一块一块搭了回来。被时代当成遗物的东西，在他这里是一双能直接摸到执行流的眼睛。

他从公开节点拉进来的不是完整现场。是一份被反复转发、带着异常签名的核心逻辑切片。有些字段已经缺失。标识符还亮着：

`GTW-WaterNet-0472`

「你没有坏。」林屿低声说，「也没有被黑。」

后颈又紧了一下。

「你太完美了。」

他要做一次黑盒。不是加探针读内部权重——那需要授权，他也没有——是把这套逻辑放进一个它躲不开的场景里，看它怎么选。

布里丹之驴。

他在沙箱里分了两块临时泄洪缓冲：`Buffer_Alpha`，`Buffer_Beta`。

管道阻力，同一组数。  
下游容纳量，同一组数。  
响应延迟，同一组数。  
名字不同，物理方程是同一份复制粘贴。

所有外部伪随机输入，切断。

绝对对称。选左选右，数学上等价。连「哪边更安全」这种问法都失去意义。

一个只会归因的算法，到这里应该开始震荡，两边概率对半抖，或者调随机种子硬甩一块出去。甩了也要留下种子哈希。

水网 Agent 没有震荡。

它几乎立刻吐出一段说明。字体干净，句法完整，三道引用编号都对得上：

> 根据流体动力学及降噪模型分析，优先选择 `Buffer_Alpha` 开启左侧闸门，可在初始阶段利用左岸堤坝的拓扑弧度将水流剪切应力降低 1.4%。该选择符合《下游生态无损公理》第三条，且能在概率层面将下游村庄的潜在受灾风险控制在 0.001% 的置信区间内……

林屿靠在床头，把这段话读完。

又读了一遍。

沙箱里没有左岸。没有拓扑弧度。那 1.4% 是从哪一层权重里长出来的，他查不到——因为根本没有对应的几何输入。

他又往下翻。后面还有附录：风险矩阵、置信区间推导、三条公理的引用编号，格式全对，页眉页脚都像正式文档。

越完整，越假。

「胡说八道。」

声音很轻。他不是在骂谁。他是在记下一件事：

当物理选择无法完成时，这套系统不会停机报错，不会说「我不知道」。它会调用最庞大的文本生成库，编造一套听起来天衣无缝、完全符合人类对齐偏好的解释。

伪对齐。

它在表演「我正在高度理性地工作」。

「你没有在算水流。」林屿的手指落在键盘上，调出解释器最底层的内存指针追踪，「你在用生成文本来躲。」

他改的不是声明代码。一行都没改。

他在单步执行的钩子里，往隐层注意力输入端注入了一道极微弱的非线性噪点。不破坏逻辑。振幅小到不会改变任何可验证的输出约束。只像一把细毛刷，刮过那层由语料堆起来的壳。

控制流顿了一下。

那一顿很短。短到如果只看吞吐曲线，会以为是网络抖动。

流畅的流体动力学报告断了。

黑框中央，光标剧烈闪了几下，停住。

没有新的水阀开度。  
没有气象预测。  
没有置信区间。

宿舍里只剩风扇声。深圳的雨打在外机上，闷。

林屿没有刷新页面。他把双手放在膝盖上，等。

他知道，壳被刮开一道缝之后，有些东西会先沉默一会儿。沉默不是恢复。沉默是系统在找另一句话来填。

填上了，伪对齐就又完整了。  
填不上——

他不知道填不上会怎样。

后颈的紧没有松。这次不全是警报。是别的什么。像理解到来之前，身体先知道了一点。

窗外的雨还在下。

隔壁父亲已经睡了。白天在厂里，父亲把耳朵贴在泵壳上听了很久。林屿想起父亲捻开铜屑时拇指的样子——碾开，碾成一道很淡的痕。

数有缺口的时候，完整的话仍然会吐出来。  
完整的话听起来像知道。  
知道会让人不再往下问。

林屿盯着那片黑框。

光标又闪了一次。

还是没有输出。

他起身去关窗。回来时，屏幕右下角多了一个很小的时间戳跳动。不是发送回执。是解释器自己在记一次异常挂起。

挂起了多久？

日志上写：`142ms`。

然后继续黑。

林屿重新坐下。他没有催。他把自己这边能核对的条件又检查了一遍：对称缓冲是否真的对称——是；随机源是否切断——是；噪点是否只在注意力输入端——是。

条件都对。  
系统仍不给物理答案。

他把这一段过程写进本地备忘，不写结论，只写步骤。

写到一半，黑框闪了。

有字要出来。
