## 一、总目标与成功标准

### 1.1 体量与结构目标

1. 全书 **45–55 万汉字**（允许分轮逼近，不设单轮硬指标）
2. 第六部 156–181：章均 **≥ 2,800**，关键战役章 **3,200–4,500**
3. 中后部（第三–五部）若干「过薄过程章」按角色/主题补足，**不**为凑字灌水
4. 三条主线 + 三关卡 + 深核战役可**连续通读成体**，冷读不掉戏

### 1.2 质量红线（全轮共用）

1. 基线只读  
2. 硬科幻是资产，嵌进动作  
3. 口吻标准：禁金句工整收尾；「不是A是B」≤1/章  
4. 禁元卡 / 维护页插页 / 笔记仪式 / 赵晨报幕 / 金句链  
5. 章节编号 ≠ 故事时间；跨章改写按故事时序校验  
6. **理论增强 = 场面化**，禁止贴理论摘要/公式推导课  
7. **地理文化 = 有人在场的具体地点**，禁止「某国某市」空名或旅游手册式描写  
8. 去现实化清洗方案仍生效：真实 AI 品牌虚构化；真实金额改原生数值；**地名可保留现实锚点**（硅谷/深圳/绍兴/东京/圣保罗等已在用）

### 1.3 理论框架使用边界（T 维度铁律）

| 允许 | 禁止 |
|---|---|
| 人物用专业判断「用到」概念（老方不懂完备性但懂闸） | 旁白讲解 A5 / 导序列 / η(N) 公式 |
| 叶澄屏幕上的拓扑地形、林屿示波器上的 1.4GHz | 插入论文式定义框 |
| 深蓝/天枢内部「不能量只能听」的身体化呈现 | 60 维光谱逐条说明书 |
| 对白里半句术语 + 动作完成 | 顾清/季深上哲学课 |
| CONC 治理动作（复核/异议/退出/签名）落在具体人 | 协议栈名词轰炸 |

CONC 合订本可作**设定与治理细节库**；伽罗瓦塔可作**深蓝/天枢意识判定**的幕后科学；60 维光谱可作**深蓝内心与魔胎伪对齐**的隐性结构——**读者先看见现象，后在需要处才感到框架**。
