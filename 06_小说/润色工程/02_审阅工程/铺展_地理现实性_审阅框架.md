## 〇、本轮用户指令（摘要）

以**数据中心**为范例，对全文做地理/国家/城市/人物/物件/语言文化的合理性审阅与细节修补：

- 故事背景国、城市、政策、部门必须与现场相符  
- 水网：是哪的水（河/湖/江）、谁管、怎么调度  
- 医疗：巴西医院不要套中国处理方式  
- 修补以**完整故事线/人物线**为单位，不是章节打补丁

## 一、作业流水线（每场景类相同）

```
1 知识底稿（地点+制度+物件+禁项）
2 扫描地图（现文 vs 底稿；标「套错 / 悬空 / 合格」）
3 补写规范（必留声部 / 必改点 / 禁项）
4 按人物线定点嵌入（1–数句/场，贴身体与物件）
5 验收（冷读像不像当地；无旅游手册；无政策想当然）
```

## 三、场景类知识卡（最低要求）

### 3.1 水网 · 绍兴柯桥

| 项 | 必须先搞清再写 |
|---|---|
| 水体类型 | **河网/平原水网 + 枢纽闸泵**，不是水库泄洪救秧式叙事；可挂曹娥江/钱塘江口外江潮背景，避免写成黄河/官厅腔 |
| 谁管 | 流域与地方水行政、枢纽调度、灌区/排涝职责；**不要**套用完全另一套行政区「河长」口吻时注意时代与职能是否匹配 |
| 气候 | 梅雨、台汛、短历时强降雨；内涝与外江顶托 |
| 物件 | 闸门、启闭机、泵、胶鞋、机柜水汽、黄泥水 |
| 禁 | 用华北节水农业语汇写江南排涝；用美国 corps of engineers 腔 |

**楚河（昂戈）**：中亚干旱区灌溉与跨境河，雷声泥石流、棉田需水——与江南**不可同构政策腔**。

### 3.2 医疗 · 圣保罗

| 项 | 必须先搞清再写 |
|---|---|
| 机构性质 | 公立/州立/慈善（如 Santa Casa 类）与私立差别；不要默认「三甲+医务科」 |
| 人 | 护士站交接、家属等待、葡语称谓与标识 |
| 设备与警报 | 输液泵、ICU 流程；报警文化与上报 |
| 禁 | 红包、病历本皮、中国医患办腔；「关系科」 |

### 3.3 算力与调查（本轮范例）

| 项 | 必须先搞清再写 |
|---|---|
| 电与冷 | 水电/风光/市电+柴发；冷板/风冷；烟尘/高温对进风 |
| 进出 | 陪同、范围文书、不可拷、律师/法务 |
| 辖区 | 美：联邦+州+公司；中：协调调查与跨境不任意复制；欧：数据保护与跨境程序 |
| 禁 | 全息中央室；无授权刷卡；「一键开深核」 |

### 3.4 深圳（人物主场）

| 项 | 注意 |
|---|---|
| 气候 | 回南天、暴雨打空调外机（正文已有） |
| 物件 | 华强北档口、旧设备、维修单手写签名 |
| 禁 | 写成「电子垃圾城」猎奇 |

### 3.5 有意留白

海边村：潮、石、风、盐——**不补地址**。

## 四、扫描标签体系

| 标签 | 含义 | 动作 |
|---|---|---|
| OK | 当地感与制度基本对 | 不动 |
| THIN | 有名无物 | 1–2 句感官/物件 |
| **WRONG** | 套错国/制度/水体 | **必改** |
| SUSPEND | 有意模糊 | 保持 |
| OVER | 旅游手册/设定宣告 | 削 |
