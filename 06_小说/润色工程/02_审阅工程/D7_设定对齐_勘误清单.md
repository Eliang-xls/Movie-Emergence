## 2. 「能证衰减」分叉（核心勘误）

### 2.1 事实分叉

| | 设定/协议层 | 正文 126 层 |
|--|------------|------------|
| 问题 | 静态能证 → 魔胎权威只增不减 | 默认排序按近期更新 → 旧贡献沉底 |
| 命名 | 「能证衰减」→ 形式化为半衰期 **18 个月** 写入协议 | **「旧贡献的可见性偏差」** |
| 时间 | 设定写 2048 前后写入协议 | 正文事件在 **2046-01**，只到草案开放评论 |
| 效果 | 权威/能证随时间衰减 | **不减权、不减署名、不减历史**；只加可见入口 |
| 文内自注 | — | 「章名上挂着『衰减』，落到文件里，一个『减』都没有。」 |

### 2.2 对齐裁决（双层，正文优先）

1. **叙事层（L-UI）**：126 = 可见性偏差。任何「126 章写了半衰期」的表述**作废**。
2. **协议层（L-协议）**：半衰期 18 个月 = 终局制度演进，**保留**于设定，但必须标明「发生在 126 之后 / 尚未在正文落地」。
3. **调研层（L-知识）**：β=1.5、18 年锁定期、残余 ~19% = 酿造 Skill 知识价值模型（`06_调研资料/04_衰减曲线与攻击机制.md`），**与 126 无直接同一性**。三者不得互指。
