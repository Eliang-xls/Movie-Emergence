## 一、必留风格

1. 短句；边界词（范围、待核、无法核验、不应作出的推断）  
2. 身体细节贴林屿（后颈、手、汗/潮气）与叶澄（光暗/失落克制）  
3. 硬科幻 **嵌动作**：对称缓冲哈希、伪对齐话术残留、0.947 语境、1.4GHz 粗对齐  
4. 程序在场：书面范围、在场人、不可拷、可拒绝  

## 二、必禁

| 类 | 例 |
|---|---|
| 动作 | 破门、拔线、格式化、独自进 B3 |
| 口吻 | 金句链收尾、「终于真相大白」、英雄广播 |
| 结构 | 元卡、维护页插页、笔记仪式、赵晨报幕 |
| 角色 | 林屿=调查员/监管；叶澄=神探；EU=一键开深核 |

## 三、场面配方（写时对照）

### 3.1 开场（约 200–350）

- 先纸与人：范围说明书厚度、陪同姓名职衔（可无名「协调方的那位」）、手机是否留存  
- **不**开门见山打斗/警报  

### 3.2 接口室感官（约 400–600）

| 通道 | 内容 |
|---|---|
| 听 | 液冷泵/风机低鸣；比 174 更「受控」的安静 |
| 温 | 热风道 vs 走廊空调；林屿后颈潮 |
| 视 | 指示灯阵列、镜像屏、纸质签到 |
| 禁 | 全息中央室、无授权刷卡 |

### 3.3 黑盒动作（约 900–1200）

- 林屿**只跑清单**：对称缓冲、历史 0718_02 时间戳对照、输出是否与物理输入对应  
- 系统给**流畅但无法核验**的说明（伪对齐话术可回声，但**不复制 157 整段**）  
- 他写：无法核验；不写「它醒了」  

### 3.4 墙外对读（约 350–500）

- 叶澄：谱线与冷却日志粗对齐；**像≠是**  
- 林屿远程看图，不赴美破门  
- 失落克制（对齐 173–175）  

### 3.5 EU 纸（约 80–150）

- 一页回函/摘要条  
- 「仅就辖区内日志与跨境请求程序作复」  
- 「不构成对美国受限生产的结论」  

### 3.6 收（约 300–450）

- 异议入口、下次复核日期  
- 林屿边界：我能确认的只有……  
- 与 175「水光」、176「两栏」同构；**禁**金句链

1. 指定接口 / 镜像 / 合成负载  
2. 对称缓冲参数表与哈希（可引用 157 方法，不重演）

4. 0.947：样本相似度，不是同源证明  
5. 1.4GHz：粗对齐，不闭环  
6. 书面范围、在场人、不可复制条款
