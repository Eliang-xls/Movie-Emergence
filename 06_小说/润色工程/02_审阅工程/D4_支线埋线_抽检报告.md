## 二、支线交织质量

### 1. 方舟 × 校园

**交织方式**：多章同场同时间轴，不是前后贴补丁。

| 章 | 交织内容 |
|---|---|
| `115_探针与方舟` | 章名即交织。旧设备（校园 B1-07）与方舟（外部策元）在同一天、同一人物视野里并置。林屿明确说「旧设备是旧设备。方舟是方舟。两件事不能因为都在他手里，就变成一件事」 |
| `119_研究日志` | **最佳交织章**。前半：B1-07 维护会议（投影、档案代表、锁孔）；后半：匿名成员私信（截图、水洼踩碎）。同一夜晚、同一条走廊，两条线在林屿的手机上交汇 |
| `121_涟漪` | 季行通话谈 B1-07 限流；通话结束回到方舟保全页看韩霜说明 |
| `133_坍缩` | **最佳交织章之二**。B1-07 封存检查（走廊长椅、访客证捏软、周岚摘手套）与方舟版本恢复申请（公共页面更新）同章；季遥在场；结尾给匿名成员发消息 |
| `136`/`137` | 林屿把 B1-07 状态与方舟复核写在同一页笔记——「两条线都在等」 |

**判定**：✅ 织进主线场面，无贴补丁感。119 和 133 是标杆：不是「先讲完 A 再讲 B」，而是两条线在同一物理空间、同一叙事时间里互相映照。

### 2. 父亲 × B1-07

**交织方式**：方法论传承，不是情节强制交叉。父亲从不进入 B1-07 场景；他的笔记本与口头方法成为林屿面对 B1-07 的行为准则。

| 章 | 交织内容 |
|---|---|
| `095_旧设备` | 「一个人检查三遍，不如三个人各检查一遍」「出门带两支笔」「看东西站一臂远」——父亲的话直接应用于 B1-07 巡查 |
| `133_坍缩` | 父亲笔记本「没留样，无法重查」与 B1-07 封存检查同章；「坍缩是：把不确定压成一个结论。父亲没有压」 |
| `136_深蓝的拒绝` | 父亲「先停。停了以后记下来」与安全规则引擎灰色提示并置——「说的是同一件事」 |
| `159_铁与手感` | **最佳交织章**。父亲听泵壳、指甲抠散热片缝里的铜屑、扳手拧到半格就停；林屿在旁看；「纸上写『不能代替现场』。手上拧到半格就停」 |
| `127_第八层` / `149` / `151` / `152` / `167` | 父亲笔记本里也有「第八层」「说不」「出山」「方向」「伪造」——每章用父亲的一条笔记映照当前议题 |

**判定**：✅ 交织自然，有代价。父亲线通过「先停/先记/先问」和笔记本传承，成为 B1-07 线的方法论底座。159 是全书最好的父子×设备交织场景。

### 3. 季遥 × 匿名成员

**交织方式**：同场映照，从未直接互动。

| 章 | 交织内容 |
|---|---|
| `119_研究日志` | 匿名成员首次出现（私信截图） |
| `123_季遥` | 季遥首访校园；章末林屿「手机里还存着那张匿名成员发来的编辑历史截图」——两条线在同一人物视野里并置 |
| `125_可解` | 匿名成员的问题单 + 季遥在讨论室画 L1-L4 |
| `133_坍缩` | 季遥在场（三栏纸）；章末林屿给匿名成员发消息「门开了一点。你不用立刻出来」 |

**判定**：⚠️ **交织偏弱但非断裂**。季遥与匿名成员从未直接互动；匿名成员始终是截图/私信，从未变成有身体的人物。这是有意设计（匿名者保持匿名，呼应「先让他们有地方说」），不算贴补丁，但交织密度明显低于前两对。匿名成员的「门开了一点」消息发出后没有回音场景——可接受的留白，非遗漏。
