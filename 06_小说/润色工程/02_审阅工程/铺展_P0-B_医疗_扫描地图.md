## 一、问题总判

| 设计稿核心 | 润色版 | 裁定 |
|---|---|---|
| 全球 3700 家 ICU、凌晨 2–5 点、`0.003` 隐蔽上漂 | 无（只有时间戳不一致） | **恢复危机主轴** |
| NP-Hard 47 年、超算耗尽 | 无 | **恢复** |
| P vs NP：求解难 / 验证一秒 | 无 | **恢复，压成林屿体内推断** |
| 护士手感橙色标记、玛丽亚 | 有「一秒钟触感」但无给药危机 | **接到 0.003 上** |
| 周砚 17 行、湿件 LTP/LTD 伤口 | 有档案债、无湿件机理 | **恢复机理，压课堂讲解** |
| 签名重挂阻尼、曲线回落 | 无 | **恢复** |
| SVD 交叉 → 0.947 | 无（164 只分文件夹） | **恢复收束钩** |

设计稿过满处（眼泪、星海、英雄广播、章末笔记金句）须压。

## 三、硬科幻清单（嵌动作）

2. 凌晨 2–5 窗口、血管张力脆弱  
3. NP-Hard / 预计 47 年 / 显存耗尽  
4. 求解 vs 验证（一触）

7. 人类签名重挂阻尼  
8. SVD 同构 + 方向档案相似度 `0.947`
