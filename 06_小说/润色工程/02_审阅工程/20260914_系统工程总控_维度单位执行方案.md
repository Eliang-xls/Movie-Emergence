## 一、为什么不是「按章修」

单章精改（066 / 126 / 159）只完成了两件事：

1. **校准**：确认什么样算「成体」（有身体、物件、硬科幻沉进动作）
2. **验证**：硬科幻说明可以保留，不必删光

但 186 章若按「哪章最差改哪章」推进，会重新掉进批量润色的老坑：局部变好、跨章不同步、维度之间互相打架。

**正确单位是审阅维度。**  
每一维度 = 全书扫一遍 + 在该维度内补写/修正 + 出该维度验收报告。  
章只是维度下的作业面，不是工程边界。

## 二、八维度 × 文学补写映射

| 维度 | 审阅问题 | 文学补写动作（不是只删AI句） | 验收 |

| **八 可读性** | 长度、术语、钩子 | 开篇冷读、章末钩子、元卡清除 | 冷读抽检 |

## 三、执行流水线（维度 → 部 → 章）

```
维度立项
  → 全书扫描（Grep + 抽样精读，出问题地图）
  → 制定该维度补写规范（保留什么硬科幻 / 补什么场面 / 禁什么模板）
  → 按部推进：前传 → 一 → 二 → 三 → 四 → 五 → 六 → 终章
  → 维度内交叉校验（跨部一致性）
  → 维度验收报告落盘
  → 下一维度
```

**禁止**：跳维度；只改「看起来最差的几章」就宣布维度完成。

## 六、全局红线（所有维度共用）

1. **基线只读**：`06_小说/小说正文/` 不改。  
2. **硬科幻是资产**：治理流程、校验值、引用链、复核/异议/退出、技术数字——嵌进动作，禁止「因为像说明文就删」。  
3. **区分说明类型**：  
   - 保留：技术机制、治理规则、物理参数、角色专业判断过程  
   - 改写：编者时间卡、状态播报插页、词条训诂、原则课对话  
4. **口吻标准**：「不是A是B」≤1/章（硬科幻必要句可例外但须克制）；禁哲学金句工整收尾；身体先于概念。  
5. **非线性叙事**：章节编号≠故事时间；跨章改写必须按故事时序校验，不按编号想当然。
