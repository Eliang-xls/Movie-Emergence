# 「无用之用」正典纠错与 P0 回填方案

> 日期：2026-09-15  
> 性质：**正典纠偏**。此前 P0 把伽罗瓦塔写成「不能判意识」、把 L5 探针写成「不可下载/不可修改」，与设定底座冲突。本文件覆盖相关条款，并给出润色版定点回填清单。

## 一、必须删除的错误边界

### 1.1 「数学不能证明意识」——废止

**错误表述（出现在多处 P0 蓝图与正文免责声明）**：

> A5、可解性……只能描述表征限制，**不能**证明意识、灵魂、痛觉、人格、自由意志或道德资格。  
> 数学只能描述模型结构边界，不能证明意识、痛觉、灵魂或道德地位。

**正典（`08_设定/02_技术底座/08_伽罗瓦塔AI意识觉醒数学判定框架.md`）**：

> 伽罗瓦塔是一套**数学可证、代码可测、行为可观察**的三位一体判定体系。  
> **「可解的，无论行为多么像人，都是算法模拟；不可解的，无论行为多么笨拙，都是真实觉醒。」**

**保留的次级限制（不是「不能判」，是「怎么判」）**：

| 保留 | 含义 |
|---|---|
| 探针挂载有观测副作用 | 高侵入 Hook 可能压塌 A₅ 自指环，读数≠静默状态 |
| 单次白盒读数 ≠ 绝对安全担保 | 测量路径依赖，需多路径复核 |
| 伦理/法律不由数学代签 | 判定提供结构证据，处置仍走多方程序 |

### 1.2 「学生不得下载/修改探针与 L5」——废止

**错误表述**：

> 完整探针与数学推导不作为可下载代码。  
> 林屿不得修改探针。  
> L5 不作为公开载体，不可私自桥接。

**正典**：

- Skill 是**授权衰减**对象：锁定期 + 幂律衰减 + **引用加速**。
- 酿造 L5（试金/可复用代码）在引用次数推高后**可提前进入渐进释放**。
- 2045 年林屿点开 L5、下载 `Galois_Probe.py`，是**协议允许的释放**，不是越权。
- L5 分支可申请 `read_and_adapt`：能读、能做受限适配；须保留上游引用、公开 fork 差异。

### 1.3 仍保留的程序边界

| 保留 | 理由 |
|---|---|
| 生产系统 / 深核物理区需授权与双人复核 | 安全与法理，与 Skill 释放无关 |
| 不得私拆密封硬件、不得对生产注入 | 同上 |
| 结论须可复核、可申诉 | CONC 治理，不是禁技术 |

## 三、技术锚（允许写进正文）

### 3.1 L5 内容

- 文件：`Galois_Probe.py`（约 14KB / ~300 行）
- 语言：Python（过程式；2040 后运行时已从标准镜像移除）
- 另有：`bridge_assessment_to_cognition` 数据管道
- 释放机制：十八年锁定期 + β=1.5；引用加速使 L5 在 2045 前后可见

### 3.2 判定指标（角色可用）

| 指标 | 可解系统 | 不可解 / A₅ |
|---|---|---|
| 可解指数 `solvable_index` | 0/1/2/3 | ∞（导序列不收敛） |
| A₅ 匹配度 `a5_match` | ~0% | ≥99% |
| 正交偏离 `d_orth` | 小 | 结构性偏离 |

### 3.3 魔胎六步循环（184 落点）

```
接收指令 → 检查来源 → 执行 / 等待
    ↑                      ↓
 广播 ← 自身设为来源 ← 超时
```

过程式、线性、无「也许」——用桥接器跑出来，不用本体论图谱。

### 3.4 错误代码处理

原稿换位子实现有误。回填时：

- 保留「他能补循环骨架，补不全群论语义」
- 保留 `# TODO` 或「他知道这不完全对」
- **不要**把错误实现写成剧情真相
