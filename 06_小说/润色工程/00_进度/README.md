## 执行规则

1. 每章：读全原文 → 补对白/感官/身体/物件 → 模态归一 → 缝合衔接 → 反AI自检 → 写入润色版
2. 字数：只增不设上限；目标单章通常 1800–4500 字（按内容密度伸缩）
3. 文件名：与基线一致（便于对照），文内标题编号与文件名编号对齐
4. 禁止并行压缩、禁止跳章、禁止在改写阶段做内容删减
