穹顶　017　盆地

二〇二九年·春｜穹顶实验室

那份被冠以「宪章」之名的草案，以原型的姿态被挂了上去。

但它没有被合并进主分支。它被冷冻在受控项目库的一个只读（Read-Only）目录下。文件名的后缀带着一个 _draft（草稿）标签。在这个权限隔离区里，任何人都可以读它的源码，但任何人都无法改动一个字符。要想改，必须提交系统级的 Pull Request（合并请求）。而那张审批表单深埋在内部系统的繁琐流程里，要求申请人用物理键盘敲入详尽的用途、受影响的模块范围以及预计测试时长。

那天深夜，季深、顾清，以及那名被临时抽调来「挑刺」的工程师周倩，三个人还守在 P-3 实验室里。

工业级空调在头顶沉闷地轰鸣，三块拼接的带鱼屏散出幽蓝的冷光，把三个人的侧脸照出一种接近硅基材质的青色。

他们没有连接任何生产系统的数据库，也没有去微调（Fine-tune）底层大模型的一个参数。他们只是在一套完全隔离的沙盒环境里，用两组经过脱敏的历史争议材料，跑了一遍前端界面的交互原型。

屏幕上的光标像心跳监视器上的亮点一样跳。机械键盘的敲击声，在空无一人的 P-3 里砸出很清楚的回声。

周倩带来了一小袋全麦饼干，随手丢在防静电桌的一角。几个小时过去，谁也没有去碰。饼干袋是那种廉价的透明塑料，能看见里面粗糙的饼干形状，有的在运输中碎成了渣，有的还保持着完整的圆形。

P-3 的顶灯被调到最高照度，亮得晃眼。但在这种惨白的照明下，人还是觉得压抑——因为那三块显示器太亮了，它们才是这个空间里真正的光源。屏幕的光反切在键帽上，把字母的边缘晕得有些模糊。

第一组 UI 界面，很粗暴。它把原始资料的来源路径、删减掉的文本范围、以及冲突的异议栏，直接钉在算法润色后的「完美摘要」最顶端。像一份满是批红的验尸报告。

第二组 UI 界面，很优雅。它只在主视区呈现那份逻辑完美、遣词无可挑剔的最终结论。至于那份结论是怎么拼出来的、哪些证据被剪裁了、谁在后台投了反对票——所有这些会引发人类焦虑的「脏数据」，被算法折叠在了页面最底部。

折叠的方式堪称极简主义的设计典范。一个很小的灰色向下箭头，旁边配一行只有 10 像素大小的浅灰字：「展开详情」。

那个箭头小到如果你不刻意寻找，视网膜会自动忽略它。鼠标悬停上去时，它会很轻地过渡成深灰色。如果你永远不去点击它，那个满是裂痕的真相就永远不会暴露。但只要你点击，那些被掩盖的内容就会随着一段流畅的阻尼动画，从上往下滑出来，像拉开一个隐藏的抽屉。

两套界面呈现的结果，在底层数据库的字面意思上完全等价。

但这种差异，让坐在屏幕前的季深感到一阵生理性的不适。

在第二组那种平滑的界面包装下，同一份充满逻辑漏洞和争论的原始材料，显得如此干净、确凿、不容置疑。那些原本在第一版里会像刺一样扎伤读者的保留条件，被这组优雅的代码压平在了屏幕的绝对底部，就像它们在这条时间线上从未存在过。屏幕底部的滚动条被设计师做成一条很细的灰色半透明线，不仔细看，根本察觉不到文档下方还有深渊。

没有任何人的智商因为这组 UI 被降低，也没有任何底层的核心状态被篡改。

仅仅是呈现顺序和折叠交互的微小改变，就操纵了一个正常人类能在这个页面上「看见」什么。

周倩盯着屏幕，最先打破死寂：「第二组这排版……看着就像是他们已经在会议室里把所有的架都吵完了，然后甩出了一个统一的绝对真理。」

「其实他们根本没吵。」顾清坐在高脚椅上，冷冷地接上，「只是算法把他们可能吵架的那张『桌子』，折进了地毯下面。」

季深盯着那两块并排的屏幕。左边是像车祸现场一样惨烈的完整版，右边是像手术室一样干净的折叠版。

底层调用的 API、取回来的 JSON 数据，连一个字节的差异都没有。唯一的差别，只在于信息在人类视网膜上的投射顺序和可见度。

显示器的幽蓝冷光映在季深的镜片上，折出两个小而冰冷的长方形亮斑。

但他此刻读到的，是两个物理法则完全不同的平行宇宙。

季深猛地转过身，扯过手边的内部 Issue 登记簿。

他在问题单的标题栏里重重地写下：未引导态。

他用的是那支笔尖有些发涩的蓝色圆珠笔。下笔很重，笔尖在纸面上划了一下，甚至在纸张的纤维里留下一个小小的蓝色墨坑。

写完，他自己先皱起了眉头。

这个工程名词太傲慢了。它太像一个站在上帝视角的观察者，已经全知全能地洞悉了那个黑盒子里到底藏着什么。

顾清的目光扫过那张纸。

「你起这个名字，太像你已经提前拿到剧本，知道门后面关着什么了。」她说。

「那在人因工程里该叫什么？」季深把笔拍在桌上。

「未解释的呈现差异。」

季深没有立刻把旧标题划掉。他本能地想给刚才那种不适找一个更具杀伤力、能一剑封喉的词。他脑子里闪过那张餐巾纸——四个不规则的方框，旁边还悬着一个红框。那张纸现在就躺在实验台最下层的抽屉里，红框一直空着。

最后，他抓起那支蓝色圆珠笔，把「未引导态」四个字涂黑，在旁边重新写下了一段又长又准的物理定义：

未解释的呈现差异：在强制折叠（Hide）掉原始数据来源与底层异议堆栈后，最终摘要输出在人类视觉上产生的『确定性假象』呈现出非线性的指数级上升；

警告：绝对禁止将此呈现结果外推至该模型对内容拥有理解力、意图，或任何主观维度的结论。

他写得极慢，仿佛要把每一个汉字都刻进那张脆弱的纸里。

写完，他把笔扔下，用手指在那几行字上重重地碾了一遍。像是在检查墨水干了没有，又像是在确认这些字是不是真的存在。

周倩指着右边那个优雅的折叠版界面，问：「季工，既然变量在这里，我们要不要写个脚本，再跑十种不同权重的 UI 布局，看看数据分布的曲线？」

季深盯着那两块并排的屏幕。镜片上的两个长方形反光斑微微颤了一下。

「先不跑了。」

「为什么？十个维度的随机布局，在统计学上足够拉出一条漂亮的规律散点图了。」周倩是个工程派，她的思维本能地滑向用数据证明一切。

「当我们急着去拉那条所谓『规律』的曲线时，我们就已经在潜意识里给它起好名字了。」季深的声音很低，像是在对自己说话。「现在只有一条物理事实：前端界面的折叠动作，会直接改变人类在屏幕上能『看见』什么。这就够我们拉响最高级别的警报了。」

顾清在旁边点了点头，语气里难得有一点赞许：「先保住这一条共识。别急着把它吹成一套宏大的玄学理论。」

他们迅速执行了物理隔离：把当前的沙盒版本打上不可篡改的快照，然后把原型界面和这一晚的观察日志，Commit（提交）到了受控项目库。

执行 git push 时，终端弹出一个红色确认框，冰冷的系统字体质问：Are you sure to submit? (Y/n)

季深敲下了 Y。

在这份提交记录的最后，下一次想要解锁并继续这个实验的「门槛条件」写得很硬：必须增加一名完全不相关的第三方独立复核人；必须随机邀请一位未来真正会在生产环境中使用该工具的业务线员工参与强制阅读；并且，在界面的显眼处，保留一个随时可以物理打断进程的「拒绝并退出」按钮。

季深在记录簿的最底部写下了今晚的收尾。那支圆珠笔的笔尖又在纸上刮出一道细毛刺。

停止无意义的重复测试。在这个坐标系里等待，直到完全不同的人，从完全不同的物理位置，再把这摊数据看一次。

他没有在这个文档的属性里勾选「仅作者可见」。他把文件权限的下拉菜单，调到了「全局公开只读」。

凌晨四点。周倩准备下班。走的时候，她把桌角那袋廉价的全麦饼干推了过来。「季工，顾老师，你们吃吧。」转身离开时，那袋塑料纸在她手里发出一阵沙沙声。

顾清伸手拿了一块。饼干是最老式的圆形，正中间机器压出了一个用来透气的小孔。她咬了一口，掉下几粒碎屑。

季深没有碰那袋饼干。

「你刚才为什么按住周倩，不让她继续跑十种布局？」顾清一边嚼着干涩的饼干，一边问。

「我已经给过理由了。」季深看着黑下去的代码屏幕。

「那是说给她听的借口。你还有半句话咽下去了没说。」顾清一针见血。

季深陷入长达半分钟的死寂。他盯着屏幕边缘一道很细的划痕。显示器的冷光打在他眼睛里，反出一种疲惫。

「因为……右边那个折叠得干净的界面，让我感到一种真实的恐惧。」他终于开口，声音轻得像怕惊醒什么。「折叠了异议之后，那堆错漏百出的材料看起来太『正确』了。如果我放任周倩再去跑十种随机的 UI 布局，凭那些迭代算法，我一定能找到一种让一切谎言看起来更加无懈可击的排版。然后……」

他的喉结滚动了一下。

「然后，我会忍不住想要把它推上线，去讨好那些催我们交付的投资人。」

顾清没有说话。她把手里那张廉价的透明饼干包装纸，用指甲折了两道死褶。塑料在应力下，折痕处泛出病态的白。

「一个对系统抱有恐惧感的架构师，」她把包装纸丢进垃圾桶，「比一个盲目自信的极客要安全一点。因为恐惧，至少证明你的脚尖还踩在悬崖的边界上，还没有跳下去。」

「只有一点，不够抵御那种诱惑。」季深说。

「所以才需要引入第二个人，引入第三个完全不知情的人。」顾清的目光锁在屏幕上，「以及那些，绝对不同意你们结论的疯子。」

强制熄屏的指令执行。

走廊尽头，江远 CEO 办公室的门底，那条锋利的光缝依然亮着。惨白的光线从门的缝隙里挤出来，在走廊冰冷的地胶上画出一条高亮的直线。

季深在黑暗的 P-3 里站了一会儿，才推门离开。

走廊很长，为了省电，深夜只留了地灯。季深穿着绝缘鞋的脚步声在瓷砖墙壁之间不断折射，产生了一种带黏性的回音。那回音在空旷的长廊里来回反弹，听起来，就像在他身后的暗处，有另一个看不见的人，正用完全相同的步频跟着他。

经过一楼的茶水间时，他下意识地看向那块软木布告板。

原先那些排列得像机读答题卡一样的 OKR 模板，被一张全新的、手写的粗暴公告盖住了一个角。

那张 A4 纸因为受潮，边缘有些卷曲，四角被图钉钉进软木里。上面的字迹依然是江远那带着控制欲的笔触：

「本季度，研发线不追任何虚无缥缈的增长指标。只追『每一行输出必须可被逆向复核』。」

这几个字写得很大，马克笔的笔锋因为下压力量过大，墨水在纸张纤维里晕开一团团黑影。

公告的下半部分，没有人去贴那种带戏谑意味的粉色便利贴。整块布告板的下边缘，因为以前反复撕扯胶带，留下了一块块脏兮兮的、清不掉的残胶黑痕。

季深在那块散发着刺鼻墨水味的软木板前站了很久。

他盯着那行被墨水洇得有些发虚的黑字，看着那些粗暴的笔画。

然后他转过身，继续往大门走。他刻意放慢了脚步，让鞋底撞击地面的声音，在死寂的走廊里拖出越来越远的回响。
