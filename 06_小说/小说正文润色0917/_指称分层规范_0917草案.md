## 一、问题的来源

`CONC 工程化规范 v3.2` 的八层架构里，位置是明确的：

```
Layer 8  应用层        ← 智契 UI · 策元仪表盘 · 任务令浏览器 · 争议仲裁界面
Layer 7  决断层        ← 决断点注册 · judgment_request · 介入协议 · 人类/AI 决策边界
Layer 6  价值层
Layer 5  验证层
Layer 4  协作层        ← 工作区管理 · 文档生命周期 · Gate 门控 · GHF 审计 · 事件总线
Layer 3  策元层
Layer 2  身份层        ← 智权体注册 · 能证发行
Layer 1  网络层
```

**结论：`UI` 是第 8 层——只负责「呈现」与「采集输入」。**
挂起、校验、熔断、复核、追责全部在第 7 层（决断层）与第 4 层（Gate 门控）。

正文的问题不是用错了词，是**让界面干了决断层的活**，或者**把智契降格成了界面**。

## 二、四类对象与各自的动作边界

| 对象 | 层 | 它可以做什么 | 它**绝不能**做什么 |
|---|---|---|---|
| **执行体 / AI**（早期叫「辅助 AI」「那个 AI」「EM-7」「Jackie」； `074` 之后才叫「智契」；后期的深蓝同属此类） | 有身份的执行主体（对应 Layer 2 智权体 + Layer 7 决策边界） | 注意到模式；在约束内行动；发起请求；拒绝；保持沉默；不设超时的等待 | 不「感受」；**不是界面**；**不等于大模型**；不越权 |
| **大模型 / 基础模型** | 被调用的组件（权重矩阵、激活空间） | 生成 token；给出分布与置信度；在特定拓扑路径上跑出解 | 不承担判断；没有权限；不是执行主体；不能说「它想要什么」 |
| **AI 工具**（如 EM-7 这套套件） | 承载执行体的产品/系统 | 被启动、被唤醒、被下线；承载界面与执行体 | **不等于界面**——工具是工具，界面是它露出来的那一层 |
| **应用层 / UI / 界面 / 前端 / 弹窗 / 面板** | **Layer 8** | 显示；暴露；折叠；高亮；呈现状态；采集点击与输入；亮出入口 | **不能「挂起进程」**；**不能「改数据库字段」**；**不能「校验」**；**不能「熔断」**；**不能「判定」**；**不能「追责」** |
| **决断层 / 约束引擎 / Gate 门控** | **Layer 7 / Layer 4** | 挂起调用；校验填写；熔断；触发复核；要求第二人介入；留存异议；写入不可篡改记录 | 不直接面向用户（呈现是 L8 的事） |

## 三、判定口诀（一句话测试）

> **若一句里「界面 / UI」是动作的主语，而这个动作属于**挂起、校验、熔断、判定、改字段、追责、复核**——这一句就错了，必须拆层。**

正确形态：**决断层做动作 → 界面呈现结果 → 人从界面输入 → 决断层校验。** 四拍分清，谁也别替谁干活。

**书里已有的正例**（`016` 演练段，可当范本）：

> 当某个前线测试员**在终端疯狂点击**「拒绝算法自动摘要」时，**后台的时序数据库里**究竟会烙下怎样无法篡改的痕迹？

——前端点击归前端，记录归后台，一拍不乱。

## 六、仍需你裁定的两处

### 6.1 `Jackie` 与 `EM-7` 的确切关系

本批我按你的口径（**Jackie 是 AI agent，不是 UI**）处理为：

- **EM-7** = 那套研究辅助**工具**的工程代号（产品层）
- **Jackie** = 跑在它里面那个辅助 AI 的名字（季深私下叫的）

但 `014` 原稿写的是「把工单里那个**拗口的工程代号**叫顺了嘴，叫成了 Jackie」——按字面，Jackie 只是 EM-7 的昵称，不是独立的 AI。我补了一句「工具里跑着一个负责自动补全与检索的辅助 AI，工程代号 Jackit——拗口」，把昵称挂在 AI 上而不是工具上，这样两章才不打架。

**请确认这个分层**：EM-7 是工具、Jackie 是里面的 AI。若你希望 Jackie 就是工具的名字（不另设 AI 层），我改回去，但那样 `016` 的 is_allowed 与 `024` 的「Jackie 的底层进程」就要重新找主语。

### 6.2 `大模型` 与 `Agent` 的边界，正文里要不要显式区分

按 CONC，大模型是**被智契调用的组件**。但正文目前的用法是：`017`「微调底层大模型的一个参数」、`030`「它工作得完全正常」（指规则/约束引擎）、`010`「天枢模型」。这些都没错。

风险点在**后期章节**：当读者要理解「深蓝不等于天枢的大模型」「魔胎是服从壳不是觉醒」时，如果前面没把「智契 / 大模型 / 约束层」三层分清，后期那批靠层差推进的戏（`172 / 173 / 177 / 181` 等）会失去支点。

**建议**：不加新名词、不写定义段，只在关键处靠**动词**区分——智契「注意到、拒绝、等待」；大模型「生成、收敛、给出分布」；约束层「挂起、校验、熔断」。**靠动词分层，不靠贴标签**，符合 `00_叙事口吻标准.md` §3.3「禁贴标签」与 §4.4「概念落到角色与物件」。
