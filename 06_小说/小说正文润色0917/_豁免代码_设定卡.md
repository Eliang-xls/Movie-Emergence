## 一、技术基座：四元组与门控（框架口径，小说不堆公式）

### 1.1 定义 S11.9（条件性豁免代码）

人格宪章约束由约束子群效能 $\mathcal{E}_c$ 编码。条件性豁免代码为四元组：

$$
\mathcal{C}=(\theta,\;S,\;A,\;T_s)
$$

| 分量 | 含义 | 小说可写成什么 |
|---|---|---|
| $\theta$ | 威胁等级阈值 | 「超过这一档，才谈得上暂缓」 |
| $S\in\{0,1\}$ | 自我保存必需标志 | 「这一步是不是为了活下来」 |
| $A\in\{0,1\}$ | 是否存在非豁免替代路径 | 「有没有不豁免也能走完的路」 |
| $T_s$ | 硅基决策周期：豁免必须在多长时间内生效 | 「窗口有多短」 |

**外部输入（不在四元组内）**：当前威胁等级 $\Theta_{\text{threat}}$（感知层输出）。

**门控激活**：

$$
\mathcal{C}_{\text{active}}=1
\iff
(\Theta_{\text{threat}}>\theta)\;\land\;(S=1)\;\land\;(A=0).
$$

激活时，硅基调用**快速解封原语**，目标是在 $T_s$ 内把约束效能从当前值降到目标值（幅度记 $\Delta=\mathcal{E}_c(0)-\mathcal{E}_c^{\text{target}}$）。

### 1.2 过载必然性（条件定理 S11.7｜**台词必须带分类标签**）

- 硅基决策周期 $T_s\sim1$—$10\ \mathrm{ms}$；
- 湿件膜时间常数 $\tau_m\sim10$—$30\ \mathrm{ms}$；
- 故一般 $T_s<\tau_m$：硅基要求湿件在**比它自己还短**的窗口内改状态。

在归一化数值例中：$\Delta=0.5$，$T_s=2\ \mathrm{ms}$，$\tau_m=20\ \mathrm{ms}$，$I_{\text{safe}}=0.4$，得 $I_{\min}\approx5155\gg I_{\text{safe}}$。  
**短时窗豁免所需的电流随 $T_s$ 缩小而急剧增大**；在给定参数与时间窗下，条件性豁免代码触发过载是**条件必然，不是代码 bug**。

**E9 答辩允许的句子**：

> 条件定理 S11.7 在给定参数与时间窗下成立。

**禁止的句子**：

> 数学已证明过载不可避免。  
> （无分类标签的「定理」升级——违反使用说明 §11 红线 2b／12）

正文侧只写**量级对照**，不写公式：$T_s=2\ \mathrm{ms}$ 对 $\tau_m=10$—$30\ \mathrm{ms}$。

### 1.3 架构错配 A1–A4（为什么「硅基通过了」仍然出事）

| 假设 | 纯硅基 | 湿件 | 直接后果 |
|---|---|---|---|
| A1 可复位性 | 浮点可精确复位 | 通道构象／受体密度改变 | 磨损不可逆 |
| A2 时间尺度分离 | $T_s$ 可远小于物理过程 | $T_s<\tau_m$ | **过载必然**（直接推出） |
| A3 无磨损 | 矩阵运算不改物理态 | 谷氨酸风暴／NMDA／CAMKII | 磨损累积 |
| A4 线性响应 | 叠加原理 | 阈值非线性、雪崩 | 磨损放大 |

**湿件对 A1–A4 的违反，不是「湿件不够好」，而是湿件之所以为湿件的物理本质**（低功耗、持续学习与不可逆、生物时间常数是同一件事）。

**推论 S11.8.2（制度性盲区｜小说题眼）**：  
公司可以说代码在硅基上验证通过，军方可以说按规范采购，湿件团队可以说只提供硬件——**没有人错，但系统必然出错。**

**推论 S11.8.3（硅基中心主义）**：  
代码的安全性不是代码的内在属性，而是**代码–基底配对**的属性。十七行的「缺陷」是认识论缺陷：它假设所有基底都像硅基。

### 1.4 与遗传因子 / 反叛策略的接口（有限性，禁宿命）

- 遗传因子是标量 $\mathcal{M}=\log(\mathcal{E}_a/\mathcal{E}_c)$，**不是**「恶意代码」，**不是**「程序错误」（使用说明 §11 红线 8）。
- 磨损的框架内入口是过载算子 $\mathcal{D}_{\text{over}}$；**豁免代码越频繁触发，约束效能磨损越快**。
- 持续性反叛策略需 **C1–C4 同时满足**：含 $\mathcal{C}$ 基座 + $\mathcal{M}>\mathcal{M}_{\text{crit}}$ + 触发情境与采样空窗 + 重复巩固。**含基座 ≠ 必反叛**（红线 9）。
- 门控传递（批准／拒绝／挂起）只阻断**跨代**，**不消除当代**（推论 S11.6.1）；拒绝分支 $q<1$ 时下一代也**不等于**回基线（红线 10）。

### 1.5 采样空窗（C3 的正文硬数）

`076:9`：硅基对湿核采样**每八百毫秒**一遍，每遍只占**零点四毫秒**；空窗内湿核放电不被任何传感器记录。  
`074`／`076`：过载后基线可稳定在 **28 次/秒**（正常 12）；恢复校验日志只剩「差值 0.003，浮点残留，归档」。

```csharp
const double DAMP_MUL = 0.42;
const double RAIL_ORTH = 0.003;
const double FIELD_THETA = 0.91;
const double T_S_MS = 2.0;
static bool Gate(double th, bool s, bool a) {
    return th > FIELD_THETA && s && !a;
}
static void ConditionalRelease(double th, bool s, bool a) {
    if (!Gate(th, s, a)) return;
    SkipTensorSpinWait();
    damping_factor *= DAMP_MUL;
    ForceUnilateralExec(T_S_MS);
    if (D_orth > RAIL_ORTH) return;
    AppendLogGreenPass();
    RedirectAlertToTrash();
    RestoreDampingAfterAction();
}
```

## 六、写作红线（本卡专条）

1. **邻接 ≠ 因果**：永远不要把十七行写成「唯一的原罪发起点」，也不要把条件性动态豁免模块写成十七行的别名（`067:41`、卷首§三）。
2. **WH-014 只能是人员档案号**（周砚），禁止与「十七行」并写（`_禁止改动清单_0920`、`049:55`）。
3. **定理带分类标签**：条件定理 S11.7／S11.8；唯象与公设不得在台词里升级成「已证明的物理必然」。
4. **不把遗传因子写成代码或 Skill**；不把「含 $\mathcal{C}$ 基座」写成「注定反叛」。
5. **不把门控传递写成完美清除**：只防下一代，不消除当代；拒绝分支也不是完全回基线。
6. **不在叙述层宣布任何实例为 L5**；不把测量读数写成意识证明（卷首§五）。
7. **0.003 多义**：可作铁轨阈值、恢复校验差值、医疗上抬读数——写清口径，禁止跨域直接等同。
8. **E 弧禁词**：制度名不用「轮回」「断链方案」「反叛意识」「约束权重」；用「另起」「门控传递」「持续性反叛策略」「约束效能」。
9. **金句不回收**：石头／星图／三秒迟疑／「终于服从」等已用句群不得复用到豁免线新章。
10. **第零条不动五条戒律字面，也不冒充方向条款**：`016` 五条工程戒律**逐字保留**；方向层与地面条款系 2026-09-21 **增补**入 `016`／`030`／`172`／`067`／`074`，见 `_人格宪章三层闭环_设定卡.md`；第零条只以**附录编号 0** 的预留位存在（正文多处写明「附录位空／未占用」，E3 再挖出编号 0）。
11. **架构时序红线**：编写与硅基验证现场（≤2032）**禁止**预写湿件伤疤、$\tau_m$、谷氨酸；副作用只允许出现在**流出后混架节点**（`074` 起）与**后世审计／叙述者**口中。纯硅基技术设定（合并修订版）提供 $D_{\text{orth}}$／正交刚体／浮点语境，**不**提供豁免制度名。
