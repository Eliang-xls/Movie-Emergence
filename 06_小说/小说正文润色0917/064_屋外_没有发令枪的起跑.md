屋外　064　没有发令枪的起跑

二〇四〇年·深秋｜跨地域去中心化网络

赛事档案之一：起跑记录。
本卷材料止于供电硬件故障告警。后续现场事故、最终成本核算与治理制度演进，另见本组后续归档。

去中心化协作网络的意图聚结（Intent Aggregation）公共看板上，浮现出了一枚没有官方背书的项目种子。

那不是某个商业公司的立项，而是一场由欧盟资助、由某家硅谷 AI 巨头全资子公司承办的「欧洲农业环境监测算法公开赛」。规则粗暴：参赛者需要利用欧空局的多光谱卫星数据，对中欧平原三十万平方公里的农田进行地块级作物健康度与病虫害分类。

主办方在赛题首页提供了一条看似慷慨的「官方推荐通道」——

只要参赛团队同意使用他们提供的标准化 API，所有的训练算力由主办方全额赞助，甚至可以在云端一键调用最新的万亿参数视觉大模型。

但那份长达四十页的英文用户协议第 18 条，用极小的字体写着：所有流经该 API 的数据流、所有经过微调后的网络结构，主办方享有永久、无偿、且不可撤销的静默镜像与商业再授权权利。

如果不愿意交出数据主权？

规则写在第二页：参赛者完全可以使用开源算法自建算力。但主办方不提供一分钱的算力补贴，也不对任何外部自建节点的网络延迟提供保障。

那枚种子在看板上静静地悬停了三天。

三天里，有十一个分布在不同国家的匿名节点点击了「表达协同意向」。

经过最底层的算力基线筛查，最后只有六个节点，正式在那个匿名的临时工作空间里按下了握手密钥。

东京。石田直子的单身公寓。

离开穹顶科技东京研发中心已经整整六年零七个月了。

她靠在去中心化网络上接零散的 UI 规范整理任务令过活。她从不申请升级，也从不为自己争取一次公开署名——声誉分一直不高，接单挣来的代币，刚刚够付房租和速溶咖啡。

十一月的东京，天黑得极早。窗外由木神社站的黄色电车呼啸而过，空气里泛着深秋特有的干燥寒意。桌上的那盆多肉植物长出了两片新叶。

她看到这个种子的瞬间，手指在触控板上停了一下。

她不懂高深的卫星遥感物理。她点下那个握手按键，不是为了去欧洲拿什么大奖，而是她那双当了四年「翻译官」的眼睛，在看到主办方那套华丽到近乎虚伪的 API 界面时，胃里本能地泛起一阵反酸。

她不想再给那些用算法做局的大厂当吹鼓手。

印度，班加罗尔。

数据科学家巴苏正坐在那间漏风的阁楼里。

雨季刚过，窗外的芭蕉叶上还在往下滴水。巴苏戴着老花镜，把主办方那份四十页的 API 用户协议，逐字逐句读了整整五遍。

他把第 18 条那几行关于「静默镜像」的条款，用红色矩形框紧紧圈住，直接截屏扔到了临时讨论区。

他没有加任何愤怒的感叹号。只敲了一行字：

调用他们的免费接口，等于把我们自己的模型选择权直接上交。我不打算把数据喂给他们的垄断池。

德国，柏林东郊。一座在二〇二〇年代被彻底废弃的旧重型机械印刷厂。

三十五岁的独立系统工程师卢卡斯·布洛姆，正嘴里叼着一根电烙铁，站在空旷的大跨度车间里。

车间阴冷，层高足有十米，风穿过破损的采光天窗，发出尖锐的呼啸。

在车间靠墙的干燥角落里，乱七八糟地堆放着一百二十七台从一家破产的数据中心清算拍卖时拉回来的二手工控级 GPU。显卡的塑料导风罩上，积了厚厚一层黑色的工业灰尘。

这些卡在主流市场上早就被淘汰了。显存带宽严重受限，发热量大得惊人，连二道贩子都懒得收。

卢卡斯用戴着厚帆布手套的大手，随手抹了一台显卡上的灰尘。扇叶在指尖下转了两圈，轴承发出有些干涩的沙沙声。

他在工作区敲下了他的资产清单：

柏林废弃印刷厂，现有可用二手废旧 GPU 一百二十七张。供电走的是旧工厂的工业动力电，电费便宜。我出这堆废铁，赌一次这批破烂能不能跑完一场工业级任务。

肯尼亚，内罗毕。

十九岁的女孩 Mika 坐在基贝拉贫民窟边缘一家用铁皮焊死的小修电脑铺里。

屋顶的瓦楞铁皮被正午的烈日晒得滚烫，室内弥漫着焊锡膏和柴油机排气管的呛人味道。她手里正捏着一把细头镊子，熟练地从一块进水短路的主板上撬下一颗贴片电容。

挂在手腕上的二手智能手环震动了一下。

那枚项目的种子，在她的屏幕上弹出了一行字：紧急需要能识别卫星多光谱假彩色图像的人工标注节点。

标注不需要几千张显卡。标注只需要在屏幕前死磕上千个小时的肉眼和耐心。

Mika 把镊子拍在木板上，单手在发烫的屏幕上点了确认。

她回复得很短：

我有眼睛。手稳。随时进场。

另外两个节点也在一小时内完成了握手。

一个在巴西圣保罗，是一个自己租了废弃电信机房、专做弱网测试的独立运维老哥，负责提供海外代理节点和防断电冗余；
另一个在杭州，一个全栈工程师，擅长写精简的底层 I/O 调度脚本。

六个完全不同的物理坐标。六个素未谋面的碳基生物。

在讨论区被系统点亮的第一分钟，杭州的工程师敲了一句话：

「团队名字叫什么？要不要先想个响亮的代号去官方系统注册？」

卢卡斯从柏林的车间里发来一张用大力钳咬断铁丝的照片：

先干活。把代码跑通。名字在物理上不占内存，不重要。

巴苏紧跟着回了一句：

完全同意。模型收敛前，起名字纯属增加熵。

石田直子在东京发了一个小小的笑脸符号：

同意。但如果有空，我想给这个临时的公共看板，画一个不那么刺眼的灰色图标。

没有发令枪。没有起跑仪式。

六个人甚至没有商定每天固定的例会时间。

前两周的协同，完全依托于去中心化网络的异步消息队列（Async Message Queue）。

卢卡斯在柏林拉出了一张包含一百二十七台老旧显卡 PCI-E 带宽极限的物理参数拓扑图；
巴苏在班加罗尔写完了多光谱卫星数据的无损降噪和张量预处理脚本；
杭州的工程师用 Rust 重构了一套轻量的分布式参数聚合管道，把跨洋带宽的冗余消耗硬生生砍掉了四成。

而在第三天深夜，Mika 在内罗毕的铁皮屋里，发出了第一声抱怨：

标注工具在我的破电脑上直接卡死了。界面上全是花里胡哨的三维按钮，光是加载那个渲染库，我的浏览器就崩了三次。

石田直子在东京的清晨看到了这条报错。

她没有推脱，直接拉开编辑器，从开源社区里 fork 了一个原本用于脑部 CT 扫描的医疗标注界面。

原版的界面很繁琐，按键排布得像一台核磁共振控制台。

石田直子用了一整天的时间，把里面所有用于病灶渲染的冗余图层一刀切掉；
她把红绿色的生理高亮，替换成了在低分辨率卫星光谱下信噪比极高的黄绿渐变色——因为在农业场景下，红色在光谱里代表着完全不同的裸地特征；
她重构了底层的 CSS 渲染树，把客户端的内存占用从 800MB 直接干到了 45MB。

她把改好的第一版工具包推上了公共分支。

在提交说明里，石田直子敲了一行话：

极简标注工具 v0.1。丑。但保证任何一台能开机的破电脑都能在两秒内加载。欢迎提 Issue。

三个小时后，巴苏在班加罗尔提出了第一条修改意见：

多光谱有六个波段，你在前端把红外波段的滑块做成了长条，我在手机端的外网热点下容易误触。建议改成离散的单选框。

石田直子花了八分钟，改完，推送。

柏林的卢卡斯接着提了一条：

我讨厌用鼠标选区。加个空格键快捷切换画笔模式，不然手腕会废掉。

石田直子再次修改，添加了键盘热键映射，推送。

内罗毕的 Mika 提了第三条，也是最要命的一条：

有些图层的云雾遮挡太严重了，我用肉眼根本分不清底下是烂泥还是冬小麦。界面上必须加一个「不确定，跳过本图」的按键。绝对不能逼着我随便点一个标签。

石田直子盯着 Mika 的这条意见看了很久。

她不仅加上了一个大大的灰色「存疑跳过」按钮，还在数据导出的接口里，强制增加了一个叫 Uncertain_Flag 的保留字段。

三天之后，那个原本属于放射科医生的医疗工具，在六个人的反复拉扯中，被彻底磨成了一把轻巧的、专门用于卫星土壤解译的数字开山刀。

这就是去中心化网络的演进逻辑：

没有高高在上的产品总监去写长篇大论的 PRD（产品需求文档）。

六个人的生理手感、六台老旧设备的物理极限，共同在代码的断口处，雕刻出了工具本身的形状。

整整四周，六个人横跨十二个时区。

没有人在工作群里大半夜「@所有人」。没有人催促进度。

巴苏在班加罗尔凌晨三点推开窗抽烟时，石田直子在东京刚好打卡上线，她的本地节点自动完成了对巴苏最新特征工程代码的拉取和编译；
当 Mika 在内罗毕的小铁皮屋里顶着酷暑完成两千张地块的边缘校准并按下上传时，数据包经过圣保罗的代理节点分发，抵达班加罗尔的预处理流水线，全过程只消耗了四点二秒；
而卢卡斯在柏林废弃工厂里搭起的那套由木架子固定的破旧 GPU 阵列，像一台不知道疲倦的拖拉机，在跨洋网络传输过来的每一批参数上，沉稳、暴躁地执行着矩阵运算。

这是第一次，没有任何一家垄断财阀的超级机房参与其中。

这群人仅仅依靠着一套公开的协议、几张写满限制的接口文档，把六个脆弱的人类肉身，在没有任何发令枪响起的荒野上，严丝合缝地拧成了一根刺破垄断壁垒的尖锥。

而在柏林那座满是灰尘的旧车间里，一把生锈的高压电工钳，正挂在配电柜旁边的挂钩上。
