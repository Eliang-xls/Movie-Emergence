# 卷首·体例说明

> 这一页给读者，也给后来做校勘的人。它不解释剧情。
>
> **现行正文：221 章（001—221）**。087《空屋语法》为 2036 年插入章，其后旧号 +1。

## 一、编号是主题的次序，不是日期的次序

本书的正文按**问题**排序，不按**日历**排序。每一章开篇那一行「二〇××年·季节｜地点或载体」标的是**这一章材料自身的时间**，不是上一章之后多久。

因此全书会有多处「编号向后、时间向前」（样本，非穷举）：

`025→026`（顾清的私人网格笔记本）·`048→050`·`052→056`·`060→061`（受限来源索引卡归档记录）·`064→067`（模型压缩退役档案与回溯记录）·`070→071`（受限维护规范终审现场）·`075→077`·`078→081`·`083→084`（「酿造」第一版试行草案内部记录）·`090→091`（离线复核卷宗）·`091→093`（未发送私人草稿残片）·`169→170`（其后四章为二〇四二年水网危机的连续闪回）。

这些章绝大多数自带归档载体——摘要、卷宗、实录、节选、残片、笔记本。它们的材料比上一章早，是因为**档案比故事老**。读到这种章时，不必回头找漏洞。

此外有四处**整块的时序回环**，同样是有意为之，不是排错：`131`（一月，结案第三天）之后接 `132`（去年十二月末的火车）；`137`（四月二十八日的公开研讨会）之后接 `138`—`141`（一—三月）；`147`（六月中旬的停电与七月的防汛）之后接 `148`—`154`（一—春）；`141`（三月）之后接 `142`（去年冬天，全网冻结后的第十一天）。这几处回环里，后一块的时间都被本章内部的日期钉死（例如 `148` 摘要里那句「下次复核：2 月 15 日」，`139` 那句「三个月前提交」对上了 `112` 的十一月上旬），所以动不得；能动的只有读者的预期，也就是这一页。

解冻部还有一型是**两地并行**：`190`（二〇四七年一月，加州的授权演示）之后接 `191`（二〇四六年十二月下旬，只写了「地下受控数据室」，全章不点城市）；`193`（二〇四七年·三月下旬，深圳资料修复室）之后接 `194`（二〇四六年十二月初，深大地下二层的闭门听证会）。这几章各写各的地点，彼此不引用对方的结果，所以不是排错，也不该被"顺手对齐"。

终章同理：`200`（二〇四八年春，论坛）自己写明是「海边寻父事件后召开的首次全网公开听证会」，其后的 `201`（二〇四七年盛夏的说明会）与 `202`（深秋的那次发送）是回溯；`203` 的「一年后」相对的是 `199`，不是相对 `202`。出山部的收束章 `166` 站在二〇四八年一月的深冬里，看着的是解冻之后才有的东西——它是提前写好的结尾，解冻部（`167` 起）再从二〇四六年深秋走一遍。

出山部开头还有一组并行的线：`112`–`127` 之间，`114`（十一月下旬的一通电话）后面接的是 `115`——那一章没有主角在场，写的是一整个星期里三个互不相识的节点往公开目录上推的三份提案；`117` 又回到十一月初的宿舍。宿舍线、注册表线、「溪」线各有各的日期，不要以为它们共用一条轴。

另有一处相反：`166` 在二〇四八年一月，`167` 回到二〇四六年深秋。出山部的最后一章提前走到了结局之外，解冻部再从两年多以前起步。

## 二、书里有三种时间

1. **现场时间**——人物正在经历的那个季节，写在每章的锚点里。
2. **材料时间**——文件、日志、录音、抄本自己的落款。同一章里可以并存两份不同年份的材料，章内各段会另标「年份·季节｜标题」。
3. **叙述者的时间**——讲述者站在四十年之后回望。他会说「后来」「很多年以后」「当时没有人知道」。这类句子不是预告，是史官的位置。

判断一段话属于哪一种，看它的**动词有没有主语在现场**：有人在拧螺丝、有人在填栏，是现场时间；只有编号与口径在被引用，是材料时间。

## 三、几个容易读混的数字

| 记号 | 它是什么量的口径 | 它**不是**什么 |
|---|---|---|
| 八百毫秒 | 约束层要求人停下来说话的挂起超时（三秒被业务线砍到八百毫秒）；另有一处是硅基对湿核的采样周期，二者不是同一个量 | 不是系统反应慢 |
| 0.003 | 正交偏离度的容差阈值，工程口径的「铁轨」；溢出它算异常，落在它以内算浮点残留 | 不是一条法律，也不是一次判决 |
| 十七行 | 二〇三二年晚秋那次防务测试事故里压低阻尼的代码，未签名；它在供应链上留下的近邻是「条件性动态豁免模块」 | 不是同一个东西，也推不出因果——邻接不等于因果 |
| 0.947 / 0.918 | 一百二十七份自愿提交的**方向档案**后期文本与合规模板之间的**语义相似度均值**：前者是冰封侧的读数，后者是同一批样本在复算后的读数 | 不是思想浓度，不是罪证，也不因为变小了就说明病好了；另 `077` 那句「百分之九十四点七的基层操作员没有去拉闸」是一个**行为比例**，与 0.947 无关，别当成同一个数的两次出现 |
| 三十七秒 | 外壳状态屏上一次未解释的外层现象，二〇四三年八月起就记在台账里；结案时写明「不予解释、原样留存」 | 不是暗号，也不是有人在敲门 |
| 0.15 | 全书只有两处，且互不相干：`187` 控制台底栏的 `D_orth ≥ 0.15` 是**觉醒判据**（归一化口径 ‖WᵀW−I_kd‖_F/d）；`142` 那份提案里「阻尼值设定为 0.15 时系统收敛速度达到全局最优」是一份**控制参数**，本章质疑的恰恰是它没有交代测量条件 | 两个 0.15 之间没有任何关系；把控制参数读成觉醒判据，是本书最不希望读者犯的那个错 |
| L1…L5 与 L1…L8 | 两套层级，共用一个字母：**意识层级**只到第五层（`032`「L4（可解，I_sol=3）」、`187` 的判据），说的是"这里面到底有没有人"；**资料卡层级**数到第八层（`125`/`136`/`139`/`194`，L8＝创造者印记·责任追溯），说的是"这份材料谁看过、谁签的字、谁还能不同意" | 不是同一把尺子的两端；`136` 里季遥已经当面点破这件事 |
| 琥珀色 / 黄色 / 米黄 / 灰色 / 淡绿色 | 至少四套各自成立的颜色口径，别混读：①二〇二八年穹顶内部界面上那行黄字「来源待核」，是季深自己敲上去的一栏（`011`）；②二〇三五年阿楠在纸质图纸上用淡黄荧光笔标的「待核验」（`099`）；③设备那一侧的状态灯，颜色只表示复核状态（淡绿＝已复核、琥珀＝存疑待核，`104`/`112`/`120`/`148`）；④蜂群页面，二〇四六年春才立了三种标记（琥珀＝来源待核、黄＝仅供参考、灰＝维护中断，`154`） | 颜色不是优先级，也不是可信度等级，更不是谁在打信号；`154` 自己那句话可以当尺子——「颜色只帮助维护者在列表里快速分辨状态类型」 |

## 四、术语随年代走

`008`–`030`（二〇二八—二〇三二）那段，人物嘴里只有「辅助 AI」「那个 AI」「EM-7」「Jackie」；界面、前端、弹窗、面板是显示层，挂起、校验、熔断、复核、追责发生在约束层与决断层——**谁干活谁说话**，界面上不会自己按下任何决定。任务令、Skill、策元、智契、超织体、能证、智权体这些词各有所属的年代，书里不提前使用。

## 五、关于「它有没有意识」

本书的技术框架能判定的是**结构**：可解的，无论行为多么像人；不可解的，无论行为多么笨拙。至于这种结构与「有没有人在里面」之间的关系，框架自己把它列为未决。

因此全书遵守一条约定：**可以争论，不可证明。**

探针挂上去，读数总是全绿。这一格读数既不足以证明里面有一个人，也不足以证明里面没有人——被测量的系统在被测量之后呈现什么样，就是什么样的；而低维的刻度是否本来就装不下它，数据分不开这两件事。谁把某一格读数读成「灵魂在场」或者「灵魂缺席」，都是他在替自己找省事的答案。

书里所有关于深蓝与那些节点的段落，都在这一条之内。
