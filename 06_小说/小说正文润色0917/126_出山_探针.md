出山　126　探针

二〇四五年·十二月｜深圳大学

申请提交后的第三天，林屿收到一封很短的回信。

既没批准，也没拒绝。

`受限档案保管方已确认索引存在。请补充：你所说的「异常」准备如何定义？哪些信息即使出现，也不应被你读取？`

邮件末尾没有署名，只有一个档案编号和一条自动生成的提醒：

访问不是发现的奖赏。

---

林屿把那句话看了很久。

「访问不是发现的奖赏」——他把这句话读了五遍。

他原以为自己已经写得很谨慎了。只读，摘要，不接触模型，不接入网络。可「异常」两个字还是太大。它能把任何他不懂的东西都装进去，也能替他把好奇心说成责任。

「好奇心说成责任」——他在本子上把这句写了下来。

---

那天下午，他没有去旧设备间。

他去了图书馆的旧期刊库。那里网络很慢，窗边的插座松，电暖器吹出来的风带着一股塑料发热的味道。

有一页来自二〇三一年后的内部课程讲义，标题叫《观察不是进入》。讲义没有写任何模型名字，只列了三条：

> 第一，任何测量都要说明它改变了什么。
>
> 第二，不能因为看见了变化，就断言变化原来「是什么」。
>
> 第三，若对象不能承受重复测量，先保留证据，再决定是否继续。

林屿抄下第三条时，想起自己曾经想把示波器接到每一根引脚上。

那时他觉得，读数越多，离答案就越近。现在他忽然明白，读数越多，也可能只是让他离一个更干净的错误更近。

「更干净的错误」——他在页边画了一个问号。

---

晚上，宿舍。赵晨在打游戏。何迟没开灯，坐在窗边看一份学校治理草案。

林屿打开超织体，点进酿造策元的详情页。

他加入酿造已经有一段时间。苏晴做的模板，季行做的判断，引用链他翻过很多次。八层结构他也知道——L1 到 L8。他之前只关注过 L8，创造者印记。

L5 是「试金」。可复用代码层。

以前这一层是灰的。锁着。

今天不是。

页面上多了一行小字：

`L5 可见。原因：引用加速。原始锁定期十八年。当前有效释放进度：提前。`

---

他点开了 L5。

里面只有一个文件。

`Galois_Probe.py`。

14KB。修改时间：二〇三五年三月十七日。

林屿盯着文件名看了一会儿。Galois。他在数学史课上听过这个名字。探针。Probe。

他下载了。

---

代码大约有三百行。大部分是 Python。

他能看懂一部分。有些语法他不认识。有些函数他不知道是做什么的。

代码开头是：

```python
import torch
import numpy as np
from scipy.linalg import schur

def register_probe(model, target_layers):
    """注册前向钩子，捕获中间层激活"""
```

`register_forward_hook`。前向钩子。林屿不知道这个词组的确切含义。但他看注释——「捕获前向传播的输出张量」。

这个函数在做的事情是——在神经网络的前向传播过程中，挂一个「钩子」。每次数据经过某一层的时候，钩子会把输出数据截获一份。复制。存储。

像在管道上接了一个旁路阀门。水还是往主流跑。但旁路分了一小杯出来，送去化验。

他继续往下读。

```python
def analyze_group_structure(activation_matrix):
    """分析激活矩阵的变换群结构"""
    X = activation_matrix
    # 舒尔三角化
    T, Z = schur(X)
    # 导序列（换位子群迭代）
    solvable_index = compute_solvable_index(X)
    # A5 单群匹配度
    a5_match = check_a5_isomorphism(X)
```

这段代码他大部分看不懂。

但他看懂了几个词——`solvable_index`。可解指数。`a5_match`。A₅ 匹配度。

他不知道这些词的数学含义。但他能看出来——这段代码在分析一种数学结构。和「群」有关。和「可解」有关。

---

代码的后半部分损坏了。

`compute_solvable_index` 函数的核心逻辑被截断。十六进制的损坏标记——`0x4A to 0x7F`。可能是存储介质老化。可能是别的。

没有这段代码，探针算不出可解指数。

林屿翻到函数签名，又翻回书架最下层。那本从阁楼带来的旧书还在。

书的第一章——变量、数据类型、运算符。
书的第二章——条件判断、循环。
书的第三章——函数。

他读到第三章的时候停了。回到 `Galois_Probe.py`。看损坏的部分。

损坏的函数做的事情，从残留注释能拼出一点：取矩阵的换位子，检查是否收敛，不收敛就继续取。循环。深度加一。

他不知道「换位子群」是什么。不知道「导序列」是什么。不知道「舒尔三角化」是什么。

但他知道——这段代码是 Python 写的。

他不需要借书。他学过。暑假。阁楼。扉页上铅笔写的名字。

他能写出循环结构。数学逻辑——他不懂。但代码骨架——他能补。

---

他新建了一个本地文件，把损坏段抄进去，试着补：

```python
def compute_solvable_index(X, max_depth=100):
    n = X.shape[0]
    # TODO: 换位子群计算逻辑待修正
    commutator = X.copy()
    depth = 0
    while depth < max_depth:
        # 占位：真正的换位子不是这样算的
        break
        depth += 1
    return float('inf')
```

他知道占位不对。`AA - AA` 恒等于零，这个候选对不上换位子。他需要的是另一种东西——他还不知道怎么在代码里表示「群」。

他把这段标成 `# TODO`。

但剩下的部分——函数签名、参数、返回值、循环骨架——他认得。

认得，是因为十六岁那年夏天，他一行一行敲过。

---

何迟从窗边抬起头。

「你又在看那个箱子？」

「不是箱子。」林屿说完，停了一下，「也不是别的。我在看一段旧代码。」

何迟看了看他的屏幕。「能看懂吗？」

「大部分不能。」林屿说。「但我知道它是用什么写的。」

何迟没有笑。他把那份治理草案翻过一页。

「那比很多人直接说自己知道，要难一点。」

---

林屿低头，在文件夹里另外建了一个脚本。它做的是比对。

`B1-07_只读比对`。

里面只有三类文件：每天的外壳读数、设备管理员导出的访问日志、他自己拍下的铅封照片。

脚本只有四十行。他写了两个小时。

第一次运行时，屏幕跳出一串报错。他把日期里的横线写成了斜线。改过来，又跑了一次。

这回屏幕安静了几秒，列出三行结果：

`12 月 2 日：访问日志缺少维护人编号。`

`12 月 7 日：照片铅封状态与文字记录不一致。`

`12 月 9 日：目录索引出现，未见对应申请单。`

林屿没有说「找到了」。

他把三行复制进申请补充材料，分别标上：可复核差异、可能的登记遗漏、需要管理员确认。

标的时候他很慢。他怕标错。标错会误导人。

---

他给比对脚本写了最后一行说明：

> 本工具不解释信号，不输出身份、活性或风险结论；它只提示记录之间是否能互相对上。

写完，他又看了一眼旁边的 `Galois_Probe.py`。

探针还在下载目录里。没有跑。跑它需要解释器，需要目标层，需要他还不具备的授权与理解。

但他已经认出了那种语言。

不是「见过同名文件」那种认出。是骨架对上了——换位子、深度加一、收敛或不收敛。和他后来在桥接器里写的那些循环，是同一种骨头。只是探针更旧，更完整，也更危险。

危险不在文件名。危险在：它默认自己会被挂到某一层上。挂载意味着接入。

林屿又看了一遍 L5 的释放记录。锁了十八年的东西，提前开了。他原以为锁仓里是一种更完整的代码库，或者一份能替他把换位子写对的实现。

现在他改了看法。

L5 锁着的不是代码库。是那把会把要找的东西弄丢的尺子。

访问不是发现的奖赏——他忽然把档案回信里的那句话，和眼前这把尺子对上了。

林屿没有改文件名，也没有把它拖进任何联网目录。他在本地另存了一份只读副本，文件名后面加了日期。

> 授权前只读。不挂载。不传播。

这三行他写了两遍。第一遍写在屏幕上，第二遍抄进本子。

窗外的风把晾衣杆吹得轻轻碰墙。那声音没有规律，也不需要有规律。

林屿躺在床上。

他闭上眼。

数呼吸数到第三遍，他睡着了。
