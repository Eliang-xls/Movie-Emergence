## 二、逐篇改动说明

### 043　太平滑了

**删**
- 「极其」类强化词 9 处（极其冷硬 / 极其敷衍 / 极其庞大 / 极其克制 / 极其冰冷 / 极其圆滑 / 极其残暴 / 极其微弱 / 极其规律）→ 全部换成可触摸细节或直接删。
- 「极度」类 4 处、「彻底／近乎完美无瑕／教科书般的平稳态」等形容词堆。
- **顾清那段哥德尔讲义**。原文是让角色替叙述者讲一遍主题（「完美无瑕的平滑，就是伪造者留下的最大指纹」），违反 §2.3「叙述者论文腔」与 §3.1 顾清「间隙」词典。
- 结尾三处叙述者自评（「这仅仅是一份刺眼的病理学诊断」「这并不是一场教科书式的大捷」）。

**改**
- 顾清的意见改为**两行问句 + 标为「待补」**：问权限边界、问系统没查什么。这是她的词典用法（看边界、留白、拒绝替人下结论），与锚点 N《零点七》同一逻辑。
- 「物理」原本被当程度副词用（物理气味 / 物理破绽 / 物理消磁 / 物理动作）→ 只保留字面义。
- 老方手记、声音共鸣（风扇漏半个节拍）两处原样保住——这是他的人物核心资产，属 §5.1「角色绑定」，不得削。

**增**
- 车间现场：松香烟、放大镜缺口、电容剪脚台面、半卷焊锡丝、对街短视频声。
- 顾清工位的纸张与凉茶（服务她「堆满纸张的工位」原有设定）。
- 小陈的反应节拍。

**核**：七个大版本、三个空哈希、四个不同国别邮箱同套套话、受控未知异常簇、三条防御建议——事实全部保留，未增删案情。
