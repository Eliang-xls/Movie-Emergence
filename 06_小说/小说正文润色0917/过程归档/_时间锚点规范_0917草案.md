## 一、格式标准

**统一为两段式，中间用全角竖线分隔：**

```
年份·季节｜地点或载体
```

**示例：**

```
二〇二九年·夏末｜穹顶 P-3 实验室
二〇三〇年·初冬｜受限来源索引卡归档记录
二〇三四年·盛夏｜深圳，华强北
二〇四六年·一月｜方舟策元共享复核频道
```

**规则：**

1. **年份必写**，一律用汉字数字（「二〇二九年」而非「2029 年」），与现有 156 章保持一致。
2. **季节或月份二者择一**，不并写。能定到月就写月（`一月`），只能定到季就写季（`初春`）。
3. **第二段写「地点」或「载体」，二选一**：
   - 这是**现场章节**（有具体场景与人物动作）→ 写地点：`深圳，南山`、`波士顿，剑桥市`
   - 这是**档案章节**（章头本身就是卷宗名，无现场）→ 写载体：`受限来源索引卡归档记录`、`公开协作复盘资料卡`
   - 载体名以该章正文里已出现的名称为准，**不新造**。
4. **保留原有的采集凭据语**（如「脱敏」「节选」「绝密级」），放在第二段之后，用顿号连接。
   - `二〇三二年·晚秋｜事故后绝密级责任追溯档案（删节版节选）`
5. **不改动正文任何一行**。锚点是加在标题行下方、正文之前独立成行，**不替换**原有开篇句。

## 五、与润色流程的关系

**执行方式：随批处理，不单开一轮。**

**理由：**

1. **锚点是推出来的，不是独立事实。** 定 148 的时间，前提是先读懂 146（2046.01）和 147。单开一轮标时间，等于把邻居章读两遍，且第一遍是粗读，判断质量反而更差。
2. **主要理由是审阅控制。** 补锚点是在给正文**增加事实断言**，属有实质风险的改动。它应当和同一章的其余润色**同时呈现在你眼前**——你读到那一章，一眼就能看到「这章定了 X 年 X 月」，判断错当批就能否掉。若单开一轮，四十多条新断言一次性涌来，你反而拦不住。
3. **第 1 类（8 章）几乎零判断**，顺手就做了，没有必要为它开专项。

**交付约定：** 此后每批的交货说明里增加一行——`本批新增时间锚点：＿＿＿｜依据：＿＿＿`，供你在审阅那批正文时顺带核。第 3 类中判断余地较大的章，我会在说明里多写一句依据，方便你否。
