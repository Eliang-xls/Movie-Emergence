## 2. 科层熵增论述：正文落点总图

设计要的力学链（文学化，不点名）：

```
公司存在理由 = 内部协作摩擦 < 外部摩擦
     ↓ 规模上升
沟通路径数近似 N² 增长；每多一层翻译，判断丢一分
     ↓ 科层自救（六页纸 / OKR / 20% / 小队自治）
流程本身变成新的对齐成本
     ↓ 高墙（竞业/资料边界）
墙保住资产，也锁住流动；认同型纽带换不成合同条款
     ↓ 外部协作摩擦被 CONC 协议改写
墙的收益结构失效 → 开放日 / 桥 / 有条件共生
```

| 环节 | 现文状态 | 本方案动作 |
|------|----------|------------|
| 内部摩擦优势（正命题） | 无 | **补** 江远扩张逻辑（P1） |
| 路径超线性 / 层层翻译 | 体感有，力学无 | **补** 通道数体感 + 翻译链（P0） |
| 六页纸异化 | 有诞生，无死亡 | **补** 形式主义暗线（P0） |
| 20% 死亡 | 无 | **补** 标语被盖（P0） |
| 小队自治失败 | 无 | **补** 轻量「项目组」失败（P1） |
| 高墙 / 向心力切换 | 050 有协商 | **补** 江远结构自觉一句（P0） |
| 外部摩擦被改写（逆命题） | 038「他们不需要我们了」弱 | **补** 边际协调账 + 开放日一句（P0） |

## 3. 修改项明细

### P0-1　沟通路径超线性：体感锚（科层熵增的「可数」证据）

**位置**：`第一部_012_两种温度.md`  
**插入点**：走廊「认识其中七八个」之后、茶水间六页纸公告之前（约第 15–17 行之间）  
**功能**：不给最优 N，只给「人多以后对齐变贵」的直觉；为第二部熵增埋物理感。

**建议插入（约 8–12 行，口吻对齐现文）：**

> 有一次他在楼梯口站了一会儿。  
> 三个人说话，两两之间都要听一遍。五个人，就要多听几遍。十个人的会，他数过：真正把同一件事说清楚的线，比人数涨得快。  
> 不是人坏。是线多。  
> 线一多，「先听谁」就变成一件事。那件事本身也要开会。  
> 他没把这个算成公式。他只是觉得，走廊在变长。

**禁止**：出现 \(C=N(N-1)/2\)、「双披萨」、「邓巴」。

### P0-2　Coase 正命题：江远为什么必须养人（公司的存在理由）

**位置**：`第一部_012_两种温度.md`  
**插入点**：A 轮对话段，「除了钱，还有件事」之前，或紧接估值「比我们预期高了三成」之后  
**功能**：为第六部「墙的收益结构变了」埋可反转的台词；江远不是不懂管理，是太懂公司逻辑。

**建议插入：**

> 「钱要花在人上。」江远说。「外面找一个懂我们方向的研究员，每次谈判、签保密、对需求，加起来比自己养一个贵，还慢。公司存在的意思，就是把这些摩擦放在屋子里，一次付清。」  
> 季深没接。他想的是屏幕上的点，不是屋子。

**回指点**（见 P0-6）：第六部开放日/桥，同一件事被现实改写。

### P0-4　江远的结构自觉（向心力切换，不点 T22）

**位置**：`第二部_050_害怕自由.md`  
**插入点**：江远「单方面叙事效率高」自白之后、「协商结束时」之前  
**功能**：把竞业/高墙从「人品」拉回「规模结构」；设计 T22 的文学等价物。

**建议插入：**

> 晚些时候他在本子上写过一句，没给任何人看：  
> 「小办公室里，人留下是因为信同一件事。  
> 现在人留下，要靠合同、职级和下个月的工资。  
> 信不够用了。不是谁背叛了信。是屋子太大了。」

### P0-6　外部摩擦被改写：开放日 / 桥上的「逆命题」回指

**时间线**：现文 2046；1/110 已在 2040 公开复盘存在，**第六部不再重证成本**，只处理「墙为何非开不可」。

**位置**：`第六部_159_桥.md` 或 `157_开放日.md`  
**推荐 159**：江远看草案段（「他没有承诺开放更多资料」之后）

**建议插入：**

> 他在「未被采纳的替代方案与理由」那一栏空了一会儿。  
> 二〇二七年他说过：公司把摩擦放在屋子里，一次付清。  
> 现在屋外也能付清——用别人写好的范围说明、可撤回的权限和能回头的复核人。  
> 不是外部突然变便宜了。是外部学会了把摩擦拆成可以逐条核对的东西。  
> 屋子还大。只是房租的算法变了。  
> 他没有写「房租」。他写：`边界成本需按可核对项重估。`  
> 写完他觉得还是太软。又加了一句：`不是道德问题。是结构变了。`

**与 P0-2 首尾呼应**；读者不需要知道 Coase。

## 6. 验收标准

改完后，不读设计文档的读者应能感到：

1. **人一多，对齐就变贵**——且不是「最优 5 人」教条（012 + 037）。  
2. **江远的墙有结构理由，不是变坏**（050 + 049）。  
3. **公司里自救的流程自己会长胖**（042 六页/20%）。  
4. **到开放日，问题不是道德开放，是外部摩擦算法变了**（012 ↔ 159 呼应）。  
5. **CONC 的出现是「科层熵增到顶 + 外部可核对协作变便宜」的推论**，而不是「大家更善良」。

反验收（出现即改回）：
- 正文出现 Coase / Dunbar / T22 / Squad / 沟通拓扑熵 / NID  
- 甜蜜点章被改出山峰或最优人数  
- 1/110 在第六部被重证一遍  
- 新段落变成管理学说明文（无物件、无动作）

## 7. 与 CONC 论述的对齐句（写进设计校订版用）

> 穹顶的伟大，是把「屋内摩擦一次付清」推到极致；  
> 穹顶的天花板，是屋内对齐成本超线性上升，自救流程成为新熵源；  
> CONC 不取消摩擦，而是把摩擦拆成可复核、可退出、可分叉的协议，  
> 使「外部一次谈清」在结构上优于「内部层层翻译」。  
> 因此大迁徙不是道德胜利，是边界成本重估后的流动。

此句不进正文，只进 archive 设计校订，供后续章节引用口径统一。
