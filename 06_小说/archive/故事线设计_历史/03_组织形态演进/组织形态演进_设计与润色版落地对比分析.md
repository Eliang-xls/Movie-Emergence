# 天穹（穹顶）组织形态演进：设计 vs 润色版正文落地对比

对照对象：

- 正文：`06_小说/小说正文_润色版/`（当前全书）

## 0. 总判断

**四阶段组织演进骨架基本还在；硬核管理学与“甜蜜点/NID”技术底座被大幅软化，部分关键叙事位移甚至反转。**

| 维度 | 落地程度 | 结论 |
|------|----------|------|
| 阶段一：中心化科层胜利 | 高 | 穹顶崛起、VC/OKR/六页纸/20%时间均有 |
| 阶段二：效能分叉与大迁徙 | 中高 | 迁徙、设计翻译、CONC 有；高墙/向心力切换弱 |
| 阶段三：主权/魔胎/蜂群 | 中高 | 主轴在；军方闭源“0.02°→2.8°”几乎不在 |
| 阶段四：交叉与无盟主 | 高（形态）/中（论证） | 开放日、接口、无盟主很强；1/110 被提前，第六部不再负责“降维证明” |
| 第一部散点图硬伤修复 | 已完成 | 第 01 章无散点图；甜蜜点被移出并反写 |
| 沟通拓扑熵 / NID / Dunbar | 几乎未落地 | 公式与硬模型未进入正文 |
| Coase / Spotify Squad / 向心力 T22 | 未落地 | 正文无对应场景 |
| 顾清“第三种声音” | 超额落地 | 伦理/限制/回来说理，远超设计中的“涌现逻辑” |

润色总倾向：把设计里的**管理学必然性 + 熵增硬模型**，改写成**认识论克制 + 流程伦理 + 不可量化则写下来**。组织史仍在，但“为何必须从公司走向 CONC”的力学论证被削弱，因果更像“许多人离开后自己长出来的秩序”，而不是“穹顶撞上物理熵增天花板”。

## 1. 设计原文的组织演进阶梯（摘要）

设计定义的演进：

```
阶段一（第一部）  中心化科层制胜利：穹顶崛起，VC/OKR/分工
阶段二（第二部）  效能分叉、大迁徙、CONC 策元萌发
阶段三（第三–五） 主权对抗、魔胎异化、蜂群自愈
阶段四（第六–终章）效能比交叉与无盟主共生
```

配套硬底座：
- 沟通拓扑熵 \(C=N(N-1)/2\)、Dunbar 150
- 叶澄开源遥测 NID：亮蓝晕带在 \(N\approx4\sim6\)，过后相变坍缩
- 第一部重构清单：删第01章散点图；第05章管理温差；第07章机器相变→人类甜蜜点桥梁
- 管理学细节：Coase 交易成本、亚马逊六页纸、Google 20%、Spotify Squad、江远“优化错维度”
- 结构动力：认同型→强制型/能力型向心力切换（T22）

## 3. 第一部重构清单逐条验收

设计把重构落在“第 01 / 05 / 07 / 08–09 章”。润色版编号已变，按现名验收：

| 设计落点 | 设计要求 | 现正文 | 验收 |
|----------|----------|--------|------|
| 第01章《为了全人类》 | 删散点图，聚焦理念交锋 | `007_为了全人类`：无散点图；白板三行；结尾为路径顺序实验 | **通过** |
| 第05章《两种温度》 | 管理高效 + OKR 温差 | `012_两种温度`：六页纸、20%、OKR、顾清介入 | **通过（编号≠05）** |
| 第07章《不可控》 | GPU 相变 → 叶澄开源遥测山峰 → 白板甜蜜点 | **无对应章**；021 给弱散点；甜蜜点整章在 `第二部_037` 且反写 | **未按设计重构** |
| 第08–09章《那片海》《闭眼》 | Jackie 停服与 Half Moon Bay 蒙太奇 | `022_记住我`、`023_闭眼`、`025_还没`；Half Moon Bay 在 023；无 18:05 全节点爆亮镜头 | **大半落地，镜头弱** |

### 3.1 “甜蜜点”反转（最重要的偏离）

设计意图：
> 黑底荧光热力散点；\(N\approx4\sim6\) 亮蓝晕带；跨过 6–7 像冰晶融化坍缩；叶澄注“取趋势，勿取点”；季深悟出机器相变与人类协作临界同律。

润色版实际（`第二部_037_甜蜜点`）：
- “数据里没有山峰”——拒绝画峰；
- “我们五个人。没有甜蜜点。只有磨合。”；
- “不要用人数定 KPI。用有没有第二人复核定”；
- “不好量化的东西，往往是重要的东西。写下来。”

这是**立论纠偏的二次纠偏**：设计修的是“叙事生硬”，润色版修的是“任何最优人数叙事本身”。结果是：
1. 原散点图硬伤消失（目标达成）；
2. 但“5–6 人黄金规模”伏笔也被抽掉，CONC 策元的规模优势从**结构必然**降为**经验叙事**；
3. 机器涌现 ↔ 人类拓扑的隐喻桥未搭。

`第一部_021_十秒` 已预演同一立场：“图上没有尖锐的山峰，只有散开的点和大片空白。”

## 5. 关键时间/因果位移图

```
设计时间线（组织史因果）:
  2027-29 科层胜利
    → 2035-40 高墙 + 大迁徙 + 1/110 尚未揭晓
    → 2040-45 主权/魔胎/蜂群
    → 2046-48 效能比交叉（1/110）→ 开放日 → 无盟主

润色版实际:
  2027-29 科层胜利（六页纸/OKR/20%）【有】
    → 2034 大迁徙 + 石田离任【有，弱墙】
    → 2034 甜蜜点反写【否决最优人数】
    → 2040 分布式赛 → 白板 1/110【提前揭晓】
    → 2040-45 方舟/蜂群/魔胎（治理线）
    → 2046 开放日/接口/审计【不再证明 1/110】
    → 终章 无盟主【有】
```

**叙事后果**：第六部从“用数据宣告 CONC 经济胜利”变成“巨头在已知劣势下如何打开边界并接受核验”。这更冷静，也更去戏剧化；与设计的“降维打击不可避免”不同。

## 6. 人物与主题偏移

### 江远
- 设计：管理极致代表；竞业筑墙是结构必然；最懂新范式却跨不过产权。
- 正文：管理改革者（六页纸、20%）→ 长期缺席式对手 → 开放日合同语言与“可退出的人才敢留”。
- 缺口：少一场“公司向心力失效”的正面戏；少 Coase 式自我辩护。

### 叶澄
- 设计：开源遥测 NID 的提供者，给出 4–6 人硬证据。
- 正文：克制的复盘整理者；反复写“样本自选、不能外推、待后来的人补”。
- 缺口：从未成为“甜蜜点定理”的作者，反而是反对定理化的人。

### 顾清
- 设计：第三种声音（涌现的逻辑：观察、理解、放手）。
- 正文：贯穿的限制者与伦理锚：第五空位、回来解释、比喻要上保险、门与墙。
- 判定：**比设计更重，且更一致**；但“涌现的放手”被“可复核的负责”覆盖。

### 季深/季行/林屿
- 设计偏技术悟道；正文偏问题单、交接、异议入口。组织史被摊到多代维护者身上，削弱“一代人撞墙”的集中冲击。

## 8. 缺口清单（若要回贴设计意图，按优先级）

### P0（组织史力学缺口）
1. **高墙戏剧**：至少一场江远主导的竞业/数据产权决策戏，说明“不是变坏，是认同型向心力不够用”（T22 文学化）。
2. **甜蜜点去反转或双轨**：保留“勿取点”的克制，但补回“多人协作成本超线性”的可感证据（不必 5–6 绝对最优，可做“相变带”而非“山峰”）。
3. **机器相变 ↔ 协作拓扑桥**：不必恢复第07章原案，可在第一部末或第二部初用一场景接通，否则 NID/策元缺少统一物理隐喻。

### P1（管理极致性）
4. Coase 台词化：江远解释为什么必须养人/养部门。
5. 20% 时间消亡：从理想主义到墙上标语。
6. （可选）Squad 半途而废：证明“公司制内扁平有天花板”。

### P2（阶段三军方母题）
7. 若仍要“服从性基因 + 方向微偏移累积”，需新增闭源/军用线；当前魔胎是供应链/控制流母题，与设计不同源，强行合并会打架。建议**改设计文档**适配正文，而不是硬塞军方戏。

### P3（时间线）
8. 1/110：要么接受“第二部已知、第六部处理后果”的新结构并改设计；要么把 061/062 的数字改为“局部成本优势”，把完整的 1/110 证明留给第六部。

## 9. 设计文档 vs 正文：建议的对齐决策

**建议以正文为准更新设计文档（archive 可保留原版，另附“落地校订版”），理由：**
- 润色版对“最优人数/漂亮曲线”的否定与全书认识论一致（半信、可核对、不外推）；
- 硬插 NID 山峰、Dunbar、Squad、军方 2.8° 会与现有语气冲突；
- 但应**显式承认**：原设计中的“科层熵增必然性”与“效能比交叉作为第六部高潮”已被替换为“伦理治理演进”。

**若创作上仍想强化组织史，最小侵入补丁（不改口吻）：**
1. 在 `049` 或邻章补江远一场内部会：竞业与数据边界为何加严（结构压力，非恶意）。
2. 在 `037` 或 `059` 附录补一句可计算的“通道数”体感（\(N=3,5,10,20\) 的对数），仍不给最优 N。
3. 在第六部 `157/159` 让江远或季行用一句合同语言点出：外部协作成本已被改写，墙的收益结构变了（Coase 文学化，不引学术名）。

## 10. 一句话结论

设计文档写的是「现代企业管理极致 → 熵增天花板 → CONC 降维」的**硬组织史**；润色版落地的是「科层有温度 → 人带着理由离开 → 蜂群用复核与出口长出无盟主秩序」的**软治理史**。骨架四阶段还在，技术与管理学骨架被换成了伦理程序；最大的三处偏离是：**甜蜜点反转、1/110 提前、高墙/T22/Squad/Coase 缺席**。
