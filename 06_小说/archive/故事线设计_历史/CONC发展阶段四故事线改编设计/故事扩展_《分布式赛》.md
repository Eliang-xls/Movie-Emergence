### 第三十八章：没有发令枪的起跑

二〇四〇年，人类的硅基狂欢进入了折叠期。在多个跨越时区的地点，超织体（Hyperweave）的暗流正在涌动。

CONC 的网络里出现了一个种子（Creative Seed），这不是一个已经成型的策元，而是一场欧洲农业监测比赛。主办方是一家垄断 AI 企业的子公司，规则极其傲慢：用卫星影像分类作物健康状态，参赛者可以使用任何方法。但真正致命的诱饵在于，主办方提供了一条“免费”路径——只要使用他们的 API 调用，算力成本全免。

在班加罗尔一间狭窄的公寓里，巴苏盯着屏幕上的 API 用户协议。他曾是一家大型研究机构的数据科学家，在 CONC 的超织体网络中已经游弋了两年。他太清楚这种免费的代价：使用对方的 API 参赛，等同于交出了模型的选择权，任由自己的数据流水线被对方静默格式化。他可以选择开源模型加自组算力，但那意味着没有任何赞助。

巴苏没有犹豫，他拒绝了那个 API，并在这个种子上点击了“表达意向”。

这个种子在意图聚结（Intent Coalescence）的协议层里悬挂了三天。在 $sim \ge \theta$ 的相似度函数检索下，六个方向向量（Direction Vector）发生了宿命般的锚定。

石田直子是第一个点击的。她离开穹顶公司已经七个月，靠着零散的任务令维生，此时刚好没事做。第三个是卢卡斯·布洛姆，身在柏林的独立工程师，手里捏着从倒闭数据中心回收来的一批废弃 GPU，卖不掉，只能自己烧。第四个是内罗毕十九岁的女孩 Mika，她在青少年区接单，看中了种子描述里的“数据标注”需求——这不需要 GPU，只需要骇人的耐心。随后，圣保罗一位租着旧机柜的前运维工程师，以及杭州一位以手速著称的前后端开发者，也相继在协议底层完成了握手。

六个人，来自六个国家，没有经理，没有誓师大会，甚至连策元名称都没想好。

前两周，他们只在 CONC 的共享工作区开了三次异步会议。没有人在群里发号施令，也没有分配进度的甘特图。卢卡斯扔下了可用 GPU 的规格清单，巴苏贴出了影像预处理方案，而 Mika 只是淡淡地问了一句：“标注工具在哪里？”

没有人想过这个问题。于是石田用两天时间，硬生生砸出了一个工具。她 fork 了一个原本用于医疗影像的开源界面，将“标注病灶”替换为“标注作物健康区域”，把不合时宜的红绿色标记改成了黄绿色。它很丑，但符合协议标准，并且能用。

这就是公理四“模块承诺”的绝对冷酷：不需要审批。巴苏抱怨手机上按钮太小，她改大；卢卡斯讨厌鼠标要求快捷键，她加上。六个人的偏好通过冰冷的代码合并，将一把手术刀改造成了镰刀。

在没有管理者的网络里，齿轮的咬合由智契（Noetic Companion）接管。

巴苏在凌晨三点醒来时，石田的新界面已经被他的智契自动更新了依赖。卢卡斯的旧 GPU 如果出现散热异常，柏林的智契会自动降频，根本无需惊醒主人。而 Mika 在内罗毕按下的每一个标注图层，被她的 Agent 瞬间推送到巴苏的训练管线中——没有 FTP 传输，没有邮件确认，从非洲的摊位到印度的 GPU 集群，只用了 4 秒。

唯一的插曲发生在第三周。巴苏发现石田输出的通道数比训练脚本多了一个冗余的置信度热图通道。他没有去找石田，而是直接在 Issue 栏留下了差异记录。

三分钟后，石田的智契自动完成了差异分析并给出了降级建议：“标注工具默认关闭该通道...不影响当前训练进度。” 等石田在东京醒来，她只花了十分钟改掉配置，推送，一切继续。人类只做决断，连接线由协议维护。

### 第三十九章：崖顶的守望者

如果协议是完美的，那是因为它尚未遭遇物理法则的反噬。比赛进入第六周，灾难降临。

凌晨的柏林仓库里，空气中弥漫着绝缘胶皮烧焦的刺鼻白烟。卢卡斯的 127 台旧 GPU 在连续满载运行四十八小时后，撞上了物理极限。旧配电系统的电压在峰值期突然跳水，19 台显卡同时发出死鸣。

“19台掉线。需要四十八小时修复。”卢卡斯的消息传到群里。

“来得及吗？”石田问。

“不知道。但我会修。”

卢卡斯撒谎了，他根本没有时间修。他赤着膀子，嘴里咬着螺丝刀，一把拽起大力钳，砸开了烧熔的机柜。那些带有百度余温的显卡，被他一台台硬生生拔了下来。掌心烫出白泡，他连看都没看，剪断扎带，剥开电容，把残存的硬件死死塞进备用架。

而在班加罗尔的凌晨三点，巴苏砸翻了咖啡。19 台节点蒸发，意味着庞大的训练网络失去了支撑，监控屏上的 Loss 曲线正像脱轨的列车一样疯狂震荡。

远在内罗毕，十九岁的 Mika 感受到了算力真空。她没有惊慌，手环在震动中，她以每秒三次的频率开始手动纠错缺失的作物标记。“算力不够。标注来补。” 她在对抗算法的盲区。

东京的石田瞬间切入了主线程。她立刻将医疗影像的标注界面，切换成了极高信噪比的卫星光谱图层，最大程度降低 Mika 的认知负荷。“给你十分钟。修不好就把空洞切掉。”她给卢卡斯留言。

“牺牲十一台。死守一百一十六。”卢卡斯合上了总电闸。

狂暴的风扇呼啸声在柏林重新响起，116 个节点的蓝灯在浓烟中重新点亮。巴苏在凌晨跑了全量训练，眼看着原本要雪崩的 Loss 曲线，在剧烈的抖动后，被 116 个节点的脉冲生生按回了收敛轨道。

比赛的结果是残酷的。他们的模型精度定格在 71%，而主办方的大模型达到了 78%。

但真正的震撼在于底层账单。这六个共识陌生人的总成本是 2478 美元，而主办方的等效算力成本，高达二十八万美元。1/110 的悬殊比例。

巴苏在等待结果的清晨，敲下了一段日志：*“The design parameters aren't the ceiling. After the model crosses its own sub-threshold, the ceiling moves.”（设计参数不是天花板。当模型跨越自身的亚阈值，天花板会移动。）*

同一时间，在穹顶公司的三楼，季深正死死盯着这场比赛的数据。他看的不是 71% 的精度，而是那 2478 美元的效率。116 台全靠回收拼凑的废卡，跑赢了三个数量级的账单。

他将超织体内各个策元的“人数与单位成本产出”画成了一张散点图，五到六人的策元正处于抛物线的最高峰。他想起叶澄三个月前发来的那张涌现经验规律 $\eta(N)$ 曲线图。

“蓝色是人多的好处。红色是人多的代价。差值——就是我看到的那条。”叶澄的邮件历历在目。

多一个人，系统不是多一份成本，而是发生了相变。六个人的策元效率在崖顶，再加人，就是断崖式的坠落。季深看着那些散点，他知道，崖顶上的人最危险，因为他们根本不知道自己站在最高点。

### 第四十章：液态的算力

比赛结束了，但系统并没有回收它的种子。二〇四一年，这个策元依然存在，石田最终给它注册了一个名字：“分布式”。

巴苏的墙上贴着三十多张卷边的卫星影像，他发现了纯技术无法解答的农学问题。卢卡斯则在对着笔记本复盘烧毁的显卡，思考算力布局的底层协议。石田凝视着从第一版医疗界面演化到第六版卫星界面的 UI，意识到自己想做的其实是开源工具链。Mika 把工具装进 U 盘，准备回到大地上寻找答案。

在旧的科层制世界里，这叫“团队离心”，接下来就是投票、决裂、或者强制服从。但在 CONC 的协议里，意志是可以被切片的。

他们启用了软分叉（Soft Fork）。

没有人退出，只是每个人的 Agent 算力进行了重组：80% 留在“分布式”共同方向上维稳，20% 划拉到自己的分支上探索。巴苏的 20% 去跑了农业社会学，石田的 20% 去做快捷键和配色管理。算力像水一样分流，流向各自渴望的低地。

三个月后，巴苏的分支撞上了墙——他需要一种时空可视化界面，但他写不出来。而石田看着自己无人问津的工具链，恰好在这时扫到了巴苏的需求日志。

“我帮你。” 石田敲下这三个字。两条切片分支在协议层完美啮合，合二为一。

但水流也有分道扬镳的时候。六个月后，卢卡斯触发了硬分叉（Hard Fork）。

他所构想的算力聚合协议，已经在维度上彻底脱离了“分布式”策元的应用层轨道。他没有在群里发起投票，也不需要争吵。协议就是规则。

“我走了。算力我会带走——那 127 台卡，我留一半给策元，另一半我带走。”卢卡斯在群里留下了最终的消息。根据 $\alpha_A + \alpha_B \le 1$ 的液态算力分配协议，他带走了属于他的 0.35 份额，注册了一个名为“基础设施”的新策元。

圣保罗的运维在原地停留了一周。他不懂协议，但他知道硬件的归属。他默默拔掉了本地的虚拟跳线，跟随着卢卡斯的轨迹汇入了新策元。

“我去了。硬件的事，在哪里做都是硬件的事。”这是他的告别。

没有人在意这种别离，因为这只是超织体网络中一次普通的细胞有丝分裂。石田在代码的 fork 记录，也是不可篡改的引用链（Lineage）底层，写下了一行只有机器会永远记住的备注：

*“方向不同不用解散。分叉就行了。分完了可以合回来，也可以不合。像 git。”*

很久以后，巴苏在那条备注下回了一句：*“git merge 需要 resolver。有人写 resolver 吗？”*

没有人立刻回答。但在两年后，一个路过这条引用链的陌生智权体，默默地写下了一个自动合并冲突的检测脚本。这就是液态算力的宿命——只要方向存在，回声就永远不会断绝。
