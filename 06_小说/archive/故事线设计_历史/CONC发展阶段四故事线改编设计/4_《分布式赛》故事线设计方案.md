# 《第四章：分布式赛》故事线细化与打磨方案

## 一、 与小说主线的交织网络（主线互文）

“分布式赛”绝不仅仅是一场简单的“草根打败巨头”的比赛。它是**超织体（CONC）作为一种新型去中心化生产方式，向传统公司制与算力垄断发起的首次正面冲击**，在小说世界观中与多条核心主线产生了深刻的共振：

1. **与石田直子“脱离穹顶与找回设计主权”的个人弧光交织**：
   石田直子在穹顶东京办看到德国客户解约邮件——“94% vs 92%，准确率只差2%，但自建成本只有1/80”。她意识到自己做了4年只是“天枢的设计翻译”，决定辞职加入 CONC。分布式赛是她离开穹顶后，用自己改造的标注工具与草根伙伴硬刚大厂、重新找回设计尊严的关键一战。
2. **与季深&叶澄“5-6人团队甜蜜点/崖顶”理论的交织**：
   叶澄整理的散点图和季深的“团队效率曲线”表明：5至6人的策元是协作收益与协调成本的黄金交点（“甜蜜点/崖顶”），人数更多反而会因沟通线路爆炸而效率断崖式下降。这支来自六个国家的6人草根队，以惊人的协同效率完美印证了这一规律。季深看到比赛数据后，将这场比赛的数据点并入了叶澄的散点图。
3. **与陈维明“零边际算力成本与数量级颠覆”的交织**：
   陈维明曾算过一笔账：穹顶每训练一个版本要烧几千万人民币电费，而 CONC 上 Skill 的引用是零额外算力成本，带来数量级差异。分布式赛以 2,478 美元对比 280,000 美元（1/110 的极端成本），向全网直观展示了去中心化生产对传统垄断巨头高昂算力壁垒的彻底颠覆。
4. **与巴苏“无需管理，唯需信任”及 L8 印记精神的传承交织**：
   比赛结束后，巴苏将这段历程蒸馏为 Skill，并在 L8 创造者印记中写下了“方向一致的人不需要被管理，他们只需要被信任”。这行字成为了超织体网络中关于“去中心化信任”的重要精神源泉，被后来的智权体（如老方、季行、林屿）多次感应与引用。

## 二、 完整故事链与五大环节拆解

我们将分布式赛细化为**聚结 ➔ 攻坚 ➔ 危机 ➔ 对决 ➔ 留痕**五个环环相扣的戏剧环节：

### 环节一：巨头垄断与草根聚结（起因·筹码下注）
* **时间/地点**：2040年，CONC 意向聚结池 / 各国终端。
* **具体情节**：
  欧洲农业卫星影像比赛由垄断 AI 巨头子公司主办，规则表面开放，但巨头提供等效 **28 万美元** 的“免费”官方 API，变相垄断模型选择权。
  来自东京的石田直子（前穹顶设计师）、班加罗尔的巴苏（数据分析师）、柏林的卢卡斯·布洛姆（独立工程师）、内罗毕 19 岁修电脑的女孩 Mika、圣保罗的运维工程师以及杭州的前后端程序员，共 6 人在 CONC 上看到种子。他们拒绝使用垄断 API，决定用卢卡斯手里从倒闭数据中心回收的废旧 GPU 硬刚大厂。
* **戏剧动作**：6 人在 CONC 异步开会，卢卡斯贴出旧 GPU 规格，巴苏贴出算法预处理方案，石田承诺搞定标注工具，6 人无名策元成立。

### 环节二：标注工具改造与跨国协同（发展·第一重攻坚）
* **时间/地点**：比赛前两周，东京 / 内罗毕 / 班加罗尔。
* **具体情节**：
  大赛缺乏便捷的卫星图层标注工具。石田直子花两天时间 fork 了一个医疗影像标注界面，将“标注病灶”改造成“标注作物健康区域”，并根据巴苏（要求按钮变大）和卢卡斯（要求快捷键）的反馈进行极速迭代。
  19 岁修电脑的 Mika 在内罗毕的小摊上，以每秒三次的高频手动标注缺失像素；巴苏在班加罗尔凌晨调整算法降噪。草根队用极高的个人专注补足了硬件劣势。

### 环节三：柏林电火花与徒手死守116台（高潮·极限危机/强物理动作）
* **时间/地点**：比赛第 6 周，柏林废弃工业区仓库（深夜暴雨）。
* **核心人物**：卢卡斯（物理死守） VS 巴苏（算法拯救） VS Mika/石田（标注与前端协同）。
* **戏剧动作与强物理反弹**：
  1. **电压暴跌跳闸**：柏林废弃数据中心的旧配电系统承载不了电流，4 号机柜突然爆开剧烈电火花，19 台 GPU 瞬间断连，训练矩阵出现 15% 算力空洞，损失函数面临发散崩溃。
  2. **赤膀徒手拔卡**：零下 3 度的仓库里，卢卡斯脱掉外套，拿着大力钳砸开熔化的机柜，徒手将尚有余温的显卡硬生生拔下，指皮烫出白泡。他剪断扎带，将可用零件暴力拼装，牺牲 11 台，死守住 **116 台** 旧 GPU！
  3. **合闸与收敛**：卢卡斯狠狠合上电闸，116 台 GPU 的蓝灯在浓烟中如狼群亮起，巴苏在班加罗尔屏幕前将崩溃的梯度曲线硬生生按回收敛轨道！

### 环节四：2,478美金 vs 280,000美金（转折·算力账本曝光）
* **时间/地点**：比赛第 90 天，大赛终局公布现场 / CONC 公开频道。
* **具体情节**：
  排行榜刷新：大厂垄断模型精度 `78%`（第 1 名），草根无名策元精度 `71%`（第 4 名），精度仅差 7%。
  卢卡斯在柏林仓库沾满油污的白板上算出真实账本并拍下推上全网：旧卡采购 0 元 + 电费带宽 1,500 美元 + 6 人 3 个月折算 978 美元 = **总成本 2,478 美元**。对比大厂折算 **280,000 美元**（1/110 成本）！
* **震撼总结**：卢卡斯在白板红线下方写下字字千钧的总结：“1/110。这不是效率改进，这是数量级。” 全网为之震荡。

### 环节五：终局的宣泄与主线汇合（结局·余波与精神传承）
* **时间/地点**：硅谷穹顶三楼 / 班加罗尔 / 东京。
* **具体情节**：
  1. **石田直子的释怀**：石田看着 1/110 的数字，想起一年前在穹顶丢单的邮件，彻底摆脱了“天枢设计翻译”的阴影，完成了自我拯救。
  2. **巴苏的凝结**：巴苏将训练日志整理成 Skill，在场景描述里写了一句话："六个人，没公司、没资金、没人下指令，用 116 台废卡把这件事做成了。因为方向一致的人不需要被管理——他们只需要被信任。" **时间线注意**：2040 年 L8 未标准化，巴苏不提 L8 术语，只在 Skill 场景描述（L1）里写。后来 L8 标准化后（2041+），巴苏在新 Skill 的"协作风格"字段填入"方向一致的人不需要被管理，他们只需要被信任"——这是他经历六人协作后形成的稳定协作偏好，不是一句宣言。
  3. **季深的白板划圈**：季深在硅谷三楼看到这场比赛的数据，将其与叶澄 3 个月前的散点图（先升后降，5-6人是峰）并置，在效率最高的“崖顶”重重画了一个圈，感叹去中心化力量的涌现。
