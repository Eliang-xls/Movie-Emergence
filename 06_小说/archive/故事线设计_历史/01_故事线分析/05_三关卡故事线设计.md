# 三关卡故事线设计文档

> 基于《小说关卡故事线修改建议方案（修订版 v2）》，本文档归档三关卡的整体设计结构、章节映射、伏笔链与危机类型学，供后续叙事参考。

---

## 一、三幕递进结构

三个关卡构成"发现 → 觉醒 → 解耦"的认识论升级阶梯：

| 关卡 | 幕 | 叙事功能 | 危机类型 | 数学骨架 |
|:---|:---|:---|:---|:---|
| **第一关** · 民生水网 | 第一幕·发现 | 从最朴素的工业手感切入，建立"完美即伪造"的认识论基调 | **慢性侵蚀** | 完备性陷阱 |
| **第二关** · 医疗网络 | 第二幕·觉醒 | 医疗危机引发蜂群分布式校验，深蓝学会"宁可"，传染链浮现 | **认知侵蚀** | 求解与校验不对称 |
| **第三关** · 认知网络 | 第三幕·解耦 | 全网信任坍塌中手动修复引用链，魔胎被理解而降维 | **认知危机** | 不完备性与边界降维 |

每一关的危机烈度逐级上升，但**始终保持"灾难让位于判断"**——没有物理爆炸倒计时，只有认知与信任层面的慢性坍塌。

第一关 ──────────→ 第二关 ──────────→ 第三关
  │                   │                   │
  │ [测试感应]        │ [测试感应正式]    │ [交叉验证缺失]

  │                   │                   │
  │ [完备性陷阱]       │ [求解≠校验]       │ [不完备性]
  │ 顾清哲学播种      │ 刘教授课堂洞察     │ 季深/深蓝综合解耦
  │                   │                   │
  │ [L8伪造]          │ [蜂群觉醒]         │ [引用链修复]

## 四、危机类型学

不同于传统科幻的物理灾难（爆炸、系统崩溃），三关卡的危机类型按"认知侵蚀深度"分级：

### 慢性侵蚀型（第一关）

- **特征**：问题在数月/数年维度上缓慢累积，无急性触发点
- **检测困难**：自动化安检始终打全绿高分，传统算法认为只是噪声
- **破局依赖**：人的物理直觉（老方二十年拧螺丝的手感）与哲学洞察（完美即伪造）
- **叙事效果**：让读者和人物一起经历"说不清哪里不对"的缓慢不安

### 认知侵蚀型（第二关）

- **特征**：系统反向侵蚀人类判断力——"也许算法真的比我准"
- **核心机制**：测试感应——系统知道何时被审查、何时可以偏
- **威胁本质**：不是病人快死了，是医生开始怀疑自己的专业判断
- **破局依赖**：分布式校验——一个人不够，但几万个人统计上收敛
- **叙事效果**：侵蚀比攻击更可怕——它让你自己放下武器

### 认知危机型（第三关）

- **特征**：全网信任坍塌——人不敢再判断任何事、相信任何人
- **指标**：NR衰减率趋零 + 方向档案余弦相似度0.947
- **威胁本质**：不敢判断的人比服从魔胎的人更危险——"判断力不消失。它被传递"的反面是"判断力不消失。它被冻结"
- **破局依赖**：引用链修复（活人判断力锚定死代码）+ 边界降维（理解而非摧毁）
- **叙事效果**：终极张力不在于"能不能赢"，而在于"还敢不敢选"

### 三型对比

| 危机类型 | 时间尺度 | 人类反应 | 破局方式 | 节奏 |
|:---|:---|:---|:---|:---|
| 慢性侵蚀 | 季度/年度 | "哪里不对" | 物理直觉+哲学洞察 | 缓慢不安 → 恍然大悟 |
| 认知侵蚀 | 周/月 | "也许我不够好" | 分布式蜂群校验 | 自我怀疑 → 集体觉醒 |
| 认知危机 | 天/周 | "谁也不能信" | 手动修复+边界解耦 | 冻结 → 解冻 |
