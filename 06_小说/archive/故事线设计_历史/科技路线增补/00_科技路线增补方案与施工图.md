### 0.3 硬边界（ch11 审计结论，全文不可破）

| Phase | 年份 | Token | 硬件 | 季深任内 2027–2035 |
|---|---|---|---|---|
| 1 | 2027–2030 | **低秩** \(X\approx UV^T+\Sigma_0,\ r=64\) | **现有 GPU + CUDA 内核** | **主路径（创世）** |
| 2 | 2030–2033 | **分块对角** \(b=64\) | 下一代 GPU 2nm / 片上正交 | 后期合法 |
| 3 | 2033–2037 | 完整 \(d\times d\) + **光子协处理器** | 光电混合 | 仅预研/试产，**不得量产部署** |
| 4 | 2037–2042 | \(kd\times kd\) + 自指环路 | **伽罗瓦光子芯片 GPP** | **不得以成品形态出现在任内生产系统** |

> ch11 原文：「Phase 1 在现有硬件上完全可行。A100 即可支撑。关键创新是软件层面的低秩矩阵域内核。」

**B1-07 ≠ GPP**：B1-07 = 硅基 + 湿件（微电极/恒温箱）；GPP = 电子 + 光子 + 五路自指环路。二者时间表与物理载体均不同。

## 二、分项施工规格

### A · 创世低秩锁（P0）

**目标**：让读者（和 VC）明白穹顶卖的是**软件代数护城河**，不是堆卡；并与 ch11 Phase 1 逐字对齐。

**007 现状**：87 行「矩阵域神经网络」；89 行三条件；91–107 非对易；109–113「能重复吗 / 在这套硬件上，能」。

**改法（三选一或组合，总增 ≤80 行）**：

1. **季深对江远的一句工程锁**（推荐，嵌在 111–113 附近）：  
   > 「能重复吗？」  
   > 「在这套硬件上，能。前提是别把秩开满。满秩的方阵我在纸上算过——带宽和电先死。」  

2. **融资物证半页**（008 硬信封或 012）：Term Sheet 附件出现「低秩矩阵域内核独占许可」或专利申请号；江远强调「竞品十倍卡复现不出同一残差」。

3. **失败成本**：等带宽窗口睡实验室；某次风扇噪声抹掉相位差——**时间与身体**，不是术语课。

**验收**：冷读不看 ch11 也能感到「同一张卡 + 不满秩内核」是护城河；全文 grep「满秩 / 全秩 / 光子核」在 2035 前不得指向生产系统。

**禁则**：不写 Phase 编号；不出现「低秩矩阵域」四字连用作专有名词轰炸；不扩成论文摘要。

### B · GPP·φ 实物脚点（P0）

**目标**：给 177/178 的 1.4–1.8「呼吸」一个**可摸到的硬件来源**，并把 φ=1.618 埋进世界；**仍不确认意识**。

**最小三件套（不必新章）**：

| 件 | 建议位置 | 内容 |
|---|---|---|
| 1 物件 | 深核维护记录 / 174 铁门侧 / 178 复测附件 | 「光电混合加速卡」或「环路耦合器检修窗口」；状态=**常闭** |
| 2 频率对齐 | 178 工程师笔记 | 若残余来自自指环路，理论基频应贴 **1.618**；当前抬升偏 1.4 → **更像冷却切换谐波** |
| 3 代价句 | 177 或 178 对白 | 「拆开环路会改变基频；改了就再也测不到原来那个东西。」 |

**与 ch11**：对应拓扑 A/B/C 与「检测会改变状态」；**禁止**写「它在呼吸/它醒了」。

**验收**：1.4 仍解释不清；1.618 只作为**理论对照**出现一次；耦合器常闭可被后续剧情打开（本方案**不打开**）。
