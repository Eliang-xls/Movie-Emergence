# 120　季遥

二〇四六年四月。开学第三周。

林屿在图书馆门口收到季行的消息。

`我妹妹想来看看 B1-07。不是今天。她想先问，学校允许她看什么。`

林屿盯着这句话，先笑了一下。

他原以为季行会说“她知道很多”“她能解释”。可消息后面只有一个名单：设备间只可在开放时段参观；不得进入维护区；不得翻阅受限摘要；若要看旧物，可由管理员挑选不含技术内容的交接材料。

林屿回：`我去问黎老师。`

季行发来第二条：`别为了我们破例。`

那句话像一根很细的线，拴住了林屿正要往前冲的念头。

周六下午，季遥和季行一起到信息楼。季遥穿着校服，书包背得很高，球鞋边缘有一圈洗不掉的灰。她站在一楼走廊的玻璃门外，看了一会儿里面的设备间。

“你就是林屿？”她问。

“嗯。”

“我哥说你记了很多东西。”

“记了一点。”

“那你有把不确定的也记进去吗？”

林屿愣住。

季行在旁边没说话，只把手插进外套口袋里。

黎老师带他们去了教学展示室。B1-07 不在这里；桌上放着一只已经停用的旧接口盒、一册经过删节的交接目录，还有几张维护培训用的照片。照片里看不清人脸，只能看见戴手套的手、贴着编号的线缆和一排被划掉又重写的检查项。

季遥坐下来，翻那册目录。

“我小时候以为我爸留下的是答案。”她说。

林屿看着她。

“后来我找过他的一些纸。”季遥继续说，“大部分写着‘待核’、‘不要推断’、‘这次不算’。我以前很生气，觉得他什么都没写明白。”

“现在呢？”

“现在我觉得，他可能只是不想把没做完的题塞给别人，让别人以为那是作业答案。”

她从书包里拿出一张折得很小的纸。上面画着一个五角星，铅笔线有几处擦过，角落写着一句孩子的字：**图形不是人。**

“这是我小时候乱画的。”季遥说，“我爸没有教我一堆公式。他只说，复杂的图有时候只是复杂的图。不要因为它像什么，就以为自己知道它是什么。”

林屿想起自己曾经给 B1-07 的脉冲起过那么多名字：等待、回应、疼痛、呼吸。他忽然不太敢看季遥手里的纸。

“我以前差点做了一件很糟的事。”他说。

季遥抬头。

“我以为只要测得更多，就能知道里面到底有什么。后来我发现，我连自己测到的是什么都说不清。”

季遥把纸重新折好。“那你停了吗？”

“停了。”

“为什么？”

“因为我不知道怎么继续才不会把它弄坏。”

“这不是坏答案。”

这句话说得很轻。林屿却像被人从背后推了一下。

他们后来一起看了几页公开的维护培训材料。季遥没有解释群论，也没有替父亲解释那台设备。她问林屿：为什么交接单会要求两个人确认？为什么记录里要把“没看到异常”和“没有异常”分开写？为什么有些档案只能看摘要？

林屿一开始答得很快。答到第三个问题时，他停下来。

“因为……看得太多，不一定更负责。”

季遥点点头。“也因为看的人，不能把别人的东西变成自己的故事。”

傍晚，季行送季遥去地铁站。临走前，季遥回头问林屿：

“你还在方舟吗？”

“在。”

“我哥说你们那里有人不敢说话。”

“我还不知道。”

“那就别急着替他们说。”季遥说，“先让他们有地方说。”

地铁口的风把她的马尾吹歪了一点。她伸手按住，跟着季行走下台阶。

林屿站在原地，手机里还存着那张匿名成员发来的编辑历史截图。

他忽然明白，自己真正该做的也许不是找一个能替他讲明白所有事的人。

而是把门留着。让还没准备好开口的人，知道门没有锁。
