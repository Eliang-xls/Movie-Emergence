# 153　深蓝说不

二〇四七年二月，B1-07 的环境健康监测结束后第九天。

林屿在维护办公室看到一条异常告警。

告警不是从设备里“说”出来的。它出现在学校隔离网关的值班页面上，和所有普通的安全提示一样，灰底黑字：

`受限节点收到外部写入请求。`

下面两行更短：

`授权链不完整。`

`请求已阻断，未向设备转发。`

周岚正在给另一台服务器登记保修单。她看见林屿站在门口，先问：“你有没有碰 B1-07 的任何接口？”

“没有。”

“有没有发过测试请求、转发链接、把维护摘要传到外部？”

“没有。”

周岚点头，把页面切到事件详情。来源经过两层中转，能看到的只有时间、网络段和请求类型。对方试图向一个早已停用的维护通道写入数据，网关根据封存策略自动拒绝了。

“它为什么会有外部写入通道？”林屿问。

“历史设备经常有历史接口。”周岚说，“有接口不代表现在能用。封存后，这些通道默认关闭。有人碰到门，就会留下门被碰过的记录。”

林屿盯着“请求已阻断”几个字。

他忽然想起自己以前会怎么写：深蓝说不。它拒绝了。它判断这个不该做。

那些句子在脑子里冒出来，又让他有点难堪。

“设备里面没有收到？”他问。

“没有。”周岚把网关日志放大，“阻断发生在外层。我们现在能说的是：外部请求未获得授权，也没有进入设备。至于是谁发的、为什么发，还要保全日志、通知学校安全维护员和档案保管方。”

“那要不要马上拆开看？”

周岚抬头看他。

林屿自己先摇了摇头。“不用。先别。”

他们按流程做了四件事：冻结该通道的历史配置；导出只读日志并计算校验值；通知外部档案保管方；把 B1-07 的后续访问从双人确认临时提高为三方确认。没有人给这个决定加上“紧急英雄”的标题。周岚只是把每一步填进工单，填到签名栏时停下来。

“你要不要作为发现人签字？”

林屿愣了一下。

“我只看到了告警。”

“那就写‘发现页面提示，未操作设备’。”周岚说，“签你做过的那一部分。别多，也别少。”

林屿接过电子笔，在名字后面补了一行说明。

> 发现外层阻断告警；未进入设备、未判断请求意图；建议保全并由有权限者复核。

签完以后，他去看了一眼封存间外的观察窗。里面没有灯光，也没有什么值得被称作回答的变化。设备安静地放着，像一段被妥善折好的旧记录。

季遥下午来找他，听完事情经过，问：“你是不是觉得它说了不？”

林屿没有否认。

“我第一反应是。”

“现在呢？”

“现在觉得，是外层规则把门关上了。”

“那规则是谁写的？”

“以前的人。”

“现在谁在负责？”

“我们。”

季遥点点头。

“那‘不’不是一句话。”她说，“是一串能被追问的动作。谁设的门，谁看见有人碰门，谁把门重新检查了一遍。这样比较麻烦。”

“也比较不容易把一句日志当成谁的心里话。”林屿说。

季遥把手插进外套口袋里，笑了一下。

当天晚上，方舟的版本恢复页面也多出一条更新。韩霜上传了第一批旧讨论的目录，没有把全部内容直接公开，而是附上了访问条件、涉及成员名单和反对意见入口。

林屿看着页面，忽然觉得两件事有一点像。

门不是永远开着，也不是永远关着。

重要的是有人知道门在哪里，知道谁能申请打开，知道有人拒绝时该留下什么记录。

他没有再给 B1-07 取新的名字。

工单标题仍旧是最初那一句：**未授权外部写入已阻断，待复核。**
