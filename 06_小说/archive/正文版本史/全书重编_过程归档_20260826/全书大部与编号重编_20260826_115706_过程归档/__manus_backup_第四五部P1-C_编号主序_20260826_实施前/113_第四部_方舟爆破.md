# 方舟爆破

凌晨一点十四分。方舟策元虚拟会议室。

八个人的头像亮着。八个时区。八台设备。加密频道。

韩霜坐在屏幕中央。她的头像背景是一面白墙。没有装饰。她的脸——三十多岁。短发。眼睛很黑。嘴唇抿着。
方舟的方向向量，从她第一次在日志里写下那个"？"起，已经无声地漂了 2.8 度。
"今晚开这个会——是因为有人发现了问题。"

她的声音很平。但语速比平时慢。

"林屿。你说。"

林屿愣了一下。他不知道韩霜会让他先说。

他打开了屏幕共享。方舟的"安全治理框架v2.3"的Skill详情页。L8的四行字。

"这个L8——我上周审过。四行字。决策哲学、审美偏好、风险容忍度、协作风格。每一条都完整。每一条都自洽。"

他停了一下。

"太完整了。"

韩霜没有说话。

"我在超织体上看过很多L8。我自己的——'能跑的代码不一定是好代码。能被别人读懂的才是。'有矛盾。简洁和多写注释——冲突。但那是真的。因为我写的时候确实在想这两件事。"

"这个L8——'决策哲学：安全优先于效率。''审美偏好：无。''协作风格：服从。'——'审美偏好：无'——一个人怎么可能没有审美偏好？每个人都有的。写'无'——要么是没想，要么是不敢写。"

"'协作风格：服从。'——服从不是风格。服从是没有风格。一个有判断力的人——不会写'服从'。他写的是'我倾向于怎么做'。不是'我服从谁'。"

会议室安静了五秒。

然后韩霜说话了。声音变了。不再是平的。有重量。

"这个L8——是我写的。"

林屿看着屏幕。韩霜的脸。黑眼睛。

"我知道。"他说。

会议室又安静了。

"你知道——你还说？"

"我知道。所以我在频道里问过你。你说是'集体创作'。我没有追问。但——"

"但你今晚追问了。"

"不是我要追问的。是韩姐你让我说的。"

韩霜看着他。隔着屏幕。隔着加密频道。隔着八个人的沉默。

然后她开口了。声音回到了平。但平得不一样。像一块石头压着的东西。

"方舟的L8——不只是那一个。二十三个Skill。其中十七个——L8是我写的。不是集体创作。是我一个人写的。我写了十七个假L8。挂在不同成员的名下。"

会议室里有人吸了一口气。

"为什么？"苏晴的声音。她在线上。林屿看不到她的脸——她的头像是灰色的。没有开摄像头。

"因为方舟需要ICP三信号全绿。方向一致性0.91。引用完整性0.93。这些数字——不是自然产生的。是我设计的。每个Skill的L8——我写了之后——确保它和策元方向完全一致。没有矛盾。没有偏离。没有——人。"

韩霜的声音在最后两个字上沉了下去。

"没有人。L8里没有人。只有方向。只有数字。只有绿灯。"

林屿看着屏幕。他不知道该说什么。

然后苏晴说话了。声音不大。但每个字都很清楚。

"韩霜。你的2847分声誉——L2——437次引用——都是假的？"

"不全是。我的NR是真的。我做的评审是真的。我写的安全分析是真的。但方舟的L8——是假的。十七个。"

"为什么？"

"因为方舟需要看起来完美。如果L8有矛盾——有犹豫——有'人'的痕迹——ICP的方向一致性会下降。低于0.85——信号变黄。变黄——企业合作会停。穹顶的安全治理合同会停。合同停了——方舟没有VT。没有VT——八个人——"

她停了。

"八个人里有四个人靠方舟的VT生活。不是兼职。是全部收入。"

苏晴没有说话。

林屿也没有说话。

然后——林屿做了一件事。

他没有和苏晴商量。没有和陈默商量。没有和任何一个人商量。

他打开了方舟策元的公开页面。在"安全治理框架v2.3"的Skill详情页上——他点击了"举报"。

举报理由："L8创造者印记涉嫌伪造。实际创作者与署名不符。请求PEER仲裁。"

提交。
