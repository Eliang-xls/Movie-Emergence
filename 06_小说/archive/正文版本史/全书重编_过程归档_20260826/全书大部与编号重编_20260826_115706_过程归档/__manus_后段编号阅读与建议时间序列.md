# 《涌现》后段编号阅读与时间索引

> **正式主序规则：** 小说正文必须以**文件名中的章节编号由小到大**阅读。第四部、第五部等“大部”标签只表示创作分组、人物线或主题归属，**不改变章节的正式阅读位置**。时间卡、档案标记与回溯说明只用于解释时间跳跃，绝不构成移动章节或以部别覆盖编号的理由。

## 一、正式编号阅读方式

当前正文唯一正式阅读方式是按数字递增：`089 → 090 → … → 122 → 125 → 128 → 131 → 132 → 133 → 134 → … → 145 → 146 → …`。不存在“读完第四部089—156后再回读第五部125—145”的部别优先顺序。

| 交错编号段 | 正式阅读顺序 | 阅读规则 |
|---|---|---|
| 089—122 | 第四部089至122 | 按连续编号顺读。 |
| 125、128、131—133 | 第五部章节插入第四部编号主线 | 在各自编号处直接阅读；不得因其标为第五部而后置。 |
| 134—138 | 第四部134至138 | 继续承接133之后的编号；不得回收到“第四部完结后”才阅读。 |
| 139—145 | 第五部139至145 | 在编号处直接阅读；其后才进入第四部146。 |
| 146—156 | 第四部146至156 | 承接145后的编号主线。 |

因此，P1工作也必须遵循同一原则：可以在章节开头加入时间卡、档案来源卡和必要的转场句，**不能仅因章节所属大部不同而挪动编号、跳读或要求读者按部别重排。**

## 四、阅读边界提醒

编号顺读时，不应把章节中出现的历史材料自动视为当下事实。对季深、深蓝 / B1-07、湿件与探针，应优先读取章节中标明的来源、时间、权限与不确定性。后段主题不是某一系统终于被证明为何物，而是不同的人如何在证据不全时留下记录、允许申诉并作出可复核的有限选择。
