# 电话

晚上。宿舍。

他给父亲打了一个电话。

"爸。"

"嗯。"

"你还好吗？"

"还行。工厂——还在裁人。"

"你——"

"我没事。你照顾好自己。钱够不够？"

"够。"

他不知道怎么跟父亲说VT的事。VT不能换钱。父亲不会理解。父亲的世界里——干活拿钱。钱买菜。买米。交房租。干活拿不到钱的——不叫干活。叫白干。

他不能跟父亲说"我在超织体里做任务令挣VT"。父亲会问"VT能换多少钱"。他得说"不能换钱"。父亲会沉默。然后说"那你做它干什么"。

他不知道怎么回答。

"爸——我挂了。"

"嗯。吃饭了没？"

"吃了。"

"多吃点。你太瘦了。"

"嗯。"

他挂了电话。躺在床上。看着天花板。

赵晨在刷手机。突然抬头。

"林屿——你看这个。"

他翻过来。屏幕上是一个超织体帖子。标题："互赞群——快速涨NR。L1到L2只需要两周。"

"互赞群？"

"就是——一群人互相给对方的Skill打高分。你给我5星，我给你5星。NR涨得很快。"

"那不是作弊吗？"

"不算。超织体协议没有禁止互相评审。只要你评审了——系统就认。不管你是不是认真评的。"

赵晨看着他。"你觉得——怎么样？"

林屿看着那个帖子。

后颈没有紧。也没有松。但他觉得——不对。

他说不出来哪里不对。但他没有去看那个帖子的详情。

"我不去。"他说。

赵晨看了他一眼。没有说话。继续刷手机。
