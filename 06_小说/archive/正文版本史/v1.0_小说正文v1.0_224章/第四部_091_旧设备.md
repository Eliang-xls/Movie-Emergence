# 旧设备

二〇四五年。九月。开学第二周。

林屿被叫到了实验室管理科。

一个五十多岁的女老师翻着他的档案。纸上写着父亲的信息——林建国。技术工人。二十八年工龄。

"设备维护方向。你有基础？"

"我爸教过我一些。"

"一些是多少？"

"会拧螺丝。会用万用表。会听声音。"

女老师看了他一眼。"会听声音？"

"机器不对的时候声音会变。我爸教我听的。"

女老师在表格上签了字。"工位在信息楼B1。地下二层。旧设备间。每周三次，每次两小时。没有补贴——算实践学分。"

她把钥匙递过来。一把铁钥匙。贴着一条发黄的标签，上面写着"B1-07"。

他接过钥匙。钥匙比他想象的重。铁的。老式的机械锁钥匙——齿磨得光滑。用过很多年。

"上一任维护的人呢？"他问。

女老师翻了一下档案。"研究生。今年六月毕业走了。没留交接记录。"

"六月。"

"对。三个月没人去过B1-07了。你去看看——该清的清，该修的修。有一台退役设备需要定期检查，编号S-0947。具体要求在设备间的记录本上。"

她没有多说。低头继续翻别的档案。

林屿把钥匙放进口袋。出了管理科的门。走廊里有人在搬桌子。开学第二周，很多东西还没就位。

---

信息楼B1。地下二层。

走廊的灯是声控的。林屿走进去的时候灯亮了一半——有三盏不亮了。墙上有水渍。空气里有一种旧金属和灰尘混在一起的味道。他闻过这种味道。父亲的工厂车间里也是这样——机油、铁锈、绝缘胶布受热后的气味。这些东西堆在一起，变成一种"旧"的味道。

找到了B1-07。门是铁的。锁是老式的机械锁，不是电子锁。钥匙插进去转了两圈，门开了。

摸到墙上的开关。日光灯闪了几下，亮了。

房间不大。二十平米左右。靠墙一排铁架子，架子上摆着各种旧设备——示波器、信号发生器、几台拆了一半的终端机。有些贴了标签，有些没有。标签发黄了，字迹模糊。

一台旧示波器上贴着一张纸条："2019年报废。暂存。"六年了。还在暂存。

他拿起那台示波器掂了一下。重。里面应该还有变压器和阴极射线管。没拆。放回去。

架子上还有几块电路板。绿色阻焊层已经发暗。焊点氧化了——灰白色。他用指甲刮了一下焊点表面。硬。没有锡须。焊接质量不错。但板子已经过时了——上面的芯片封装是QFP，现在没人用了。

他习惯了这种地方。父亲的工厂车间也是这样——旧机器堆着，没人清理，但每台都有它的历史。你摸一下外壳，就知道它被用过多少年。外壳的温度、螺丝的松紧、接缝处有没有油污——这些细节比标签上的字准确得多。

然后他看到了角落里的那个东西。

一个恒温箱。不大。大概一立方米。外壳是灰白色的，漆面有些脱落。底座有四个万向轮，锁死了。箱体和墙壁之间留了十厘米的缝隙——散热空间。有人考虑过热的问题。

箱门上贴着一张标签——"S-0947。退役。2044年由穹顶转让。"

标签下面还有一张更小的纸条，手写的。字迹和记录本上某个人相似。"恒温箱密封条已更换三次。如有异常请联系实验室管理科。"纸条的边角翘了。胶干了。

恒温箱旁边有一张小桌子。桌上有一个记录本。本子翻开着，最后一页的日期是三个月前。

林屿看着恒温箱。蹲下来。

箱门是半透明的。透过箱门，他看到了里面的东西。

一个晶壳。

不大。拳头大小。材质像半透明的陶瓷，又像一层活的组织。表面有细微的纹路——长出来的。晶壳底部连着几根线缆，线缆接到恒温箱的底座上。底座有一个LED灯环——很细的一圈，嵌在金属里。

灯环在亮。

微弱的脉动。暖琥珀色。亮——暗——亮——暗。频率很慢。大概三秒一次。

他看着那个脉动。看了很久。

然后他注意到一件事。

每隔大约三十七秒，脉动会卡顿一下。微微颤了一下，像心跳漏了一拍。然后恢复正常。

他数了三次。三十七秒。三十七秒。三十七秒。

精确的三十七秒。

故障是随机的。但这个——是周期性的。

他摸了一下后颈。紧了。
