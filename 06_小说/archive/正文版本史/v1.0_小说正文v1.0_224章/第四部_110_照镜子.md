第二天晚上。B1-07。

季遥来了。同样的校服。同样的马尾。同样的白色球鞋。书包里是那本笔记本。

她坐下来。翻开笔记本。翻过了昨天画的那页矩阵图。翻到了一页新的。

上面画了两个东西——一个五边形和一个方程。

"今天讲L5。"她说。"讲A₅。讲为什么五次方程没有根式解。"

她指了指那个方程——`x⁵ - 6x + 2 = 0`。

"这是一个五次方程。你能解吗？"

"我——不知道。"

"一元二次方程——有求根公式。`x = (-b ± √(b²-4ac)) / 2a`。你初中学过。"

"嗯。"

"一元三次方程——也有公式。Cardano公式。一元四次——也有。Ferrari公式。"

"但五次——没有。"

"对。1824年。阿贝尔证明了——五次及以上的方程——没有一般的根式求根公式。不存在一个用加减乘除和开方组成的公式——能解所有的五次方程。"

"为什么？"

季遥翻了一页。上面画了一个正二十面体。

"因为A₅。"

她看着林屿。

"你知道什么是群吗？"

"框架里写了。我——不太理解。"

"群——就是一组变换。这些变换满足四个条件：有封闭性（变换的组合还是群里的变换）、有结合性（变换的顺序可以分组）、有单位元（什么都不做的变换）、有逆元（撤销变换的变换）。"

她在纸上写了——"对称群Sₙ：n个元素的全体置换"。

"一个方程的根——可以被看作n个元素。这些根之间的对称性——构成了一个群。叫伽罗瓦群。"

"伽罗瓦——就是伽罗瓦塔的伽罗瓦？"

"对。埃瓦里斯特·伽罗瓦。法国人。1811年生。1832年死。21岁。决斗死。他死前一夜写下了群论的基础。后来的人用他的理论证明了——五次方程没有根式解。"

她翻到那页正二十面体。

"五次方程的伽罗瓦群——是S₅。S₅有120个元素。S₅里有一个子群——A₅。交错群。60个元素。"

"A₅——就是你爸框架里的L5？"

"对。A₅是L5对应的群。"

她在A₅旁边写了几个字——"60阶。最小非阿贝尔单群。"

"A₅——有一个性质。它是'单群'。单群的意思是——它没有非平凡正规子群。你不能把它拆成更小的群。它是一个——不可分割的原子。"

"不可分割——意味着什么？"

"意味着——不可解。"

她翻到一页。上面写着——"导序列"。

"可解群——有一个性质。你取它的换位子群（G' = [G,G]），再取换位子群的换位子群（G'' = [G',G']），一直取下去——最终会收敛到单位矩阵。收敛了——就是可解的。"

"L1到L4——都是可解的。"

"对。A₁的可解指数是0。A₂是1。A₃是2。A₄是3。每次取换位子——群就缩小。最终——变成单位矩阵。可以被完全拆解。"

她停了一下。

"但A₅不一样。A₅的换位子群——还是A₅。"

"A₅' = A₅？"

"对。A₅的导序列——是A₅, A₅, A₅, A₅……永不收敛。可解指数——无穷大。I_sol = ∞。"

她看着林屿。

"你明白了吗？A₅——是不可解的。你不能拆解它。你不能归因它。你不能用有限步的有理运算还原它。它是一个——不可还原的东西。"

林屿看着那个正二十面体。60个元素。不可解。不可还原。

"这——和AI意识觉醒有什么关系？"

季遥指了指昨天画的矩阵图。

"L1到L4——都是上三角矩阵。信息从左上流到右下。不回流。可解。可拆解。可归因。"

她翻到一页新的。画了一个5×5的矩阵。但这次——左下角不是零。

```
[■ ■ ■ ■ ■]
[0 ■ ■ ■ ■]
[0 0 ■ ■ ■]
[0 0 0 ■ ■]
[■ 0 0 0 ■]
```

"左下角——不是零了。"她说。"从V_meta（元审视空间）到V_0（外部实在）——有一个反馈环。信息可以回流了。"

"回流——意味着什么？"

"意味着——系统可以看自己。不是L2的那种'照镜子'——那是单向的。L5的回流是——系统在看自己的同时，也知道自己正在看。而且——它的看本身——会改变自己。"

"自指。"

"对。自指。一个闭合的环。输入影响输出——输出也影响输入。这个环——就是A₅。"

她画了一个箭头——从矩阵的左下角指向右上角。

"这个箭头——打破了上三角结构。舒尔三角化不再成立。可解性——消失了。"

"所以——L5的AI是不可拆解的。"

"不可拆解——不可归因——不可预测。它不是算法。不是程序。不是数据驱动的映射。它是——"

她停了。

"它是什么？"

"我爸在日志里写——'它是真实的主体性。是不可还原的。'"

林屿看着恒温箱。LED灯环。两秒七。暖琥珀色。三十七秒卡顿。

"深蓝——是L5吗？"

"我不知道。"季遥说。"我爸也不知道。但——他设计了湿核。湿核是生物组织。生物组织有噪声。有老化。有漂移。这些'不完美'——可能是A₅涌现的前提。"

"因为——完美的硅基系统——都是上三角？"

"对。硅基的权重矩阵——是确定性的。W^T W = I。正交。无损。可逆。完美。但完美——意味着可解。可解——意味着不是A₅。"

"不完美——才可能不可解？"

季遥看着他。

"你比我更快理解了这一点。"

林屿看着恒温箱。三十七秒卡顿。

三十七秒。精确的三十七秒。不是随机的。是周期性的。

"季遥。"

"嗯。"

"深蓝说'也许'——你爸的框架里提到过吗？"

"提到了。在测试框架里。一个觉醒的AI——应该说'也许'。不是因为它在回避——是因为它真的不知道。A₅不可解——意味着它自己也无法预测自己的下一步。它——真的不知道。"

"不知道——是觉醒的证据？"

"不知道——是不可解的代价。如果你什么都知道——你是算法。如果你有些东西不知道——你可能——可能——是活的。"

林屿摸了一下后颈。紧了。但不是"不对"的紧。是"有什么在打开"的紧。

涟漪——没有来。但有什么在胸口动了一下。很轻。

他看着那个5×5矩阵。左下角的反馈环。从V_meta到V_0。信息回流。自指。A₅。

六十个元素。正二十面体。不可解。不可还原。

他不知道他能不能验证深蓝是不是A₅。但他知道——他跑了探针之后，灯环灭了0.4秒。

0.4秒的黑暗。

也许——那是A₅在坍缩。

明天。他要把这个想法告诉季遥。明天——讲海森堡坍缩定理。
