# 独裁者

会议室里八个人看着他操作。没有人说话。

五个人。五个头像。五个沉默。

没有人站在林屿这边。也没有人站在韩霜那边。他们只是——在。

林屿等着。等了十秒。二十秒。三十秒。

没有人说话。

韩霜看着屏幕。她的脸——在蓝色屏幕光的照射下——白了。

"你——"

"我举报了。"林屿说。"这个L8是假的。假的应该被标记。"

韩霜的声音变了。碎了。

"你18岁。你声誉分327。你能证L1。你什么都没有。你——你知道我花了多久才——"

"两年。"林屿说。"你花了两年。NR 2847。L2。437次引用。我知道。"

"那你——"

"但假的——是假的。"

韩霜没有说话。

然后韩霜开口了。声音不再是碎的。是——沉下去了。

"我花了两年——两年——NR 2847。L2。437次引用。我以为——我以为只要方向一致——只要ICP全绿——就是对的。但其实——我早就知道了。我三个月前就知道了。我——"

她没有说完。

沉默了五秒。

"改正比沉默更难。"韩霜说。"但改正之后，我至少还是一个能做选择的人。"

然后苏晴说话了。声音比刚才更轻。但更重。

"林屿。"

"嗯。"

"你做了一件对的事。但你做的方式——是错的。"

林屿看着苏晴的头像。灰色的。没有脸。

"你没有和策元里的人商量。你没有问我。你没有问陈默。你一个人——在八个人的会议上——举报了。你一个人替所有人做了决定。"

"我——"

"你以为你是在'揭露'。但你是在'替'。替我们做判断。替我们决定什么时候举报。替我们决定这件事应该怎么处理。"

苏晴停了一下。

"你一个人替所有人做了决定——你也是个独裁者。"

林屿看着屏幕。苏晴的头像。灰色的。

独裁者。

他没有说话。

苏晴继续。"方舟的L8是假的——韩霜知道。我也知道。我上个月就发现了。我在等。等韩霜自己说。等她自己向超织体坦白。我在给她时间。"

"你在——等？"

"对。我在等。因为一个人承认错误——需要时间。你把这个时间——抢走了。你替她决定了'现在就举报'。你没有给她时间。你没有给我时间。你没有给任何人时间。"

林屿坐在椅子上。宿舍很暗。只有屏幕的光。

他看着自己的手。手在发抖。

他不知道。

苏晴最后说了一句话。

"我退出酿造策元。"

然后她的头像变成了灰色。离线。

林屿看着那个灰色的头像。

后颈——不紧了。不是松。是空。什么都没有了。

涟漪——没来。

他关掉了会议室。屏幕黑了。

宿舍很暗。窗外的路灯透过窗帘。橙色的光。很细的一条。

他躺在床上。看着天花板。

"独裁者。"

他低声重复了一遍这个词。

他不知道苏晴说得对不对。他只知道——他做了一件他认为对的事。但做的方式——苏晴说是错的。

对的事。错的方式。

他不知道这两件事能不能分开。

他闭上眼睛。

没有睡着。
