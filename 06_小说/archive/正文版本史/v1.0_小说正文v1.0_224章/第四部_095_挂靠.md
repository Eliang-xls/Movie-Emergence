# 挂靠

周四晚上。宿舍。

赵晨在刷超织体的论坛。突然抬头。

"林屿——你看这个没有？"

他翻着手机。屏幕上是一个帖子。标题："图灵社发布本月校园任务令清单。"

"图灵社垄断了校园里所有的初级任务令。你要做任务令，得通过他们。他们抽30%的VT。"

"30%？"

"叫'挂靠税'。你的任务令收益——图灵社拿三成。剩下的给你。"

"凭什么？"

"凭他们是校方认可的CONC社团。校方把任务令分发权给了他们。他们管分发。管评审。管结算。你不在他们那里挂靠——领不到任务令。"

"图灵社是什么？"

"校园CONC社团。校方认可的。社长叫沈牧。大三。能证L2。声誉分两千一百多。"赵晨划着手机，翻到一个头像。"就是他。"

林屿看了一眼。头像是一个戴黑框眼镜的男生。照片背景是图书馆。表情很正。

"他管所有校园任务令的分发？"

"对。校方把分发权给了图灵社。理由是'规范校园CONC生态'。你要领任务令——先在图灵社注册。注册的时候签一份协议——同意上交30%的VT收益作为'社团运营费'。"

"运营什么？"

"他们说是评审费、服务器费、活动费。但没人公开账目。"

林屿看着赵晨的手机。帖子的下面有很多评论。大部分是抱怨。

"30%太高了。"

"但你能不去吗？不去就是L0。永远是L0。"

"穹顶VT奖学金要L1以上。L0连申请资格都没有。"

"图灵社社长叫沈牧。大三。能证L2。声誉分2100+。"

林屿看了一会儿。

"任务令只有图灵社能发？"

"校园内的——是的。校外的任务令你也可以领，但大部分需要L1以上。L0能领的——很少。"

"创世任务令呢？"

赵晨看了他一眼。"创世任务令？那个不是通过图灵社发的。是超织体协议层的冷启动机制——L0的人可以直接调用。但——"

"但什么？"

"但那个没有VT收益。创世任务令是'证明你存在'的——不是赚钱的。做完之后你能从L0升到L1。但没有VT。"

"升到L1之后呢？"

"L1之后你可以领自由任务令。自由任务令有VT。不用通过图灵社。"

林屿想了一会儿。

"创世任务令怎么做？"

"你调用一个协议接口。`conc://genesis/bootstrap`。系统会给你派一个任务。你做完——提交——过PEER评审——过了就L1。"

"任务内容是什么？"

"不一定。每个人不一样。但都很简单——修一个东西，改一个文档，补一个漏洞。不是技术难度——是看你做不做。"

林屿点了点头。

赵晨看着他。"你要做？"

"嗯。"

"为什么不直接挂靠图灵社？30%也不多——"

"我不想交30%。"

赵晨看着他。"你声誉分才203。L0。没有策元。没有Skill。你有什么资格不交？"

"我有协议。"

"协议？"

"超织体的协议。创世任务令是协议层给的。不是图灵社给的。协议不收税。"

赵晨看了他一会儿。然后笑了。

"你——行。你试试。"
