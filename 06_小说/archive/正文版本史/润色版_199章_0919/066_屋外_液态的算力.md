屋外　066　液态的算力

二〇四〇年至二〇四一年。同一协作分支制度演进记录。

赛事档案之三：赛后制度与分支演化。
本章完整记录竞赛结算后的共同维护阶段，以及系统如何在没有中心控制权的前提下，通过软分叉与硬分叉完成资源与责任的物理切分。

比赛结束的那天下午，欧洲主办方的官方系统按照既定流程，关闭了提交通道。

但在那个去中心化的底层网络里，那个由六个人拼凑起来的项目种子（Seed），并没有像传统的创业公司那样，随着一次交付的结束而自动被系统垃圾回收。

这六个人没有解散。他们依然挂在同一个异步的消息频道里。

频道在很长的一段时间里没有名字。

直到一个月后，石田直子在系统里给这个分支正式申请注册自治策元凭证时，她在名称那一栏停顿了很久。最后，她敲下了三个极其平实的汉字：

分布式。

在汉语的语境里，这三个字代表着把计算负载物理切碎在不同的机器节点上；但在石田直子写下它的那一刻，它指向的是一种更辽阔的现实——六个分布在地球完全不同经纬度上的人，在各自泥泞的生活里，共同守着同一段事实。

巴苏在班加罗尔的阁楼里看到了这个名字。他没有在群里发表任何赞美的感叹。他只是在自己的工作笔记里，敲下了一行极短的手记：名字起得很准。不装。

结算完成后的第三周，巴苏把全周期所有的训练日志、数据清洗脚本、以及那一百一十六台二手显卡在遭遇火灾时的故障切片，整整齐齐地打包成了一份开源的技能包（Skill Package）。

在技能包的场景描述（Scenario Description）首页，巴苏写下了一段长达三百字的技术自白：

本技能包记录了一场发生于二〇四〇年秋季的极端物理实验：一个跨国协作组，使用一百一十六台被主流市场遗弃的工控硬件，在没有获得任何商业公司投资、没有任何法人实体背书、没有任何单一领导者下达命令的前提下，完成了一次覆盖三十万平方公里农田的工业级多光谱解译。

它的物理总成本，是中心化垄断模型的百份之一。

这份档案能够留在网络里的全部意义，绝不是为了证明我们可以脱离现实的规则去狂欢；

它仅仅证明了一件事：当一群人的目标在物理空间中短暂对齐时，他们完全可以在不向任何巨头交出灵魂的前提下，依靠最严苛的协议与彼此的责任，在荒野上凿出一条路来。

在这段自白的最底部，他用加粗字体补上了一段极其克制的警告：

去中心化协作的边界在于：它可以不需要中心，但它绝对需要可被复核的物理协议、在现场敢于承担责任的活人，以及一道随时允许节点体面离开的逃生通道。

石田直子在东京读到这段话时，在电脑前坐了整整半个小时。

她想起了四年前自己在穹顶科技东京分部收到的那份解约通报。那张薄薄的纸上写着「1/80」。当年她以为那只是一个冰冷的财务数字。

现在她才真正看清，在那个数字的底下，流淌着的是柏林车间里被烫焦的人类皮肤、内罗毕贫民窟里在燥热中死死咬紧的牙齿，以及在深夜的班加罗尔被冷咖啡泼湿的草稿纸。

那些东西，从来没有被写进过任何一家大厂光鲜亮丽的财报里。

二〇四一年初。

时间跨过了一整年。物理世界的生活重力，开始不可阻挡地对这六个人施加截然不同的拉扯力。

六个不同的方向，开始在同一个代码库里剧烈地滋生出来。

巴苏的阁楼墙壁上，钉满了整整三十多张从不同纬度拍摄的高清卫星农田影像。最早的那几张因为长期受潮，边缘已经卷曲泛黄。他从墙上取下了四张来自干旱地区的航拍图，钉在了门板后方。四张图属于四个完全不同的第三世界国家，处于完全相同的干旱气候带。但在其中一张土壤严重龟裂的地块边缘，巴苏用红色铅笔画了一个小小的问号，旁边写着一行字：为什么这里的地下水充足，却没有任何农作物生长的物理迹象？

遥感课本里没有这个答案。

直到上个月，一位在当地做农业社会学调研的朋友告诉他：因为那片土地的所有权，在法律上属于一个早就跑路了的海外避税基金会。土地被抵押了，物理上被严禁开垦。

巴苏在电脑前坐了整整两夜。他开始在代码库里开辟新的分支，试图把复杂的土地产权登记数据和卫星光谱做交叉分析。

而在柏林，卢卡斯把那晚从火场里拔出来的十一张报废显卡整整齐齐地码在木架上。他拆解了每一个烧毁的核心芯片，在显微镜下记录每一道击穿的电弧痕迹。他发现有整整七台显卡是在同一个供电拓扑上暴毙的。那不是显卡的问题，那是主板在高频参数交换时出现的总线死锁。

木架第二层还空着一格。旁边贴了一张手写条：淘汰架构，缺正交投影单元。民间能跑降级矩阵域，跑不了深同步那一层。

卢卡斯在白板上写道：这种灾难，绝对不能再依靠哪个人在半夜靠着两条胳膊去硬拔。我们需要一套能够根据硬件发热量自动重新分配算力权重的底层协议。

他开始写一套极其底层的嵌入式硬件负载均衡代码。那是一套纯粹的系统工程，距离农业遥感已经有十万八千里那么远。

在东京，石田直子把那套极简标注工具迭代了六个大版本。她把这六个版本的界面全部横向排开。第一版简陋得像个手术台，最后一版充满了各种人类工效学的微小细节。她在这六张图里，看到了六个活生生的人留下的生理指纹。

她不想再做农业了。她想把全部精力投入到开源人机交互工具链的标准化上去。

在内罗毕，Mika 把所有的标注工具代码烤进了一个最便宜的塑料 U 盘里。她给巴苏发了一条语音：「巴苏，你们在卫星上看到的是宏观的色块。但真正在地上种地的人，连手机都经常充不上电。我要回内罗毕郊区的小学去，教那里的孩子怎么用离线电脑识别自己家里的庄稼病斑。」

杭州的前后端工程师想去挑战更高速的数据缓存管道；圣保罗的运维老哥则依然雷打不动地每周去一次废弃机房，给那些旧机柜擦灰、测温，他说软件的狂热迟早会过去，物理硬件的折旧才是永恒的真理。

六个人。在物理世界上，被扯向了五个完全不同的方向。

在传统的商业公司里，这种战略方向的严重撕裂，通常意味着一场血雨腥风的管理层内斗、裁员，或者一次痛苦的分崩离析。

而在缺乏中心仲裁者的去中心化网络中，许多团队也往往会滑向另一个极端：用无休止的投票去强行绑架彼此，或者在长久的沉默中互相推诿，直到整个项目彻底烂在服务器里。

但这六个人没有开会争吵。

他们启动了一套极其平淡、但也极其冷酷的工程机制：软分叉与算力流动协议。

他们没有强迫彼此在「究竟是农业社会学更重要，还是底层硬件调度更伟大」的形而上问题上去争夺话语权。

每个人在系统的公共分配界面上，写下了自己未来半年愿意为「分布式」这个原始母体项目继续提供维护的确定性算力份额：

经过多轮极其理性的自愿认领，六个节点达成了一致的物理切分——

大家将各自掌控的硬件资源切割成两部分：大约百分之八十的算力与时间，继续锁定在「分布式」农业遥感核心库的例行漏洞修补和数据维护上；而剩下的百分之二十，被完全物理隔离出来，自由注入到各自开辟的新分支中。

算力就像水一样，顺着重力的物理通道，极其自然地流向了每一个人类灵魂真正渴望的低洼地带。

没有强制，没有背叛。

软分叉运行了整整三个月。

三个月后，巴苏在农业社会学分支上撞了墙。他虽然能看懂土地数据，但他做出来的前端图表极其反人类，复杂的时空多光谱演进图在界面上糊成了一片无法辨识的色块。他在工作区敲了一行求助信息：需要能够同时呈现时间和空间维度的低复杂度界面。我搞不定。

在东京的石田直子刚刚完成了三套交互组件的原型。她顺着系统推送看到了巴苏的报错。

她直接点开了巴苏的分支，在下面回复了三个字：

我来接。

两个原本分叉的分支，在缺乏任何指令调配的前提下，仅仅凭借着现场的真实痛感，重新以极其严密的姿态咬合在了一起。

而在半年之后，另一种更为决绝的物理裂变发生了。

卢卡斯在柏林开发的算力聚合协议越走越深。那套协议在底层完全重写了通信总线，它所需要的系统资源和工程范式，已经彻底脱离了「分布式」这个应用层项目的全部边界。

这已经不是一个简单的百分之二十业余探索所能容纳的了。

硬分叉（Hard Fork）的物理条件被完全触发了。

卢卡斯在一个阴雨连绵的周一早晨，在公共频道里敲下了一份长达五千字的技术退出声明：

各位，我手头的这套硬件协议，在架构层面上已经走到了底层网络通信的极深处。它与我们当年共同创立的「分布式」农业分析项目，在技术栈和物理使命上，已经产生了不可逆的代数漂移。

强行把它挂在同一个代码库下，只会不断增加所有人的理解成本与协作摩擦。

按照协作协议第 12 条关于硬分叉的规定，本人今天正式向全网提交流程申请：退出「分布式」项目的共同维护名单，并带走属于我个人物理管辖范围内的那一部分算力资产。

在这份声明的附录里，卢卡斯交出了一份详尽到令人发指的物理交接清册：

哪些老旧显卡依然由他在柏林的车间里继续提供日常供电；
此前欠缴的少量工业电费是如何从他个人钱包里划拨结清的；
以及在最核心的一张表格里，他把「分布式」项目过去一年里的所有主干哈希与依赖，完完整整地打成了一个永久只读的黄金镜像（Gold Image），留在了公共服务器上。

按照系统前期的物理贡献权重折算，卢卡斯申请划转 0.35 的算力信用份额，其余的 0.65 依然完整归属于「分布式」的公共资金池。

讨论区里没有一个人站出来用道德去绑架他，没有人骂他是逃兵，更没有人去威胁要冻结他的开源信誉分。

巴苏花了两天时间逐行复核了数据资产交接清单；石田直子核验了前端组件的解耦边界；而圣保罗的机房老哥则远程 Ping 了一遍所有的硬件端口。

七十二小时后，异议期满，零反对票。

硬分叉在代码底层极其顺畅地完成了物理执行。

卢卡斯带着他的 0.35 份额，在网络上正式初始化了一个全新的技术策元。在输入策元描述时，他在那间冰冷空旷的旧厂房里，敲下了一行极短的德语译文：

让底层的硬件，在机器说话之前，先有属于它们自己的物理声音。

分叉完成后的当天深夜。

圣保罗那位常年驻守在老旧机房里的运维老哥，一个人坐在由数千根跳线缠绕的终端前。

他看着屏幕上那个刚刚完成裂变的代码拓扑图。

他不懂那些高深的算法，他也记不住巴苏推导的那些复杂的偏微分方程。但他心里极其清楚一件事：柏林车间里的那一百多台显卡，是他当年飞跃大半个地球，和卢卡斯一起踩着泥水、一台一台用螺丝刀从废墟里刨出来的。

他拉开操作台下方的配电箱。

没有犹豫，没有悲壮的告别词。

他伸出布满老茧的手，极其干脆地拔掉了本地机柜通往「分布式」主干网络的那几根虚拟跳线插头。

他将那几根发烫的网络光纤，咔哒一声，清脆地插入了连接着卢卡斯那个全新硬件协议的接口槽里。

做完这一切，他在「分布式」的原项目留言板上，留下了他在这个小组里的最后一句话：

我跟着卢卡斯去了。大家保重。修机器的事，在哪个分支底下，都是修机器。

没有一个人试图用所谓的管理权去阻止这次人员和算力的物理流失。

在这个由代码和物理硬件编织的网络里，离别就仅仅是一次干脆利落的指针断开。但没有任何一个人，会因为这种离开，而被系统扣上一顶「叛徒」的帽子。

石田直子在主干代码库的 Fork 日志最底端，写下了一行单行注释：

// 走向不同的物理方向，从来不需要用一场你死我活的解散来买单。分叉（Fork）就行了。分叉之后，我们在各自的山头干活，如果哪天有需要，我们随时可以合（Merge）回来；如果不合适，那就在各自的旷野里一直走到底。代码是这样，人也是这样。

巴苏在当天深夜看到了这行注释。

他在下面简短地跟了一句：

// Git merge 在底层需要一个解决冲突的 Resolver。我们中间，有人在写这个工具吗？

石田直子当时没有回复他。

但在整整两年之后，全网一个开源的代码仓库里，真的悄无声息地上线了一套基于物理因果律的自动合并冲突检测工具。

那个工具的开发者，正是当年在这行注释底下停留过的某一个未知的年轻节点。

那套工具的 README 文档只有三行。最后一行是：

当冲突在现实中爆发时，把它赤裸裸地报错弹出来；
绝对不要在后台调用静默覆盖，假装这个世界上从未发生过任何碰撞。
