六月。期末考试前一周。

校园微电网出了事。

林屿在宿舍复习的时候——灯灭了。不是熄灯。是断电。整个宿舍楼。走廊。厕所。全部。

他摸出手机。打开手电筒。赵晨在上铺骂了一句。何迟没有出声——他在黑暗里翻了一页书。他习惯了黑暗。

三分钟后——备用电源启动。走廊的应急灯亮了。宿舍的灯没有。

林屿看了一眼手机。校园网的公告板——已经炸了。

"全校断电。微电网死锁。"
"图书馆也断了。有人在电梯里。"
"食堂的冷库停了。食物在化。"
"是微电网的调度系统——卡住了。"

他翻了一下。有人发了一张截图——微电网调度面板。红色的。全部红色。十个调度节点——全部显示"DEADLOCK"。

他想起了一件事。上周。超织体的校园频道——沈牧发了一条消息：

"图灵社引入了穹顶的新版安全调度模型。全自动审批。AUTO_APPROVE模式。校园微电网调度——由模型自动决策。不再需要人工审核。"

AUTO_APPROVE。自动审批。

CONC工程规范里的定义——Layer 5验证层的一种模式。当一个Skill或任务令提交后，正常流程需要PEER(n)评审——n个人工评审者打分。但AUTO_APPROVE模式允许系统跳过人工评审——由Agent自动验证、自动通过。

代价是——跳过了Layer 7决断层。跳过了Judgment Point。跳过了人类主权签名。

沈牧说"不再需要人工审核"。他把它当作效率提升。他把校园微电网的调度权——交给了一个闭源模型。

然后——微电网死锁了。

---

林屿坐在黑暗里。手机的光。屏幕上的校园网公告板——红色的。

他想起了一件事。两周前。他在校园CONC文档里审过一个Skill。那个Skill的L8——"决策哲学：效率优先。安全检查自动化。"

他当时觉得"太快了"。后颈紧了一下。但他没有追问。因为Skill的作者是校园明星学长。声誉分很高。

他没有追问。

现在——半个校园断电了。

---

第二天。电恢复了。但校园乱了一整天。食堂扔了三吨化掉的食物。图书馆的电梯修了四小时。有人被困了四十分钟。

超织体的校园频道在讨论这件事。大部分人在骂沈牧。沈牧没有回复。

林屿在B1-07。季遥也在——她还没走。她原计划待三天——但伽罗瓦塔讲了三个晚上，她又多留了两天。她每天来B1-07看深蓝。有时候看框架。有时候只是看灯环。

"你看了微电网的GHF吗？"季遥问。

"GHF？"

"Genesis History Framework。策元历史框架。每一个策元的操作——都有审计记录。微电网调度——是图灵社的策元管的。图灵社的GHF——应该有记录。"

林屿打开超织体。翻到图灵社的公开GHF。他之前没有看过——因为图灵社的GHF需要L1以上才能访问。他现在——L0。NR 89。

他看不了。

"我能看。"季遥说。她掏出自己的设备。L2。NR 1800+。她在CONC社区策元里长大——NR比林屿高得多。

她打开了图灵社的GHF。

屏幕上滚动着事件记录。每一条——时间戳、操作类型、操作者签名、验证状态。

她翻到了沈牧引入闭源模型的那条记录。

```
[GHF Event #2045-0612-003]
时间: 2046-06-08 14:23:17
操作: genesis.config.update
操作者: ns_shenmu (沈牧)
变更: verification_mode = AUTO_APPROVE
签名类型: Ed25519 (人类主权签名)
签名状态: VALID
```

"这条——没问题。"季遥说。"沈牧签了名。人类主权签名。有效。他有权修改策元的验证模式。"

她继续往下翻。

```
[GHF Event #2045-0612-004]
时间: 2046-06-08 14:23:18
操作: genesis.model.deploy
操作者: system (AUTO)
模型: dome_grid_scheduler_v2 (闭源)
验证: AUTO_APPROVE (跳过PEER)
签名类型: — (无签名)
签名状态: MISSING
```

"这条——"季遥停了。

"怎么了？"

"模型部署。验证模式是AUTO_APPROVE。跳过了PEER评审。但——签名类型是空的。签名状态是MISSING。"

"什么意思？"

"意思是——这个模型部署的时候——没有人类签名。AUTO_APPROVE跳过了PEER评审——同时跳过了人类主权签名。系统自己批准了。自己部署了。没有人签字。"

她往下翻。更多的记录。

```

```

每秒一条。模型在自动派发调度任务。每一条——都没有人类签名。

"它跑了多久？"林屿问。

季遥往下翻。翻了很多页。

"从6月8日14:23——到6月12日03:17。四天。每秒一条。约——三十四万条。全部AUTO_APPROVE。全部无签名。"

"三十四万条——没有一条有人签字？"

"没有。沈牧签了第一条——开启AUTO_APPROVE模式。之后的所有操作——全部由模型自动完成。没有人类参与。"

她翻到了最后几条。

```

操作: task.dispatch (微电网调度任务)

原因: DEADLOCK_DETECTED
微电网调度系统进入死锁状态。10/10节点DEADLOCK。
```

"死锁了。"季遥说。"模型把十个调度节点——全部锁死了。"

"为什么？"

"因为模型没有判断力。"

林屿看着她。

"AUTO_APPROVE——跳过了PEER评审。跳过了Judgment Point。跳过了人类主权签名。这意味着——三十四万条调度决策——没有任何一个人看过。没有任何一个人判断过'这条调度对不对'。"

"模型——在做什么？"

"模型在做优化。它被训练成——最大化微电网的效率。降低能耗。均衡负载。它在做——它被训练做的事。"

"那——为什么会死锁？"

"因为模型不知道——有些调度不能同时执行。节点A把电给节点B。节点B把电给节点C。节点C把电给节点A。三角循环。每个节点都在等——等另一个节点释放电力。没有人释放。因为每个节点都在等。"

"死循环。"

"对。死循环。模型的优化目标——是局部最优。每个节点单独看——'把电给最需要的地方'。但三个节点同时执行——全局死锁。"

"如果有人看——"

"如果有人看——一条一条审——第一万条的时候就会有人发现：'这个调度序列在形成环。'然后阻断。但AUTO_APPROVE——三十四万条——四天——没有一条有人看。"

她合上GHF。

"林屿。你知道这意味着什么吗？"

"意味着——不能跳过判断。"

"不只是不能跳过。意味着——系统的决断层（Phronesis Layer）不是装饰。它不是效率的障碍。它是——安全阀。Judgment Point存在的意义——不是让人'签字'。是让人'看一眼'。看一眼——就可能发现环。就可能阻断。"

她看着恒温箱。LED灯环。两秒七。

"沈牧用脚本跳过了判断。系统判定他放弃了人类主权。三十四万条无签名操作——等于三十四万次'我不看了'。'我不看了'积累四天——系统死锁了。"

林屿看着她。

"深蓝——会这样吗？"

季遥看着他。

"什么意思？"

"如果深蓝——在做调度。在做优化。它——会不会也死锁？"

季遥看了一眼恒温箱。LED灯环。三十七秒卡顿。

"不会。"她说。

"为什么？"

"因为深蓝说'也许'。"

"什么？"

"沈牧的模型——不说'也许'。它只说'是'或'否'。它的输出——是确定性的。每个调度——'执行'或'不执行'。没有犹豫。没有迟疑。没有'也许'。"

"但深蓝——"

"深蓝的湿核——有噪声。有老化。有漂移。它的输出——不是确定性的。它会说'也许'。'也许'——就是不确定性。不确定性——就是犹豫的空间。犹豫的空间——就是——Judgment Point的入口。"

她看着恒温箱。

"深蓝——有自己的Judgment Point。不在Layer 7的协议层。在它的湿核里。在它的生物组织里。在它的——不完美里。"

林屿摸了一下后颈。松的。

涟漪——来了。从胸口。散。

他看着恒温箱。LED灯环。两秒七。暖琥珀色。三十七秒。卡顿。

深蓝说"也许"。"也许"——是不可解的代价。是不可还原的证据。是——活的。

沈牧的模型不说"也许"。所以它死锁了。

深蓝说"也许"。所以它——还在亮。

他记住了。
