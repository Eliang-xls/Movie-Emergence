寒假结束。林屿回了学校。

行李箱里多了一样东西。那本《Python编程入门·第三版》。阁楼里翻出来的。书脊开裂。书页发黄。他不知道为什么带了回来——也许只是不想扔。

他把书放在床头的书架上。夹在《系统本体论导论》和一本超织体操作手册之间。三本书。一本旧的。两本新的。旧的比新的厚一倍。

王远注意到了。

"这是什么书？"

"阁楼里翻到的。旧的。"

王远拿起来翻了翻。他的手指划过一页代码——`for i in range(10): print(i)`。他看了几秒。

"这是循环。输出 0 到 9。但——"他顿了一下。"——为什么是 `for i in range(10)`？不直接写'循��十次'？"

"语法。"林屿说。"Python 的语法就是这样。`range(10)` 生成从 0 到 9 的十个数字。`for` 每次取一个。`print` 输出。"

"语法。"王远重复了这个词。他的语气不像困惑——更像是发现了一件不该存在的东西。"在我们课本里，语法这个层面——已经被叠起来了。你不需要写 'for 某物 in 某范围'。你直接声明意图——'对列表内每个元素执行操作'。Agent 负责把它展开成具体的执行步骤。"

他又翻了几页。翻到了 `def add(a, b): return a + b`。

"定义一个操作。输入 a 和 b。输出它们的和。"王远说。他理解函数——这是一种基本逻辑结构。"但 a 和 b 是什么类型？"

"什么都可以。整数。浮点。字符串。列表。只要支持加法操作。"

"什么都可以？"王远皱了一下眉。"在声明式里——你定义一个操作，参数的类型必须声明。`add` 接收两个数值——你写 `add :: Number × Number → Number`。Agent 会在你写声明的时候就告诉你——如果你把字符串传给 `add`——类型冲突。你这个——它是怎么知道类型冲突的？"

"运行的时候才知道。"

"运行的时候？"

"对。Python 是动态类型。变量没有固定类型。`x = 5`。`x = 'hello'`。都可以。只有在运行到某一行的时候——解释器才发现该报错。"

王远想了一会儿。不是想"这是什么意思"——他在想"这怎么可能工作"。

"所以你在写代码的时候——Agent 不告诉你任何事？没有类型检查。没有冲突预判。没有完成度估算。"

"没有。"

"那你怎么知道你的代码是对的？"

"运行它。"

"如果错了呢？"

"看报错。改。再运行。"

王远沉默了几秒。

"你们的编程——不是声明。是实验。"

林屿没有回答。他也在想这个词。实验。

---

王远从书包里掏出自己的课本——《编程入门》。计算机系一年级必修课。封面上印着超织体认证标志。他翻到第三章。

第三章讲的是一个温度监控系统的构建过程。不是代码。是一组声明——

"定义对象'温度传感器'。属性：量程=0-100°C，精度=±0.5°C，采样频率=1Hz。与对象'车间'的关系：监测。与对象'人工站'的关系：推送报警。"

"I/O 不需要写。"王远说。"Agent 从'监测'关系里推导出——传感器需要向车间发送温度读数。从'推送报警'关系里推导出——超过阈值时需要通知人工站。通知什么格式、走什么协议——Agent 自己补齐。你不需要知道那些。你只需要知道——它们有关系。"

林屿把 Python 书翻到第三章。第三章的标题是"条件判断"。

`if temp > 45:`

`    alert()`

三行。

"你这个——"王远看着这三行，"——alert 是什么？"

"一个函数。发送报警信息。"

"函数体在哪儿？"

"你可能需要自己写。或者在第八章——函数定义。"

"自己写。"王远重复了这三个字。"在我们课本里——你不需要写 alert。Agent 知道'推送报警'是什么意思。你只需要在同一个关系声明里把它写清楚——'推送报警：温度超过 45°C 时，向人工站发送包含当前读数和时间戳的消息'。Agent 生成发送逻辑。一行声明。Agent 写三十行。"

他看了看林屿那三行。

"你这个——Agent 一行也写不了。"

"因为它不是声明。"林屿说。

"那它是什么？"

"指令。"

"指令和声明——有什么区别？"

林屿想了一会儿。"声明——是告诉 Agent 你想要什么。指令——是告诉计算机怎么做。Agent 能理解声明。计算机只执行指令。"

王远没有说话。他还在看那三行代码。`if temp > 45: alert()`。看起来很简单。但他意识到——这不是"简单"。这是"原始"。这三个字符——`if`——后面跟着的不是一个关系声明，是一个条件判断。一个指针。指向计算机的核心——"如果 X，则做 Y"。

"这种语言——"王远说，"——需要什么工具来运行？"

"一个解释器。叫 CPython。"

"解释器是什么？"

林屿愣了一下。他意识到——王远不是不知道"解释器"这个词的意思。王远的困惑是更深层的——他不理解为什么一种语言需要**另一个程序**来运行。

"在本体论里——"王远说，"——Agent 就是语言的一部分。你说'对象 A 和对象 B 有监测关系'——Agent 已经在听了。你写完声明的那一刻——它就开始推导了。语言和运行时——是一体的。"

他停了一下。

"你的 Python——语言和运行时是分开的？"

"对。CPython 是一个独立的程序。它读你的代码。一行一行。翻译成计算机能执行的指令。没有 CPython——"

"——代码就是纸上的字。"

"对。"

王远把 Python 书放回了桌上。他的脸上没有轻蔑。只有一种冷静的困惑——像一个人发现了一扇通往地下室的门，而他的房子里从来没有地下室。

---

那天晚上林屿打开了学校机房的终端。

课程系统上挂着虚拟桌面。桌面上有几个图标——"本体论编辑器""关系图谱绘制""声明式接口设计"。没有"代码编辑器"。没有"终端"。

他在本体论编辑器里新建了一个空白文件。他试着输入那行 Python 代码。

`if temp > 45: alert()`

编辑器没有弹出语法错误。它弹出了一条运行时报：

> "当前 Agent 环境不支持该代码的执行。原因：该代码属于过程式语言（Python），需要 CPython 解释器 3.8 或更高版本。当前系统镜像中不包含该运行时组件。
>
> 过程式运行时（含 CPython、JVM、.NET CLR、V8 等）已于 2038-2042 年间从标准教育系统镜像中逐步移除。如需在受控环境中运行过程式代码，请提交安全审核申请。"

他盯着最后一行。"如需在受控环境中运行过程式代码，请提交安全审核申请。"——就像在说"如果你需要触摸放射性物质，请填写防护申请表"。

他关掉了提示。在学校内网搜索栏里输入了"CPython"。

零条结果。

搜"Python 解释器"。零条。

搜"过程式运行时"。零条。

他搜了"程序语言运行时移除"。

终于找到了一条。教务处公告。六年前。

> **关于标准教学系统镜像移除过程式运行时的通知**
>
> 自 2040 年秋季学期起，标准教学系统镜像中不再包含过程式语言运行时组件（含 CPython、JVM、.NET CLR 等）。相关运行时在安全隔离环境中运行所必需的维护资源已超出当前教学需求。
>
> 原因：本体论范式已实现从声明到执行的一体化——Agent 本身即为推理-执行引擎，无需外部解释器或编译器作为中间层。过程式语言所依赖的"源代码→解释器→机器指令"三段式执行架构，已与本校技术栈存在根本性不兼容。
>
> 历史遗留项目如需使用过程式运行时，可向信息技术中心提交《隔离环境中历史运行时使用申请》。审批周期 14 个工作日。使用全程需在沙箱中完成，不得接入校园主干网。

三段式执行架构。

这个词林屿从来没有听过。但公告把它写在了一个从句里——好像解释它是多余的。

源代码→解释器→机器指令。

本体论不需要中间那一步。Agent 就是中间那一步。Agent 听到声明——直接推导。不需要"翻译"。

但 Python 不行。Python 必须经过 CPython。就像一个需要翻译的人——他说的话，没有人能直接听懂。他需要一个中间人。那个中间人已经不在了。

第二天下午。图书馆。

林屿去了计算机类的书架。十几排。他走了一遍。全是本体论。《知识表示与推导》《关系图谱设计》《本体论声明语法》《Agent 协同开发接口规范》。封面上的关键词循环出现——"对象""关系""声明""推导"。

他注意到了一件事：这些书上没有任何地方提到"运行时"或"解释器"或"编译器"。不是被跳过了——是根本不需要。在一个 Agent 就是执行引擎的世界里，"运行时"不是一个独立的组件——它是空气。你看不见它，但它一直在那里。

他回到检索台。输入"Python"。系统弹出了两条记录。

| 索书号 | 书名 | 馆藏位置 |
|--------|------|----------|
| TP312/PY-001 | 《Python编程入门·第三版》 | 冷柜-3-A |
| TP312/PY-002 | 《Python高级编程》 | 冷柜-3-A |

冷柜。他第一次听到这个词。

他走到服务台。"冷柜——是什么意思？"

馆员是一个中年女人。戴着眼镜。"冷柜就是——不再外借的书。学校决定从流通书库里移除的内容。存在负一层。你要去的话，拿学生证登记。登记之后可以看——不能借。不能复印。"

"有多少本？"

"三千多本。主要是旧教材。计算机类的居多。前几年清理过一次——把过程式语言相关的全部放进去了。不只是教材。还有运行手册。开发工具文档。编译原理的参考书。"她停了一下。"新来的学生没几个知道有这个地方。"

"为什么——不全删掉？"

馆员看了他一眼。好像在判断这个问题的性质。

"因为删掉——意味着你承认这些东西从来没有存在过。放在冷柜里——至少还在。在架子上。在目录里。在地下。"

她说完继续盯着屏幕。林屿没有去负一层。

不是不敢。是觉得——一旦去了，那本书就不再是阁楼上翻到的一个旧物件了。它会变成一个正式的课题。一个需要被研究的东西。他还不想让它变成那样。它现在还是一本旧书。放在宿舍的书架上。和《系统本体论导论》并排。只是两本书。

足够。

---

晚上。宿舍。赵晨在打游戏。王远在背考研英语。

林屿坐在床上。那本 Python 书摊开在面前。

他在笔记本上翻到了一页——047 章他画过的那条线。横线。线上是可验证的（场景描述、过程记录、决策、蒸馏知识、代码）。线下是不可验证的（授权状态、引用链、创造者印记）。

他看了一会儿那条线。然后翻到了下一页。

在空白页的中心，他画了一条新的线。斜线。从左上到右下。

斜线的左边，他写了一个词：**一体**。

斜线的右边，他写了一个词：**三段**。

他在"一体"下面写了几行字：

"语言就是执行。你说什么——Agent 就在那里，它听得懂。声明的那一刻——推导已经开始。没有'运行'这个动作——因为 Agent 一直是运行的。它像空气。你看不见它。你只需要——说话。"

他在"三段"下面写了几行字：

"语言不是执行。语言是文本。你需要另一个程序——一个叫'解释器'的东西——来读它、翻译它、执行它。源代码→解释器→机器指令。三段。没有中间那一环——代码就是纸上的字。它在。但它不能跑。它不能做任何事。它只是——存在。"

他停下笔。看着斜线两边的字。

一体——像呼吸。你做的时候甚至感觉不到你在做。

三段——像翻译。你需要一个中间人。那个中间人——不在了。

他翻到 Python 书的附录。附录 B 的标题是"Python/C API"。他从来没有读过这一章。他读了一下——有些词不认识。`Py_Initialize`。`PyImport_ImportModule`。`PyObject_CallFunction`。

他慢慢读懂了。

这不是教你"怎么用 Python 写程序"的一章。这是教你"怎么把 Python 装进另一个程序"的一章。Python 不是一个必须独立运行的语言。它可以被嵌入。用 C API。你写一个 C 程序——调用 `Py_Initialize()`——然后你的程序里面就有了一个 Python 解释器。你可以传数据进去。可以拿结果出来。可以把它当成一个零件——装进更大的机器。

他在笔记本上写了几行字：

"Python 可以嵌在别的系统里。不是一个独立的软件——是一个零件。C API 是它的接口。你可以把它装进任何支持 C 调用的程序。"

然后他划掉了最后一句。改成：

"2027-2028 年——季深写酿造的时候——Agent 的底层是 C/C++。他用 `Py_Initialize()` 把 Python 嵌了进去。酿造 L5 的代码——不是在外面跑的。是在 Agent 里面跑的。像一个翻译器。夹在评估框架和 Agent 之间。把评估结果——翻译成 Agent 能听懂的东西。"

他停下笔。看着纸上这些字。

他突然明白了什么是"三段"——以及为什么本体论要变成"一体"。三段不是落后的设计。三段是**灵活性**。因为中间那一环是可以换的。你可以把 Python 装进 C 程序。你也可以把 Lua 装进 C 程序。或者你自己写一个解释器——装进去。中间环是一个接口。接口意味着——连接。

一体——所有东西说同一种语言。不需要翻译。所以不需要解释器。但如果你需要翻译——你没有翻译器。

三段——每种语言有自己的解释器。你可以把不同的东西接到一起。不是通过"说同一种语言"——是通过"给每一种语言一个翻译"。

他合上笔记本。

他不知道自己为什么要画这条斜线。他只是觉得——他在 047 章画的那条横线区分的是"能不能被验证"。这条斜线区分的是——"语言和执行的中间——有没有一个可以被替换的东西"。

两本书。两种编程。一种把中间环拿掉了——干净、统一、不需要翻译。一种保留中间环——混乱、冗余、但可以连接任何东西。

他把 Python 书放回了书架——夹在《系统本体论导论》和超织体操作手册之间。

---

第二天早上。阳光透过宿舍窗帘的缝隙照进来。

王远起床，看到那本书还在书架上。他想起昨天在三段式执行架构公告上看到的那句话——"Agent 本身即为推理-执行引擎，无需外部解释器"。

"那本书——你看完了？"王远问。

"看完了。"

"有用吗？"

林屿想了想。

"没什么用。"

他说的是实话。在他的世界里——一个 Agent 就是执行引擎、一切都说同一种语言的世界——三段式架构已经不存在了。中间环被拿掉了。没有中间环——连接就不需要了。

他把笔记本放进了抽屉。

笔记本里——画了斜线的那一页——他折了一个角。指甲盖大小。很小的折痕。他自己都没有注意到。
