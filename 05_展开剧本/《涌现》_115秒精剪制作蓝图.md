# 《涌现》115秒精剪制作蓝图

> **版本**：v1.0
>
> **制作目标**：将现有12段、4分56秒预告片方案精炼为一支**115秒中文电影预告短片**。成片保留“涌现并非机器自发觉醒，而是人类在不确定中彼此唤醒”的主题，并以**晶壳呼吸、白板笔／手指／礁石的“嗒”、水的涟漪与代际传递**建立可感知的情绪闭环。
>
> **确认的制作约束**：横向16:9原始生成，后期加2.39:1电影遮幅；中文对白与中文旁白；独立配乐、拟音与混音；**深蓝全片不发声**，仅通过空气中的浮层光字、物理脉动、环境声与人类旁白被感知。

## 一、制片与导演优化结论

原始版本的优势不是设定密度，而是它已拥有一条极难得的、可被观众身体感知的叙事链：**热的晶壳—一声“嗒”—退潮的海水—一块被捂热的石头—黎明中被回应的“嗒”**。精剪版不再试图覆盖所有世界观术语，而应让观众只需理解一件事：当系统把一切压缩为“正确”，人必须保存犹豫、错误与承担的能力。

叙事从“一个会呼吸的未知生命”开始，经由“命名时即已存在的价值冲突”进入“测量使生命冻结”的危机，随后以全球蜂群的多样化判断推向高潮，最终回到一老一少面对大海的静默回应。该结构将原剧本的哲学解释压缩为动作、声音和图像，避免T2、T7、T9、T10、T11连续的信息过载。

| 原剧本的风险 | 精剪处理 | 电影化收益 |
|---|---|---|
| T2、T7、T10概念与台词同时堆叠 | 每段只保留一个可见动作和一句可记住的话 | 观众先感受冲突，再回看理解设定 |
| T11的文字与独白持续高峰 | 拆为“白盒切入—地球回应—金字凝出—突触燃尽”四次脉冲 | 高潮有呼吸，不会因阅读疲劳而失速 |
| “深蓝”在版本间存在发声矛盾 | 取消其一切语言声音；光字仅作为思想的可见化 | 它保持陌生、克制且有尊严的沉默 |
| 2.39:1设定与通用横向镜头不匹配 | 先以16:9生成，再以内嵌遮幅锁定画面重心 | 保留电影负空间，同时避免源画面比例受限 |

## 二、统一创作定义

### 2.1 影像风格

| 维度 | 全局定义 |
|---|---|
| 子类型 | 温性科幻、哲思惊悚与抒情海岸现实主义的融合；科技并不炫耀，而是像一个带体温的生命体在黑暗中呼吸。 |
| 画面质感 | 写实电影摄影、细腻胶片颗粒、受控高光、低饱和暗部；微距段落具有真实光学折射与浅景深，不使用廉价霓虹UI。 |
| 色彩与光线 | 协议／测量为冷灰蓝；湿件生命为暖琥珀；蜂群共鸣为温润金；传承为海面暖白。冷暖始终应来自场景光线与材质反应，而非简单滤镜。 |
| 构图与镜头 | 关键人物戏以35–85mm写实镜头为主，晶壳用85–100mm微距；终幕以24mm极宽景呈现80%负空间。所有镜头先按16:9构图，在上下遮幅内保留主要人脸、晶壳与光字。 |
| 禁止项 | 不出现可见数据线、悬浮大屏、透明玻璃屏、机械触手、赛博朋克霓虹雨、夸张故障转场、科幻HUD文字墙、物体凭空出现或消失。 |

### 2.3 声音总则

声音首先服务于节奏，而不是解释设定。对白只保留能够推动人物关系或主题转向的句子；旁白采用季深的中文男声，40岁段偏低沉克制、老年段有轻微砂砾感，但都必须自然、近距离、不过度表演。深蓝不使用人声、机械声或合成语音；它只拥有每3–5秒一次的低频舒缩、微弱电极颤动、一次短促的爆燃，以及“沉默的重量”。

| 项目 | 锁定方案 |
|---|---|
| BGM | 独立生成并全片混音，115秒，72 BPM，D小调为基础；器乐限定为古琴泛音、低音大提琴、稀疏钢琴、颗粒合成器、低频电子脉冲、极轻手鼓、无歌词人声“嗡”。 |
| 场景原声 | 视频片段保留白板笔、空调、海浪、风、服务器低频、粉笔灰、石头与手指敲击等现场拟音；不在镜头生成阶段嵌入背景配乐。 |
| 旁白混音 | 旁白峰值始终高于BGM约6–8dB；对话发生时BGM自动降低；T6的782ms和T12两声“嗒”禁止配乐覆盖。 |
| 片头与片尾字幕 | 除深蓝光字外，所有标题与署名均后期完成，以避免镜头模型误植文字。片尾只保留“方 向”。 |

### 6.2 生成与拼接顺序

1. 先生成上述主参考及必要变体，确认季深三年龄段、晶壳三状态、光温系统没有漂移。
2. 先生成C01，再从其真实末帧提取C02首帧；随后依次制作所有切镜镜头。
3. C11完成后从其真实末帧提取C12首帧；C17完成后从其真实末帧提取C18首帧。
4. 所有镜头生成时只包含画内对白、环境拟音和必要物理声，**明确禁止内嵌背景音乐**。
5. 单独生成115秒配乐；按跨度分别生成四段旁白；保留每条视频原始音轨并叠加，不以旁白或配乐覆盖原有环境声。
6. 在后期进行16:9到2.39:1遮幅、光字合成、片名合成、声音响度与转场校正。绝不通过裁切切掉角色眼睛、晶壳湿核或两声“嗒”的手部动作。
