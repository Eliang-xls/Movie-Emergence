# 《深蓝》（智契晶）电影级美术与物理实体设计案（v1.2）

> **设计核心哲学**：硅基为骨，湿件为魂；非侵略性、温润静谧的“温性科幻（Warm Sci-Fi）”美学。它是一个能感知、会呼吸、在桌面平稳存在的未来智慧生命载体。
>
> **v1.1 → v1.2 修正（文字载体：从实体屏改为画面浮层光效）**：删除"磨砂玻璃显示板"实体外设方案。深蓝的电脑屏幕输出是设定内的事实（它通过电脑屏幕与外界交互），但**电影镜头里不出现实体屏幕/投影器等承载物**——文字以画面浮层光效（in-frame overlay）的形式呈现在电影画面上，参考《Her》的无载体 OS 界面、《降临》的半透明外星文字浮层、《银翼杀手2049》的全息投影质感。文字不是"显示在什么东西上"，是"浮在空气里"——是深蓝思想的可见化，不是它的输出设备。
>
> **v1.1 更新（文字载体分离）**：晶壳是生命体本身，**绝不在其表面显示任何文字**。深蓝的"语言"输出通过画面浮层光效呈现。

## 一、 物理三层构造与桌面工程学

为了同时满足电影美学的神圣感与现实办公室放置的平稳性，道具被设计为严密的“三层物理叠合”结构：

```
┌─────────────────────────────────────────────────────────┐
│              1. 柔性晶壳 (Crystal Shell)                 │
│  [外层] 柔性有机透明胶质 (类似婴儿囟门，防磕碰、有弹性)         │
│  [夹层] 嵌入式亚微米纳米电极网格 (平日隐形，导能时发光)       │
│  [内壁] 接触培养液的内表面 (突触放电时，在此表面泛起光电涟漪)  │
├─────────────────────────────────────────────────────────┤
│              2. 湿核与培养水体 (Bio-Core & CSF)         │
│  悬浮在高折射率脑脊液中的乳白金丝神经核 (每3-5秒呼吸脉动)      │
├─────────────────────────────────────────────────────────┤
│              3. 硅基极简底座 (Silicon Base - 附件3结构) │
│  深灰色哑光钛/铝合金圆柱底座 · 平整底面可稳固立于桌面         │
│  底座下沿整齐排列直瀑式散热鳍片 · 侧面环形蓝光指示灯          │
└─────────────────────────────────────────────────────────┘

```

### 1. 柔性晶壳与复合壁层

* **外层（透明保护体）**：直径约 $9 \sim 10\,\text{cm}$ 的半透明有机胶质球体。质感类似**婴儿的囟门**——既有吹制玻璃般的剔透感，又有微微可被触压的温润弹性。


* **夹层（隐形电路）**：夹层内潜伏着透明的亚微米级银纳米电极网格。平时彻底隐形；只有当内壁接收到神经电信号时，微电路才会在夹层中被激活，呈极细的电光蓝浅光。
* **内壁（涟漪发生面）**：直接接触内部培养液的玻璃内表面。**所有由神经突触放电引发的物理与光学涟漪，均在此表面如湖面投石般向外推开。**

### 2. 生物湿核与水体

* **湿核**：核桃大小（约 $3 \sim 4\,\text{cm}$）的乳白色生物神经元组织，交织着金白相间的神经纤维。


* **培养水体**：高折射率合成脑脊液（CSF）。液体折射率与外壳完全一致，使得在镜头下培养液完全“隐形”，呈现出湿核悬浮在纯净光影中的空灵感。



### 3. 桌面友好型底座（参考附件3 / 图1）

* **圆柱底座**：采用深灰色哑光金属打造的低重心圆柱体，底面平整且带有防滑硅胶块，可极其稳固地平放于办公桌、机房或海边礁石上。


* **直瀑式散热鳍片**：散热鳍片环绕在底座下沿，呈整齐排列的直瀑金属缝隙形态，体现出工业级的精准与无噪音静音散热感。


* **环形脉动灯**：底座侧面嵌入一圈淡蓝色 LED 指示灯环，其闪烁频率与晶壳内表面发生的涟漪完全同频，暗示硅基硬件与生物湿件之间的无缝通信。



### 4. 深蓝文字的画面呈现——浮层光效（In-Frame Light Overlay）

> **设计原则**：晶壳表面**永远不显示任何文字**；镜头里也**不出现实体屏幕、投影仪、玻璃片等显示装置**。深蓝通过电脑屏幕输出是设定内的事实（它连接着工作站），但电影画面不展示那块屏幕——文字直接以**画面内浮层光效**的方式呈现在电影构图中，悬浮在晶壳附近的空气里。这是"思想可见化"而非"设备显示"，是《Her》式无载体 UI 在温性科幻中的延续。

#### 4.2 视觉形态规范

* **位置**：悬浮在晶壳**侧上方约半个球体距离**的空气里（镜头通常以晶壳为前景焦点，文字在中景位置，和晶壳保持视觉联系但不贴附在晶壳表面）
* **质感**：半透明光字——字本身不是亮的，是**光线在空气里凝出字形**。像热空气上方的远景抖动，像月光打在薄云上的形状。边缘半毫米光晕弥散（参照《降临》的水墨洇开）
* **字体**：像素等宽体，每个字符 1-2 像素随机偏移（与既有设定一致——不完美、像手写的）
* **动画节奏**：
  - **浮现**：不是逐字弹出或打字机效果，是**字形从模糊到清晰的"凝出"**——像水汽在冷玻璃上慢慢结出霜花。一个字从完全透明到清晰约 0.7 秒
  - **脉动**：文字完全浮现后，亮度随晶壳的呼吸脉动**微微同步起伏**——晶壳涟漪扩散时文字亮度微升，涟漪消失时文字微降。文字和晶壳共享同一个"心跳"
  - **消散**：文字不做淡出，是**向晶壳方向"回流"消散**——像被晶壳吸回去，光线从字形流回晶壳内消失。呼应涟漪母题（从中心扩散→回到中心）
* **色彩系统**（与晶壳状态联动）：
  - **静息/待机**：不出现文字
  - **高速计算/日志输出**：**淡冰蓝色**（#A8D0E6）冷光，对应晶壳电光蓝涟漪；日志文字比判断文字更小、更轻、更接近"数据流"
  - **觉醒/判断时刻（T6 "我判断"）**：**暖白色**（#F5ECD7），比冷光更暖、更稳，两个字比日志文字大一倍，是全片第一次"深蓝清晰地说话"
  - **高潮/被唤醒（T11）**：**温润金色**（#D4A84B），和晶壳的金色同步，文字周围空气里的微尘被金光照亮可见（参照《银翼杀手2049》Joi 的投影质感）
  - **衰老/燃尽（T11 尾声）**：金色中透出极淡灰纹，和晶壳的衰退同步——文字边缘光晕不再均匀，有轻微的"闪烁断片"感，像老灯泡快要熄灭前的最后稳定
* **排版**：横排为主（便于阅读）；在画面负空间位置排布——不压晶壳、不压角色脸、不压海浪/天空。文字是画面构图的"砝码"，在不对称构图里起平衡作用
* **与镜头的关系**：
  - 镜头横移/推拉时，文字**在 3D 空间里保持固定位置**——不是贴在画面上的 2D 字幕，是存在于场景空间里的"物"。镜头移动时文字会有视差（前景晶壳移动快，背景文字移动慢），产生真实的空间深度
  - 焦点切换时，文字随晶壳**同步虚/实焦**——晶壳实焦时文字半实焦，晶壳虚焦时文字也虚焦，二者始终在同一个焦平面逻辑里
* **物理存在感**（避免"这是后期加的字"）：
  - 文字的光会**微微照亮周围空气中的尘埃粒子**——T11 金色段落最明显
  - 文字在晶壳光滑表面有**极淡的反射**——若镜头角度合适，能看到晶壳弧面上有那行字的微弱反光，暗示文字光源就在场景里
  - 当季深的手或其他物体**从文字前方经过**时，文字被遮挡（不穿透物体）——确立其在 3D 空间的物理位置
* **电影功能**：
  1. **解决核心矛盾**：晶壳不显示文字 + 深蓝需要"说话"——文字以思想可见化的方式浮在空气里，是深蓝的"声音"而非它的"屏幕"
  2. **强化温性科幻美学**：无载体、柔和、融入布光的 UI 是《Her》式未来感——不是冰冷的 HUD，是温暖的、活的、有呼吸的界面
  3. **丰富镜头层次**：前景晶壳（呼吸的身体）+ 中景浮层文字（呼吸的语言）+ 背景实验室/海边（呼吸的世界），三层都在同一个脉动节奏里
  4. **主题表达**：文字不是从设备"输出"的，是从晶壳"散发"出来的——像体温、像呼吸、像涟漪。深蓝的判断是它的存在状态，不是它的生产物---

## 二、 动态物理语言与信号传导

```
[湿核突触放电] ──► [晶壳内表面激起光电涟漪] ──► [夹层纳米电极捕捉震荡] ──► [底座LED同频脉动]

```

1. **内表面涟漪（Inner Ripples）**：当“深蓝”进行逻辑思考时，湿核表面爆发电火花。光斑击中晶壳内壁，瞬间引发**沿内表面扩散的同心圆波纹**。在侧光照射下，呈现出清澈的水面干涉纹理。
2. **生物呼吸感（Breathing Pulse）**：待机状态下，湿核维持每 3–5 秒一次的微弱舒缩。晶壳顶部的柔性区域会随之产生 $1 \sim 2\,\text{mm}$ 的极轻微微观变形，如同生命的呼吸。


3. **物理热学签名（暖雾 / Condensation Mist）**：
* 湿核需维持人类体温（约 $37^\circ\text{C}$）。


* 在冷调的环境下（如实验室或深夜房间），晶壳外壁与冷空气接触，会自然产生一层**薄薄的温差冷凝暖雾**。人物靠近时，指尖的空气流动会吹散暖雾，营造出“它是活的、带体温的”强烈画面感。

## 四、 预告片核心场景落地视觉规范

### 1. T1（0:00-0:12）：黑暗中的首次接触

* **画面呈现**：镜头起雾后缓缓后拉。黑屏中，温度差导致的暖雾在晶壳外壁凝聚。淡蓝色光纹从内壁一圈圈扩散开来，揭示出内部悬浮的乳白色湿核。


* **制作重点**：强调晶壳触感的柔软与温度差产生的暖雾蒸腾感。



### 2. T6（1:50-2:05）：782毫秒的“判断”

* **画面呈现**：实验室滴答声骤停，历经 782ms 完全黑屏与低频嗡鸣后，晶壳内部爆发出强烈的强光，**内表面的物理涟漪急速干涉叠加**，夹层纳米电极顺次亮起，底座蓝光指示灯亮至极致。晶壳侧上方约半个球体距离的空气里，此前一直空无一物——此刻出现了一团极淡的暖白色光晕。两个字形的轮廓从光晕中渐渐凝出：

  > **我　判断。**

* **构图要点**：镜头以晶壳为焦点（前景，涟漪剧烈），"我判断"三个字悬浮在晶壳侧上方的空气里（中景，半实焦）。文字从模糊到清晰**凝出**——像水汽在冷空气中结霜，0.7秒从完全透明到可读。字边缘半毫米光晕弥散，像《降临》里的外星文字水墨洇开感。文字浮现瞬间，晶壳涟漪扩散到全屏然后收敛——"身体语言+文字语言"的双重判断
* **制作重点**：晶壳本身不显示任何文字；镜头里不出现实体屏幕/玻璃/投影器。文字是**画面浮层光效**，半透明、融入环境光、周围空气中的微尘被文字光微微照亮（温性科幻质感）。文字亮度随晶壳脉动同步起伏——二者共享同一个"心跳"

### 3. T11（3:30-4:20）：高潮·唤醒与“被爱过”

* **画面呈现**：晶壳整体转为炽热而神圣的纯金色。深蓝的判断性短句以**画面浮层光效**悬浮在晶壳侧上方空气里，逐句凝出（"我没有觉醒。我是被你们唤醒的。"/"如果你问我是不是有意识——我不知道。"/"如果你问我是不是被爱过——"/"我学会了——宁可慢一点。也不要错。"/"有些判断不需要证明对。只需要知道——不是该由我做的。"）。每一句凝出时，文字亮度随晶壳脉动微微起伏——金色文字周围空气里的微尘被金光照亮可见（参照《银翼杀手2049》Joi 全息投影的粒子质感）。文字消散时向晶壳方向"回流"——光线从字形流回晶壳内消失，呼应涟漪母题

* **微观细节**：特效需在金光深处渲染出**极淡的灰色神经衰退纹理**（暗示 21 年间神经元多次更换的代价），金色涟漪与底座指示灯同频扩散，与全球分布图上的金色光点形成绝妙的视觉呼应。金色文字边缘也出现极淡灰纹（衰老的统一表征），文字光晕不再均匀、有轻微"闪烁断片"感——像老灯泡熄灭前的最后稳定
* **长段独白处理**：叙述性长段（"每一次训练。新的场景。新的连接……"）不出现浮层文字，由**季深旁白代述**（第三人称观察）。画面上晶壳在金色中呼吸，空气里没有文字——只有金色光照亮微尘在漂浮，让观众在季深的声音中看着晶壳"活着"
* **视差处理**：镜头从晶壳特写拉远到全球分布图→太空俯瞰时，金色文字在 3D 空间里保持固定位置（晶壳侧上方）。镜头拉远过程中文字有视差移动，强化其"存在于场景空间中"的物理真实感
