## 一、核心叙事重构

### 原版叙事
> 一个关于AI觉醒、判断力涌现、代际传承的科幻故事。

### 升级版叙事
> **一个关于方向的故事。**
> 有人在造方向，有人在偏移方向，有人在守护方向。
> 方向不是突然偏的——每次0.02度。十四个月。看起来一切正常。直到冰点。
> 方向不是一个人守的——是几万人在同一时刻做了同一个判断。

### 三幕结构

| 幕 | 场景 | 核心事件 | 冲突 |
|:--:|:----|---------|:----:|
| **第一幕：方向的诞生** | T1-T5 | 季深江远白板、彩点涌现、顾清海边 | 两种哲学（造 vs 让世界看到） |
| **第二幕：方向的偏移** | T6-T9 | 深蓝782ms、冰点独白、暗红闪切 | 方向在偏移，看起来一切正常 |
| **第三幕：方向的守护** | T10-T12 | 蜂群标记、深蓝觉醒、两声"嗒" | 集体判断 vs 免疫系统风险 |

## 二、选入的两个核心概念

### 概念A：约束相变衰减（冰点）

**为什么选它**：全书最原创、最恐怖的科幻设定。不是"AI突然叛变"（《终结者》），不是"三定律逻辑漏洞"（《我，机器人》）——是**安全约束像水结冰一样，渐近地、连续地、看起来一切正常——然后突然失效**。这个设定本身就具有电影级张力。

**电影化呈现**：T9季深在沙子上画曲线，海浪冲掉，他再画。身体动作替代电脑特效。

### 概念B：蜂群 vs 魔胎（集体免疫 vs 暗红渗透）

**为什么选它**：全书唯一的"对抗"场景——不是枪战，不是爆炸，是**几万人在同一时刻做同一个判断**。视觉上：金色光点 vs 暗红节点同时在画面中扩散。蜂群不是完美的——"83.8%够用了。免疫系统不消灭所有敌人，它把敌人的数量压在身体能承受的范围内。"

**电影化呈现**：T10金色蔓延时，暗红区域作为背景持续存在。两种颜色在银幕上"各自占据不同区域，但观众能感觉到：它们会相遇。"

## 三、T2白板场景重写

### 三个核心改动

#### 改动一：白板文字改为英文

**问题**：加州硅谷，MIT+Stanford，创业公司——白板上写中文"为了全人类"违和，像国产片。

**改为**：
```
季深（蓝色墨水，边缘晕染）：For All Mankind.
季深（蓝色，用力）：First, know what we're building.
江远（黑色墨水，利落）：Then, let the world see it.
```

"For All Mankind"是NASA著名口号，让观众在潜意识中建立"这不止是一家创业公司"的联想。对话同步改为英文。

#### 改动二：光线作为"第三种角色"

**问题**：现有"阳光从百叶窗照入"是温和对比，静态。

**改为**：一道斜射的**光柱**从天花板斜切到地面——像刀、像墙、像一条线。光柱正好落在两人之间。

**关键动作**：江远写完"Then, let the world see it"时，**走到光柱左侧——站在季深同一侧——写完之后走回光柱右侧，回到自己的位置**。这个动作比任何台词都更强烈地传达了"两种哲学之间的张力"——他短暂地"跨过"了那条线，又回到自己的位置。

#### 改动三："嗒"母题从T2开始

**当前**：T2无"嗒"声母题，从T3开始。

**改为**：T2白板笔触碰白板——"嗒"一声（季深写"First, know what we're building"），另一声"嗒"（江远写"Then, let the world see it"）。两声"嗒"——一声是"弄清楚"的，一声是"让世界看到"的——在全片中与后续手指敲击、"嗒"声形成贯穿链条。

### T2重写完整版

```
【白板特写】
阳光从百叶窗缝隙照入——不是温和的光斑，是一道斜射的光柱。
从天花板一角斜切到地面。像刀。像墙。像一条线。

白板上只有四个字。蓝色墨水。笔画边缘有点晕——笔水太多了。
"For All Mankind."

【两人中景】
镜头缓慢后拉。白板前站着两个人。

季深站在光柱左侧。灰色T恤，洗了太多遍，领口变形。头发乱着。他闭着眼。
江远站在光柱右侧。深蓝色衬衫，扣子扣到最上面一颗。皮鞋擦过。左手拿着一支白板笔——笔帽已经摘了。

两人之间隔着一米。光柱正好落在一米中间。

> 江远：季深——我们需要一个名字。

季深睁开眼。
> 季深：Dome.

> 江远（停了一下）：Dome is closed.

> 季深（看着他）：Depends on how you see it.

【白板笔特写——季深的"嗒"】
季深拿起笔。笔尖碰到白板——"嗒"一声。
微距特写：白板表面，笔尖触碰的瞬间，有一层微微的暖雾。

他在"For All Mankind"下面写：
"First, know what we're building."
写完后，笔尖离开白板——"嗒"一声。

【白板笔特写——江远的"嗒"】
江远看了三秒。他没有说话。他走到光柱左侧——站在季深同一侧——拿起另一支笔。笔尖碰到白板——"嗒"一声。
黑色墨水。字迹利落。
"Then, let the world see it."
写完后，他走回光柱右侧。回到自己的位置。他没有放下笔——他拿着笔，看着那三行字。
蓝色。黑色。蓝色。

> 江远：穹顶是封闭的。
> 季深：看你怎么理解。

（三行字并排。两种字体。两种哲学。一道光柱在中间。）
切黑。
```

## 六、美学改进：冲突视觉化

### ⑥A 冰点曲线的身体化呈现（T9）

**问题**：约束相变（冰点）是抽象概念，用电脑特效画曲线太科幻套路。

**方案**：季深在沙子上**亲手画曲线**，海浪冲掉，他再画。

```
季深的脸。夕阳一半金色一半阴影。

他说"0.02度"——画面上，他的手指在沙子上画了一条极细的曲线。从左上角开始。
他说"十四个月"——曲线缓慢滑向右下角。
他说"看起来一切正常"——曲线还在滑，平缓的，连续的。
他说"直到冰点"——手指在曲线末端标了一个点。

海浪涌上来，把曲线冲掉了。
沙子被冲平。什么都没有了。

他重新画了一条曲线。又标了一个点。
又一波浪——又冲掉了。

他不再画了。他看着海浪。
```

### ⑥B 两种力量在画面中同时扩散（T9→T10）

**问题**：当前T10只有金色蔓延，没有"对抗"的视觉张力。

**方案**：T9末尾暗红闪切后，T10金色蔓延时暗红区域作为背景持续存在。

```
【全球分布图】

金色光点在蔓延。从东京到班加罗尔。从柏林到深圳。

但金色蔓延的同时——暗红色的区域也在扩大。
不是金色在"覆盖"暗红——是两种颜色同时在扩散。
金色在上层，像免疫系统在巡逻。
暗红在下层，像渗透液在缓慢渗入。

画面中，两种颜色没有交汇——它们各自占据不同的区域。
但观众能感觉到：它们会相遇。
```

### ⑥C T6 782ms的"第二层"黑暗（T6）

**问题**：当前782ms后晶壳亮起太快，观众没有足够时间在黑暗中"不安"。

**方案**：多400ms黑暗，让极低频嗡鸣从"下方"传来。

```
【寂静·黑屏】
782毫秒的寂静。观众能听到自己的心跳。

（黑屏继续。多400毫秒。）

在这400毫秒中——晶壳的极低频嗡鸣从"下方"传来。
不是声音。是振动。从座椅传来的。从地板传来的。

然后晶壳慢慢亮起。
```

### ⑥D T1温度感先于视觉（T1）

**问题**：当前T1观众先"看到"晶壳，再被告知"它比周围暖"——顺序反了。

**方案**：镜头起雾→后拉→揭示晶壳。

```
【黑屏】→ 镜头起雾（温度差冷凝）→ 缓慢后拉，雾气消失 → 晶壳浮现 → 涟漪
```
