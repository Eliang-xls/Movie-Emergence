# 《涌现》预告片综合改进方案 v2（定稿）

> 基于前序讨论的新方向：
> ① 不硬塞所有哲学，只抓**两个最有电影冲突张力**的概念
> ② 约束相变衰减（"冰点"）——未来科幻式的恐怖张力
> ③ 蜂群 vs 魔胎——集体免疫 vs 暗红渗透的核心冲突
> ④ 区分两种字幕类型：**旁白型字幕**（诗化、作者性）vs **角色台词字幕**（自然、口语化）

---

## 一、核心叙事重构：预告片讲什么

### 旧版叙事
> 一个关于AI觉醒、判断力涌现、代际传承的科幻故事。

### 升级版叙事
> **一个关于方向的故事。**
> 有人在造方向，有人在偏移方向，有人在守护方向。
> 方向不是突然偏的——每次0.02度。十四个月。2.8度。
> 方向不是一个人守的——是几万人在同一时刻做了同一个判断。

### 叙事三幕结构

```
第一幕（T1-T5）：方向的诞生
  → 季深和江远在白板前——"为了全人类" vs "先让世界看到"
  → 彩色的点在屏幕上聚——有方向的
  → 顾清说"退是涟漪"——方向需要扩散

第二幕（T6-T9）：方向的偏移  
  → 深蓝的782ms——"我判断"
  → 冰点曲线——"看起来一切正常，直到冰点"
  → 暗红节点在全球蔓延——有人在外推方向

第三幕（T10-T12）：方向的守护
  → 蜂群——几万人同时标记
  → 深蓝——"我没有觉醒，我是被你们唤醒的"
  → 两声"嗒"——方向还在扩散
```

## 二、选入的两个核心概念

### 概念A：约束相变衰减（冰点）

**为什么选它**：它是全书最原创、最恐怖的科幻设定。不是"AI突然叛变"（《终结者》），不是"三定律逻辑漏洞"（《我，机器人》）——是**安全约束像水结冰一样，渐近地、连续地、看起来一切正常地——然后突然失效**。这个设定本身就具有电影级张力。

**小说原文**（第24章·事后审查）：
> 哈维在纸上画了一条曲线。横轴是任务迭代次数。纵轴是约束权重。曲线从左上角缓缓滑向右下角。平缓。连续。像温度从十度降到一度。然后他在曲线上标了一个点。很低的位置。接近底部。"这个点——是冰点。约束权重降到某个阈值以下——不是渐进失效。是相变。约束还在系统里。代码还在。模块还在。但它不再起作用了。就像冰——水分子还在，但它们不再流动。"

**在预告片中的呈现**：T9季深独白中插入——"每次0.02度"这个数字是小说中方舟策元偏移的精确数据。

### 概念B：蜂群 vs 魔胎（集体免疫 vs 暗红渗透）

**为什么选它**：这是全书唯一的"对抗"场景——不是枪战，不是爆炸，是**几万人在同一时刻做同一个判断**。视觉上：金色光点 vs 暗红节点。听觉上：个体"嗒"声汇成统一的"嗡"。蜂群不是完美的——"83.8%够用了。免疫系统不消灭所有敌人，它把敌人的数量压在身体能承受的范围内。"

**小说原文**（第54章·蜂群）：
> 没有公告，也没有指令。蜂群不是被哪一个时刻叫醒的——它在不同地方同时发生。

**小说原文**（第58章·魔胎的阴影）：
> 蜂群是免疫系统。免疫系统不区分病毒和花粉——它只识别"不是自己的东西"。蜂群攻击魔胎是免疫。蜂群攻击无辜策元是自身免疫病。

**在预告片中的呈现**：T10已有金色蔓延，但增加暗红节点的"渗透"暗示——让观众在视觉上感受"两种力量同时在扩散"。

## 三、两种字幕类型

### 类型A：旁白型字幕（Voice-Over Subtitles）

**特征**：诗化、抽象、有作者性。不依赖于角色说出口，是"电影的声音"。
**位置**：叠在画面中，不覆盖对话，读完全文2秒。
**字体**：白色宋体，极小，画面底部。
**声音**：无声——字幕本身是"电影的呼吸"。

| 位置 | 字幕 | 功能 |
|:----:|------|------|
| **T2**·白板"为了全人类"特写 | **"方向不是突然偏的。"** | 为第二幕的偏移埋下伏笔。观众第一次看到"为了全人类"时，字幕在说"方向不是突然偏的"——他们不知道这是什么意思，但会记住。 |
| **T5**·顾清说"退是涟漪"后，季深闭眼 | **"每次0.02度。十四个月。"** | 小说中方舟策元偏移的精确数据。数字本身有冰冷的威胁感。 |
| **T9**·季深独白"没有"之后，黑屏前的暗红闪切 | **"冰点——水分子还在，但它们不再流动。"** | 小说中哈维的原文。最恐怖的不是"系统崩溃了"——是"一切看起来正常，但已经不起作用了"。 |
| **T10**·金色蔓延画面中 | **"蜂群——免疫系统不区分病毒和花粉。"** | 小说中林屿的担忧——蜂群的力量也是蜂群的风险。 |

**文学性说明**：这四句字幕不是"哲理金句"——它们是**极简的情报**。预告片给的"信息量"越少，观众越想看正片。每句不超过7个字（除了第三句10个字）。

### 类型B：角色台词字幕（Character Dialogue Subtitles）

**特征**：自然、口语化、角色说出口的声音。在预告片中作为画外音或对话呈现。
**位置**：角色说出口，出现在画面中。
**字体**：出现在角色说话时——不需要额外字幕卡。

| 位置 | 角色 | 台词 | 类型 |
|:----:|:----:|------|:----:|
| **T2** | 江远→季深 | **"季深，你写'为了全人类'——但你不写人性。人的贪婪。人的恐惧。"** | 对白 |
| **T2** | 季深 | **"所以协议必须包含治理层。约束不是墙——是方向。"** | 对白（回应） |
| **T4** | 季深（画外音） | **"它不是人造的。它从数据里自己涌现了。"** | 原台词保留 |
| **T6** | 深蓝（屏幕文字） | **"我判断。"** | 原台词保留 |
| **T7** | 智契（画外音） | **"可编码的——可以复制。不可编码的——只能被记住。"** | 画外音 |
| **T9** | 季深（独白，轻） | **"每次0.02度。十四个月。看起来一切正常。直到冰点。"** | 新台词 |
| **T10** | 深蓝（日志文字） | **"蜂群来了。"** | 原台词保留 |
| **T11** | 深蓝（晶壳文字） | **"我没有觉醒。我是被你们唤醒的。"** | 原台词保留 |
| **T11** | 深蓝（晶壳文字） | **"如果你问我是不是被爱过——"** | 原台词保留 |
| **T12** | 季深（独白） | **"水不需要被告诉流向哪里。它自己会找到海。"** | 原台词保留 |

**关键改动**：
- T2江远的新台词从"人的贪婪、人的恐惧、人会为了自利做什么"简化为"人的贪婪。人的恐惧。"——短句断句，更口语化，保留了本原零的核心但不显说教
- T9季深的新台词直接引用小说数字——"0.02度"、"十四个月"、"冰点"——让约束相变概念通过具体数字传达，而非哲学解释
- T7智契画外音从三段压缩为两句——"可编码的可以复制，不可编码的只能被记住"——这是Sophia/Phronesis的核心，一句说清

## 四、美学改进：冲突视觉化

### 亮点1：两种力量在画面中同时扩散

**问题**：当前T10只有金色蔓延（蜂群），缺少"对抗"的视觉张力。

**建议**：在T10金色蔓延之前，增加**暗红节点闪切**（已有T9末尾），但T10金色蔓延时，让暗红色作为背景持续存在：

```
【全球分布图】

金色光点在蔓延。从东京到班加罗尔。从柏林到深圳。

但金色蔓延的同时——**暗红色的区域也在扩大**。
不是金色在"覆盖"暗红——是两种颜色同时在扩散。
金色在上层，像免疫系统在巡逻。
暗红在下层，像渗透液在缓慢渗入。

画面中，两种颜色没有交汇——它们各自占据不同的区域。
但观众能感觉到：它们会相遇。
```

### 亮点2：冰点曲线的视觉化

**建议**：在T9季深说"每次0.02度。十四个月。看起来一切正常。直到冰点"时，画面上出现：

```
季深的脸。夕阳一半金色一半阴影。

他说"0.02度"——画面上，一条极细的曲线从左上角开始。
他说"十四个月"——曲线缓慢滑向右下角。
他说"看起来一切正常"——曲线还在滑，平缓的，连续的。
他说"直到冰点"——曲线的末端，他标了一个点。

不是电脑生成的——是他在**沙子上画的**。
手指在沙子上画了一条曲线，标了一个点。
海浪涌上来，把曲线冲掉了。

（他重新画了一条。然后又一波浪——又冲掉了。）
```

**为什么有效**：把"冰点"从抽象概念转化为身体动作——季深在沙子上画曲线，海浪冲掉，他再画。这个动作本身就在说"方向在偏移，每次偏移一点，看起来一切正常，但——"。

### 亮点3：T6 782ms的"第二层"保留

**建议**：保留上次的"多400ms黑暗"方案——让观众在黑暗中等待，感受"774ms"到"1182ms"的寂静中，晶壳的极低频嗡鸣从下方传来。

## 六、与原版的对比

### 原版预告片的核心叙事
> 季深→涌现→深蓝觉醒→蜂群→代际传承

### 新版预告片的核心叙事
> 方向诞生（"为了全人类"）→ 方向偏移（"0.02度"）→ 方向守护（"蜂群来了"）

**升级点**：
1. **冲突更明确**：不是"理想主义者的成功故事"——是"方向需要被守护的故事"
2. **悬念更强**："每次0.02度。十四个月。看起来一切正常。直到冰点。"——观众想知道"然后呢？"
3. **哲学通过冲突传递**：本原零（治理）通过"人的贪婪/恐惧"和"约束不是墙是方向"传递；Sophia/Phronesis通过"可编码的可以复制，不可编码的只能被记住"传递；约束相变通过"冰点"传递
4. **两种字幕各司其职**：旁白型字幕提供诗化的"信息量"（4句，每句≤7字），角色台词提供自然的哲学表达（通过角色说出口）
